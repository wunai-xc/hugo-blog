## 引言

Go 虽然不是传统的面向对象语言（没有类、继承等），但通过**结构体**和**方法**机制，实现了面向对象编程的核心概念。

本章将深入讲解结构体的定义和初始化、方法的定义和调用、指针接收者和值接收者的区别，以及如何通过嵌入实现类似继承的功能。这些是写出优雅 Go 代码的基础。

**学完本章，你将能够：**
- 定义和初始化结构体
- 理解值接收者和指针接收者的区别
- 为结构体添加方法
- 使用嵌入实现结构体复用
- 编写符合 Go 风格的面向对象代码
- 理解 Go 中的多态概念

## 一、结构体基础

### 1.1 结构体定义

结构体是**多个字段的组合**，每个字段有名字和类型：

```go
package main

import "fmt"

// 定义 Person 结构体
type Person struct {
	Name string
	Age  int
	City string
}

func main() {
	// 创建结构体实例
	var p Person
	
	fmt.Println(p)  // { 0 }（零值：空字符串和 0）
	
	// 赋值
	p.Name = "Alice"
	p.Age = 30
	p.City = "Beijing"
	
	fmt.Println(p)                    // {Alice 30 Beijing}
	fmt.Printf("%+v\n", p)            // {Name:Alice Age:30 City:Beijing}
}
```

**关键点**：
- 结构体字段名**大写**表示导出（公开），小写表示私有（只能在包内访问）
- 未初始化的字段会赋予零值

### 1.2 结构体初始化

有多种方式初始化结构体：

```go
package main

import "fmt"

type Person struct {
	Name string
	Age  int
	City string
}

func main() {
	// 方式一：按字段顺序赋值（不推荐，容易出错）
	p1 := Person{"Alice", 30, "Beijing"}
	fmt.Println(p1)  // {Alice 30 Beijing}
	
	// 方式二：按字段名赋值（推荐，清晰）
	p2 := Person{
		Name: "Bob",
		Age:  25,
		City: "Shanghai",
	}
	fmt.Println(p2)  // {Bob 25 Shanghai}
	
	// 方式三：部分字段赋值（其他为零值）
	p3 := Person{
		Name: "Charlie",
		Age:  35,
	}
	fmt.Println(p3)  // {Charlie 35 }
	
	// 方式四：使用指针和 new
	p4 := new(Person)
	p4.Name = "David"
	p4.Age = 40
	fmt.Println(*p4)  // {David 40 }
}
```

> **最佳实践**：总是用**按字段名赋值**的方式，特别是当有多个字段时。

### 1.3 结构体的嵌套

结构体可以包含其他结构体：

```go
package main

import "fmt"

type Address struct {
	Street string
	City   string
	ZipCode string
}

type Person struct {
	Name    string
	Age     int
	Address Address  // 嵌套结构体
}

func main() {
	p := Person{
		Name: "Alice",
		Age:  30,
		Address: Address{
			Street:  "123 Main St",
			City:    "Beijing",
			ZipCode: "100000",
		},
	}
	
	fmt.Println(p.Name)                  // Alice
	fmt.Println(p.Address.City)          // Beijing
	fmt.Printf("%+v\n", p)               // 完整输出
}
```

### 1.4 匿名结构体

临时使用时可以定义匿名结构体：

```go
package main

import "fmt"

func main() {
	// 匿名结构体
	config := struct {
		Host string
		Port int
		Debug bool
	}{
		Host: "localhost",
		Port: 8080,
		Debug: true,
	}
	
	fmt.Printf("%+v\n", config)
	// {Host:localhost Port:8080 Debug:true}
}
```

## 二、方法

### 2.1 方法定义

方法是带有**接收者**（receiver）的函数。接收者出现在 `func` 和方法名之间：

```go
package main

import "fmt"
import "math"

type Circle struct {
	Radius float64
}

// 值接收者：接收 Circle 的副本
func (c Circle) Area() float64 {
	return math.Pi * c.Radius * c.Radius
}

// 值接收者：接收 Circle 的副本
func (c Circle) Perimeter() float64 {
	return 2 * math.Pi * c.Radius
}

func main() {
	circle := Circle{Radius: 5}
	
	fmt.Printf("半径: %.1f\n", circle.Radius)      // 半径: 5.0
	fmt.Printf("面积: %.2f\n", circle.Area())       // 面积: 78.50
	fmt.Printf("周长: %.2f\n", circle.Perimeter())  // 周长: 31.42
}
```

**关键点**：
- 方法是函数，只是多了一个接收者
- 接收者通常是**值接收者**（接收结构体的副本）

### 2.2 指针接收者

当需要修改结构体时，使用**指针接收者**：

```go
package main

import "fmt"

type BankAccount struct {
	Owner   string
	Balance float64
}

// 值接收者：无法修改原值
func (a BankAccount) Deposit_Wrong(amount float64) {
	a.Balance += amount
	fmt.Println("存入后余额:", a.Balance)
}

// 指针接收者：可以修改原值
func (a *BankAccount) Deposit(amount float64) {
	a.Balance += amount
	fmt.Println("存入后余额:", a.Balance)
}

// 指针接收者：取款
func (a *BankAccount) Withdraw(amount float64) error {
	if amount > a.Balance {
		return fmt.Errorf("余额不足")
	}
	a.Balance -= amount
	return nil
}

func main() {
	account := BankAccount{Owner: "Alice", Balance: 1000}
	
	fmt.Println("初始余额:", account.Balance)  // 初始余额: 1000
	
	// 使用错误的值接收者
	account.Deposit_Wrong(100)
	fmt.Println("Deposit_Wrong 后:", account.Balance)  // 1000（未改变）
	
	// 使用正确的指针接收者
	account.Deposit(100)
	fmt.Println("Deposit 后:", account.Balance)        // 1100
	
	// Go 自动处理指针调用
	(&account).Deposit(50)
	fmt.Println("(&account).Deposit 后:", account.Balance)  // 1150
	
	// 取款
	err := account.Withdraw(200)
	if err != nil {
		fmt.Println("错误:", err)
	}
	fmt.Println("Withdraw 后:", account.Balance)  // 950
}
```

**重要**：Go 允许对值调用指针接收者的方法（会自动取址），反之亦然。但为了清晰，应该：
- 如果方法需要**修改接收者**，使用**指针接收者**
- 如果方法只需要**读取接收者**，使用**值接收者**

### 2.3 方法值和方法表达式

可以将方法赋给变量使用：

```go
package main

import "fmt"

type Person struct {
	Name string
}

func (p Person) Greet() string {
	return fmt.Sprintf("Hello, %s!", p.Name)
}

func main() {
	p := Person{Name: "Alice"}
	
	// 方法值：绑定了接收者的方法
	greetMethod := p.Greet
	fmt.Println(greetMethod())  // Hello, Alice!
	
	// 方法表达式：未绑定接收者的方法
	greetFunc := Person.Greet
	fmt.Println(greetFunc(p))   // Hello, Alice!
	
	// 高阶函数应用
	people := []Person{
		{Name: "Alice"},
		{Name: "Bob"},
		{Name: "Charlie"},
	}
	
	for _, person := range people {
		fmt.Println(greetFunc(person))
	}
}
```

## 三、嵌入式结构体

Go 没有类继承，但支持**嵌入**（embedding）来实现代码复用和类似继承的功能。

### 3.1 匿名字段嵌入

```go
package main

import "fmt"

type Animal struct {
	Name string
	Age  int
}

func (a Animal) Speak() string {
	return fmt.Sprintf("%s makes a sound", a.Name)
}

// Dog 嵌入 Animal，继承其字段和方法
type Dog struct {
	Animal  // 匿名嵌入，相当于"继承"
	Breed string
}

func main() {
	dog := Dog{
		Animal: Animal{Name: "Buddy", Age: 5},
		Breed:  "Golden Retriever",
	}
	
	// 直接访问嵌入的字段
	fmt.Println(dog.Name)         // Buddy（不需要 dog.Animal.Name）
	fmt.Println(dog.Age)          // 5
	fmt.Println(dog.Breed)        // Golden Retriever
	
	// 调用嵌入的方法
	fmt.Println(dog.Speak())      // Buddy makes a sound
}
```

**嵌入的优点**：
- 自动获得被嵌入结构体的所有字段和方法
- 字段提升（field promotion）：可以直接访问 `dog.Name` 而不是 `dog.Animal.Name`
- 方法提升：可以直接调用 `dog.Speak()` 而不是 `dog.Animal.Speak()`

### 3.2 方法覆盖

嵌入后可以覆盖被嵌入类型的方法：

```go
package main

import "fmt"

type Animal struct {
	Name string
}

func (a Animal) Speak() string {
	return fmt.Sprintf("%s makes a generic sound", a.Name)
}

type Dog struct {
	Animal
	Breed string
}

// Dog 覆盖了 Animal 的 Speak 方法
func (d Dog) Speak() string {
	return fmt.Sprintf("%s barks: Woof! Woof!", d.Name)
}

func main() {
	dog := Dog{
		Animal: Animal{Name: "Buddy"},
		Breed:  "Golden Retriever",
	}
	
	fmt.Println(dog.Speak())                  // Buddy barks: Woof! Woof!
	fmt.Println(dog.Animal.Speak())           // Buddy makes a generic sound（显式调用原方法）
}
```

### 3.3 多重嵌入

一个结构体可以嵌入多个其他结构体：

```go
package main

import "fmt"

type Walker interface {
	Walk() string
}

type Swimmer interface {
	Swim() string
}

type Dog struct {
	Name string
}

func (d Dog) Walk() string {
	return fmt.Sprintf("%s walks on land", d.Name)
}

func (d Dog) Swim() string {
	return fmt.Sprintf("%s swims in water", d.Name)
}

type Duck struct {
	Name string
}

func (d Duck) Walk() string {
	return fmt.Sprintf("%s waddles on land", d.Name)
}

func (d Duck) Swim() string {
	return fmt.Sprintf("%s swims in water", d.Name)
}

func main() {
	dog := Dog{Name: "Buddy"}
	duck := Duck{Name: "Donald"}
	
	animals := []interface {
		Walk() string
		Swim() string
	}{dog, duck}
	
	for _, animal := range animals {
		fmt.Println(animal.Walk())
		fmt.Println(animal.Swim())
	}
}
```

## 四、工厂函数和构造器模式

虽然 Go 没有构造器，但常用**工厂函数**（通常以 `New` 开头）来创建和初始化结构体：

```go
package main

import "fmt"

type User struct {
	ID       int
	Name     string
	Email    string
	Age      int
	IsActive bool
}

// 工厂函数：创建 User 并进行验证
func NewUser(name, email string, age int) (*User, error) {
	if name == "" {
		return nil, fmt.Errorf("用户名不能为空")
	}
	if email == "" {
		return nil, fmt.Errorf("邮箱不能为空")
	}
	if age < 0 || age > 150 {
		return nil, fmt.Errorf("年龄超出合理范围")
	}
	
	return &User{
		ID:       1,  // 实际应用中应该从数据库获取
		Name:     name,
		Email:    email,
		Age:      age,
		IsActive: true,
	}, nil
}

func main() {
	// 使用工厂函数创建 User
	user, err := NewUser("Alice", "alice@example.com", 30)
	if err != nil {
		fmt.Println("错误:", err)
	} else {
		fmt.Printf("%+v\n", user)
	}
	
	// 验证失败
	user, err = NewUser("", "bob@example.com", 25)
	if err != nil {
		fmt.Println("错误:", err)  // 错误: 用户名不能为空
	}
}
```

## 五、String 方法

实现 `String()` 方法让结构体能被自动格式化：

```go
package main

import "fmt"

type Person struct {
	Name string
	Age  int
	City string
}

// 实现 fmt.Stringer 接口
func (p Person) String() string {
	return fmt.Sprintf("Person{Name: %s, Age: %d, City: %s}", p.Name, p.Age, p.City)
}

func main() {
	p := Person{Name: "Alice", Age: 30, City: "Beijing"}
	
	fmt.Println(p)       // Person{Name: Alice, Age: 30, City: Beijing}
	fmt.Printf("%v\n", p) // Person{Name: Alice, Age: 30, City: Beijing}
	fmt.Printf("%s\n", p) // Person{Name: Alice, Age: 30, City: Beijing}
}
```

## 六、实践示例

### 6.1 实现一个简单的学生管理系统

```go
package main

import (
	"fmt"
	"math"
)

type Student struct {
	ID    int
	Name  string
	Scores []float64
}

// 计算平均分
func (s Student) AverageScore() float64 {
	if len(s.Scores) == 0 {
		return 0
	}
	sum := 0.0
	for _, score := range s.Scores {
		sum += score
	}
	return sum / float64(len(s.Scores))
}

// 获取最高分
func (s Student) MaxScore() float64 {
	if len(s.Scores) == 0 {
		return 0
	}
	max := s.Scores[0]
	for _, score := range s.Scores {
		if score > max {
			max = score
		}
	}
	return max
}

// 获取最低分
func (s Student) MinScore() float64 {
	if len(s.Scores) == 0 {
		return 0
	}
	min := s.Scores[0]
	for _, score := range s.Scores {
		if score < min {
			min = score
		}
	}
	return min
}

// 获取标准差
func (s Student) StdDeviation() float64 {
	if len(s.Scores) == 0 {
		return 0
	}
	avg := s.AverageScore()
	sum := 0.0
	for _, score := range s.Scores {
		sum += (score - avg) * (score - avg)
	}
	return math.Sqrt(sum / float64(len(s.Scores)))
}

// 自定义输出
func (s Student) String() string {
	return fmt.Sprintf("Student{ID: %d, Name: %s, Average: %.2f, Max: %.2f, Min: %.2f}",
		s.ID, s.Name, s.AverageScore(), s.MaxScore(), s.MinScore())
}

func main() {
	student := Student{
		ID:    1,
		Name:  "Alice",
		Scores: []float64{85, 92, 78, 88, 95},
	}
	
	fmt.Println(student)
	fmt.Printf("标准差: %.2f\n", student.StdDeviation())
	
	// 输出：
	// Student{ID: 1, Name: Alice, Average: 87.60, Max: 95.00, Min: 78.00}
	// 标准差: 5.83
}
```

### 6.2 银行账户系统

```go
package main

import (
	"fmt"
	"time"
)

type Transaction struct {
	Type      string    // "deposit" 或 "withdrawal"
	Amount    float64
	Timestamp time.Time
}

type Account struct {
	ID           string
	Owner        string
	Balance      float64
	Transactions []Transaction
}

// 存款
func (a *Account) Deposit(amount float64) error {
	if amount <= 0 {
		return fmt.Errorf("存款金额必须大于 0")
	}
	a.Balance += amount
	a.Transactions = append(a.Transactions, Transaction{
		Type:      "deposit",
		Amount:    amount,
		Timestamp: time.Now(),
	})
	return nil
}

// 取款
func (a *Account) Withdraw(amount float64) error {
	if amount <= 0 {
		return fmt.Errorf("取款金额必须大于 0")
	}
	if amount > a.Balance {
		return fmt.Errorf("余额不足，当前余额: %.2f", a.Balance)
	}
	a.Balance -= amount
	a.Transactions = append(a.Transactions, Transaction{
		Type:      "withdrawal",
		Amount:    amount,
		Timestamp: time.Now(),
	})
	return nil
}

// 获取交易历史
func (a Account) GetStatement() string {
	statement := fmt.Sprintf("账户: %s (所有者: %s)\n当前余额: %.2f\n交易记录:\n", a.ID, a.Owner, a.Balance)
	for _, t := range a.Transactions {
		statement += fmt.Sprintf("  %s: %s %.2f 元 (时间: %s)\n",
			t.Timestamp.Format("2006-01-02 15:04:05"),
			t.Type,
			t.Amount,
			"")
	}
	return statement
}

func main() {
	account := Account{
		ID:    "ACC001",
		Owner: "Alice",
		Balance: 1000,
	}
	
	account.Deposit(500)
	account.Withdraw(200)
	account.Deposit(300)
	
	fmt.Println(account.GetStatement())
}
```

## 七、常见坑点

| 坑 | 表现 | 解决 |
|:--:|------|------|
| **忘记指针接收者修改无效** | 结构体值未改变 | 需要修改时用 `(s *Struct)` 指针接收者 |
| **嵌入字段名冲突** | 编译器报错或行为异常 | 显式指定 `struct.Field` 或避免冲突名 |
| **nil 指针调用方法** | panic | 始终检查指针是否为 nil |
| **误将值接收者作为指针调用** | 行为异常 | Go 会自动转换，但要理解差异 |
| **工厂函数返回指针还是值** | 设计不一致 | 统一规范（通常返回指针便于修改） |
| **大型结构体用值接收者** | 性能差（复制开销大） | 大结构体使用指针接收者 |
