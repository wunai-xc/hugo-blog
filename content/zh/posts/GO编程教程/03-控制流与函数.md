## 引言

**控制流**是程序的"骨架"——它决定了代码按什么顺序执行，以及在什么条件下跳过或重复某些步骤。**函数**则是代码复用的基石，让我们可以将逻辑封装成可复用的模块。

Go 的控制流和函数设计简洁而强大。本章将详细讲解 if/else、switch、for 循环等控制结构，以及 Go 独特的多返回值、可变参数等函数特性。

**学完本章，你将能够：**
- 使用 if/else、switch 进行条件判断
- 掌握 for 循环的所有用法（计数循环、条件循环、遍历）
- 编写高效的 switch 语句
- 定义函数并使用多返回值
- 理解可变参数和匿名函数
- 合理使用 defer 延迟执行

## 一、条件语句

### 1.1 if/else 基础

```go
package main

import "fmt"

func main() {
	age := 20
	
	if age < 18 {
		fmt.Println("未成年")
	} else if age >= 18 && age < 65 {
		fmt.Println("成年人")
	} else {
		fmt.Println("退休年龄")
	}
}
```

**关键点**：
- Go 的 `if` 条件不需要括号（不同于 C/Java）
- 开括号 `{` 必须在同一行（Go 的风格约定）
- 支持 `else if` 和 `else` 分支

### 1.2 if 的短语句形式

Go 允许在 if 条件前执行一个短语句，这在判断前需要初始化变量时很有用：

```go
package main

import (
	"fmt"
	"math/rand"
)

func main() {
	// 语法：if <短语句>; <条件> { ... }
	if x := rand.Intn(10); x > 5 {
		fmt.Println(x, "大于 5")
	} else {
		fmt.Println(x, "小于等于 5")
	}
	
	// fmt.Println(x)  // ❌ 错误：x 的作用域仅限于 if 块内
}
```

这个形式在处理错误时特别有用：

```go
package main

import (
	"fmt"
	"strconv"
)

func main() {
	s := "123"
	
	// 转换字符串并立即判断是否出错
	if num, err := strconv.Atoi(s); err != nil {
		fmt.Println("转换失败:", err)
	} else {
		fmt.Println("转换成功:", num)
	}
}
```

### 1.3 switch 语句

`switch` 用于多分支判断，比多个 if/else if 更清晰：

```go
package main

import "fmt"

func main() {
	day := 3
	
	switch day {
	case 1:
		fmt.Println("星期一")
	case 2:
		fmt.Println("星期二")
	case 3:
		fmt.Println("星期三")
	case 4:
		fmt.Println("星期四")
	case 5:
		fmt.Println("星期五")
	case 6:
		fmt.Println("星期六")
	case 7:
		fmt.Println("星期日")
	default:
		fmt.Println("无效的日期")
	}
	// 输出：星期三
}
```

**关键点**：
- 每个 `case` 后的值必须是**常量或表达式结果**
- 一个 `case` 匹配后会**自动跳出**（不同于 C/Java 的 fall-through 行为）
- `default` 分支是可选的

### 1.4 switch 的 fallthrough

如果想让一个 case 执行后继续执行下一个 case，使用 `fallthrough`：

```go
package main

import "fmt"

func main() {
	grade := 'A'
	
	switch grade {
	case 'A':
		fmt.Println("优秀")
		fallthrough  // 继续执行下一个 case
	case 'B':
		fmt.Println("良好")
	case 'C':
		fmt.Println("及格")
	default:
		fmt.Println("不及格")
	}
	// 输出：
	// 优秀
	// 良好
}
```

### 1.5 switch 表达式求值

switch 后面不一定要有条件，可以写成 `switch` 后跟多个条件分支：

```go
package main

import "fmt"

func main() {
	age := 25
	
	switch {
	case age < 13:
		fmt.Println("儿童")
	case age < 18:
		fmt.Println("青少年")
	case age < 60:
		fmt.Println("成年人")
	default:
		fmt.Println("老年人")
	}
	// 输出：成年人
}
```

这种写法等价于 `if/else if/else`，但在多条件判断时更结构清晰。

### 1.6 switch 多值匹配

一个 case 可以有多个值：

```go
package main

import "fmt"

func main() {
	fruit := "apple"
	
	switch fruit {
	case "apple", "pear", "banana":  // 多个值用逗号分隔
		fmt.Println("这是水果")
	case "carrot", "potato":
		fmt.Println("这是蔬菜")
	default:
		fmt.Println("分类未知")
	}
	// 输出：这是水果
}
```

## 二、循环语句

Go 只有一种循环结构：**for**。但它足以应对所有循环场景。

### 2.1 基础 for 循环

最常见的计数循环：

```go
package main

import "fmt"

func main() {
	for i := 0; i < 5; i++ {
		fmt.Println(i)
	}
	// 输出：0 1 2 3 4
}
```

**语法**：`for <初始化>; <条件>; <增量> { ... }`

类似于 C/Java，但不需要括号。

### 2.2 条件循环（while）

省略初始化和增量，只保留条件：

```go
package main

import "fmt"

func main() {
	sum := 0
	i := 0
	
	for i < 10 {  // 相当于 while
		sum += i
		i++
	}
	
	fmt.Println("sum:", sum)  // 输出：sum: 45
}
```

### 2.3 无限循环

省略所有条件，形成无限循环（通常需要 break 跳出）：

```go
package main

import "fmt"

func main() {
	for {
		fmt.Println("无限循环")
		break  // 跳出循环
	}
}
```

### 2.4 range 遍历（最常用）

`range` 用于遍历切片、数组、map 和字符串：

**遍历数组**：

```go
package main

import "fmt"

func main() {
	fruits := [3]string{"apple", "banana", "cherry"}
	
	// 获取索引和值
	for i, fruit := range fruits {
		fmt.Printf("%d: %s\n", i, fruit)
	}
	// 输出：
	// 0: apple
	// 1: banana
	// 2: cherry
	
	// 只获取值（忽略索引）
	for _, fruit := range fruits {
		fmt.Println(fruit)
	}
	
	// 只获取索引（忽略值）
	for i := range fruits {
		fmt.Println(i)
	}
}
```

**遍历字符串**：

```go
package main

import "fmt"

func main() {
	s := "Hello"
	
	for i, char := range s {
		fmt.Printf("%d: %c (ASCII: %d)\n", i, char, char)
	}
	// 输出：
	// 0: H (ASCII: 72)
	// 1: e (ASCII: 101)
	// 2: l (ASCII: 108)
	// 3: l (ASCII: 108)
	// 4: o (ASCII: 111)
}
```

**遍历 map**：

```go
package main

import "fmt"

func main() {
	scores := map[string]int{
		"Alice": 90,
		"Bob":   85,
		"Charlie": 92,
	}
	
	for name, score := range scores {
		fmt.Printf("%s: %d\n", name, score)
	}
	// 输出（顺序不固定）：
	// Alice: 90
	// Bob: 85
	// Charlie: 92
}
```

### 2.5 break 和 continue

**break** 跳出循环，**continue** 跳过当前迭代：

```go
package main

import "fmt"

func main() {
	// break 示例
	for i := 0; i < 10; i++ {
		if i == 5 {
			break  // 当 i == 5 时跳出循环
		}
		fmt.Println(i)
	}
	// 输出：0 1 2 3 4
	
	fmt.Println("---")
	
	// continue 示例
	for i := 0; i < 5; i++ {
		if i == 2 {
			continue  // 跳过 i == 2 的迭代
		}
		fmt.Println(i)
	}
	// 输出：0 1 3 4
}
```

### 2.6 标签和 goto

Go 支持 `goto` 和标签。虽然通常不推荐，但在某些场景（如错误处理）下有用：

```go
package main

import "fmt"

func main() {
	for i := 0; i < 3; i++ {
		for j := 0; j < 3; j++ {
			if i == 1 && j == 1 {
				goto exit  // 跳到 exit 标签
			}
			fmt.Printf("(%d, %d) ", i, j)
		}
	}
	
exit:
	fmt.Println("\n程序终止")
}
// 输出：(0, 0) (0, 1) (0, 2) (1, 0) 
// 程序终止
```

> **⚠️ 建议**：避免滥用 goto，会让代码难以理解。只在必要时（如错误处理）使用。

## 三、函数定义

### 3.1 基础函数

```go
package main

import "fmt"

// 函数定义语法：func <函数名>(<参数列表>) <返回值类型> { ... }
func greet(name string) string {
	return "Hello, " + name
}

func main() {
	result := greet("Alice")
	fmt.Println(result)  // Hello, Alice
}
```

### 3.2 多个参数

```go
package main

import "fmt"

func add(a int, b int) int {
	return a + b
}

// 简化写法：相同类型的参数可以只在最后指定类型
func multiply(a, b int) int {
	return a * b
}

func main() {
	fmt.Println(add(3, 4))        // 7
	fmt.Println(multiply(3, 4))   // 12
}
```

### 3.3 多返回值（Go 特色）

Go 支持函数返回多个值，这在处理错误时特别有用：

```go
package main

import (
	"fmt"
	"strconv"
)

// 返回两个值：结果和错误
func divide(a, b float64) (float64, error) {
	if b == 0 {
		return 0, fmt.Errorf("分母不能为零")
	}
	return a / b, nil
}

func main() {
	result, err := divide(10, 2)
	if err != nil {
		fmt.Println("错误:", err)
	} else {
		fmt.Println("结果:", result)  // 结果: 5
	}
	
	result, err = divide(10, 0)
	if err != nil {
		fmt.Println("错误:", err)  // 错误: 分母不能为零
	}
}
```

### 3.4 命名返回值

Go 允许为返回值命名，这样可以直接在函数内使用这些变量：

```go
package main

import "fmt"

// 返回值被命名为 sum 和 product
func calculate(a, b int) (sum int, product int) {
	sum = a + b          // 直接赋值，无需显式 return
	product = a * b
	return               // 隐式返回 sum 和 product
}

func main() {
	s, p := calculate(3, 4)
	fmt.Println("Sum:", s, "Product:", p)  // Sum: 7 Product: 12
}
```

> **提示**：命名返回值让代码自文档化，但如果函数逻辑复杂，可能会降低可读性。

### 3.5 可变参数

使用 `...` 表示函数可以接受任意数量的参数：

```go
package main

import "fmt"

// 可接受 0 个或多个 int 参数
func sum(nums ...int) int {
	total := 0
	for _, num := range nums {
		total += num
	}
	return total
}

func main() {
	fmt.Println(sum())              // 0
	fmt.Println(sum(1))             // 1
	fmt.Println(sum(1, 2, 3))       // 6
	fmt.Println(sum(1, 2, 3, 4, 5)) // 15
	
	// 展开切片
	nums := []int{10, 20, 30}
	fmt.Println(sum(nums...))       // 60
}
```

**混合固定参数和可变参数**：

```go
package main

import "fmt"

func printStrings(prefix string, strs ...string) {
	fmt.Println("Prefix:", prefix)
	for i, s := range strs {
		fmt.Printf("  [%d]: %s\n", i, s)
	}
}

func main() {
	printStrings("Items", "apple", "banana", "cherry")
	// 输出：
	// Prefix: Items
	//   [0]: apple
	//   [1]: banana
	//   [2]: cherry
}
```

### 3.6 匿名函数和闭包

Go 支持匿名函数（也叫闭包），可以捕获外部作用域的变量：

```go
package main

import "fmt"

func main() {
	// 匿名函数：定义并立即调用
	func(name string) {
		fmt.Println("Hello, " + name)
	}("Alice")  // 输出：Hello, Alice
	
	// 匿名函数赋给变量
	greet := func(name string) string {
		return "Hi, " + name
	}
	fmt.Println(greet("Bob"))  // Hi, Bob
}
```

**闭包示例**（捕获外部变量）：

```go
package main

import "fmt"

func makeCounter() func() int {
	count := 0
	
	return func() int {
		count++
		return count
	}
}

func main() {
	counter := makeCounter()
	
	fmt.Println(counter())  // 1
	fmt.Println(counter())  // 2
	fmt.Println(counter())  // 3
	
	// 每个闭包有独立的 count
	counter2 := makeCounter()
	fmt.Println(counter2())  // 1
}
```

### 3.7 defer 延迟执行

`defer` 语句延迟函数的执行，直到包含函数返回。常用于资源清理：

```go
package main

import "fmt"

func main() {
	fmt.Println("Start")
	
	defer fmt.Println("Deferred 1")
	defer fmt.Println("Deferred 2")
	defer fmt.Println("Deferred 3")
	
	fmt.Println("End")
}
// 输出：
// Start
// End
// Deferred 3     （后进先出）
// Deferred 2
// Deferred 1
```

**多个 defer 的执行顺序**：后进先出（LIFO，栈的特性）。

**实际应用：文件处理**：

```go
package main

import (
	"fmt"
	"os"
)

func readFile(filename string) {
	file, err := os.Open(filename)
	if err != nil {
		fmt.Println("打开文件失败:", err)
		return
	}
	
	// 使用 defer 确保文件关闭
	defer file.Close()
	
	// 读取文件内容
	fmt.Println("文件已打开，处理中...")
	// ... 具体的文件处理逻辑
	
	fmt.Println("处理完成，文件即将关闭")
}

func main() {
	readFile("example.txt")
}
```

即使函数中途返回或发生 panic，`defer` 后的清理代码仍会执行。

### 3.8 函数作为参数

Go 支持将函数作为参数传递：

```go
package main

import "fmt"

// 高阶函数：接受一个函数作为参数
func apply(fn func(int, int) int, a int, b int) int {
	return fn(a, b)
}

func add(a, b int) int {
	return a + b
}

func multiply(a, b int) int {
	return a * b
}

func main() {
	fmt.Println(apply(add, 3, 4))      // 7
	fmt.Println(apply(multiply, 3, 4)) // 12
	
	// 也可以直接传递匿名函数
	fmt.Println(apply(func(a, b int) int {
		return a - b
	}, 10, 3))  // 7
}
```

## 四、综合示例

编写一个程序，计算多个数字的统计信息（最大值、最小值、平均值）：

```go
package main

import (
	"fmt"
	"math"
)

// 计算统计信息
func stats(nums ...float64) (min float64, max float64, avg float64) {
	if len(nums) == 0 {
		return math.NaN(), math.NaN(), math.NaN()
	}
	
	min = nums[0]
	max = nums[0]
	sum := 0.0
	
	for _, num := range nums {
		if num < min {
			min = num
		}
		if num > max {
			max = num
		}
		sum += num
	}
	
	avg = sum / float64(len(nums))
	return
}

func main() {
	numbers := []float64{10, 25, 15, 30, 5, 20}
	
	min, max, avg := stats(numbers...)
	
	fmt.Printf("数据集: %v\n", numbers)
	fmt.Printf("最小值: %.2f\n", min)
	fmt.Printf("最大值: %.2f\n", max)
	fmt.Printf("平均值: %.2f\n", avg)
}
// 输出：
// 数据集: [10 25 15 30 5 20]
// 最小值: 5.00
// 最大值: 30.00
// 平均值: 17.50
```

## 五、常见坑点

| 坑 | 表现 | 解决 |
|:--:|------|------|
| **if 开括号位置** | 语法错误 | 开括号 `{` 必须在同一行 |
| **switch 无 break** | 意外行为（Go 自动 break，不同于 C/Java） | 需要 fallthrough 才继续 |
| **for 中的 range 修改** | 修改不生效 | range 遍历得到的是**副本**，修改指针参数需要引用类型 |
| **defer 执行时机** | 理解不清 | defer 在函数**返回前**执行，顺序为 LIFO |
| **闭包变量共享** | 闭包修改外部变量互相影响 | 设计时要意识到这一点，或使用独立变量 |
| **return 后还有 defer** | 误认为 defer 不执行 | defer 在 return **之前**执行，可以修改返回值 |
