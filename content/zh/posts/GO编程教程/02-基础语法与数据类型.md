## 一、变量声明

### 1.1 完整声明（显式指定类型）

最基础的方式是使用 `var` 关键字：

```go
package main

import "fmt"

func main() {
	var age int
	var name string
	var height float64
	var isStudent bool

	fmt.Println(age)      // 0（int 的零值）
	fmt.Println(name)     // ""（空字符串）
	fmt.Println(height)   // 0（float64 的零值）
	fmt.Println(isStudent) // false（bool 的零值）
}
```

**关键点**：
- 未初始化的变量会赋予**零值**（zero value）
  - `int` 类型的零值是 `0`
  - `string` 的零值是 `""` 空字符串
  - `bool` 的零值是 `false`
  - 指针的零值是 `nil`

### 1.2 带初值声明

```go
var age int = 25
var name string = "Alice"
var height float64 = 1.75
var isStudent bool = true
```

### 1.3 类型推导（推荐）

Go 可以根据**赋值右侧的类型**自动推导变量类型，这样代码更简洁：

```go
var age = 25           // age 类型被推导为 int
var name = "Alice"     // name 类型被推导为 string
var height = 1.75      // height 类型被推导为 float64
var isStudent = true   // isStudent 类型被推导为 bool
```

### 1.4 短声明（最常用）

在**函数内部**，可以用 `:=` 进行短声明，既声明又赋值：

```go
func main() {
	age := 25
	name := "Alice"
	height := 1.75
	isStudent := true
	
	fmt.Printf("%v %v %v %v\n", age, name, height, isStudent)
	// 输出：25 Alice 1.75 true
}
```

> **⚠️ 注意**：`:=` 只能在**函数内部**使用。在全局作用域必须用 `var`。

### 1.5 多变量同时声明

```go
// 方式一：并列声明
var x, y, z int = 1, 2, 3

// 方式二：用括号分组（推荐用于全局变量）
var (
	age      int
	name     string
	height   float64
	isStudent bool
)

// 方式三：短声明同时赋值（函数内部）
a, b, c := 1, 2, 3
fmt.Println(a, b, c)  // 输出：1 2 3
```

### 1.6 变量作用域

Go 的作用域遵循**词法作用域**（lexical scoping）规则：

```go
package main

import "fmt"

var globalVar = "我是全局变量"  // 包级别（全局）

func main() {
	localVar := "我是局部变量"   // 函数级别
	fmt.Println(globalVar)     // ✅ 可以访问全局变量
	fmt.Println(localVar)      // ✅ 可以访问局部变量
	
	if true {
		blockVar := "块级变量"    // if 块内
		fmt.Println(blockVar)   // ✅ 可以访问
	}
	// fmt.Println(blockVar)    // ❌ 错误：blockVar 作用域已结束
}
```

## 二、常量

常量是**编译时确定、运行时不可修改**的值。使用 `const` 关键字声明：

### 2.1 基础常量声明

```go
const pi float64 = 3.14159
const maxConnections int = 100
const appName string = "MyApp"
const version = "1.0.0"  // 类型推导

fmt.Println(pi)
// pi = 3.14  // ❌ 错误：不能修改常量
```

### 2.2 多常量声明

```go
const (
	Sunday    = 0
	Monday    = 1
	Tuesday   = 2
	Wednesday = 3
	Thursday  = 4
	Friday    = 5
	Saturday  = 6
)
```

### 2.3 枚举模式（iota）

Go 中没有专门的枚举类型，但可以用 `iota` 实现自动递增：

```go
const (
	Jan = iota  // 0
	Feb         // 1
	Mar         // 2
	Apr         // 3
	May         // 4
	Jun         // 5
	Jul         // 6
	Aug         // 7
	Sep         // 8
	Oct         // 9
	Nov         // 10
	Dec         // 11
)

fmt.Println(Jan, Feb, Mar)  // 输出：0 1 2
```

**iota 高级用法**：

```go
const (
	KB = 1 << (10 * iota)  // 1 << 0 = 1
	MB                     // 1 << 10 = 1024
	GB                     // 1 << 20 = 1048576
	TB                     // 1 << 30 = 1073741824
)

fmt.Println(KB, MB, GB, TB)
// 输出：1 1024 1048576 1073741824
```

### 2.4 常量 vs 变量

| 特性 | 常量 | 变量 |
|------|------|------|
| 声明 | `const` | `var` 或 `:=` |
| 赋值 | 仅在声明时，之后不可修改 | 可多次修改 |
| 编译时确定 | ✅ 必须 | ✅ 运行时赋值 |
| 性能 | 更高（编译时计算） | 稍低（运行时存储） |

## 三、基本数据类型

### 3.1 整数类型

Go 提供有符号和无符号整数：

| 类型 | 范围 | 常见用途 |
|------|------|---------|
| `int8` | -128 ~ 127 | 小范围 |
| `int16` | -32768 ~ 32767 | 中等范围 |
| `int32` | -2^31 ~ 2^31-1 | 一般用途 |
| `int64` | -2^63 ~ 2^63-1 | 大数据 |
| `int` | 平台相关（32 或 64 位） | **推荐：最通用** |
| `uint8` | 0 ~ 255 | 字节 |
| `uint16` | 0 ~ 65535 | 端口号 |
| `uint32` | 0 ~ 2^32-1 | 无符号数 |
| `uint64` | 0 ~ 2^64-1 | 大无符号数 |
| `uint` | 平台相关 | **推荐：通用无符号** |

**实践示例**：

```go
package main

import "fmt"

func main() {
	var age int = 25
	var count uint = 100
	var smallNum int8 = 120
	
	fmt.Println(age, count, smallNum)
	
	// 溢出示例
	var num int8 = 127
	fmt.Println(num)      // 127
	// num++               // ❌ 如果溢出会变成 -128（二进制环绕）
}
```

> **最佳实践**：优先使用 `int` 和 `uint`，除非有明确的内存或范围限制。

### 3.2 浮点数类型

```go
var pi float32 = 3.14       // 单精度（32 位）
var e float64 = 2.71828     // 双精度（64 位，推荐）

fmt.Println(pi, e)
```

**精度问题示例**：

```go
func main() {
	var f float64 = 0.1
	var sum float64 = 0
	
	for i := 0; i < 10; i++ {
		sum += f
	}
	
	fmt.Println(sum)              // 输出：0.9999999999999999
	fmt.Println(sum == 1.0)       // false（浮点数精度误差）
}
```

> **⚠️ 坑**：浮点数存在精度问题，不应该用 `==` 比较。金融计算应使用 `big.Decimal` 等库。

### 3.3 字符串类型

```go
var greeting string = "Hello, Go!"
var empty string           // 零值是空字符串 ""

fmt.Println(greeting)      // Hello, Go!
fmt.Println(len(greeting)) // 11（字符串长度）
fmt.Println(empty == "")   // true
```

**字符串操作**：

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	s := "Hello, Go!"
	
	// 字符串长度
	fmt.Println(len(s))                    // 11
	
	// 字符串连接
	greeting := "Hello" + ", " + "Go!"
	fmt.Println(greeting)                  // Hello, Go!
	
	// 字符串包含
	fmt.Println(strings.Contains(s, "Go")) // true
	
	// 字符串替换
	fmt.Println(strings.Replace(s, "Go", "Golang", 1))  // Hello, Golang!
	
	// 字符串分割
	fmt.Println(strings.Split(s, ", "))   // [Hello Go!]
	
	// 字符串大小写转换
	fmt.Println(strings.ToUpper(s))       // HELLO, GO!
	fmt.Println(strings.ToLower(s))       // hello, go!
}
```

**原始字符串和转义**：

```go
// 普通字符串（支持转义）
s1 := "Hello\nWorld"
fmt.Println(s1)
// 输出：
// Hello
// World

// 原始字符串（不转义反斜杠）
s2 := `C:\Users\name\file.txt`
fmt.Println(s2)  // C:\Users\name\file.txt（保持原样）

// 多行字符串
s3 := `Line 1
Line 2
Line 3`
fmt.Println(s3)
```

### 3.4 布尔类型

```go
var isActive bool = true
var isDeleted bool = false

fmt.Println(isActive)   // true
fmt.Println(isDeleted)  // false

// 逻辑运算
fmt.Println(true && false)   // false
fmt.Println(true || false)   // true
fmt.Println(!true)           // false
```

### 3.5 字节和符文（byte 和 rune）

Go 在字符串处理上有两个特殊类型：

```go
// byte：无符号 8 位整数，代表 ASCII 字符
var b byte = 'A'
fmt.Println(b)      // 65（'A' 的 ASCII 值）

// rune：有符号 32 位整数，代表 Unicode 字符
var r rune = '中'
fmt.Println(r)      // 20013（Unicode 码点）

// 字符串转 byte 数组
s := "Hello"
byteArray := []byte(s)
fmt.Println(byteArray)  // [72 101 108 108 111]

// 字符串转 rune 数组（处理多字节字符）
s2 := "你好"
runeArray := []rune(s2)
fmt.Println(runeArray)  // [20320 22909]
fmt.Println(len(s2))    // 6（字节数）
fmt.Println(len(runeArray))  // 2（字符数）
```

> **关键**：`len()` 返回字符串的字节数，不是字符数。对于包含中文的字符串，需转为 rune 数组。

## 四、类型转换

Go 是**强类型语言**，不同类型之间不能直接操作，必须显式转换。

### 4.1 显式类型转换

```go
package main

import "fmt"

func main() {
	var a int32 = 100
	var b int64 = int64(a)   // int32 → int64
	fmt.Println(b)            // 100
	
	var x float64 = 3.14
	var y int = int(x)        // float64 → int（丢弃小数部分）
	fmt.Println(y)            // 3
	
	var c = 42
	var d string = fmt.Sprintf("%d", c)  // int → string
	fmt.Println(d)            // "42"
}
```

### 4.2 字符串与数字转换

**字符串转数字**：

```go
package main

import (
	"fmt"
	"strconv"
)

func main() {
	// 字符串 → 整数
	s := "123"
	num, err := strconv.Atoi(s)  // String to Integer
	if err != nil {
		fmt.Println("转换失败:", err)
	} else {
		fmt.Println(num)  // 123（int 类型）
	}
	
	// 字符串 → int64
	s2 := "456"
	num2, err := strconv.ParseInt(s2, 10, 64)  // 10 进制，64 位
	if err != nil {
		fmt.Println("转换失败:", err)
	} else {
		fmt.Println(num2)  // 456（int64 类型）
	}
	
	// 字符串 → float64
	s3 := "3.14"
	f, err := strconv.ParseFloat(s3, 64)  // 64 位精度
	if err != nil {
		fmt.Println("转换失败:", err)
	} else {
		fmt.Println(f)  // 3.14（float64 类型）
	}
}
```

**数字转字符串**：

```go
package main

import (
	"fmt"
	"strconv"
)

func main() {
	// 整数 → 字符串
	num := 42
	s := strconv.Itoa(num)  // Integer to ASCII
	fmt.Println(s)          // "42"
	
	// int64 → 字符串
	num2 := int64(789)
	s2 := strconv.FormatInt(num2, 10)  // 10 进制
	fmt.Println(s2)         // "789"
	
	// float64 → 字符串
	f := 3.14159
	s3 := strconv.FormatFloat(f, 'f', 2, 64)  // 保留 2 位小数
	fmt.Println(s3)         // "3.14"
}
```

## 五、指针基础

指针是**存储某个变量内存地址的变量**。理解指针对后续学习 Go 至关重要。

### 5.1 指针声明和取值

```go
package main

import "fmt"

func main() {
	x := 42
	var p *int = &x   // p 是 int 指针，存储 x 的地址
	
	fmt.Println(x)     // 42（x 的值）
	fmt.Println(&x)    // 0xc000010088（x 的地址，格式因系统而异）
	fmt.Println(p)     // 0xc000010088（指针 p 的内容，即 x 的地址）
	fmt.Println(*p)    // 42（解引用：访问指针指向的值）
}
```

**符号说明**：
- `&` 取址符：获取变量的内存地址
- `*` 解引用符：访问指针指向的值

### 5.2 通过指针修改值

```go
func main() {
	x := 10
	p := &x
	
	fmt.Println(x)   // 10
	
	*p = 20          // 通过指针修改 x 的值
	
	fmt.Println(x)   // 20（x 的值已改变）
	fmt.Println(*p)  // 20
}
```

### 5.3 指针的零值

```go
var p *int         // 指针的零值
fmt.Println(p)     // <nil>
// fmt.Println(*p) // ❌ panic：解引用 nil 指针导致崩溃
```

> **⚠️ 坑**：访问 nil 指针会导致程序崩溃，必须先检查。

### 5.4 函数中使用指针

指针最常见的用途是在**函数中修改参数**：

```go
// ❌ 错误：按值传递，无法修改原值
func increment(x int) {
	x++  // 只修改了形参的副本
}

// ✅ 正确：按指针传递，可以修改原值
func incrementByPointer(p *int) {
	*p++  // 修改了指针指向的原值
}

func main() {
	num := 10
	
	increment(num)
	fmt.Println(num)  // 10（未改变）
	
	incrementByPointer(&num)
	fmt.Println(num)  // 11（已改变）
}
```

## 六、综合示例

结合本章内容，编写一个程序计算学生成绩统计：

```go
package main

import (
	"fmt"
	"strconv"
	"strings"
)

func main() {
	// 常量定义
	const studentName string = "张三"
	const totalSubjects int = 3
	
	// 变量声明
	var scores [3]int = [3]int{85, 92, 78}
	var totalScore int = 0
	
	// 计算总分
	for i := 0; i < totalSubjects; i++ {
		totalScore += scores[i]
	}
	
	// 计算平均分
	averageScore := float64(totalScore) / float64(totalSubjects)
	
	// 输出结果
	fmt.Println("学生姓名:", studentName)
	fmt.Println("各科成绩:", strings.Trim(fmt.Sprint(scores[:]), "[]"))
	fmt.Println("总分:", totalScore)
	fmt.Printf("平均分: %.2f\n", averageScore)
	
	// 输出为 JSON 格式的字符串（示范类型转换）
	result := "{\"name\":\"" + studentName + "\",\"average\":" + strconv.FormatFloat(averageScore, 'f', 2, 64) + "}"
	fmt.Println("JSON:", result)
}
```

**输出**：
```
学生姓名: 张三
各科成绩: [85 92 78]
总分: 255
平均分: 85.00
JSON: {"name":"张三","average":85.00}
```

## 七、常见坑点总结

| 坑 | 表现 | 解决 |
|:--:|------|------|
| **`:=` 用于全局作用域** | 语法错误 | 全局用 `var`，函数内用 `:=` |
| **浮点数相等比较** | 浮点数精度误差导致 `==` 失效 | 用 `math.Abs()` 或允许误差范围比较 |
| **字符串 byte 长度混淆** | `len("你好")` 返回 6（字节），不是 2（字符） | 用 `len([]rune(s))` 获得字符数 |
| **nil 指针解引用** | 程序崩溃 | 始终检查指针是否为 nil |
| **类型隐式转换** | 编译器报错 | 显式强制转换 `int(x)` |
