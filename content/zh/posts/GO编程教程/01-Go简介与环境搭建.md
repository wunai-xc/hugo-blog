## 引言

Go 语言（又称 Golang）由 Google 在 2007 年推出，在 2009 年正式开源。它是一门编译型、并发型、有垃圾回收的编程语言，专为解决现代软件开发的痛点而生。

如果你曾为 C++ 的复杂性感到困扰，或对 Python 的性能不满意，Go 可能是你的答案。本章将帮你理解 Go 的核心特性，并完成环境搭建，为后续学习打好基础。

**学完本章，你将能够：**
- 理解 Go 语言的设计理念和应用场景
- 完成 Go 开发环境的安装和配置
- 编写并运行第一个 Go 程序
- 理解 Go 项目的基本目录结构

## 一、Go 语言概览

### 1.1 Go 的核心设计理念

Go 语言的设计目标是**简单、快速、安全、并发**。设计者 Rob Pike 等人希望创造一门语言，能够：

- **简洁**：语法规则少，代码易读易写。与 Java 或 C++ 不同，Go 用"做一件事只有一种方式"的哲学
- **高效编译**：编译速度快（秒级），编译结果是静态链接的单一二进制文件，无需依赖
- **内置并发**：goroutine 和 channel 让并发编程像写顺序代码一样简单
- **自动内存管理**：内置垃圾回收（GC），开发者无需手动管理内存
- **强类型 + 类型推导**：既保留类型安全，又能智能推导，减少冗余代码

### 1.2 Go 的应用场景

Go 广泛应用于：

| 领域 | 典型项目 | 原因 |
|------|--------|------|
| 云原生 & 容器 | Docker、Kubernetes | 并发好、部署简单、资源占用少 |
| 微服务 | gRPC、Istio | 高性能、低延迟、网络通信优化 |
| 命令行工具 | Hugo、Terraform | 快速编译、无依赖、易分发 |
| 后端服务 | Web API、游戏服务器 | 高并发处理能力 |
| 系统工具 | 监控、日志、存储 | 底层控制 + 开发效率平衡 |

### 1.3 Go vs 其他语言

```
语言       编译速度  运行速度  学习曲线  并发能力  应用场景
────────────────────────────────────────────────────────
Go         ⚡⚡⚡   ⚡⚡⚡   ⭐⭐⭐   ⚡⚡⚡  云原生、后端
Python     ⭐      ⭐      ⚡⚡⚡   ⭐⭐   数据、脚本
Java       ⚡⚡    ⚡⚡⚡   ⭐      ⚡⚡   企业应用
C++        ⚡⚡    ⚡⚡⚡   ⭐      ⭐⭐   系统、游戏
Rust       ⚡⚡    ⚡⚡⚡   ⭐      ⚡⚡⚡  系统编程
```

> **Go 的独特优势**：开发效率（接近 Python）+ 运行性能（接近 C++）+ 并发能力（业界最优）

## 二、环境搭建

### 2.1 安装 Go 编译器

#### **Windows**

1. 访问 [golang.org/dl](https://golang.org/dl)
2. 下载 `go1.21.x.windows-amd64.msi`（或最新版本）
3. 双击运行安装程序，按默认路径安装（通常是 `C:\Program Files\Go`）
4. 安装程序会自动添加到 `PATH` 环境变量

**验证安装：** 打开 PowerShell 或 CMD，运行：
```powershell
go version
```

应该看到类似输出：
```
go version go1.21.0 windows/amd64
```

#### **macOS**

**方式一：使用 Homebrew（推荐）**

```bash
brew install go
```

**方式二：直接下载**

1. 访问 [golang.org/dl](https://golang.org/dl)
2. 下载 `go1.21.x.darwin-amd64.pkg`（Intel Mac）或 `go1.21.x.darwin-arm64.pkg`（Apple Silicon）
3. 双击安装

**验证安装：**
```bash
go version
```

#### **Linux**

**方式一：包管理器（Debian/Ubuntu）**

```bash
sudo apt update
sudo apt install golang-go
```

**方式二：官方二进制**

```bash
wget https://go.dev/dl/go1.21.0.linux-amd64.tar.gz
sudo tar -C /usr/local -xzf go1.21.0.linux-amd64.tar.gz
export PATH=$PATH:/usr/local/go/bin
```

将最后一行添加到 `~/.bashrc` 或 `~/.zshrc`，使 PATH 永久生效。

**验证安装：**
```bash
go version
```

### 2.2 配置 GOPATH 和 GOROOT

现代 Go（1.11+）用**模块机制**（Go Modules），不一定需要配置 `GOPATH`，但了解它有帮助。

**GOROOT**：Go 安装目录（通常自动设置）
```bash
go env GOROOT
# 输出：C:\Program Files\Go（Windows）或 /usr/local/go（Mac/Linux）
```

**GOPATH**：Go 工作区目录（存放第三方包），现代项目不强制需要
```bash
go env GOPATH
# 输出：~/go（默认）
```

> 现代 Go 项目用 `go.mod` 管理依赖，无需手动配置 GOPATH。

### 2.3 配置代理（针对国内用户）

如果在国内，直接访问官方包仓库较慢，配置代理加速：

```bash
go env -w GO111MODULE=on
go env -w GOPROXY=https://goproxy.cn,direct
```

验证配置：
```bash
go env | grep GOPROXY
```

## 三、第一个 Go 程序

### 3.1 创建项目目录

```bash
# 创建项目文件夹
mkdir hello-world
cd hello-world

# 初始化 Go 模块（为项目创建 go.mod）
go mod init example.com/hello
```

此时会生成一个 `go.mod` 文件，内容大致如下：
```
module example.com/hello

go 1.21
```

### 3.2 编写代码

创建文件 `main.go`：

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, Go World!")
}
```

**代码解析：**

| 行 | 说明 |
|:--:|------|
| `package main` | 声明这是一个**可执行程序**（必须叫 main）。若是库文件则 package 名可自定义 |
| `import "fmt"` | 导入 `fmt` 包，用于格式化输出。`fmt` 是 Go 标准库的一部分 |
| `func main()` | Go 程序的**入口函数**，执行时从这里开始。类似其他语言的 `main()` |
| `fmt.Println(...)` | 调用 fmt 包的 Println 函数，打印字符串并自动换行 |

### 3.3 运行程序

#### **方式一：直接运行（推荐用于开发）**

```bash
go run main.go
```

输出：
```
Hello, Go World!
```

`go run` 会编译并立即执行程序，无需生成二进制文件，适合开发调试。

#### **方式二：编译后运行**

```bash
go build
```

生成可执行文件：
- Windows：`hello.exe`
- Mac/Linux：`hello`

运行可执行文件：
```bash
./hello          # Mac/Linux
hello.exe        # Windows
```

输出相同：
```
Hello, Go World!
```

> **对比**：`go run` 便于开发测试，`go build` 生成的二进制文件可单独分发（无需 Go 环境）

### 3.4 常见坑点

**坑 1：文件名或包名错误**
```go
// ❌ 错误：包名不是 main
package myapp

func main() { ... }
```

会报错：`runtime.main_main·f: function main not defined`

**解决**：可执行程序必须是 `package main`

---

**坑 2：导入包后没有使用**
```go
// ❌ 错误：导入 fmt 但没用
import "fmt"

func main() {
	println("hello")  // 直接用内置 println，没用 fmt
}
```

Go 编译器会报错：`imported and not used: "fmt"`

**解决**：要么删除导入，要么使用这个包。IDE（如 VS Code）装 Go 扩展后，保存会自动清理未用导入。

---

**坑 3：代码行末忘记必要符号**
```go
// ❌ 错误：大括号位置（Go 风格限制）
func main() 
{
	fmt.Println("hello")
}
```

Go 要求开括号 `{` 必须在同一行。会报错：`syntax error: unexpected semicolon or newline`

**解决**：
```go
// ✅ 正确
func main() {
	fmt.Println("hello")
}
```

## 四、项目结构速览

一个典型的 Go 项目长这样：

```
hello-world/
├── go.mod              ← 模块定义（项目元数据）
├── go.sum              ← 依赖版本锁定（自动生成）
├── main.go             ← 程序入口
├── utils.go            ← 辅助模块（同 package main）
├── internal/           ← 内部包（不对外暴露）
│   └── config/
│       └── config.go
└── README.md
```

**关键文件说明：**

| 文件 | 用途 |
|------|------|
| `go.mod` | **必须**。记录项目名、Go 版本、依赖包版本 |
| `go.sum` | 自动生成。记录依赖的哈希值，确保版本一致性 |
| `main.go` | 程序入口（对于可执行程序） |
| `internal/` | 目录，存放内部包。在 Go 1.4+ 中，internal 下的包无法被项目外导入 |

## 五、常用命令速查

| 命令 | 作用 |
|------|------|
| `go version` | 查看 Go 版本 |
| `go env` | 显示 Go 环境变量 |
| `go mod init <module>` | 初始化项目，创建 go.mod |
| `go run <file.go>` | 编译并运行代码（开发用） |
| `go build` | 编译程序，生成可执行文件 |
| `go install` | 编译并安装到 `$GOPATH/bin` |
| `go test` | 运行测试（后续章节讲） |
| `go fmt` | 代码格式化 |
| `go vet` | 代码静态分析，找潜在 bug |
| `go get -u <package>` | 下载和更新依赖包 |
