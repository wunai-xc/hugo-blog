## 引言

并发（concurrency）是 Go 最强大的特性之一。不同于传统的线程模型，Go 提供了**轻量级的 goroutine** 和优雅的 **channel** 机制，让开发者能轻松地编写高并发程序。

Go 的设计哲学是：**"不要通过共享内存来通信，而是通过通信来共享内存"** 。本章将详细讲解 goroutine、channel、select，以及同步原语（mutex、WaitGroup）的正确使用方式。

**学完本章，你将能够：**
- 创建和管理 goroutine
- 理解 channel 的各种用法
- 使用 select 多路复用
- 避免常见的并发陷阱（数据竞争、死锁）
- 使用互斥锁和 WaitGroup 进行同步
- 编写高效、安全的并发程序

## 一、Goroutine 基础

### 1.1 创建 Goroutine

Goroutine 是由 Go 运行时管理的轻量级线程。创建一个 goroutine 的成本远低于 OS 线程：

```go
package main

import (
	"fmt"
	"time"
)

func sayHello(name string) {
	for i := 1; i <= 3; i++ {
		fmt.Printf("Hello, %s (第 %d 次)\n", name, i)
		time.Sleep(100 * time.Millisecond)
	}
}

func main() {
	// 启动 goroutine
	go sayHello("Alice")
	go sayHello("Bob")
	
	// 主 goroutine 休眠，等待其他 goroutine 完成
	time.Sleep(500 * time.Millisecond)
	
	fmt.Println("主程序结束")
}
// 输出（交错）：
// Hello, Alice (第 1 次)
// Hello, Bob (第 1 次)
// Hello, Alice (第 2 次)
// Hello, Bob (第 2 次)
// Hello, Alice (第 3 次)
// Hello, Bob (第 3 次)
// 主程序结束
```

**关键点**：
- `go` 关键字启动新的 goroutine
- 主函数不会等待其他 goroutine，必须手动同步
- goroutine 是并发（不一定是并行），取决于系统和 Go 调度器

### 1.2 Goroutine 与函数

任何函数都可以用 `go` 启动为 goroutine。匿名函数也可以：

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	// 普通函数
	go func(name string) {
		fmt.Printf("匿名函数: %s\n", name)
	}("Alice")
	
	// 闭包捕获外部变量（需要注意竞态）
	for i := 1; i <= 3; i++ {
		// ❌ 错误示例：闭包捕获 i 的引用
		// go func() {
		//     fmt.Println(i)  // 可能输出 2, 3, 4（而不是 1, 2, 3）
		// }()
		
		// ✅ 正确示例：参数传递
		go func(num int) {
			fmt.Printf("goroutine %d\n", num)
		}(i)
	}
	
	time.Sleep(100 * time.Millisecond)
}
```

> **⚠️ 常见坑**：闭包捕获循环变量时，要通过参数传递而不是直接引用。

## 二、Channel 基础

### 2.1 创建和基本操作

Channel 是 goroutine 之间**通信的管道**：

```go
package main

import "fmt"

func main() {
	// 创建无缓冲 channel
	ch := make(chan string)
	
	// 发送数据的 goroutine
	go func() {
		fmt.Println("发送: Hello")
		ch <- "Hello"
		fmt.Println("发送完成")
	}()
	
	// 接收数据
	message := <-ch
	fmt.Printf("接收: %s\n", message)
}
// 输出：
// 发送: Hello
// 接收: Hello
// 发送完成
```

**关键点**：
- `<-` 操作符用于发送和接收
- 无缓冲 channel：发送者阻塞，直到有接收者；接收者阻塞，直到有发送者
- 这自动实现了 goroutine 之间的**同步**

### 2.2 有缓冲 Channel

创建指定容量的 channel，可以不立即阻塞：

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	// 创建容量为 2 的 channel
	ch := make(chan int, 2)
	
	// 可以发送两个值而不阻塞
	ch <- 1
	ch <- 2
	fmt.Println("已发送两个值")
	
	// 第三个会阻塞
	// ch <- 3  // 此时会阻塞，直到有人接收
	
	// 接收值
	fmt.Println(<-ch)  // 1
	fmt.Println(<-ch)  // 2
}
```

### 2.3 关闭 Channel

使用 `close()` 关闭 channel。接收关闭的 channel 会收到零值和 false：

```go
package main

import "fmt"

func main() {
	ch := make(chan int)
	
	go func() {
		for i := 1; i <= 3; i++ {
			ch <- i
		}
		close(ch)  // 关闭 channel
	}()
	
	// 遍历 channel 直到关闭
	for v := range ch {
		fmt.Println(v)
	}
	// 输出：1 2 3
	
	// 尝试接收已关闭的 channel
	val, ok := <-ch
	fmt.Printf("val: %v, ok: %v\n", val, ok)
	// val: 0, ok: false
}
```

**⚠️ 重要**：只有**发送者**应该关闭 channel，接收者不应该。发送到已关闭的 channel 会 panic。

## 三、高级 Channel 用法

### 3.1 Channel 方向

Channel 可以限制为只发送或只接收：

```go
package main

import "fmt"

// 只发送 channel
func sendValues(ch chan<- int) {
	for i := 1; i <= 3; i++ {
		ch <- i
	}
	close(ch)
}

// 只接收 channel
func receiveValues(ch <-chan int) {
	for v := range ch {
		fmt.Println(v)
	}
}

func main() {
	ch := make(chan int)
	
	go sendValues(ch)
	receiveValues(ch)
}
```

### 3.2 Select 多路复用

`select` 用于处理多个 channel：

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	ch1 := make(chan string)
	ch2 := make(chan string)
	
	// 两个 goroutine 在不同时间发送
	go func() {
		time.Sleep(100 * time.Millisecond)
		ch1 <- "ch1: 消息"
	}()
	
	go func() {
		time.Sleep(200 * time.Millisecond)
		ch2 <- "ch2: 消息"
	}()
	
	// select 等待第一个就绪的 channel
	for i := 0; i < 2; i++ {
		select {
		case msg := <-ch1:
			fmt.Println(msg)
		case msg := <-ch2:
			fmt.Println(msg)
		case <-time.After(300 * time.Millisecond):
			fmt.Println("超时")
		}
	}
}
```

### 3.3 Select 默认分支

`default` 分支在所有 channel 都阻塞时执行，实现非阻塞操作：

```go
package main

import "fmt"

func main() {
	ch := make(chan int)
	
	// 非阻塞发送
	select {
	case ch <- 1:
		fmt.Println("发送成功")
	default:
		fmt.Println("channel 满，不阻塞")
	}
	
	// 非阻塞接收
	select {
	case v := <-ch:
		fmt.Println("接收到:", v)
	default:
		fmt.Println("channel 空，不阻塞")
	}
}
```

### 3.4 Timeout 模式

使用 `time.After` 实现 timeout：

```go
package main

import (
	"fmt"
	"time"
)

func fetchData(ch chan string) {
	time.Sleep(2 * time.Second)  // 模拟耗时操作
	ch <- "数据已获取"
}

func main() {
	ch := make(chan string)
	
	go fetchData(ch)
	
	select {
	case data := <-ch:
		fmt.Println(data)
	case <-time.After(1 * time.Second):
		fmt.Println("超时：操作耗时过长")
	}
}
// 输出：超时：操作耗时过长
```

## 四、同步原语

### 4.1 Mutex（互斥锁）

保护共享资源不被多个 goroutine 同时访问：

```go
package main

import (
	"fmt"
	"sync"
)

type Counter struct {
	mu    sync.Mutex
	count int
}

func (c *Counter) Increment() {
	c.mu.Lock()
	defer c.mu.Unlock()
	c.count++
}

func (c *Counter) Value() int {
	c.mu.Lock()
	defer c.mu.Unlock()
	return c.count
}

func main() {
	counter := &Counter{}
	
	// 启动多个 goroutine 并发增加计数
	for i := 0; i < 5; i++ {
		go func() {
			for j := 0; j < 100; j++ {
				counter.Increment()
			}
		}()
	}
	
	// 等待一段时间（实际应用中应该用 WaitGroup）
	// 实际应该让这个程序继续到底，goroutine 不会自动等待
}
```

### 4.2 RWMutex（读写锁）

允许多个读操作并发，但写操作是独占的：

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

type Cache struct {
	mu    sync.RWMutex
	data  map[string]interface{}
}

func (c *Cache) Get(key string) (interface{}, bool) {
	c.mu.RLock()
	defer c.mu.RUnlock()
	val, ok := c.data[key]
	return val, ok
}

func (c *Cache) Set(key string, val interface{}) {
	c.mu.Lock()
	defer c.mu.Unlock()
	c.data[key] = val
}

func main() {
	cache := &Cache{data: make(map[string]interface{})}
	
	// 多个读操作可以并发
	for i := 0; i < 3; i++ {
		go func(id int) {
			val, ok := cache.Get("key")
			fmt.Printf("读操作 %d: %v, %v\n", id, val, ok)
			time.Sleep(10 * time.Millisecond)
		}(i)
	}
	
	// 写操作是独占的
	go func() {
		cache.Set("key", "value")
		fmt.Println("写操作完成")
	}()
	
	time.Sleep(100 * time.Millisecond)
}
```

### 4.3 WaitGroup

等待一组 goroutine 完成：

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

func main() {
	var wg sync.WaitGroup
	
	// 添加 3 个 goroutine
	wg.Add(3)
	
	for i := 1; i <= 3; i++ {
		go func(id int) {
			defer wg.Done()  // 在函数结束时标记完成
			
			fmt.Printf("Worker %d 开始\n", id)
			time.Sleep(time.Duration(id*100) * time.Millisecond)
			fmt.Printf("Worker %d 完成\n", id)
		}(i)
	}
	
	fmt.Println("等待所有 worker 完成...")
	wg.Wait()  // 阻塞，直到所有 goroutine 完成
	fmt.Println("所有 worker 已完成")
}
// 输出：
// 等待所有 worker 完成...
// Worker 1 开始
// Worker 2 开始
// Worker 3 开始
// Worker 1 完成
// Worker 2 完成
// Worker 3 完成
// 所有 worker 已完成
```

### 4.4 Once（一次性执行）

确保某个操作只执行一次，常用于初始化：

```go
package main

import (
	"fmt"
	"sync"
)

var (
	instance string
	once     sync.Once
)

func getInstance() string {
	once.Do(func() {
		instance = "实例化一次"
		fmt.Println("首次调用时初始化")
	})
	return instance
}

func main() {
	for i := 1; i <= 3; i++ {
		fmt.Printf("第 %d 次调用: %s\n", i, getInstance())
	}
}
// 输出：
// 首次调用时初始化
// 第 1 次调用: 实例化一次
// 第 2 次调用: 实例化一次
// 第 3 次调用: 实例化一次
```

## 五、实践项目：工作线程池

```go
package main

import (
	"fmt"
	"sync"
)

// Task 代表一个任务
type Task struct {
	ID   int
	Name string
}

// WorkerPool 管理多个工作 goroutine
type WorkerPool struct {
	taskChan chan Task
	wg       sync.WaitGroup
}

// NewWorkerPool 创建工作线程池
func NewWorkerPool(numWorkers int) *WorkerPool {
	pool := &WorkerPool{
		taskChan: make(chan Task, 10),  // 有缓冲 channel
	}
	
	// 启动工作 goroutine
	pool.wg.Add(numWorkers)
	for i := 1; i <= numWorkers; i++ {
		go pool.worker(i)
	}
	
	return pool
}

// worker 处理任务的 goroutine
func (p *WorkerPool) worker(id int) {
	defer p.wg.Done()
	
	for task := range p.taskChan {
		fmt.Printf("Worker %d 处理 Task %d: %s\n", id, task.ID, task.Name)
	}
}

// Submit 提交任务
func (p *WorkerPool) Submit(task Task) {
	p.taskChan <- task
}

// Wait 等待所有任务完成
func (p *WorkerPool) Wait() {
	close(p.taskChan)  // 关闭 channel，worker 会收到信号停止
	p.wg.Wait()
}

func main() {
	pool := NewWorkerPool(3)  // 创建 3 个工作线程
	
	// 提交 10 个任务
	for i := 1; i <= 10; i++ {
		pool.Submit(Task{
			ID:   i,
			Name: fmt.Sprintf("任务_%d", i),
		})
	}
	
	fmt.Println("所有任务已提交，等待处理...")
	pool.Wait()
	fmt.Println("所有任务处理完成")
}
```

## 六、并发编程最佳实践

### 6.1 避免数据竞争

使用 `-race` 标志运行测试检测数据竞争：

```bash
go run -race main.go
go test -race ./...
```

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var (
		mu    sync.Mutex
		count = 0
	)
	
	var wg sync.WaitGroup
	wg.Add(2)
	
	// Goroutine 1
	go func() {
		defer wg.Done()
		for i := 0; i < 1000; i++ {
			mu.Lock()
			count++
			mu.Unlock()
		}
	}()
	
	// Goroutine 2
	go func() {
		defer wg.Done()
		for i := 0; i < 1000; i++ {
			mu.Lock()
			count++
			mu.Unlock()
		}
	}()
	
	wg.Wait()
	fmt.Println("最终计数:", count)  // 2000
}
```

### 6.2 避免死锁

按照相同顺序获取多个锁：

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var (
		mu1 sync.Mutex
		mu2 sync.Mutex
	)
	
	// ✅ 正确：两个 goroutine 都按相同顺序获取锁
	var wg sync.WaitGroup
	wg.Add(2)
	
	go func() {
		defer wg.Done()
		mu1.Lock()
		defer mu1.Unlock()
		mu2.Lock()
		defer mu2.Unlock()
		fmt.Println("Goroutine 1 完成")
	}()
	
	go func() {
		defer wg.Done()
		mu1.Lock()
		defer mu1.Unlock()
		mu2.Lock()
		defer mu2.Unlock()
		fmt.Println("Goroutine 2 完成")
	}()
	
	wg.Wait()
}
```

### 6.3 管道 (Pipeline) 模式

使用 channel 构建数据处理管道：

```go
package main

import "fmt"

// 生成数字
func generate(max int) <-chan int {
	ch := make(chan int)
	go func() {
		for i := 1; i <= max; i++ {
			ch <- i
		}
		close(ch)
	}()
	return ch
}

// 平方
func square(in <-chan int) <-chan int {
	ch := make(chan int)
	go func() {
		for v := range in {
			ch <- v * v
		}
		close(ch)
	}()
	return ch
}

// 过滤偶数
func filterEven(in <-chan int) <-chan int {
	ch := make(chan int)
	go func() {
		for v := range in {
			if v%2 == 0 {
				ch <- v
			}
		}
		close(ch)
	}()
	return ch
}

func main() {
	// 构建管道：生成 -> 平方 -> 过滤
	nums := generate(5)
	squares := square(nums)
	evens := filterEven(squares)
	
	// 消费结果
	for v := range evens {
		fmt.Println(v)
	}
	// 输出：4 16（1² 不是偶数，2²=4，3² 不是偶数，4²=16，5² 不是偶数）
}
```

## 七、常见坑点

| 坑 | 表现 | 解决 |
|:--:|------|------|
| **闭包捕获循环变量** | goroutine 打印不同值 | 通过参数传递而不是直接引用 |
| **goroutine 泄漏** | 内存持续增长 | 确保所有 goroutine 都能正常退出 |
| **发送到关闭 channel** | panic | 只有发送者才能关闭 channel |
| **接收无缓冲 channel 的零值** | 混淆是否有数据 | 总是检查 ok：`v, ok := <-ch` |
| **死锁** | 程序卡住 | 按顺序获取多个锁，使用 select 设置超时 |
| **数据竞争** | 不确定的行为 | 用 mutex 或 channel 保护共享资源，用 `-race` 检测 |
