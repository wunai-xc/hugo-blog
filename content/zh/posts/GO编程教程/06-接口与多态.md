## 引言

**接口**是 Go 面向对象编程的核心。不同于 Java 需要显式声明 `implements`，Go 采用**隐式实现**——只要类型实现了接口的所有方法，就自动满足这个接口。

这个设计极大地提高了代码的灵活性和复用性。本章将详细讲解接口的定义、实现、多态、类型断言和类型开关，以及如何编写解耦且易于测试的代码。

**学完本章，你将能够：**
- 定义和实现接口
- 理解隐式实现的威力
- 使用接口实现多态
- 进行类型断言和类型开关
- 使用空接口处理任意类型
- 设计良好的接口（接口隔离原则）
- 编写可测试的代码

## 一、接口基础

### 1.1 接口定义

接口定义了**方法集合**，任何实现了这些方法的类型都满足这个接口：

```go
package main

import "fmt"

// 定义 Writer 接口
type Writer interface {
	Write(data string) error
}

// File 实现了 Writer 接口
type File struct {
	Name string
}

func (f *File) Write(data string) error {
	fmt.Printf("写入文件 %s: %s\n", f.Name, data)
	return nil
}

// Buffer 也实现了 Writer 接口
type Buffer struct {
	data string
}

func (b *Buffer) Write(data string) error {
	b.data += data
	fmt.Printf("写入缓冲: %s\n", data)
	return nil
}

func main() {
	var w Writer
	
	// File 满足 Writer 接口
	file := &File{Name: "test.txt"}
	w = file
	w.Write("Hello")
	
	// Buffer 也满足 Writer 接口
	buffer := &Buffer{}
	w = buffer
	w.Write("World")
}
```

**关键点**：
- 接口只定义**方法签名**，不提供实现
- 任何类型若实现了接口的**所有方法**，就自动满足这个接口
- **无需显式声明** `implements`（Go 与 Java 的关键区别）

### 1.2 隐式实现的威力

这个例子展示了隐式实现如何解耦代码：

```go
package main

import "fmt"

// 定义通用接口
type Reader interface {
	Read() (string, error)
}

// 多个不同的实现
type FileReader struct {
	Name string
}

func (f *FileReader) Read() (string, error) {
	return fmt.Sprintf("读取文件: %s", f.Name), nil
}

type NetworkReader struct {
	URL string
}

func (n *NetworkReader) Read() (string, error) {
	return fmt.Sprintf("从网络读取: %s", n.URL), nil
}

type DatabaseReader struct {
	Query string
}

func (d *DatabaseReader) Read() (string, error) {
	return fmt.Sprintf("执行查询: %s", d.Query), nil
}

// 通用函数：接受任何 Reader
func processData(r Reader) {
	data, err := r.Read()
	if err != nil {
		fmt.Println("错误:", err)
		return
	}
	fmt.Println("处理数据:", data)
}

func main() {
	// 所有不同的实现都可以用同一个函数处理
	processData(&FileReader{Name: "data.txt"})
	processData(&NetworkReader{URL: "http://example.com/api"})
	processData(&DatabaseReader{Query: "SELECT * FROM users"})
}
// 输出：
// 处理数据: 读取文件: data.txt
// 处理数据: 从网络读取: http://example.com/api
// 处理数据: 执行查询: SELECT * FROM users
```

这就是**多态**的体现：同一个函数能够处理多种不同的类型。

### 1.3 接口组合

接口可以嵌入其他接口：

```go
package main

import "fmt"

// 基础接口
type Reader interface {
	Read() (string, error)
}

type Writer interface {
	Write(data string) error
}

// 组合接口：同时要求 Reader 和 Writer 的方法
type ReadWriter interface {
	Reader
	Writer
}

type File struct {
	Name string
	Content string
}

func (f *File) Read() (string, error) {
	return f.Content, nil
}

func (f *File) Write(data string) error {
	f.Content = data
	return nil
}

func main() {
	var rw ReadWriter = &File{Name: "test.txt"}
	
	// 可以调用 Reader 的方法
	content, _ := rw.Read()
	fmt.Println("读取:", content)
	
	// 可以调用 Writer 的方法
	rw.Write("新内容")
	content, _ = rw.Read()
	fmt.Println("读取:", content)
}
```

## 二、类型断言

### 2.1 基础类型断言

类型断言用于从接口值中**提取具体类型**：

```go
package main

import "fmt"

type Shape interface {
	Area() float64
}

type Circle struct {
	Radius float64
}

func (c Circle) Area() float64 {
	return 3.14 * c.Radius * c.Radius
}

type Rectangle struct {
	Width, Height float64
}

func (r Rectangle) Area() float64 {
	return r.Width * r.Height
}

func main() {
	var s Shape
	
	// 赋值一个 Circle
	s = Circle{Radius: 5}
	
	// 类型断言：s 是 Circle 吗？
	if c, ok := s.(Circle); ok {
		fmt.Printf("圆的半径: %.2f\n", c.Radius)
	}
	
	// 赋值一个 Rectangle
	s = Rectangle{Width: 10, Height: 5}
	
	// 类型断言：s 是 Rectangle 吗？
	if r, ok := s.(Rectangle); ok {
		fmt.Printf("矩形尺寸: %.2f x %.2f\n", r.Width, r.Height)
	}
}
```

**关键点**：
- 类型断言语法：`value, ok := interfaceValue.(ConcreteType)`
- `ok` 为 true 表示类型匹配，false 表示不匹配
- 若不检查 `ok`，类型不匹配时会 panic

### 2.2 不安全的类型断言（不推荐）

```go
package main

import "fmt"

type Animal interface{}

func main() {
	var a Animal = "hello"
	
	// ✅ 安全：检查第二个返回值
	s, ok := a.(string)
	if ok {
		fmt.Println("字符串:", s)
	}
	
	// ❌ 不安全：直接使用，不匹配会 panic
	// i := a.(int)  // panic: interface conversion: interface {} is string, not int
}
```

### 2.3 类型开关（Type Switch）

类型开关用于对多种类型进行不同处理：

```go
package main

import "fmt"

func describeType(v interface{}) {
	switch v := v.(type) {  // 注意这里的 type 关键字
	case int:
		fmt.Printf("整数: %d\n", v)
	case float64:
		fmt.Printf("浮点数: %.2f\n", v)
	case string:
		fmt.Printf("字符串: %s\n", v)
	case bool:
		fmt.Printf("布尔值: %v\n", v)
	default:
		fmt.Printf("未知类型: %T\n", v)
	}
}

func main() {
	describeType(42)
	describeType(3.14)
	describeType("hello")
	describeType(true)
	describeType([]int{1, 2, 3})
}
// 输出：
// 整数: 42
// 浮点数: 3.14
// 字符串: hello
// 布尔值: true
// 未知类型: []int
```

## 三、空接口

### 3.1 空接口基础

空接口 `interface{}` 不包含任何方法，因此**所有类型都实现了空接口**：

```go
package main

import "fmt"

func printAnything(v interface{}) {
	fmt.Println(v)
}

func main() {
	printAnything(42)
	printAnything("hello")
	printAnything(3.14)
	printAnything([]int{1, 2, 3})
	printAnything(map[string]int{"a": 1, "b": 2})
}
```

这让 Go 在编译时仍保持类型安全，但在需要时有运行时的灵活性。

### 3.2 空接口切片

存储任意类型的值：

```go
package main

import "fmt"

func main() {
	// 空接口切片可以存储任意类型
	values := []interface{}{
		42,
		"hello",
		3.14,
		true,
		[]int{1, 2, 3},
	}
	
	for i, v := range values {
		fmt.Printf("[%d] %T: %v\n", i, v, v)
	}
}
// 输出：
// [0] int: 42
// [1] string: hello
// [2] float64: 3.14
// [3] bool: true
// [4] []int: [1 2 3]
```

### 3.3 在函数中使用空接口

```go
package main

import (
	"fmt"
	"strconv"
)

// 通用格式化函数
func Format(v interface{}) string {
	switch val := v.(type) {
	case nil:
		return "<nil>"
	case bool:
		return strconv.FormatBool(val)
	case int:
		return strconv.Itoa(val)
	case float64:
		return fmt.Sprintf("%.2f", val)
	case string:
		return val
	default:
		return fmt.Sprintf("%v", v)
	}
}

func main() {
	fmt.Println(Format(42))
	fmt.Println(Format(3.14))
	fmt.Println(Format("hello"))
	fmt.Println(Format(true))
	fmt.Println(Format(nil))
}
```

## 四、Reader 和 Writer 接口

Go 标准库中最常用的两个接口：

### 4.1 io.Reader 接口

```go
package main

import (
	"fmt"
	"io"
	"strings"
)

// io.Reader 接口定义：
// type Reader interface {
//     Read(p []byte) (n int, err error)
// }

func ReadAll(r io.Reader) (string, error) {
	result := ""
	buf := make([]byte, 1024)
	for {
		n, err := r.Read(buf)
		if n > 0 {
			result += string(buf[:n])
		}
		if err == io.EOF {
			break
		}
		if err != nil {
			return "", err
		}
	}
	return result, nil
}

func main() {
	// strings.Reader 实现了 io.Reader
	reader := strings.NewReader("Hello, Go World!")
	content, _ := ReadAll(reader)
	fmt.Println(content)  // Hello, Go World!
}
```

### 4.2 io.Writer 接口

```go
package main

import (
	"fmt"
	"os"
)

// io.Writer 接口定义：
// type Writer interface {
//     Write(p []byte) (n int, err error)
// }

func WriteMessage(w io.Writer, message string) error {
	_, err := w.Write([]byte(message))
	return err
}

func main() {
	// os.Stdout 实现了 io.Writer
	WriteMessage(os.Stdout, "写入标准输出\n")
	
	// os.Stderr 也实现了 io.Writer
	WriteMessage(os.Stderr, "写入标准错误\n")
}
```

## 五、实现常用接口

### 5.1 实现 fmt.Stringer

```go
package main

import "fmt"

// fmt.Stringer 接口定义：
// type Stringer interface {
//     String() string
// }

type Point struct {
	X, Y float64
}

func (p Point) String() string {
	return fmt.Sprintf("Point(%.1f, %.1f)", p.X, p.Y)
}

func main() {
	p := Point{3.5, 4.2}
	fmt.Println(p)  // Point(3.5, 4.2)
}
```

### 5.2 实现 fmt.GoStringer

```go
package main

import "fmt"

type Version struct {
	Major, Minor, Patch int
}

func (v Version) String() string {
	return fmt.Sprintf("v%d.%d.%d", v.Major, v.Minor, v.Patch)
}

func (v Version) GoString() string {
	return fmt.Sprintf("Version{Major:%d, Minor:%d, Patch:%d}", 
		v.Major, v.Minor, v.Patch)
}

func main() {
	v := Version{1, 2, 3}
	fmt.Println(v)      // v1.2.3
	fmt.Printf("%#v\n", v)  // Version{Major:1, Minor:2, Patch:3}
}
```

## 六、接口的最佳实践

### 6.1 接口隔离原则

设计小而专一的接口，而不是大而宽泛的接口：

```go
package main

import "fmt"

// ❌ 不好：一个庞大的接口
type BadAnimal interface {
	Eat()
	Sleep()
	Walk()
	Fly()
	Swim()
}

// ✅ 好：多个小接口
type Eater interface {
	Eat()
}

type Sleeper interface {
	Sleep()
}

type Walker interface {
	Walk()
}

type Flyer interface {
	Fly()
}

type Swimmer interface {
	Swim()
}

// Dog 只需要实现它真正需要的方法
type Dog struct{}

func (d Dog) Eat()  { fmt.Println("Dog is eating") }
func (d Dog) Sleep() { fmt.Println("Dog is sleeping") }
func (d Dog) Walk()  { fmt.Println("Dog is walking") }

// 现在 Dog 可以满足多个小接口
var _ Eater = Dog{}
var _ Sleeper = Dog{}
var _ Walker = Dog{}
```

### 6.2 接口作为函数参数

```go
package main

import (
	"fmt"
	"io"
	"os"
	"strings"
)

// 通用函数：接受任何 Reader
func CountLines(r io.Reader) (int, error) {
	count := 0
	buf := make([]byte, 1024)
	for {
		n, err := r.Read(buf)
		for i := 0; i < n; i++ {
			if buf[i] == '\n' {
				count++
			}
		}
		if err == io.EOF {
			break
		}
		if err != nil {
			return 0, err
		}
	}
	return count, nil
}

func main() {
	// 可以处理字符串
	reader1 := strings.NewReader("line1\nline2\nline3")
	lines, _ := CountLines(reader1)
	fmt.Printf("字符串行数: %d\n", lines)
	
	// 也可以处理文件
	file, _ := os.Open("example.txt")
	defer file.Close()
	lines, _ = CountLines(file)
	fmt.Printf("文件行数: %d\n", lines)
}
```

## 七、实践项目：支付系统

```go
package main

import (
	"fmt"
	"time"
)

// 定义支付接口
type PaymentMethod interface {
	Pay(amount float64) error
	Refund(transactionID string, amount float64) error
}

// 信用卡支付
type CreditCard struct {
	CardNumber string
	ExpiryDate string
	CVV        string
}

func (c *CreditCard) Pay(amount float64) error {
	fmt.Printf("使用信用卡 %s 支付 %.2f 元\n", c.CardNumber, amount)
	return nil
}

func (c *CreditCard) Refund(transactionID string, amount float64) error {
	fmt.Printf("信用卡退款: 交易ID %s, 金额 %.2f 元\n", transactionID, amount)
	return nil
}

// 支付宝支付
type AliPay struct {
	AccountID string
}

func (a *AliPay) Pay(amount float64) error {
	fmt.Printf("使用支付宝账户 %s 支付 %.2f 元\n", a.AccountID, amount)
	return nil
}

func (a *AliPay) Refund(transactionID string, amount float64) error {
	fmt.Printf("支付宝退款: 交易ID %s, 金额 %.2f 元\n", transactionID, amount)
	return nil
}

// 微信支付
type WeChat struct {
	UserID string
}

func (w *WeChat) Pay(amount float64) error {
	fmt.Printf("使用微信账户 %s 支付 %.2f 元\n", w.UserID, amount)
	return nil
}

func (w *WeChat) Refund(transactionID string, amount float64) error {
	fmt.Printf("微信退款: 交易ID %s, 金额 %.2f 元\n", transactionID, amount)
	return nil
}

// 订单结构体
type Order struct {
	ID        string
	Amount    float64
	CreatedAt time.Time
}

// 支付处理函数：接受任何支付方法
func ProcessPayment(order Order, method PaymentMethod) error {
	fmt.Printf("处理订单 %s, 金额 %.2f 元\n", order.ID, order.Amount)
	return method.Pay(order.Amount)
}

func main() {
	order := Order{
		ID:     "ORD001",
		Amount: 99.99,
		CreatedAt: time.Now(),
	}
	
	// 使用不同的支付方式
	methods := []PaymentMethod{
		&CreditCard{CardNumber: "4111111111111111", ExpiryDate: "12/25", CVV: "123"},
		&AliPay{AccountID: "user@example.com"},
		&WeChat{UserID: "wechat_user_123"},
	}
	
	for i, method := range methods {
		fmt.Printf("\n--- 支付方式 %d ---\n", i+1)
		ProcessPayment(order, method)
		method.Refund("TXN001", 99.99)
	}
}
```

## 八、常见坑点

| 坑 | 表现 | 解决 |
|:--:|------|------|
| **类型断言 panic** | 程序崩溃 | 总是检查第二返回值 `ok` |
| **接口比较 panic** | 比较不同类型接口时 panic | 使用 `!=nil` 检查 nil 接口 |
| **指针 vs 值接收者** | 接口匹配失败 | 定义接口时明确接收者类型 |
| **循环导入** | 编译失败 | 使用空接口或重构代码结构 |
| **nil 接口值** | 行为异常 | 区分 `nil` 值和实现接口的 nil 指针 |
| **接口太宽泛** | 代码耦合度高 | 应用接口隔离原则，设计小接口 |
