## 引言

在之前的文章中，我们学习了Java的基本语法、数据类型和运算符。然而，一个程序如果仅仅是顺序执行一系列语句，其功能将极其有限。真正的编程需要能够根据条件做出决策（分支）和重复执行某些操作（循环）。

**流程控制**是编程语言的核心能力之一，它决定了程序代码的执行顺序。Java提供了丰富的流程控制语句，包括条件判断语句（`if-else`、`switch`）和循环语句（`for`、`while`、`do-while`），以及跳转语句（`break`、`continue`、`return`）。

本文将系统讲解Java中的所有流程控制语句，帮助读者掌握编写灵活、高效程序的能力。

## 第一章 条件判断语句

条件判断语句允许程序根据条件是否成立来决定执行哪一段代码。Java提供了两种条件判断结构：`if` 系列和 `switch`。

### 1.1 if 语句

`if` 语句是最基本的条件判断结构，它根据布尔表达式的值来决定是否执行某段代码。

#### 1.1.1 单分支 if

```text
if (条件表达式) {
    // 条件为 true 时执行的代码
}
```

```java
public class IfDemo {
    public static void main(String[] args) {
        int age = 20;

        if (age >= 18) {
            System.out.println("你已成年，可以进入");
        }
        System.out.println("程序继续执行...");
    }
}
```

#### 1.1.2 双分支 if-else

```text
if (条件表达式) {
    // 条件为 true 时执行
} else {
    // 条件为 false 时执行
}
```

```java
public class IfElseDemo {
    public static void main(String[] args) {
        int score = 85;

        if (score >= 60) {
            System.out.println("及格");
        } else {
            System.out.println("不及格");
        }
    }
}
```

#### 1.1.3 多分支 if-else if-else

```text
if (条件1) {
    // 条件1为 true 时执行
} else if (条件2) {
    // 条件1为 false 且条件2为 true 时执行
} else if (条件3) {
    // 条件1、2为 false 且条件3为 true 时执行
} else {
    // 所有条件都为 false 时执行
}
```

```java
public class IfElseIfDemo {
    public static void main(String[] args) {
        int score = 85;

        if (score >= 90) {
            System.out.println("优秀");
        } else if (score >= 80) {
            System.out.println("良好");
        } else if (score >= 70) {
            System.out.println("中等");
        } else if (score >= 60) {
            System.out.println("及格");
        } else {
            System.out.println("不及格");
        }
    }
}
```

#### 1.1.4 嵌套 if

```java
public class NestedIfDemo {
    public static void main(String[] args) {
        int age = 25;
        boolean isStudent = true;

        if (age >= 18) {
            System.out.println("成年人");
            if (isStudent) {
                System.out.println("且是学生，可享受学生优惠");
            } else {
                System.out.println("不是学生");
            }
        } else {
            System.out.println("未成年人");
        }
    }
}
```

### 1.2 switch 语句

`switch` 语句用于根据一个表达式的值，从多个分支中选择一个执行。它比多个 `if-else if` 结构更清晰。

```text
switch (表达式) {
    case 值1:
        // 当表达式的值等于值1时执行
        break;
    case 值2:
        // 当表达式的值等于值2时执行
        break;
    ...
    default:
        // 当表达式不等于任何 case 值时执行
        break;
}
```

```java
public class SwitchDemo {
    public static void main(String[] args) {
        int day = 3;
        String dayName;

        switch (day) {
            case 1:
                dayName = "星期一";
                break;
            case 2:
                dayName = "星期二";
                break;
            case 3:
                dayName = "星期三";
                break;
            case 4:
                dayName = "星期四";
                break;
            case 5:
                dayName = "星期五";
                break;
            case 6:
                dayName = "星期六";
                break;
            case 7:
                dayName = "星期日";
                break;
            default:
                dayName = "无效日期";
                break;
        }
        System.out.println(dayName);
    }
}
```

> **重要说明**：`break` 语句用于跳出 `switch` 结构。如果省略 `break`，程序会继续执行下一个 `case` 中的代码（称为“穿透”）。

#### switch 的“穿透”特性

```java
public class SwitchFallThroughDemo {
    public static void main(String[] args) {
        int month = 3;
        String season;

        switch (month) {
            case 12:
            case 1:
            case 2:
                season = "冬季";
                break;
            case 3:
            case 4:
            case 5:
                season = "春季";
                break;
            case 6:
            case 7:
            case 8:
                season = "夏季";
                break;
            case 9:
            case 10:
            case 11:
                season = "秋季";
                break;
            default:
                season = "无效月份";
                break;
        }
        System.out.println(month + "月是" + season);
    }
}
```

#### Java 14+ 的 switch 增强特性

```java
public class SwitchEnhancedDemo {
    public static void main(String[] args) {
        // 使用箭头（->）替代冒号（:），不需要 break
        String day = "星期三";
        String result = switch (day) {
            case "星期一", "星期二", "星期三", "星期四", "星期五" -> "工作日";
            case "星期六", "星期日" -> "周末";
            default -> "无效";
        };
        System.out.println(result);

        // 使用 yield 返回值（Java 13+）
        int score = 85;
        String grade = switch (score / 10) {
            case 10, 9 -> "A";
            case 8 -> "B";
            case 7 -> "C";
            case 6 -> "D";
            default -> {
                System.out.println("不及格");
                yield "F";
            }
        };
        System.out.println("等级：" + grade);
    }
}
```

## 第二章 循环控制语句

循环语句用于重复执行某段代码，直到满足特定的终止条件。Java提供了三种循环结构：`for`、`while` 和 `do-while`。

### 2.1 for 循环

`for` 循环适用于已知循环次数的情况，是最常用的循环结构。

```text
for (初始化; 条件判断; 更新) {
    // 循环体
}
```

```java
public class ForDemo {
    public static void main(String[] args) {
        // 基本 for 循环：打印 1 到 10
        for (int i = 1; i <= 10; i++) {
            System.out.print(i + " ");
        }
        System.out.println();

        // 计算 1 到 100 的和
        int sum = 0;
        for (int i = 1; i <= 100; i++) {
            sum += i;
        }
        System.out.println("1 到 100 的和：" + sum);

        // 多重初始化
        for (int i = 0, j = 10; i < j; i++, j--) {
            System.out.println("i=" + i + ", j=" + j);
        }

        // 死循环（注意：通常是错误用法）
        // for (;;) {
        //     System.out.println("无限循环");
        // }
    }
}
```

### 2.2 while 循环

`while` 循环在每次迭代前检查条件，条件为 `true` 时继续执行。

```text
while (条件表达式) {
    // 循环体
}
```

```java
public class WhileDemo {
    public static void main(String[] args) {
        // 打印 1 到 10
        int i = 1;
        while (i <= 10) {
            System.out.print(i + " ");
            i++;
        }
        System.out.println();

        // 计算 1 到 100 的和
        int sum = 0;
        int j = 1;
        while (j <= 100) {
            sum += j;
            j++;
        }
        System.out.println("1 到 100 的和：" + sum);

        // 无限循环（通常配合 break 使用）
        // while (true) {
        //     System.out.println("无限循环");
        // }
    }
}
```

### 2.3 do-while 循环

`do-while` 循环与 `while` 的区别在于：它会**先执行一次**循环体，再检查条件。因此，即使条件为 `false`，循环体也至少执行一次。

```text
do {
    // 循环体
} while (条件表达式);
```

```java
public class DoWhileDemo {
    public static void main(String[] args) {
        // do-while 至少执行一次
        int i = 1;
        do {
            System.out.print(i + " ");
            i++;
        } while (i <= 10);
        System.out.println();

        // 即使条件不成立，也至少执行一次
        int j = 20;
        do {
            System.out.println("j = " + j);
            j++;
        } while (j <= 10);
        // 输出：j = 20（执行一次后条件为 false，退出）
    }
}
```

### 2.4 三种循环的对比

| 循环类型 | 适用场景 | 特点 |
|---------|---------|------|
| `for` | 已知循环次数（计数循环） | 初始化、条件、更新集中在头部 |
| `while` | 未知循环次数，条件驱动 | 先判断后执行，可能一次都不执行 |
| `do-while` | 至少需要执行一次的循环 | 先执行后判断，至少执行一次 |

```java
public class LoopComparisonDemo {
    public static void main(String[] args) {
        // for 循环：已知次数
        System.out.println("=== for 循环 ===");
        for (int i = 0; i < 5; i++) {
            System.out.println("i = " + i);
        }

        // while 循环：未知次数，条件驱动
        System.out.println("=== while 循环 ===");
        int j = 0;
        while (j < 5) {
            System.out.println("j = " + j);
            j++;
        }

        // do-while 循环：至少执行一次
        System.out.println("=== do-while 循环 ===");
        int k = 0;
        do {
            System.out.println("k = " + k);
            k++;
        } while (k < 5);
    }
}
```

## 第三章 跳转语句

跳转语句用于改变程序执行的正常流程，在循环中实现提前退出或跳过某些迭代。

### 3.1 break 语句

`break` 用于立即终止当前循环或 `switch` 语句，程序跳转到循环或 `switch` 之后的代码继续执行。

```java
public class BreakDemo {
    public static void main(String[] args) {
        // break 跳出循环
        System.out.println("=== break 示例 ===");
        for (int i = 1; i <= 10; i++) {
            if (i == 6) {
                break; // i等于6时跳出循环
            }
            System.out.print(i + " ");
        }
        System.out.println("循环结束");

        // 在嵌套循环中，break 只跳出当前内层循环
        System.out.println("\n=== 嵌套循环 break ===");
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= 5; j++) {
                if (j == 3) {
                    break; // 只跳出内层循环
                }
                System.out.print("(" + i + "," + j + ") ");
            }
            System.out.println();
        }

        // 使用标签跳出指定循环（带标签的 break）
        System.out.println("\n=== 标签 break ===");
        outerLoop:
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= 5; j++) {
                if (j == 3) {
                    break outerLoop; // 跳出外层循环
                }
                System.out.print("(" + i + "," + j + ") ");
            }
            System.out.println();
        }
        System.out.println("所有循环结束");
    }
}
```

### 3.2 continue 语句

`continue` 用于跳过本次循环中剩余的代码，立即进入下一次迭代。

```java
public class ContinueDemo {
    public static void main(String[] args) {
        // 打印 1 到 10 之间的奇数
        System.out.println("=== 打印奇数 ===");
        for (int i = 1; i <= 10; i++) {
            if (i % 2 == 0) {
                continue; // 偶数时跳过本次循环，不打印
            }
            System.out.print(i + " ");
        }
        System.out.println();

        // continue 与 while 的注意事项
        System.out.println("=== while 中的 continue ===");
        int j = 0;
        while (j < 10) {
            j++;
            if (j % 2 == 0) {
                continue;
            }
            System.out.print(j + " ");
        }
        System.out.println();

        // 注意：在 while 中使用 continue 时，确保更新语句在 continue 之前
        System.out.println("=== 错误示例（死循环） ===");
        int k = 0;
        while (k < 10) {
            // k++; // 如果将更新放在这里...
            if (k % 2 == 0) {
                continue; // k永远不会递增，导致死循环
            }
            k++; // 放在后面会导致死循环
            System.out.print(k + " ");
        }
        // 为避免上述错误，建议使用 for 循环
    }
}
```

### 3.3 return 语句

`return` 用于从方法中返回，它会结束当前方法的执行并返回结果（如果有返回值）。

```java
public class ReturnDemo {
    public static void main(String[] args) {
        System.out.println("main 开始");
        int result = calculate(10, 20);
        System.out.println("计算结果：" + result);
        System.out.println("main 结束");
    }

    public static int calculate(int a, int b) {
        System.out.println("进入 calculate 方法");
        if (a > b) {
            return a; // 提前返回
        }
        if (a < 0) {
            return 0; // 提前返回
        }
        System.out.println("执行加法");
        return a + b;
    }
}
```

### 3.4 break vs continue vs return 对比

| 语句 | 作用范围 | 效果 |
|------|---------|------|
| `break` | 循环或 switch | 退出当前循环或 switch 结构 |
| `continue` | 循环 | 跳过本次迭代，进入下一次 |
| `return` | 方法 | 退出当前方法，返回调用处 |

## 第四章 综合示例

以下是一个综合运用条件判断和循环控制的学生成绩管理程序。

```java
import java.util.Scanner;

public class GradeManagementSystem {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.println("=== 学生成绩管理系统 ===");

        // 输入学生人数
        System.out.print("请输入学生人数：");
        int studentCount = scanner.nextInt();

        // 存储学生信息
        String[] names = new String[studentCount];
        int[] scores = new int[studentCount];
        String[] grades = new String[studentCount];

        // 输入每个学生的姓名和成绩
        for (int i = 0; i < studentCount; i++) {
            System.out.println("\n第 " + (i + 1) + " 位学生");
            System.out.print("姓名：");
            names[i] = scanner.next();
            System.out.print("成绩：");
            scores[i] = scanner.nextInt();

            // 根据成绩评定等级（if-else if 结构）
            if (scores[i] >= 90) {
                grades[i] = "A";
            } else if (scores[i] >= 80) {
                grades[i] = "B";
            } else if (scores[i] >= 70) {
                grades[i] = "C";
            } else if (scores[i] >= 60) {
                grades[i] = "D";
            } else {
                grades[i] = "F";
            }
        }

        // 统计各等级人数（switch 示例）
        int countA = 0, countB = 0, countC = 0, countD = 0, countF = 0;
        int sumScore = 0;
        int maxScore = Integer.MIN_VALUE;
        int minScore = Integer.MAX_VALUE;
        String maxName = "", minName = "";

        for (int i = 0; i < studentCount; i++) {
            sumScore += scores[i];

            // 统计等级人数（使用 switch）
            switch (grades[i]) {
                case "A":
                    countA++;
                    break;
                case "B":
                    countB++;
                    break;
                case "C":
                    countC++;
                    break;
                case "D":
                    countD++;
                    break;
                default:
                    countF++;
                    break;
            }

            // 记录最高分和最低分
            if (scores[i] > maxScore) {
                maxScore = scores[i];
                maxName = names[i];
            }
            if (scores[i] < minScore) {
                minScore = scores[i];
                minName = names[i];
            }
        }

        // 显示统计结果
        System.out.println("\n=== 统计结果 ===");
        System.out.println("总人数：" + studentCount);
        System.out.println("平均分：" + (double) sumScore / studentCount);
        System.out.println("最高分：" + maxScore + "（" + maxName + "）");
        System.out.println("最低分：" + minScore + "（" + minName + "）");
        System.out.println("\n等级分布：");
        System.out.println("A（90-100）：" + countA + " 人");
        System.out.println("B（80-89）：" + countB + " 人");
        System.out.println("C（70-79）：" + countC + " 人");
        System.out.println("D（60-69）：" + countD + " 人");
        System.out.println("F（0-59）：" + countF + " 人");

        // 显示每个学生的详细信息
        System.out.println("\n=== 详细名单 ===");
        for (int i = 0; i < studentCount; i++) {
            System.out.println(names[i] + "：成绩 " + scores[i] + "，等级 " + grades[i]);
        }

        scanner.close();
    }
}
```

## 总结

本文系统讲解了Java中的流程控制语句：

| 类型 | 语句 | 核心用途 |
|------|------|---------|
| **条件判断** | `if-else` | 根据条件执行不同的代码块 |
| **条件判断** | `switch` | 根据单一表达式的值选择多个分支 |
| **循环** | `for` | 已知次数的循环 |
| **循环** | `while` | 条件驱动的循环 |
| **循环** | `do-while` | 至少执行一次的循环 |
| **跳转** | `break` | 跳出循环或switch |
| **跳转** | `continue` | 跳过本次循环迭代 |
| **跳转** | `return` | 结束方法的执行 |
