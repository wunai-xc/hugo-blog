## 引言

在面向对象编程的三大特征中，**封装**保证了数据的安全性，**继承**实现了代码的复用，而**多态**（Polymorphism）则是面向对象编程的灵魂所在。

多态的字面意思是“多种形态”。在Java中，多态指的是**同一个方法调用在不同对象上可以表现出不同的行为**。简单来说，就是“一个接口，多种实现”。多态让程序在面对不同对象时能够灵活地调整行为，极大地提高了代码的可扩展性和可维护性。

本文将系统讲解Java中的多态机制，包括多态的实现条件、向上转型与向下转型、`instanceof` 运算符的使用，以及多态的经典应用场景。

## 第一章 多态概述

### 1.1 什么是多态

**多态**（Polymorphism）是面向对象编程的三大特征之一，它允许不同的对象对同一个消息（方法调用）做出不同的响应。

多态的核心思想是：**“父类引用指向子类对象”**。当使用父类类型的引用变量指向子类对象时，通过该引用变量调用的方法实际上是子类重写后的方法。

```java
// 多态的核心代码
Animal animal = new Dog();  // 父类引用指向子类对象
animal.makeSound();         // 实际调用的是 Dog 的 makeSound() 方法
```

### 1.2 多态的优势

1. **提高代码的可扩展性**：当需要增加新类型时，不需要修改已有代码，只需添加新类即可。
2. **提高代码的复用性**：通过父类引用操作子类对象，可以编写通用的代码处理多种类型。
3. **降低耦合度**：依赖抽象（父类/接口）而非具体实现（子类），使代码更灵活。

### 1.3 多态的实现条件

在Java中，实现多态需要满足三个条件：

1. **继承关系**：存在父类和子类的继承关系（或接口与实现类的关系）。
2. **方法重写**：子类必须重写父类的方法（或实现接口的方法）。
3. **父类引用指向子类对象**：使用父类类型的引用变量指向子类对象。

## 第二章 多态的实现方式

### 2.1 基于继承的多态

通过父类引用指向子类对象实现多态。

```java
// 父类
class Animal {
    public void makeSound() {
        System.out.println("动物发出声音...");
    }
}

// 子类1
class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("汪汪叫！");
    }

    public void wagTail() {
        System.out.println("摇尾巴！");
    }
}

// 子类2
class Cat extends Animal {
    @Override
    public void makeSound() {
        System.out.println("喵喵叫！");
    }

    public void scratch() {
        System.out.println("抓沙发！");
    }
}

// 子类3
class Duck extends Animal {
    @Override
    public void makeSound() {
        System.out.println("嘎嘎叫！");
    }

    public void swim() {
        System.out.println("游泳！");
    }
}

public class PolymorphismDemo {
    public static void main(String[] args) {
        // 父类引用指向子类对象
        Animal animal1 = new Dog();
        Animal animal2 = new Cat();
        Animal animal3 = new Duck();

        // 同一个方法调用，表现出不同的行为
        animal1.makeSound(); // 汪汪叫！
        animal2.makeSound(); // 喵喵叫！
        animal3.makeSound(); // 嘎嘎叫！
    }
}
```

### 2.2 基于接口的多态

通过接口引用指向实现类对象实现多态。

```java
// 定义接口
interface Drawable {
    void draw();
}

// 实现类1
class Circle implements Drawable {
    @Override
    public void draw() {
        System.out.println("画一个圆形");
    }
}

// 实现类2
class Rectangle implements Drawable {
    @Override
    public void draw() {
        System.out.println("画一个矩形");
    }
}

// 实现类3
class Triangle implements Drawable {
    @Override
    public void draw() {
        System.out.println("画一个三角形");
    }
}

public class InterfacePolymorphism {
    public static void main(String[] args) {
        // 接口引用指向实现类对象
        Drawable d1 = new Circle();
        Drawable d2 = new Rectangle();
        Drawable d3 = new Triangle();

        d1.draw(); // 画一个圆形
        d2.draw(); // 画一个矩形
        d3.draw(); // 画一个三角形
    }
}
```

### 2.3 多态的两种形式

| 多态形式 | 场景 | 示例 |
|---------|------|------|
| **编译时多态** | 方法重载 | 同一个类中多个同名方法，参数列表不同 |
| **运行时多态** | 方法重写 + 父类引用指向子类对象 | `Animal a = new Dog(); a.makeSound();` |

## 第三章 向上转型与向下转型

### 3.1 向上转型（Upcasting）

**向上转型**是将子类对象赋值给父类引用。这是自动的、安全的转型，是Java多态的基础。

```java
// 向上转型（自动）
Animal animal = new Dog();  // 将 Dog 对象转为 Animal 类型

// 向上转型后，只能调用父类中定义的方法
animal.makeSound(); // 可以调用（被子类重写）
// animal.wagTail(); // 错误！父类引用不能调用子类特有的方法
```

**向上转型的特点**：

1. 自动进行，无需强制转换。
2. 父类引用只能访问父类中定义的成员（包括被子类重写的方法）。
3. 子类特有的成员（新增的属性和方法）不可见。

### 3.2 向下转型（Downcasting）

**向下转型**是将父类引用强制转换回子类类型。这是需要显式操作的不安全转型。

```java
// 向下转型（强制）
Animal animal = new Dog();  // 先向上转型
Dog dog = (Dog) animal;     // 再向下转型

// 向下转型后，可以访问子类特有的成员
dog.wagTail();  // 可以调用
```

**向下转型的注意事项**：

1. 需要显式的强制类型转换。
2. 如果转型不匹配，会抛出 `ClassCastException`。
3. 在转型前，通常使用 `instanceof` 进行类型检查。

```java
public class CastingDemo {
    public static void main(String[] args) {
        Animal animal = new Dog();  // 向上转型

        // 正确的向下转型
        if (animal instanceof Dog) {
            Dog dog = (Dog) animal;
            dog.wagTail(); // 安全
        }

        // 错误的向下转型（会抛出 ClassCastException）
        if (animal instanceof Cat) {
            Cat cat = (Cat) animal; // 不会执行，因为 instanceof 为 false
        }

        // 如果不做 instanceof 检查直接转型
        // Cat cat = (Cat) animal; // 运行时抛出 ClassCastException
    }
}
```

### 3.3 转型对比

| 特性 | 向上转型 | 向下转型 |
|------|---------|---------|
| **方向** | 子类 → 父类 | 父类 → 子类 |
| **安全性** | 安全（自动） | 不安全（需要检查） |
| **语法** | 自动，无需显式转换 | 需要显式强制转换 `(子类类型)` |
| **访问能力** | 只能访问父类成员 | 可访问子类所有成员 |
| **使用场景** | 多态、参数传递 | 需要调用子类特有方法时 |

## 第四章 instanceof 运算符

`instanceof` 是Java中的一个二元运算符，用于检查一个对象是否属于某个类（或接口）的实例。

### 4.1 基本用法

```java
// 语法：对象 instanceof 类名/接口名
boolean result = object instanceof ClassName;

// 返回 true 的情况：
// 1. object 是 ClassName 的直接实例
// 2. object 是 ClassName 的子类的实例
// 3. object 是 ClassName 的实现类的实例（当 ClassName 是接口时）
```

### 4.2 详细示例

```java
class Animal {}
class Dog extends Animal {}
class Cat extends Animal {}
class GoldenRetriever extends Dog {}

public class InstanceofDemo {
    public static void main(String[] args) {
        Animal animal = new Dog();

        System.out.println(animal instanceof Animal);      // true
        System.out.println(animal instanceof Dog);         // true
        System.out.println(animal instanceof Cat);         // false
        System.out.println(animal instanceof GoldenRetriever); // false

        // null 的 instanceof 永远返回 false
        Animal nullAnimal = null;
        System.out.println(nullAnimal instanceof Dog);    // false

        // 数组和接口的 instanceof
        String[] arr = new String[10];
        System.out.println(arr instanceof Object);       // true
        System.out.println(arr instanceof String[]);     // true
        System.out.println(arr instanceof Cloneable);    // true
    }
}
```

### 4.3 使用 instanceof 的安全转型

`instanceof` 最常见的应用场景就是在向下转型之前进行类型检查，避免 `ClassCastException`。

```java
public class SafeCast {
    public static void handleAnimal(Animal animal) {
        // 使用 instanceof 进行类型检查
        if (animal instanceof Dog) {
            Dog dog = (Dog) animal;
            dog.wagTail();
            System.out.println("处理狗");
        } else if (animal instanceof Cat) {
            Cat cat = (Cat) animal;
            cat.scratch();
            System.out.println("处理猫");
        } else if (animal instanceof Duck) {
            Duck duck = (Duck) animal;
            duck.swim();
            System.out.println("处理鸭子");
        } else {
            System.out.println("未知动物");
        }
    }

    public static void main(String[] args) {
        handleAnimal(new Dog());   // 处理狗
        handleAnimal(new Cat());   // 处理猫
        handleAnimal(new Duck());  // 处理鸭子
        handleAnimal(new Animal());// 未知动物
    }
}
```

## 第五章 多态的经典应用场景

### 5.1 方法参数的多态

使用父类或接口类型作为方法参数，可以使方法接受多种子类对象，提高代码的通用性。

```java
public class PolymorphicParameter {

    // 使用父类类型作为参数
    public static void makeSound(Animal animal) {
        animal.makeSound(); // 实际调用子类重写的方法
    }

    // 使用接口类型作为参数
    public static void drawShape(Drawable drawable) {
        drawable.draw();
    }

    public static void main(String[] args) {
        // 可以传入任何 Animal 的子类对象
        makeSound(new Dog());    // 汪汪叫！
        makeSound(new Cat());    // 喵喵叫！
        makeSound(new Duck());   // 嘎嘎叫！

        // 可以传入任何 Drawable 的实现类对象
        drawShape(new Circle());    // 画一个圆形
        drawShape(new Rectangle()); // 画一个矩形
        drawShape(new Triangle());  // 画一个三角形
    }
}
```

### 5.2 集合中的多态

使用父类或接口类型的集合，可以存储多种子类对象。

```java
import java.util.ArrayList;
import java.util.List;

public class PolymorphicCollection {
    public static void main(String[] args) {
        // 使用父类类型的集合存储多种子类对象
        List<Animal> animals = new ArrayList<>();
        animals.add(new Dog());
        animals.add(new Cat());
        animals.add(new Duck());

        // 统一处理所有动物
        for (Animal animal : animals) {
            animal.makeSound(); // 每个动物发出自己的声音
        }
        // 输出：
        // 汪汪叫！
        // 喵喵叫！
        // 嘎嘎叫！
    }
}
```

### 5.3 返回值多态

方法可以返回父类类型，实际返回子类对象。

```java
public class PolymorphicReturn {

    public static Animal getAnimal(int type) {
        switch (type) {
            case 1: return new Dog();
            case 2: return new Cat();
            case 3: return new Duck();
            default: return new Animal();
        }
    }

    public static void main(String[] args) {
        // 返回值是 Animal 类型，但实际是子类对象
        Animal animal = getAnimal(1);
        animal.makeSound(); // 汪汪叫！

        animal = getAnimal(2);
        animal.makeSound(); // 喵喵叫！

        animal = getAnimal(3);
        animal.makeSound(); // 嘎嘎叫！
    }
}
```

## 第六章 多态与设计原则

### 6.1 开闭原则（Open-Closed Principle）

开闭原则是面向对象设计最重要的原则之一：**对扩展开放，对修改关闭**。多态是实现开闭原则的关键机制。

```java
// 违反开闭原则的设计（需要修改已有代码）
class Calculator {
    public int calculate(String type, int a, int b) {
        if (type.equals("add")) {
            return a + b;
        } else if (type.equals("subtract")) {
            return a - b;
        }
        // 要添加新运算，必须修改这个类
        return 0;
    }
}

// 符合开闭原则的设计（使用多态扩展）
interface Operation {
    int execute(int a, int b);
}

class AddOperation implements Operation {
    @Override
    public int execute(int a, int b) {
        return a + b;
    }
}

class SubtractOperation implements Operation {
    @Override
    public int execute(int a, int b) {
        return a - b;
    }
}

class MultiplyOperation implements Operation {
    @Override
    public int execute(int a, int b) {
        return a * b;
    }
}

class Calculator2 {
    public int calculate(Operation operation, int a, int b) {
        return operation.execute(a, b);
    }
}

// 要添加新运算，只需要添加新类，不需要修改已有代码
```

### 6.2 里氏替换原则（Liskov Substitution Principle）

里氏替换原则是开闭原则的基础：**子类对象必须能够替换父类对象，而不影响程序的正确性**。

```java
// 符合里氏替换原则
class Bird {
    public void move() {
        System.out.println("移动...");
    }
}

class Sparrow extends Bird {
    @Override
    public void move() {
        System.out.println("飞...");
    }
}

class Ostrich extends Bird {
    @Override
    public void move() {
        System.out.println("跑...");
    }
}

// 违反里氏替换原则（子类删除了父类的行为）
class Penguin extends Bird {
    @Override
    public void move() {
        // 企鹅不会飞，但继承了 Bird 的 move() 语义
        // 这违反了里氏替换原则
        System.out.println("游泳...");
    }
}
```

## 第七章 综合示例

以下是一个综合运用多态的图形绘制系统。

```java
/**
 * 图形接口
 */
interface Shape {
    double area();
    double perimeter();
    void draw();
}

/**
 * 圆形
 */
class Circle implements Shape {
    private double radius;

    public Circle(double radius) {
        this.radius = radius;
    }

    @Override
    public double area() {
        return Math.PI * radius * radius;
    }

    @Override
    public double perimeter() {
        return 2 * Math.PI * radius;
    }

    @Override
    public void draw() {
        System.out.println("画圆形：半径=" + radius + "，面积=" + area() + "，周长=" + perimeter());
    }
}

/**
 * 矩形
 */
class Rectangle implements Shape {
    private double width;
    private double height;

    public Rectangle(double width, double height) {
        this.width = width;
        this.height = height;
    }

    @Override
    public double area() {
        return width * height;
    }

    @Override
    public double perimeter() {
        return 2 * (width + height);
    }

    @Override
    public void draw() {
        System.out.println("画矩形：宽=" + width + "，高=" + height + "，面积=" + area() + "，周长=" + perimeter());
    }
}

/**
 * 三角形
 */
class Triangle implements Shape {
    private double sideA;
    private double sideB;
    private double sideC;

    public Triangle(double sideA, double sideB, double sideC) {
        this.sideA = sideA;
        this.sideB = sideB;
        this.sideC = sideC;
    }

    @Override
    public double area() {
        double s = (sideA + sideB + sideC) / 2;
        return Math.sqrt(s * (s - sideA) * (s - sideB) * (s - sideC));
    }

    @Override
    public double perimeter() {
        return sideA + sideB + sideC;
    }

    @Override
    public void draw() {
        System.out.println("画三角形：三边=" + sideA + "," + sideB + "," + sideC +
                          "，面积=" + area() + "，周长=" + perimeter());
    }
}

/**
 * 图形管理器
 */
class ShapeManager {
    private List<Shape> shapes = new ArrayList<>();

    public void addShape(Shape shape) {
        shapes.add(shape);
    }

    public void drawAll() {
        System.out.println("=== 绘制所有图形 ===");
        for (Shape shape : shapes) {
            shape.draw();
        }
    }

    public double totalArea() {
        double total = 0;
        for (Shape shape : shapes) {
            total += shape.area();
        }
        return total;
    }

    public double totalPerimeter() {
        double total = 0;
        for (Shape shape : shapes) {
            total += shape.perimeter();
        }
        return total;
    }

    // 根据类型统计数量
    public void countByType() {
        int circles = 0, rectangles = 0, triangles = 0;
        for (Shape shape : shapes) {
            if (shape instanceof Circle) circles++;
            else if (shape instanceof Rectangle) rectangles++;
            else if (shape instanceof Triangle) triangles++;
        }
        System.out.println("圆形：" + circles + "个");
        System.out.println("矩形：" + rectangles + "个");
        System.out.println("三角形：" + triangles + "个");
    }
}

/**
 * 测试类
 */
public class ShapeSystem {
    public static void main(String[] args) {
        ShapeManager manager = new ShapeManager();

        // 添加不同形状
        manager.addShape(new Circle(5));
        manager.addShape(new Rectangle(4, 6));
        manager.addShape(new Triangle(3, 4, 5));
        manager.addShape(new Circle(3));
        manager.addShape(new Rectangle(2, 8));

        // 绘制所有图形
        manager.drawAll();

        // 统计信息
        System.out.println("\n=== 统计信息 ===");
        System.out.println("总面积：" + String.format("%.2f", manager.totalArea()));
        System.out.println("总周长：" + String.format("%.2f", manager.totalPerimeter()));
        manager.countByType();
    }
}
```

## 总结

本文系统讲解了Java中的多态机制：

| 知识点 | 核心要点 |
|--------|---------|
| **多态定义** | 同一个方法调用在不同对象上表现不同行为 |
| **实现条件** | 继承 + 重写 + 父类引用指向子类对象 |
| **向上转型** | 子类→父类，自动安全，只能访问父类成员 |
| **向下转型** | 父类→子类，需强制转换，建议配合 `instanceof` |
| **instanceof** | 检查对象是否属于某类型，用于安全转型 |
| **多态应用** | 方法参数、集合存储、返回值、设计模式 |
| **设计原则** | 开闭原则、里氏替换原则 |
