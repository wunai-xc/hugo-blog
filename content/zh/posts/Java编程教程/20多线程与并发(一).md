## 引言

在现代计算机系统中，**多任务处理**是常态：你可以一边听音乐一边写代码，浏览器同时加载多个网页，操作系统后台运行着数十个服务进程。这种并行处理能力正是通过**多线程**技术实现的。

**多线程**（Multithreading）是Java语言的核心特性之一，它允许程序同时执行多个任务，从而提高程序的响应速度和资源利用率。从桌面应用的后台计算，到Web服务器的并发请求处理，多线程无处不在。

本文将系统讲解Java多线程编程的基础知识，包括进程与线程的概念、线程的创建与启动、生命周期以及线程的常用方法。

## 第一章 进程与线程

### 1.1 进程（Process）

**进程**是操作系统进行资源分配和调度的基本单位。每个进程都有独立的内存空间（代码段、数据段、堆栈），一个进程崩溃不会影响其他进程。

```text
┌─────────────────────────────────────────────────────────────┐
│                        进程模型                             │
├─────────────────────────────────────────────────────────────┤
│  进程A                       进程B                          │
│  ┌─────────────────────┐    ┌─────────────────────┐       │
│  │   代码区             │    │   代码区             │       │
│  │   数据区             │    │   数据区             │       │
│  │   堆区               │    │   堆区               │       │
│  │   栈区               │    │   栈区               │       │
│  └─────────────────────┘    └─────────────────────┘       │
│  独立内存空间                独立内存空间                    │
│  进程间通信（IPC）                                           │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 线程（Thread）

**线程**是CPU调度和执行的**最小单位**。一个进程可以包含多个线程，同一进程内的线程**共享**进程的内存空间（堆、方法区），但每个线程有自己的**栈**和**程序计数器（PC）**。

```text
┌─────────────────────────────────────────────────────────────┐
│                  进程内的多线程模型                         │
├─────────────────────────────────────────────────────────────┤
│  进程                                                       │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  共享区域：堆 + 方法区                               │  │
│  ├───────────────────────────────────────────────────────┤  │
│  │  线程1         线程2         线程3                    │  │
│  │  ┌──────────┐  ┌──────────┐  ┌──────────┐          │  │
│  │  │  PC      │  │  PC      │  │  PC      │          │  │
│  │  │  栈      │  │  栈      │  │  栈      │          │  │
│  │  └──────────┘  └──────────┘  └──────────┘          │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

### 1.3 进程与线程的对比

| 对比维度 | 进程 | 线程 |
|---------|------|------|
| **资源分配** | 独立的内存空间 | 共享进程的内存空间 |
| **调度单位** | 操作系统调度 | CPU调度的基本单位 |
| **切换开销** | 大（需要切换地址空间） | 小（共享地址空间） |
| **通信方式** | 进程间通信（IPC）复杂 | 通过共享内存直接通信 |
| **独立性** | 相互隔离，一个崩溃不影响其他 | 一个线程崩溃可能影响整个进程 |
| **创建开销** | 大 | 小 |

### 1.4 并发与并行

**并发（Concurrency）** ：多个任务在**同一时间段**内交替执行（单核CPU）。宏观上看似同时，微观上每个时刻只有一个任务在执行。

**并行（Parallelism）** ：多个任务在**同一时刻**真正同时执行（多核CPU）。

```text
并发（单核）：
时间 →  ┌─A─┐ ┌─B─┐ ┌─A─┐ ┌─C─┐
        A和B交替执行，任意时刻只有一个在运行

并行（多核）：
时间 →  ┌─A───┐
        ┌─B───┐
        ┌─C───┐
        A、B、C在同一时刻真正同时运行
```

## 第二章 线程的创建与启动

Java提供了多种创建线程的方式，从最基础的继承 `Thread` 到现代的 `Callable` 和线程池。

### 2.1 方式一：继承 Thread 类

```java
public class ExtendsThreadDemo {
    public static void main(String[] args) {
        // 创建线程对象
        MyThread t1 = new MyThread("线程A");
        MyThread t2 = new MyThread("线程B");

        // 启动线程（调用 start() 方法）
        t1.start();
        t2.start();

        // 主线程继续执行
        System.out.println(Thread.currentThread().getName() + " 结束");
    }
}

class MyThread extends Thread {
    public MyThread(String name) {
        super(name);
    }

    @Override
    public void run() {
        for (int i = 0; i < 5; i++) {
            System.out.println(getName() + " 执行第 " + (i + 1) + " 次");
            try {
                Thread.sleep(100); // 休眠100ms
            } catch (InterruptedException e) {
                System.out.println(getName() + " 被中断");
                break;
            }
        }
        System.out.println(getName() + " 执行完毕");
    }
}
```

### 2.2 方式二：实现 Runnable 接口

`Runnable` 接口适合多个线程共享同一份任务代码，且更符合面向接口编程的原则。

```java
public class RunnableDemo {
    public static void main(String[] args) {
        // 创建 Runnable 任务
        MyRunnable task = new MyRunnable();

        // 创建多个线程共享同一个任务
        Thread t1 = new Thread(task, "线程A");
        Thread t2 = new Thread(task, "线程B");
        Thread t3 = new Thread(task, "线程C");

        t1.start();
        t2.start();
        t3.start();
    }
}

class MyRunnable implements Runnable {
    private int counter = 0;

    @Override
    public void run() {
        for (int i = 0; i < 5; i++) {
            synchronized (this) { // 需要同步保证线程安全
                counter++;
                System.out.println(Thread.currentThread().getName() +
                        " 计数: " + counter);
            }
            try {
                Thread.sleep(50);
            } catch (InterruptedException e) {
                System.out.println(Thread.currentThread().getName() + " 被中断");
                break;
            }
        }
    }
}
```

### 2.3 方式三：实现 Callable 接口（Java 5+）

`Callable` 接口支持**返回值**和**抛出异常**，比 `Runnable` 更强大。

```java
import java.util.concurrent.*;

public class CallableDemo {
    public static void main(String[] args) {
        // 创建 Callable 任务
        Callable<String> task = new MyCallable();

        // 使用 ExecutorService 提交任务
        ExecutorService executor = Executors.newSingleThreadExecutor();
        Future<String> future = executor.submit(task);

        try {
            // 获取执行结果（会阻塞直到任务完成）
            String result = future.get();
            System.out.println("任务结果: " + result);
        } catch (InterruptedException | ExecutionException e) {
            System.out.println("任务执行异常: " + e.getMessage());
        } finally {
            executor.shutdown();
        }

        // 使用 FutureTask 包装 Callable
        FutureTask<String> futureTask = new FutureTask<>(new MyCallable());
        new Thread(futureTask).start();
        try {
            System.out.println("FutureTask 结果: " + futureTask.get());
        } catch (InterruptedException | ExecutionException e) {
            System.out.println("任务执行异常: " + e.getMessage());
        }
    }
}

class MyCallable implements Callable<String> {
    @Override
    public String call() throws Exception {
        // 模拟耗时任务
        Thread.sleep(1000);
        return "Hello from Callable! 当前时间: " + System.currentTimeMillis();
    }
}
```

### 2.4 三种方式的对比

| 对比维度 | Thread | Runnable | Callable |
|---------|--------|----------|----------|
| **是否有返回值** | ❌ | ❌ | ✅ |
| **是否能抛出异常** | ❌ | ❌ | ✅ |
| **使用方式** | 继承类 | 实现接口 | 实现接口 |
| **适用场景** | 简单任务 | 多个线程共享任务 | 需要返回值的任务 |

### 2.5 start() 与 run() 的区别

```java
public class StartVsRunDemo {
    public static void main(String[] args) {
        MyThread t = new MyThread("Test");

        // 调用 run() 方法：在当前线程中执行，不会启动新线程
        // t.run(); // 在主线程中执行，输出 "main 执行..."

        // 调用 start() 方法：启动新线程，JVM 自动调用 run()
        t.start(); // 在新线程中执行
    }
}
```

## 第三章 线程的生命周期

### 3.1 线程的六种状态

Java线程在生命周期中会经历以下六种状态：

```text
┌─────────────────────────────────────────────────────────────────┐
│                    线程状态转换图                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│    NEW ──────────→ RUNNABLE ──────────→ TERMINATED             │
│    （新建）        （可运行）           （终止）                │
│                     │  │                                        │
│                     │  ├──→ BLOCKED（阻塞，等待锁）             │
│                     │  ├──→ WAITING（无限等待）                 │
│                     │  └──→ TIMED_WAITING（有限等待）           │
│                     │                                           │
│    BLOCKED/WAITING/TIMED_WAITING ──────→ RUNNABLE             │
│    （获得锁/被唤醒/超时）                                       │
└─────────────────────────────────────────────────────────────────┘
```

| 状态 | 说明 |
|------|------|
| **NEW** | 线程刚被创建，尚未调用 `start()` |
| **RUNNABLE** | 线程可运行，等待CPU时间片（包括运行中和等待调度） |
| **BLOCKED** | 线程阻塞，等待获取监视器锁（synchronized） |
| **WAITING** | 线程无限等待，需要其他线程显式唤醒（`wait()`、`join()`） |
| **TIMED_WAITING** | 线程有限等待，超时后自动唤醒（`sleep()`、`wait(timeout)`） |
| **TERMINATED** | 线程执行完毕或异常退出 |

### 3.2 查看线程状态

```java
public class ThreadStateDemo {
    public static void main(String[] args) throws InterruptedException {
        // NEW 状态
        Thread t = new Thread(() -> {
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        });
        System.out.println("NEW: " + t.getState());

        // RUNNABLE 状态
        t.start();
        System.out.println("RUNNABLE: " + t.getState());

        // TIMED_WAITING 状态（等待sleep结束）
        Thread.sleep(100);
        System.out.println("TIMED_WAITING: " + t.getState());

        // TERMINATED 状态
        t.join();
        System.out.println("TERMINATED: " + t.getState());

        // 查看所有线程的状态
        Thread[] threads = new Thread[Thread.activeCount()];
        Thread.enumerate(threads);
        for (Thread thread : threads) {
            if (thread != null) {
                System.out.println(thread.getName() + ": " + thread.getState());
            }
        }
    }
}
```

## 第四章 线程常用方法

### 4.1 sleep()：线程休眠

`Thread.sleep()` 让当前线程暂停执行指定的时间（毫秒），进入 **TIMED_WAITING** 状态。

```java
public class SleepDemo {
    public static void main(String[] args) {
        System.out.println("开始: " + new Date());

        try {
            // 休眠 2 秒
            Thread.sleep(2000);
        } catch (InterruptedException e) {
            System.out.println("线程被中断");
        }

        System.out.println("结束: " + new Date());

        // 休眠的另一种写法（Java 1.5+）
        try {
            TimeUnit.SECONDS.sleep(3); // 休眠3秒
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
}
```

### 4.2 join()：等待线程完成

`join()` 让当前线程**等待**调用 `join()` 的线程执行完毕，进入 **WAITING** 状态。

```java
public class JoinDemo {
    public static void main(String[] args) throws InterruptedException {
        Thread t1 = new Thread(() -> {
            System.out.println("线程1 开始工作...");
            try {
                Thread.sleep(2000);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
            System.out.println("线程1 工作完成");
        });

        Thread t2 = new Thread(() -> {
            System.out.println("线程2 开始工作...");
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
            System.out.println("线程2 工作完成");
        });

        t1.start();
        t2.start();

        // 主线程等待 t1 完成
        System.out.println("主线程等待 t1 完成...");
        t1.join();
        System.out.println("t1 已完成，继续执行主线程");

        // 等待 t2 完成（带超时）
        System.out.println("等待 t2 完成，最多3秒...");
        t2.join(3000);
        System.out.println("主线程结束");
    }
}
```

### 4.3 yield()：线程让步

`Thread.yield()` 让当前线程**让出CPU时间片**，从 RUNNABLE 状态回到 RUNNABLE 状态（不会进入阻塞状态），让其他同等优先级的线程有机会执行。

```java
public class YieldDemo {
    public static void main(String[] args) {
        Thread t1 = new Thread(() -> {
            for (int i = 0; i < 10; i++) {
                System.out.println("线程A: " + i);
                if (i % 2 == 0) {
                    System.out.println("线程A 让出CPU");
                    Thread.yield();
                }
            }
        });

        Thread t2 = new Thread(() -> {
            for (int i = 0; i < 10; i++) {
                System.out.println("线程B: " + i);
            }
        });

        t1.start();
        t2.start();
    }
}
```

> **注意**：`yield()` 只是一个提示，JVM 不保证一定会让出CPU，实际效果依赖于操作系统调度。

## 第五章 线程优先级与守护线程

### 5.1 线程优先级

Java 线程的优先级范围为 `1`（MIN_PRIORITY）到 `10`（MAX_PRIORITY），默认优先级为 `5`（NORM_PRIORITY）。高优先级的线程有更大概率获得CPU时间片。

```java
public class PriorityDemo {
    public static void main(String[] args) {
        // 创建三个不同优先级的线程
        Thread t1 = new Thread(new PriorityTask(), "低优先级");
        Thread t2 = new Thread(new PriorityTask(), "中优先级");
        Thread t3 = new Thread(new PriorityTask(), "高优先级");

        // 设置优先级
        t1.setPriority(Thread.MIN_PRIORITY); // 1
        t2.setPriority(Thread.NORM_PRIORITY); // 5
        t3.setPriority(Thread.MAX_PRIORITY); // 10

        // 查看优先级
        System.out.println("t1 优先级: " + t1.getPriority());
        System.out.println("t2 优先级: " + t2.getPriority());
        System.out.println("t3 优先级: " + t3.getPriority());

        t1.start();
        t2.start();
        t3.start();
    }
}

class PriorityTask implements Runnable {
    @Override
    public void run() {
        long sum = 0;
        for (int i = 0; i < 10000000; i++) {
            sum += i;
        }
        System.out.println(Thread.currentThread().getName() +
                " 计算完成, 优先级: " + Thread.currentThread().getPriority());
    }
}
```

> **注意**：优先级依赖于操作系统实现，在不同平台上可能表现不同。**不要依赖优先级来保证程序正确性**。

### 5.2 守护线程（Daemon Thread）

**守护线程**是后台线程，当所有非守护线程结束时，JVM 会自动退出，守护线程也会被终止。典型应用：垃圾回收线程、日志监控线程。

```java
public class DaemonDemo {
    public static void main(String[] args) {
        // 创建守护线程
        Thread daemon = new Thread(() -> {
            int count = 0;
            while (true) {
                count++;
                System.out.println("守护线程运行中... " + count);
                try {
                    Thread.sleep(500);
                } catch (InterruptedException e) {
                    System.out.println("守护线程被中断");
                    break;
                }
            }
        });

        // 必须在 start() 之前设置
        daemon.setDaemon(true);
        daemon.start();

        // 主线程执行3秒后结束
        try {
            Thread.sleep(3000);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }

        System.out.println("主线程结束，JVM 退出，守护线程自动终止");
    }
}
```

**守护线程的特点**：
- 不能持有重要资源（如文件、数据库连接），因为随时可能被终止。
- 不能在 `finally` 块中执行重要清理，因为 JVM 退出时可能不执行 `finally`。
- 常用于后台监控、心跳检查等辅助任务。

### 5.3 设置线程名称

```java
public class ThreadNameDemo {

    }
}
```

## 第六章 线程中断机制

### 6.1 interrupt()、isInterrupted() 与 interrupted()

Java 提供了一种**协作式**的中断机制，而不是强制终止线程。

```java
public class InterruptDemo {
    public static void main(String[] args) throws InterruptedException {
        // 示例1：通过中断标志退出
        Thread t1 = new Thread(() -> {
            while (!Thread.currentThread().isInterrupted()) {
                System.out.println("线程1 正在运行...");
                try {
                    Thread.sleep(100);
                } catch (InterruptedException e) {
                    // 当 sleep 被中断时，中断标志被清除
                    System.out.println("线程1 被中断（sleep期间）");
                    // 重新设置中断标志
                    Thread.currentThread().interrupt();
                    break;
                }
            }
            System.out.println("线程1 退出");
        });
        t1.start();
        Thread.sleep(500);
        t1.interrupt();

        // 示例2：检查 interrupted() 状态
        Thread t2 = new Thread(() -> {
            int count = 0;
            // interrupted() 检查并清除中断状态
            while (!Thread.interrupted()) {
                count++;
                System.out.println("线程2 计数: " + count);
                if (count >= 5) {
                    Thread.currentThread().interrupt(); // 主动中断
                }
            }
            System.out.println("线程2 退出，共计数: " + count);
        });
        t2.start();
        t2.join();

        // 示例3：捕获 InterruptedException 后的处理
        Thread t3 = new Thread(() -> {
            try {
                Thread.sleep(10000);
            } catch (InterruptedException e) {
                // 捕获异常后，中断标志被清除
                System.out.println("线程3 被中断");
                // 保存中断状态，上层代码可以检查
                Thread.currentThread().interrupt();
                return;
            }
        });
        t3.start();
        Thread.sleep(100);
        t3.interrupt();
    }
}
```

### 6.2 中断方法的对比

| 方法 | 说明 | 是否清除中断状态 |
|------|------|-----------------|
| `interrupt()` | 设置中断标志 | — |
| `isInterrupted()` | 检查中断标志（实例方法） | 否 |
| `interrupted()` | 检查中断标志（静态方法） | **是** |

## 第七章 综合示例

```java
import java.util.*;
import java.util.concurrent.TimeUnit;

/**
 * 多线程下载模拟器
 */
public class DownloadSimulator {
    private static final int TOTAL_SIZE = 1000; // 总大小
    private int downloaded = 0;
    private boolean completed = false;

    public static void main(String[] args) {
        DownloadSimulator simulator = new DownloadSimulator();

        // 创建下载线程
        Thread downloader = new Thread(simulator::download, "下载器");

        // 创建进度监控线程（守护线程）
        Thread monitor = new Thread(() -> {
            while (!simulator.isCompleted()) {
                int progress = simulator.getProgress();
                System.out.println("下载进度: " + progress + "%");
                try {
                    Thread.sleep(500);
                } catch (InterruptedException e) {
                    System.out.println("监控线程被中断");
                    break;
                }
            }
            System.out.println("下载完成！");
        }, "监控器");
        monitor.setDaemon(true);

        // 启动线程
        downloader.start();
        monitor.start();

        // 等待下载完成
        try {
            downloader.join();
            System.out.println("主线程: 下载任务完成");
        } catch (InterruptedException e) {
            System.out.println("主线程被中断");
        }
    }

    public void download() {
        Random random = new Random();
        while (downloaded < TOTAL_SIZE) {
            int chunk = random.nextInt(20) + 1;
            downloaded = Math.min(downloaded + chunk, TOTAL_SIZE);
            System.out.println("已下载: " + downloaded + "/" + TOTAL_SIZE);

            try {
                TimeUnit.MILLISECONDS.sleep(random.nextInt(200) + 50);
            } catch (InterruptedException e) {
                System.out.println("下载被中断");
                return;
            }
        }
        completed = true;
    }

    public int getProgress() {
        return (downloaded * 100) / TOTAL_SIZE;
    }

    public boolean isCompleted() {
        return completed;
    }
}

/**
 * 多线程数据处理器
 */
class DataProcessor {
    private List<Integer> data = new ArrayList<>();
    private final int THREAD_COUNT = 4;

    public void process() {
        // 准备数据
        for (int i = 1; i <= 100; i++) {
            data.add(i);
        }

        // 分片处理
        int size = data.size();
        int chunkSize = size / THREAD_COUNT;

        List<Thread> threads = new ArrayList<>();

        for (int i = 0; i < THREAD_COUNT; i++) {
            int start = i * chunkSize;
            int end = (i == THREAD_COUNT - 1) ? size : (i + 1) * chunkSize;
            List<Integer> chunk = data.subList(start, end);

            Thread t = new Thread(() -> processChunk(chunk, start));
            threads.add(t);
            t.start();
        }

        // 等待所有线程完成
        for (Thread t : threads) {
            try {
                t.join();
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }

        System.out.println("所有数据处理完成");
    }

    private void processChunk(List<Integer> chunk, int offset) {
        String threadName = Thread.currentThread().getName();
        for (Integer value : chunk) {
            // 模拟处理
            try {
                Thread.sleep(10);
            } catch (InterruptedException e) {
                break;
            }
            // 实际处理逻辑（平方）
            int result = value * value;
            System.out.println(threadName + ": " + value + "² = " + result);
        }
        System.out.println(threadName + " 处理完成, 共 " + chunk.size() + " 项");
    }

    public static void main(String[] args) {
        DataProcessor processor = new DataProcessor();
        processor.process();
    }
}
```

## 总结

本文系统讲解了Java多线程编程的基础知识：

| 知识点 | 核心要点 |
|--------|---------|
| **进程与线程** | 进程是资源分配单位，线程是调度单位，线程共享进程内存 |
| **并发与并行** | 并发是交替执行，并行是同时执行 |
| **创建线程** | `Thread`、`Runnable`、`Callable` 三种方式 |
| **start() vs run()** | `start()` 启动新线程，`run()` 仅在当前线程执行 |
| **线程状态** | NEW → RUNNABLE → BLOCKED/WAITING/TIMED_WAITING → TERMINATED |
| **sleep()** | 休眠指定时间，进入 TIMED_WAITING |
| **join()** | 等待目标线程完成，进入 WAITING |
| **yield()** | 主动让出CPU，仍为 RUNNABLE |
| **interrupt()** | 设置中断标志，协作式终止 |
| **优先级** | 1-10，依赖操作系统 |
| **守护线程** | 后台线程，非守护线程结束时自动终止 |
