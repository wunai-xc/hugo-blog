## 引言

在前面的文章中，我们学习了类、继承和多态。然而，在面向对象设计中，我们常常需要定义一些“抽象的”概念——它们本身不应该被实例化，而是作为子类的模板或规范。这时就需要使用**抽象类**和**接口**。

**抽象类**（Abstract Class）提供了一种部分实现的设计模板，允许我们定义通用的属性和方法，同时将某些方法留给子类去具体实现。

**接口**（Interface）则是一种纯粹的设计规范，它只定义方法签名而不提供实现，实现了真正意义上的“契约式设计”。

理解抽象类和接口是掌握面向对象设计的关键一步，也是学习设计模式和框架的基石。

本文将系统讲解抽象类和接口的概念、语法、区别、使用场景以及它们在实际设计中的应用。

## 第一章 抽象类

### 1.1 什么是抽象类

**抽象类**（Abstract Class）是使用 `abstract` 关键字修饰的类。它不能被实例化，通常作为其他类的基类，提供通用的属性和方法。

抽象类可以包含：
- **抽象方法**：只有方法声明，没有方法体（用 `abstract` 修饰）
- **具体方法**：有完整实现的方法
- **成员变量**：与普通类一样

### 1.2 抽象方法的定义

```java
public abstract class Animal {
    // 成员变量
    protected String name;
    protected int age;

    // 构造方法
    public Animal(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 抽象方法：只有声明，没有方法体
    public abstract void makeSound();

    // 抽象方法：只有声明，没有方法体
    public abstract void move();

    // 具体方法：子类可以直接使用或重写
    public void eat() {
        System.out.println(name + "正在吃东西...");
    }

    public void sleep() {
        System.out.println(name + "正在睡觉...");
    }

    public void display() {
        System.out.println("名字：" + name + "，年龄：" + age);
    }
}
```

### 1.3 抽象类的使用

抽象类必须被子类继承，子类必须实现所有抽象方法（除非子类也是抽象类）。

```java
// 子类：Dog
public class Dog extends Animal {
    private String breed;

    public Dog(String name, int age, String breed) {
        super(name, age);
        this.breed = breed;
    }

    // 必须实现父类的抽象方法
    @Override
    public void makeSound() {
        System.out.println(name + "汪汪叫！");
    }

    @Override
    public void move() {
        System.out.println(name + "在奔跑...");
    }

    public void wagTail() {
        System.out.println(name + "摇尾巴！");
    }
}

// 子类：Fish
public class Fish extends Animal {
    public Fish(String name, int age) {
        super(name, age);
    }

    @Override
    public void makeSound() {
        System.out.println(name + "咕噜咕噜...");
    }

    @Override
    public void move() {
        System.out.println(name + "在游泳...");
    }
}
```

### 1.4 抽象类的特点

| 特点 | 说明 |
|------|------|
| **不能实例化** | `new Animal()` 是编译错误 |
| **可以包含抽象方法** | 抽象方法没有方法体，子类必须实现 |
| **可以包含具体方法** | 子类可以直接使用或重写 |
| **可以包含构造方法** | 子类通过 `super()` 调用 |
| **可以包含成员变量** | 与普通类一样 |
| **可以包含 `final` 方法** | 子类不能重写 |

## 第二章 接口

### 2.1 什么是接口

**接口**（Interface）是Java中一种完全抽象的类型，它定义了一组方法签名，但不提供任何实现。接口表达的是“具有某种能力”的概念，强调的是**“能做什么”**，而不是“是什么”。

接口中的所有方法默认都是 `public abstract` 的（Java 8之前）。接口不能有实例变量（只能有常量）。

### 2.2 接口的定义

```java
// 接口定义
public interface Drawable {
    // 常量（隐式 public static final）
    String TYPE = "可绘制对象";

    // 抽象方法（隐式 public abstract）
    void draw();

    void resize(double factor);
}

// 接口可以多继承
public interface Shape extends Drawable, Comparable<Shape> {
    double area();
    double perimeter();
}
```

### 2.3 接口的实现

类使用 `implements` 关键字实现接口，必须实现接口中的所有抽象方法。

```java
// 实现单个接口
public class Circle implements Drawable {
    private double radius;

    public Circle(double radius) {
        this.radius = radius;
    }

    @Override
    public void draw() {
        System.out.println("画一个圆形，半径：" + radius);
    }

    @Override
    public void resize(double factor) {
        radius *= factor;
        System.out.println("调整后半径：" + radius);
    }
}

// 实现多个接口
public class Rectangle implements Drawable, Comparable<Rectangle> {
    private double width;
    private double height;

    public Rectangle(double width, double height) {
        this.width = width;
        this.height = height;
    }

    @Override
    public void draw() {
        System.out.println("画一个矩形，宽：" + width + "，高：" + height);
    }

    @Override
    public void resize(double factor) {
        width *= factor;
        height *= factor;
    }

    @Override
    public int compareTo(Rectangle other) {
        double thisArea = width * height;
        double otherArea = other.width * other.height;
        return Double.compare(thisArea, otherArea);
    }
}
```

### 2.4 Java 8+ 接口增强

Java 8 引入了**默认方法**（Default Method）和**静态方法**（Static Method），Java 9 引入了**私有方法**。

#### 默认方法（Default Method）

默认方法使用 `default` 关键字修饰，允许在接口中提供方法的默认实现。

```java
public interface Calculator {
    // 抽象方法
    int add(int a, int b);

    // 默认方法：提供默认实现
    default int subtract(int a, int b) {
        return a - b;
    }

    // 默认方法：提供默认实现
    default int multiply(int a, int b) {
        return a * b;
    }

    // 静态方法
    static void showType() {
        System.out.println("这是一个计算器接口");
    }
}

// 实现类可以选择使用默认实现或重写
public class SimpleCalculator implements Calculator {
    @Override
    public int add(int a, int b) {
        return a + b;
    }

    // 可以选择不重写 subtract() 和 multiply()
}

// 也可以重写默认方法
public class AdvancedCalculator implements Calculator {
    @Override
    public int add(int a, int b) {
        System.out.println("执行加法...");
        return a + b;
    }

    @Override
    public int subtract(int a, int b) {
        System.out.println("执行减法...");
        return a - b;
    }

    // 不重写 multiply()，使用默认实现
}
```

#### 静态方法

接口中的静态方法通过接口名直接调用。

```java
public interface Utils {
    static void printMessage(String msg) {
        System.out.println(msg);
    }
}

// 使用
Utils.printMessage("Hello, World!");
```

#### 私有方法

Java 9 允许在接口中定义私有方法，用于在默认方法之间共享代码。

```java
public interface Formatter {
    default String format(String text) {
        return addHeader(addFooter(text));
    }

    default String formatWithBorder(String text) {
        return "======" + addHeader(addFooter(text)) + "======";
    }

    // 私有方法（Java 9+）
    private String addHeader(String text) {
        return "*** " + text;
    }

    private String addFooter(String text) {
        return text + " ***";
    }
}
```

## 第三章 抽象类 vs 接口

### 3.1 对比总览

| 对比维度 | 抽象类 | 接口（Java 8+） |
|---------|--------|----------------|
| **关键字** | `abstract class` | `interface` |
| **实例化** | 不能 | 不能 |
| **继承/实现** | `extends`（单继承） | `implements`（多实现） |
| **构造方法** | 可以有 | 不能有 |
| **成员变量** | 可以（任意访问修饰符） | 只能是 `public static final` |
| **抽象方法** | 可以有 | 可以有 |
| **具体方法** | 可以有 | 默认方法（`default`） |
| **静态方法** | 可以有 | 可以有（Java 8+） |
| **访问修饰符** | 所有修饰符都可以 | 默认 `public` |
| **使用场景** | 表示"是什么"（is-a） | 表示"能做什么"（can-do） |

### 3.2 选择建议

| 场景 | 推荐 |
|------|------|
| 类之间有明确的父子关系（is-a） | 抽象类 |
| 需要共享代码实现 | 抽象类 |
| 需要定义行为规范（can-do） | 接口 |
| 需要多继承（多个能力） | 接口 |
| 需要提供默认实现 | 接口（默认方法） |
| 需要定义常量 | 接口 |
| 设计框架和API | 接口为主 |

### 3.3 两者结合使用

在实际设计中，抽象类和接口常常配合使用。一个经典的设计模式是：

1. **接口定义规范**（"能做什么"）
2. **抽象类提供默认实现**（减少子类代码量）
3. **具体类完成最终实现**

```java
// 1. 接口：定义规范
public interface Database {
    void connect(String url, String user, String password);
    void execute(String sql);
    void disconnect();
}

// 2. 抽象类：提供默认实现
public abstract class AbstractDatabase implements Database {
    protected Connection connection;

    @Override
    public void connect(String url, String user, String password) {
        // 通用的连接逻辑
        System.out.println("连接到数据库：" + url);
        // 实际连接代码...
    }

    @Override
    public abstract void execute(String sql); // 留给子类实现

    @Override
    public void disconnect() {
        if (connection != null) {
            System.out.println("断开数据库连接");
            // 实际断开代码...
        }
    }

    // 额外的通用方法
    protected void log(String message) {
        System.out.println("[DB] " + message);
    }
}

// 3. 具体类：最终实现
public class MySQLDatabase extends AbstractDatabase {
    @Override
    public void execute(String sql) {
        log("执行SQL: " + sql);
        // MySQL 特定的执行逻辑
        System.out.println("MySQL执行：" + sql);
    }
}

public class PostgreSQLDatabase extends AbstractDatabase {
    @Override
    public void execute(String sql) {
        log("执行SQL: " + sql);
        // PostgreSQL 特定的执行逻辑
        System.out.println("PostgreSQL执行：" + sql);
    }
}
```

## 第四章 实际应用场景

### 4.1 模板方法模式

抽象类是**模板方法模式**（Template Method Pattern）的基础。模板方法模式定义一个操作中的算法骨架，将某些步骤延迟到子类中实现。

```java
// 抽象类：定义模板方法
public abstract class Beverage {
    // 模板方法：定义算法骨架（final防止子类修改）
    public final void prepare() {
        boilWater();
        brew();
        pourInCup();
        addCondiments();
        System.out.println("饮品制作完成！\n");
    }

    private void boilWater() {
        System.out.println("烧水...");
    }

    private void pourInCup() {
        System.out.println("倒入杯中...");
    }

    // 抽象方法：由子类实现
    protected abstract void brew();

    // 抽象方法：由子类实现
    protected abstract void addCondiments();

    // 钩子方法：子类可以重写
    protected boolean wantsCondiments() {
        return true;
    }
}

// 子类：咖啡
public class Coffee extends Beverage {
    @Override
    protected void brew() {
        System.out.println("冲泡咖啡粉...");
    }

    @Override
    protected void addCondiments() {
        if (wantsCondiments()) {
            System.out.println("加糖和牛奶...");
        }
    }
}

// 子类：茶
public class Tea extends Beverage {
    @Override
    protected void brew() {
        System.out.println("浸泡茶叶...");
    }

    @Override
    protected void addCondiments() {
        if (wantsCondiments()) {
            System.out.println("加柠檬...");
        }
    }

    @Override
    protected boolean wantsCondiments() {
        // 茶通常不加调料
        return false;
    }
}

// 使用
public class TemplateDemo {
    public static void main(String[] args) {
        Beverage coffee = new Coffee();
        coffee.prepare();

        Beverage tea = new Tea();
        tea.prepare();
    }
}
```

### 4.2 策略模式

接口是**策略模式**（Strategy Pattern）的基础，它允许在运行时动态切换算法。

```java
// 策略接口
public interface SortStrategy {
    void sort(int[] array);
}

// 具体策略1：冒泡排序
public class BubbleSort implements SortStrategy {
    @Override
    public void sort(int[] array) {
        int n = array.length;
        for (int i = 0; i < n - 1; i++) {
            for (int j = 0; j < n - 1 - i; j++) {
                if (array[j] > array[j + 1]) {
                    int temp = array[j];
                    array[j] = array[j + 1];
                    array[j + 1] = temp;
                }
            }
        }
        System.out.print("冒泡排序：");
    }
}

// 具体策略2：快速排序
public class QuickSort implements SortStrategy {
    @Override
    public void sort(int[] array) {
        quickSort(array, 0, array.length - 1);
        System.out.print("快速排序：");
    }

    private void quickSort(int[] array, int low, int high) {
        if (low < high) {
            int pi = partition(array, low, high);
            quickSort(array, low, pi - 1);
            quickSort(array, pi + 1, high);
        }
    }

    private int partition(int[] array, int low, int high) {
        int pivot = array[high];
        int i = low - 1;
        for (int j = low; j < high; j++) {
            if (array[j] <= pivot) {
                i++;
                int temp = array[i];
                array[i] = array[j];
                array[j] = temp;
            }
        }
        int temp = array[i + 1];
        array[i + 1] = array[high];
        array[high] = temp;
        return i + 1;
    }
}

// 上下文
public class Sorter {
    private SortStrategy strategy;

    public Sorter(SortStrategy strategy) {
        this.strategy = strategy;
    }

    public void setStrategy(SortStrategy strategy) {
        this.strategy = strategy;
    }

    public void sort(int[] array) {
        int[] copy = array.clone();
        strategy.sort(copy);
        System.out.println(java.util.Arrays.toString(copy));
    }
}

// 使用
public class StrategyDemo {
    public static void main(String[] args) {
        int[] arr = {5, 2, 8, 1, 9, 3};

        Sorter sorter = new Sorter(new BubbleSort());
        sorter.sort(arr);

        sorter.setStrategy(new QuickSort());
        sorter.sort(arr);
    }
}
```

## 第五章 综合示例

以下是一个完整的绘图系统，综合运用了抽象类和接口。

```java
import java.util.ArrayList;
import java.util.List;

/**
 * 形状抽象类
 */
abstract class Shape {
    protected String color;

    public Shape(String color) {
        this.color = color;
    }

    // 抽象方法
    public abstract double area();
    public abstract double perimeter();

    // 具体方法
    public void display() {
        System.out.println("颜色：" + color + "，面积：" + area() + "，周长：" + perimeter());
    }

    // 静态方法
    public static void printShapeInfo(Shape shape) {
        shape.display();
    }
}

/**
 * 可移动接口
 */
interface Movable {
    void move(double dx, double dy);

    // 默认方法
    default void printPosition() {
        System.out.println("当前位置：(" + getX() + ", " + getY() + ")");
    }

    double getX();
    double getY();
}

/**
 * 可缩放接口
 */
interface Scalable {
    void scale(double factor);
}

/**
 * 圆形
 */
class Circle extends Shape implements Movable, Scalable {
    private double x, y;
    private double radius;

    public Circle(String color, double x, double y, double radius) {
        super(color);
        this.x = x;
        this.y = y;
        this.radius = radius;
    }

    @Override
    public double area() {
        return Math.PI * radius * radius;
    }

    @Override
    public double perimeter() {
        return 2 * Math.PI * radius;
    }

    @Override
    public void move(double dx, double dy) {
        x += dx;
        y += dy;
        System.out.println("圆形移动到 (" + x + ", " + y + ")");
    }

    @Override
    public void scale(double factor) {
        radius *= factor;
        System.out.println("圆形缩放：半径 = " + radius);
    }

    @Override
    public double getX() { return x; }

    @Override
    public double getY() { return y; }

    @Override
    public void display() {
        super.display();
        printPosition();
        System.out.println("半径：" + radius);
    }
}

/**
 * 矩形
 */
class Rectangle extends Shape implements Movable, Scalable {
    private double x, y;
    private double width, height;

    public Rectangle(String color, double x, double y, double width, double height) {
        super(color);
        this.x = x;
        this.y = y;
        this.width = width;
        this.height = height;
    }

    @Override
    public double area() {
        return width * height;
    }

    @Override
    public double perimeter() {
        return 2 * (width + height);
    }

    @Override
    public void move(double dx, double dy) {
        x += dx;
        y += dy;
        System.out.println("矩形移动到 (" + x + ", " + y + ")");
    }

    @Override
    public void scale(double factor) {
        width *= factor;
        height *= factor;
        System.out.println("矩形缩放：宽 = " + width + "，高 = " + height);
    }

    @Override
    public double getX() { return x; }

    @Override
    public double getY() { return y; }

    @Override
    public void display() {
        super.display();
        printPosition();
        System.out.println("宽：" + width + "，高：" + height);
    }
}

/**
 * 绘图系统测试
 */
public class DrawingSystem {
    public static void processShape(Shape shape) {
        if (shape instanceof Movable) {
            Movable movable = (Movable) shape;
            movable.move(1, 1);
        }
        if (shape instanceof Scalable) {
            Scalable scalable = (Scalable) shape;
            scalable.scale(1.2);
        }
        shape.display();
        System.out.println();
    }

    public static void main(String[] args) {
        List<Shape> shapes = new ArrayList<>();
        shapes.add(new Circle("红色", 0, 0, 5));
        shapes.add(new Rectangle("蓝色", 10, 10, 4, 6));

        for (Shape shape : shapes) {
            processShape(shape);
        }

        // 直接使用接口引用
        Movable movable = new Circle("绿色", 20, 20, 3);
        movable.move(5, 5);
        movable.printPosition();
    }
}
```

## 总结

本文系统讲解了抽象类与接口：

| 知识点 | 核心要点 |
|--------|---------|
| **抽象类** | `abstract` 修饰，不能实例化，可包含具体方法和抽象方法 |
| **抽象方法** | 只有声明没有实现，子类必须实现 |
| **接口** | 定义行为规范，支持多实现 |
| **默认方法** | Java 8+，接口中的具体方法 |
| **静态方法** | Java 8+，接口中的类方法 |
| **抽象类 vs 接口** | 抽象类表示"is-a"，接口表示"can-do" |
| **模板方法模式** | 抽象类定义算法骨架 |
| **策略模式** | 接口定义算法规范 |
