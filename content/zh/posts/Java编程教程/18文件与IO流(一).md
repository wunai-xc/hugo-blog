## 引言

在程序开发中，数据持久化是必不可少的能力。无论是读取配置文件、处理用户上传的文件、生成日志文件，还是进行数据备份，都离不开对文件的操作。

Java提供了强大的I/O（Input/Output）体系来处理数据的输入和输出。这套体系以**流（Stream）** 为核心概念，数据可以从文件、网络、内存等不同来源读取，也可以写入到不同的目的地。

本文将系统讲解Java中文件操作和字节流的基础知识，包括 `File` 类的使用、字节流的体系结构、文件的读写操作以及缓冲流的使用。

## 第一章 File 类

### 1.1 File 类概述

`java.io.File` 类是文件和目录路径名的抽象表示。它提供了创建、删除、重命名、获取文件属性等操作，但**不涉及文件内容的读写**。

```java
import java.io.*;

public class FileDemo {
    public static void main(String[] args) {
        // 创建 File 对象（可以是文件或目录）
        File file1 = new File("test.txt");
        File file2 = new File("C:\\Users\\Admin\\Documents\\file.txt");
        File file3 = new File("C:/Users/Admin/Documents/file.txt"); // 跨平台

        // 使用父路径和子路径
        File file4 = new File("C:\\Users\\Admin", "Documents\\file.txt");
        File file5 = new File(new File("C:\\Users\\Admin"), "Documents\\file.txt");

        // 获取路径信息
        System.out.println("getPath: " + file1.getPath());
        System.out.println("getAbsolutePath: " + file1.getAbsolutePath());
        System.out.println("getName: " + file1.getName());
        System.out.println("getParent: " + file1.getParent());

        // 判断方法
        System.out.println("exists: " + file1.exists());
        System.out.println("isFile: " + file1.isFile());
        System.out.println("isDirectory: " + file1.isDirectory());
        System.out.println("isAbsolute: " + file1.isAbsolute());

        // 获取文件属性
        System.out.println("length: " + file1.length() + " bytes");
        System.out.println("lastModified: " + new java.util.Date(file1.lastModified()));
    }
}
```

### 1.2 File 的常用方法

```java
import java.io.*;
import java.util.Arrays;

public class FileMethodsDemo {
    public static void main(String[] args) throws IOException {
        // 1. 创建文件

        if (!file.exists()) {
            boolean created = file.createNewFile(); // 创建新文件
            System.out.println("文件创建成功：" + created);
        }

        // 2. 创建目录
        File dir = new File("myDir");
        if (!dir.exists()) {
            boolean created = dir.mkdir(); // 创建单级目录
            System.out.println("目录创建成功：" + created);
        }

        // 3. 创建多级目录
        File multiDir = new File("a/b/c/d");
        if (!multiDir.exists()) {
            boolean created = multiDir.mkdirs(); // 创建多级目录
            System.out.println("多级目录创建成功：" + created);
        }

        // 4. 列出目录内容
        File currentDir = new File(".");
        String[] files = currentDir.list();
        System.out.println("当前目录内容：" + Arrays.toString(files));

        // 带过滤器的列出
        File[] txtFiles = currentDir.listFiles((dir1, name) -> name.endsWith(".txt"));
        System.out.println("文本文件：" + Arrays.toString(txtFiles));

        // 5. 重命名
        File newFile = new File("renamed.txt");
        if (file.exists()) {
            boolean renamed = file.renameTo(newFile);
            System.out.println("重命名成功：" + renamed);
        }

        // 6. 删除
        File toDelete = new File("toDelete.txt");
        toDelete.createNewFile();
        if (toDelete.exists()) {
            boolean deleted = toDelete.delete(); // 直接删除
            System.out.println("删除成功：" + deleted);
        }

        // 7. 删除目录（必须为空）
        File emptyDir = new File("emptyDir");
        emptyDir.mkdir();
        boolean deleted = emptyDir.delete();
        System.out.println("空目录删除：" + deleted);

        // 8. 获取磁盘信息
        File root = new File("C:/");
        System.out.println("总空间：" + root.getTotalSpace() / (1024*1024*1024) + " GB");
        System.out.println("可用空间：" + root.getFreeSpace() / (1024*1024*1024) + " GB");
    }
}
```

## 第二章 I/O 流概述

### 2.1 什么是流

**流（Stream）** 是Java中处理数据传输的抽象概念。它表示一组有顺序的、有起点和终点的数据序列。输入流用于从数据源读取数据，输出流用于向数据目标写入数据。

### 2.2 流的分类

根据处理数据单位的不同，流分为**字节流**和**字符流**：

| 类型 | 父类 | 处理单位 | 适用场景 |
|------|------|---------|---------|
| **字节流** | InputStream / OutputStream | 字节（8位） | 二进制数据（图片、音频、视频、任意文件） |
| **字符流** | Reader / Writer | 字符（16位） | 文本数据（.txt、.java、.xml等） |

根据数据流向的不同，流分为**输入流**和**输出流**：

```text

│                                                             │

│  ┌─────────────┐  ┌─────────────┐ ┌─────────────┐ ┌─────┐ │
│  │InputStream  │  │   Reader    │ │OutputStream │ │Writer│ │
```

### 2.3 字节流与字符流的对比

| 对比项 | 字节流 | 字符流 |
|--------|--------|--------|
| **基本单位** | 字节（byte） | 字符（char，2字节） |
| **父类** | InputStream / OutputStream | Reader / Writer |
| **适用数据** | 二进制数据（图片、视频、音频） | 文本数据 |
| **是否需要处理编码** | 不需要（直接传输字节） | 需要（使用字符编码） |
| **常用子类** | FileInputStream, FileOutputStream | FileReader, FileWriter |

## 第三章 字节输入流（InputStream）

### 3.1 InputStream 的继承体系

```text
InputStream（抽象类）
├── FileInputStream（文件输入流）
├── BufferedInputStream（缓冲输入流）
├── DataInputStream（数据输入流）
├── ObjectInputStream（对象输入流）
├── ByteArrayInputStream（字节数组输入流）
├── PipedInputStream（管道输入流）
└── SequenceInputStream（序列输入流）
```

### 3.2 InputStream 的核心方法

| 方法 | 说明 |
|------|------|
| `int read()` | 读取一个字节（返回0-255，-1表示结束） |
| `int read(byte[] b)` | 读取数据到字节数组，返回实际读取的字节数 |
| `int read(byte[] b, int off, int len)` | 读取数据到字节数组的指定位置 |
| `long skip(long n)` | 跳过指定数量的字节 |
| `int available()` | 返回可读取的字节数估计值 |
| `void close()` | 关闭流，释放资源 |

### 3.3 FileInputStream 的使用

```java
import java.io.*;

public class FileInputStreamDemo {
    public static void main(String[] args) {
        // 方式一：读取单个字节
        try (FileInputStream fis = new FileInputStream("test.txt")) {
            int data;
            while ((data = fis.read()) != -1) {
                System.out.print((char) data);
            }
        } catch (IOException e) {
            System.out.println("读取失败：" + e.getMessage());
        }

        // 方式二：读取到字节数组
        try (FileInputStream fis = new FileInputStream("test.txt")) {
            byte[] buffer = new byte[1024];
            int bytesRead;
            while ((bytesRead = fis.read(buffer)) != -1) {
                System.out.println("读取了 " + bytesRead + " 字节");
                // 转换为字符串并输出
                System.out.print(new String(buffer, 0, bytesRead));
            }
        } catch (IOException e) {
            System.out.println("读取失败：" + e.getMessage());
        }

        // 方式三：使用 available() 预设缓冲区大小
        try (FileInputStream fis = new FileInputStream("test.txt")) {
            byte[] buffer = new byte[fis.available()];
            fis.read(buffer);
            System.out.println(new String(buffer));
        } catch (IOException e) {
            System.out.println("读取失败：" + e.getMessage());
        }
    }
}
```

### 4.3 FileOutputStream 的使用

```java
import java.io.*;

public class FileOutputStreamDemo {
    public static void main(String[] args) {
        // 方式一：写入单个字节
        try (FileOutputStream fos = new FileOutputStream("output1.txt")) {
            // 默认覆盖原有内容
            fos.write(65); // 'A'
            fos.write(66); // 'B'
            fos.write(67); // 'C'
        } catch (IOException e) {
            System.out.println("写入失败：" + e.getMessage());
        }

        // 方式二：写入字节数组
        try (FileOutputStream fos = new FileOutputStream("output2.txt")) {
            byte[] data = "Hello, World!".getBytes();
            fos.write(data);
        } catch (IOException e) {
            System.out.println("写入失败：" + e.getMessage());
        }

        // 方式三：追加模式（第二个参数为 true）
        try (FileOutputStream fos = new FileOutputStream("output2.txt", true)) {
            byte[] data = "\nAppend content".getBytes();
            fos.write(data);
        } catch (IOException e) {
            System.out.println("写入失败：" + e.getMessage());
        }

        // 方式四：写入指定部分
        try (FileOutputStream fos = new FileOutputStream("output3.txt")) {
            byte[] data = "Hello, World!".getBytes();
            fos.write(data, 7, 5); // 写入 "World"
        } catch (IOException e) {
            System.out.println("写入失败：" + e.getMessage());
        }
    }
}
```

## 第五章 文件复制示例

### 5.1 逐字节复制（低效）

```java
public class CopyFileDemo {
    // 方式一：逐字节复制（最慢，不推荐）
    public static void copyByteByByte(String src, String dest) throws IOException {
        try (FileInputStream fis = new FileInputStream(src);
             FileOutputStream fos = new FileOutputStream(dest)) {
            int data;
            while ((data = fis.read()) != -1) {
                fos.write(data);
            }
        }
    }

    // 方式二：使用缓冲区复制（推荐）
    public static void copyWithBuffer(String src, String dest) throws IOException {
        try (FileInputStream fis = new FileInputStream(src);
             FileOutputStream fos = new FileOutputStream(dest)) {
            byte[] buffer = new byte[8192]; // 8KB 缓冲区
            int bytesRead;
            while ((bytesRead = fis.read(buffer)) != -1) {
                fos.write(buffer, 0, bytesRead);
            }
        }
    }

    // 方式三：使用 Buffered 流（高效）
    public static void copyWithBufferedStream(String src, String dest) throws IOException {
        try (BufferedInputStream bis = new BufferedInputStream(new FileInputStream(src));
             BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream(dest))) {
            byte[] buffer = new byte[8192];
            int bytesRead;
            while ((bytesRead = bis.read(buffer)) != -1) {
                bos.write(buffer, 0, bytesRead);
            }
        }
    }

    // 性能测试
    public static void main(String[] args) {
        String src = "large_file.dat";
        String dest = "copy.dat";

        try {
            // 测试逐字节复制（非常慢）
            long start = System.currentTimeMillis();
            copyByteByByte(src, dest);
            long end = System.currentTimeMillis();
            System.out.println("逐字节复制耗时：" + (end - start) + "ms");

            // 测试缓冲区复制
            start = System.currentTimeMillis();
            copyWithBuffer(src, dest + "2");
            end = System.currentTimeMillis();
            System.out.println("缓冲区复制耗时：" + (end - start) + "ms");

            // 测试 Buffered 流复制
            start = System.currentTimeMillis();
            copyWithBufferedStream(src, dest + "3");
            end = System.currentTimeMillis();
            System.out.println("Buffered流复制耗时：" + (end - start) + "ms");
        } catch (IOException e) {
            System.out.println("复制失败：" + e.getMessage());
        }
    }
}
```

## 第六章 缓冲字节流

### 6.1 BufferedInputStream 与 BufferedOutputStream

缓冲流通过内部缓冲区减少对磁盘的直接访问，提高I/O性能。

```java
import java.io.*;

public class BufferedStreamDemo {
    public static void main(String[] args) {
        // 写入数据（使用 BufferedOutputStream）
        try (BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("buffered.txt"))) {
            String text = "Hello, Buffered Stream!";
            bos.write(text.getBytes());
            bos.write("\n第二行内容".getBytes());
            // 自动 flush 或手动调用 bos.flush()
        } catch (IOException e) {
            System.out.println("写入失败：" + e.getMessage());
        }

        // 读取数据（使用 BufferedInputStream）
        try (BufferedInputStream bis = new BufferedInputStream(new FileInputStream("buffered.txt"))) {
            byte[] buffer = new byte[1024];
            int bytesRead;
            while ((bytesRead = bis.read(buffer)) != -1) {
                System.out.print(new String(buffer, 0, bytesRead));
            }
        } catch (IOException e) {
            System.out.println("读取失败：" + e.getMessage());
        }

        // 使用 mark/reset 标记位置
        try (BufferedInputStream bis = new BufferedInputStream(new FileInputStream("buffered.txt"))) {
            // 标记位置（必须支持 reset）
            if (bis.markSupported()) {
                bis.mark(100); // 标记当前位，允许读取最多100字节后再返回
                System.out.println("第一个字符：" + (char) bis.read());
                System.out.println("第二个字符：" + (char) bis.read());
                bis.reset(); // 回到标记位置
                System.out.println("reset 后第一个字符：" + (char) bis.read());
            }
        } catch (IOException e) {
            System.out.println("操作失败：" + e.getMessage());
        }
    }
}
```

### 6.2 flush 方法的重要性

```java
public class FlushDemo {
    public static void main(String[] args) {
        // 不调用 flush - 数据可能丢失
        try (BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("no_flush.txt"))) {
            bos.write("This data might not be written".getBytes());
            // 没有 flush，程序结束前 JVM 会 flush，但如果异常则可能丢失
        } catch (IOException e) {
            System.out.println("写入失败：" + e.getMessage());
        }

        // 手动调用 flush
        try (BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("with_flush.txt"))) {
            bos.write("This data is written immediately".getBytes());
            bos.flush(); // 强制将缓冲区内容写入磁盘
        } catch (IOException e) {
            System.out.println("写入失败：" + e.getMessage());
        }

        // 使用 PrintStream（自动 flush）
        try (PrintStream ps = new PrintStream(new FileOutputStream("auto_flush.txt"))) {
            ps.println("Auto flush line 1");
            ps.println("Auto flush line 2");
            // PrintStream 会在换行时自动 flush
        } catch (IOException e) {
            System.out.println("写入失败：" + e.getMessage());
        }
    }
}
```

## 第七章 其他字节流

### 7.1 DataInputStream 与 DataOutputStream

用于读写基本数据类型（int、double、boolean 等）。

```java
import java.io.*;

public class DataStreamDemo {
    public static void main(String[] args) {
        // 写入基本数据类型
        try (DataOutputStream dos = new DataOutputStream(new FileOutputStream("data.dat"))) {
            dos.writeInt(100);
            dos.writeDouble(3.14);
            dos.writeBoolean(true);
            dos.writeUTF("Hello, Data!");
        } catch (IOException e) {
            System.out.println("写入失败：" + e.getMessage());
        }

        // 读取基本数据类型（必须按写入顺序读取）
        try (DataInputStream dis = new DataInputStream(new FileInputStream("data.dat"))) {
            int i = dis.readInt();
            double d = dis.readDouble();
            boolean b = dis.readBoolean();
            String s = dis.readUTF();

            System.out.println("int: " + i);
            System.out.println("double: " + d);
            System.out.println("boolean: " + b);
            System.out.println("String: " + s);
        } catch (IOException e) {
            System.out.println("读取失败：" + e.getMessage());
        }
    }
}
```

### 7.3 PrintStream（打印流）

```java
import java.io.*;

public class PrintStreamDemo {

            System.setOut(originalOut);
            System.out.println("恢复控制台输出");
        } catch (IOException e) {
            System.out.println("重定向失败：" + e.getMessage());
        }
    }
}
```

## 第八章 综合示例

```java
import java.io.*;
import java.util.*;

/**
 * 文件工具类 - 综合运用字节流
 */
public class FileUtils {
    private static final int BUFFER_SIZE = 8192;

    /**
     * 复制文件
     */
    public static void copyFile(String source, String dest) throws IOException {
        copyFile(source, dest, true);
    }

    /**
     * 复制文件（可选择是否覆盖）
     */
    public static void copyFile(String source, String dest, boolean overwrite) throws IOException {
        File destFile = new File(dest);
        if (destFile.exists() && !overwrite) {
            throw new IOException("目标文件已存在：" + dest);
        }

        // 确保目标目录存在
        File parent = destFile.getParentFile();
        if (parent != null && !parent.exists()) {
            parent.mkdirs();
        }

        try (BufferedInputStream bis = new BufferedInputStream(new FileInputStream(source));
             BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream(dest))) {
            byte[] buffer = new byte[BUFFER_SIZE];
            int bytesRead;
            while ((bytesRead = bis.read(buffer)) != -1) {
                bos.write(buffer, 0, bytesRead);
            }
        }
    }

    /**
     * 获取文件扩展名
     */
    public static String getExtension(String filename) {
        int lastDot = filename.lastIndexOf('.');
        if (lastDot > 0) {
            return filename.substring(lastDot + 1).toLowerCase();
        }
        return "";
    }

    /**
     * 获取文件大小（可读格式）
     */
    public static String getReadableSize(long size) {
        String[] units = {"B", "KB", "MB", "GB", "TB"};
        int unitIndex = 0;
        double readableSize = size;
        while (readableSize >= 1024 && unitIndex < units.length - 1) {
            readableSize /= 1024;
            unitIndex++;
        }
        return String.format("%.2f %s", readableSize, units[unitIndex]);
    }

    /**
     * 统计目录大小
     */
    public static long getDirectorySize(File dir) {
        if (!dir.isDirectory()) {
            return dir.length();
        }
        long size = 0;
        File[] files = dir.listFiles();
        if (files != null) {
            for (File file : files) {
                size += getDirectorySize(file);
            }
        }
        return size;
    }

    /**
     * 删除目录（递归）
     */
    public static boolean deleteDirectory(File dir) {
        if (!dir.exists()) {
            return false;
        }
        if (dir.isDirectory()) {
            File[] files = dir.listFiles();
            if (files != null) {
                for (File file : files) {
                    deleteDirectory(file);
                }
            }
        }
        return dir.delete();
    }

    /**
     * 按扩展名过滤文件
     */
    public static List<File> filterByExtension(File dir, String... extensions) {
        List<File> result = new ArrayList<>();
        if (!dir.isDirectory()) {
            return result;
        }
        Set<String> extSet = new HashSet<>(Arrays.asList(extensions));
        File[] files = dir.listFiles();
        if (files != null) {
            for (File file : files) {
                if (file.isFile()) {
                    String ext = getExtension(file.getName());
                    if (extSet.contains(ext)) {
                        result.add(file);
                    }
                }
            }
        }
        return result;
    }

    /**
     * 文件分割
     */
    public static void splitFile(String filename, long partSize) throws IOException {
        File file = new File(filename);
        if (!file.exists()) {
            throw new IOException("文件不存在：" + filename);
        }

        long fileSize = file.length();
        int partCount = (int) Math.ceil((double) fileSize / partSize);

        try (BufferedInputStream bis = new BufferedInputStream(new FileInputStream(file))) {
            byte[] buffer = new byte[BUFFER_SIZE];
            for (int i = 0; i < partCount; i++) {
                String partName = filename + ".part" + (i + 1);
                try (BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream(partName))) {
                    long remaining = Math.min(partSize, fileSize - (long) i * partSize);
                    while (remaining > 0) {
                        int toRead = (int) Math.min(BUFFER_SIZE, remaining);
                        int bytesRead = bis.read(buffer, 0, toRead);
                        if (bytesRead == -1) break;
                        bos.write(buffer, 0, bytesRead);
                        remaining -= bytesRead;
                    }
                }
                System.out.println("创建分片：" + partName);
            }
        }
    }

    /**
     * 合并文件
     */
    public static void mergeFile(String output, String... parts) throws IOException {
        try (BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream(output))) {
            byte[] buffer = new byte[BUFFER_SIZE];
            for (String part : parts) {
                try (BufferedInputStream bis = new BufferedInputStream(new FileInputStream(part))) {
                    int bytesRead;
                    while ((bytesRead = bis.read(buffer)) != -1) {
                        bos.write(buffer, 0, bytesRead);
                    }
                }
            }
        }
        System.out.println("合并完成：" + output);
    }
```
