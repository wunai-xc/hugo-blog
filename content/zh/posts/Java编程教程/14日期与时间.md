## 引言

在程序开发中，日期和时间的处理是一个极其常见但又容易出错的任务。从用户注册时间、订单创建时间、日志记录，到定时任务调度、时区转换、日期计算，几乎每个应用程序都离不开对时间的处理。

Java对日期时间的支持经历了多次演进。早期的 `java.util.Date` 和 `java.util.Calendar` 存在诸多设计缺陷，使用起来既不直观又容易出错。Java 8 引入了全新的 `java.time` 包（基于 JSR-310），彻底重构了日期时间API，提供了更加清晰、不可变、线程安全的日期时间处理能力。

本文将系统讲解Java中的日期与时间处理，从传统API到现代API，帮助读者全面掌握Java中的时间处理技术。

## 第一章 传统日期时间API

### 1.1 Date 类

`java.util.Date` 是Java最早提供的日期时间类，但它存在诸多缺陷。

```java
import java.util.Date;

public class DateDemo {
    public static void main(String[] args) {
        // 创建当前日期时间
        Date now = new Date();
        System.out.println("当前时间：" + now);

        // 创建指定时间（1970-01-01 00:00:00 以来的毫秒数）
        Date date = new Date(1000000000L);

        // 获取时间戳（毫秒）
        long timestamp = now.getTime();
        System.out.println("时间戳：" + timestamp);

        // 比较日期
        Date date1 = new Date();
        Date date2 = new Date();
        System.out.println("date1 before date2: " + date1.before(date2));
        System.out.println("date1 after date2: " + date1.after(date2));

        // Date 的缺陷：
        // 1. 年份从1900开始（getYear()返回年份-1900）
        // 2. 月份从0开始（0=一月）
        // 3. 不是线程安全的
        // 4. 没有时区处理能力
        System.out.println("年份：" + (now.getYear() + 1900));
        System.out.println("月份：" + (now.getMonth() + 1));
        System.out.println("日期：" + now.getDate());
    }
}
```

### 1.2 Calendar 类

`Calendar` 是对 `Date` 的改进，提供了一套更完整的日期时间操作API。

```java
import java.util.Calendar;
import java.util.Date;

public class CalendarDemo {
    public static void main(String[] args) {
        // 获取 Calendar 实例
        Calendar calendar = Calendar.getInstance();

        // 获取日期时间信息
        int year = calendar.get(Calendar.YEAR);
        int month = calendar.get(Calendar.MONTH) + 1; // 月份从0开始
        int day = calendar.get(Calendar.DAY_OF_MONTH);
        int hour = calendar.get(Calendar.HOUR_OF_DAY);
        int minute = calendar.get(Calendar.MINUTE);
        int second = calendar.get(Calendar.SECOND);

        System.out.println("当前时间：" + year + "-" + month + "-" + day + " " +
                          hour + ":" + minute + ":" + second);

        // 设置日期
        calendar.set(2026, Calendar.JANUARY, 1, 0, 0, 0);
        Date date = calendar.getTime();
        System.out.println("设置的时间：" + date);

        // 日期运算
        calendar.add(Calendar.DAY_OF_MONTH, 100); // 加100天
        System.out.println("100天后：" + calendar.getTime());

        calendar.add(Calendar.MONTH, -3); // 减3个月
        System.out.println("再减3个月：" + calendar.getTime());

        // 获取本周第一天（周一）
        calendar.setFirstDayOfWeek(Calendar.MONDAY);
        calendar.set(Calendar.DAY_OF_WEEK, Calendar.MONDAY);
        System.out.println("本周周一：" + calendar.getTime());

        // 获取本月第一天
        calendar.set(Calendar.DAY_OF_MONTH, 1);
        System.out.println("本月第一天：" + calendar.getTime());

        // Calendar 的缺陷：
        // 1. 月份从0开始，容易出错
        // 2. 不是线程安全的
        // 3. 复杂的API设计
        // 4. 没有处理日期时间计算的专用类型
    }
}
```

### 1.3 SimpleDateFormat（日期格式化）

`SimpleDateFormat` 用于将日期格式化为字符串，或将字符串解析为日期。

```java
import java.text.ParseException;
import java.text.SimpleDateFormat;
import java.util.Date;

public class DateFormatDemo {
    public static void main(String[] args) throws ParseException {
        Date now = new Date();

        // 格式化日期
        SimpleDateFormat sdf1 = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
        System.out.println("yyyy-MM-dd HH:mm:ss: " + sdf1.format(now));

        SimpleDateFormat sdf2 = new SimpleDateFormat("yyyy年MM月dd日 HH:mm");
        System.out.println("yyyy年MM月dd日 HH:mm: " + sdf2.format(now));

        SimpleDateFormat sdf3 = new SimpleDateFormat("yyyy-MM-dd");
        System.out.println("yyyy-MM-dd: " + sdf3.format(now));

        // 解析字符串为日期
        String dateStr = "2026-08-12 14:30:00";
        Date parsed = sdf1.parse(dateStr);
        System.out.println("解析结果：" + parsed);

        // 常用格式符号
        // yyyy - 年份（4位）
        // MM - 月份（2位）
        // dd - 日（2位）
        // HH - 小时（24小时制）
        // hh - 小时（12小时制）
        // mm - 分钟
        // ss - 秒
        // SSS - 毫秒
        // E - 星期几

        // 线程安全问题（需要额外处理）
        // SimpleDateFormat 不是线程安全的
    }
}
```

## 第二章 java.time 包概述

### 2.1 为什么需要新的日期时间API

传统日期时间API存在以下问题：

1. **非线程安全**：`Date` 和 `SimpleDateFormat` 都不是线程安全的。
2. **月份从0开始**：设计反直觉，容易出错。
3. **缺乏不可变性**：`Date` 是可变的，容易产生副作用。
4. **时区处理能力弱**：时区支持有限且复杂。
5. **API设计糟糕**：方法命名混乱，难以使用。

Java 8 引入了新的 `java.time` 包，基于 JSR-310 规范，具有以下特性：

1. **不可变性**：所有核心类都是不可变的，线程安全。
2. **清晰性**：API 设计清晰，职责分明。
3. **直观性**：月份从1开始，符合人类习惯。
4. **时区支持完善**：提供了完整的时区处理能力。
5. **丰富的计算能力**：提供了日期加减、时间差计算等功能。

### 2.2 java.time 核心类

| 类名 | 说明 |
|------|------|
| `LocalDate` | 日期（年-月-日），不含时间 |
| `LocalTime` | 时间（时:分:秒.纳秒），不含日期 |
| `LocalDateTime` | 日期+时间，不含时区信息 |
| `Instant` | 时间戳（纳秒精度） |
| `ZonedDateTime` | 带时区的日期时间 |
| `Period` | 日期差（年、月、日） |
| `Duration` | 时间差（时、分、秒、纳秒） |
| `DateTimeFormatter` | 日期时间格式化 |
| `ZoneId` | 时区ID |

### 3.5 Period（日期差）

```java
import java.time.Period;

public class PeriodDemo {
```

## 第六章 时区处理

### 6.1 ZoneId 和 ZonedDateTime

```java
import java.time.ZoneId;
import java.time.ZonedDateTime;
import java.time.LocalDateTime;
import java.util.Set;

public class TimeZoneDemo {
    public static void main(String[] args) {
        // 获取所有时区ID
        Set<String> zones = ZoneId.getAvailableZoneIds();
        // System.out.println("可用时区数量：" + zones.size());

        // 获取系统默认时区
        ZoneId defaultZone = ZoneId.systemDefault();
        System.out.println("系统默认时区：" + defaultZone);

        // 创建指定时区的 ZoneId
        ZoneId shanghai = ZoneId.of("Asia/Shanghai");
        ZoneId tokyo = ZoneId.of("Asia/Tokyo");
        ZoneId newYork = ZoneId.of("America/New_York");

        // 获取带时区的日期时间
        ZonedDateTime nowShanghai = ZonedDateTime.now(shanghai);
        ZonedDateTime nowTokyo = ZonedDateTime.now(tokyo);
        ZonedDateTime nowNewYork = ZonedDateTime.now(newYork);

        System.out.println("上海时间：" + nowShanghai);
        System.out.println("东京时间：" + nowTokyo);
        System.out.println("纽约时间：" + nowNewYork);

        // 时区转换
        ZonedDateTime zdt = ZonedDateTime.now();
        System.out.println("当前时区时间：" + zdt);

        ZonedDateTime tokyoTime = zdt.withZoneSameInstant(tokyo);
        System.out.println("东京时间：" + tokyoTime);

        // LocalDateTime 转换为 ZonedDateTime
        LocalDateTime ldt = LocalDateTime.now();
        ZonedDateTime zdt2 = ldt.atZone(shanghai);
        System.out.println("LocalDateTime + 时区：" + zdt2);
    }
}
```

## 第七章 格式化与解析

### 7.1 DateTimeFormatter

`DateTimeFormatter` 是 `java.time` 包中的格式化工具，线程安全且功能强大。

```java
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;
import java.time.format.FormatStyle;

public class DateTimeFormatterDemo {
    public static void main(String[] args) {
        LocalDateTime now = LocalDateTime.now();

        // 预定义格式
        DateTimeFormatter isoFormatter = DateTimeFormatter.ISO_LOCAL_DATE_TIME;
        System.out.println("ISO: " + isoFormatter.format(now));

        // 自定义格式
        DateTimeFormatter formatter1 = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
        System.out.println("yyyy-MM-dd HH:mm:ss: " + now.format(formatter1));

        DateTimeFormatter formatter2 = DateTimeFormatter.ofPattern("yyyy年MM月dd日 HH:mm:ss");
        System.out.println("yyyy年MM月dd日: " + now.format(formatter2));

        DateTimeFormatter formatter3 = DateTimeFormatter.ofPattern("yyyy/MM/dd E HH:mm");
        System.out.println("yyyy/MM/dd E: " + now.format(formatter3));

        // 解析字符串
        String dateStr = "2026-08-12 14:30:45";
        LocalDateTime parsed = LocalDateTime.parse(dateStr, formatter1);
        System.out.println("解析结果：" + parsed);

        // 使用 withZone 指定时区
        DateTimeFormatter formatterWithZone = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss Z")
                .withZone(java.time.ZoneId.of("Asia/Shanghai"));
        String formattedWithZone = formatterWithZone.format(now);
        System.out.println("带时区：" + formattedWithZone);
    }
}
```

## 第八章 综合示例

```java
import java.time.*;
import java.time.format.DateTimeFormatter;
import java.time.temporal.ChronoUnit;
import java.util.*;

/**
 * 日期时间工具类
 */
public class DateTimeUtils {
    // 日期格式常量
    public static final String DATE_PATTERN = "yyyy-MM-dd";
    public static final String TIME_PATTERN = "HH:mm:ss";
    public static final String DATETIME_PATTERN = "yyyy-MM-dd HH:mm:ss";

    // 日期格式化器（线程安全）
    private static final DateTimeFormatter DATE_FORMATTER = DateTimeFormatter.ofPattern(DATE_PATTERN);
    private static final DateTimeFormatter TIME_FORMATTER = DateTimeFormatter.ofPattern(TIME_PATTERN);
    private static final DateTimeFormatter DATETIME_FORMATTER = DateTimeFormatter.ofPattern(DATETIME_PATTERN);

    /**
     * 获取当前日期
     */
    public static LocalDate getToday() {
        return LocalDate.now();
    }

    /**
     * 获取当前时间
     */
    public static LocalTime getCurrentTime() {
        return LocalTime.now();
    }

    /**
     * 获取当前日期时间
     */
    public static LocalDateTime getCurrentDateTime() {
        return LocalDateTime.now();
    }

    /**
     * 格式化日期
     */
    public static String formatDate(LocalDate date) {
        return date != null ? DATE_FORMATTER.format(date) : "";
    }

    /**
     * 格式化日期时间
     */
    public static String formatDateTime(LocalDateTime dateTime) {
        return dateTime != null ? DATETIME_FORMATTER.format(dateTime) : "";
    }

    /**
     * 解析日期
     */
    public static LocalDate parseDate(String dateStr) {
        try {
            return LocalDate.parse(dateStr, DATE_FORMATTER);
        } catch (Exception e) {
            return null;
        }
    }

    /**
     * 解析日期时间
     */
    public static LocalDateTime parseDateTime(String dateTimeStr) {
        try {
            return LocalDateTime.parse(dateTimeStr, DATETIME_FORMATTER);
        } catch (Exception e) {
            return null;
        }
    }

    /**
     * 计算两个日期之间的天数差
     */
    public static long daysBetween(LocalDate start, LocalDate end) {
        return start.until(end, ChronoUnit.DAYS);
    }

    /**
     * 计算两个日期时间之间的分钟差
     */
    public static long minutesBetween(LocalDateTime start, LocalDateTime end) {
        return start.until(end, ChronoUnit.MINUTES);
    }

    /**
     * 获取某月的第一天
     */
    public static LocalDate getFirstDayOfMonth(int year, int month) {
        return LocalDate.of(year, month, 1);
    }

    /**
     * 获取某月的最后一天
     */
    public static LocalDate getLastDayOfMonth(int year, int month) {
        return LocalDate.of(year, month, 1).withDayOfMonth(
                LocalDate.of(year, month, 1).lengthOfMonth()
        );
    }

    /**
     * 获取年龄（周岁）
     */
    public static int getAge(LocalDate birthDate) {
        if (birthDate == null) return -1;
        return Period.between(birthDate, LocalDate.now()).getYears();
    }

    /**
     * 判断是否为周末
     */
    public static boolean isWeekend(LocalDate date) {
        DayOfWeek dow = date.getDayOfWeek();
        return dow == DayOfWeek.SATURDAY || dow == DayOfWeek.SUNDAY;
    }

    /**
     * 获取两个日期之间的所有日期列表
     */
    public static List<LocalDate> getDateRange(LocalDate start, LocalDate end) {
        List<LocalDate> dates = new ArrayList<>();
        LocalDate current = start;
        while (!current.isAfter(end)) {
            dates.add(current);
            current = current.plusDays(1);
        }
        return dates;
    }

    /**
     * 判断日期时间是否在某个时间范围内（开区间，不包含边界）
     */
    public static boolean isBetween(LocalDateTime target, LocalDateTime start, LocalDateTime end) {
        return target.isAfter(start) && target.isBefore(end);
    }

    public static void main(String[] args) {
        System.out.println("=== 日期时间工具类测试 ===");

        // 当前时间
        System.out.println("今天：" + formatDate(getToday()));
        System.out.println("当前时间：" + formatDateTime(getCurrentDateTime()));

        // 日期解析
        LocalDate date = parseDate("2026-08-12");
        System.out.println("解析日期：" + date);

        // 日期差
        LocalDate start = LocalDate.of(2026, 8, 1);
        LocalDate end = LocalDate.of(2026, 8, 31);
        System.out.println("8月1日到8月31日相差" + daysBetween(start, end) + "天");

        // 年龄计算
        LocalDate birth = LocalDate.of(2000, 1, 1);
        System.out.println("出生日期：" + birth);
        System.out.println("年龄：" + getAge(birth) + "岁");

        // 判断周末
        System.out.println("2026-08-12是周末吗：" + isWeekend(date));

        // 日期范围
        System.out.println("8月1日到8月5日：");
        for (LocalDate d : getDateRange(LocalDate.of(2026, 8, 1), LocalDate.of(2026, 8, 5))) {
            System.out.println("  " + formatDate(d));
        }

        // 时区转换
        ZonedDateTime beijing = ZonedDateTime.now(ZoneId.of("Asia/Shanghai"));
        ZonedDateTime tokyo = beijing.withZoneSameInstant(ZoneId.of("Asia/Tokyo"));
        System.out.println("北京时间：" + formatDateTime(beijing.toLocalDateTime()));
        System.out.println("东京时间：" + formatDateTime(tokyo.toLocalDateTime()));
    }
}
```

## 总结

本文系统讲解了Java中的日期与时间处理：

| 知识点 | 核心要点 |
|--------|---------|
| **传统 Date/Calendar** | 存在设计缺陷，不推荐新项目使用 |
| **LocalDate** | 日期（年-月-日），不可变，线程安全 |
| **LocalTime** | 时间（时:分:秒.纳秒），不可变 |
| **LocalDateTime** | 日期+时间，不含时区 |
| **ZonedDateTime** | 带时区的日期时间 |
| **Instant** | 时间戳（UTC），适合跨时区场景 |
| **Period** | 日期差（年、月、日） |
| **Duration** | 时间差（时、分、秒） |
| **DateTimeFormatter** | 线程安全的日期格式化工具 |
