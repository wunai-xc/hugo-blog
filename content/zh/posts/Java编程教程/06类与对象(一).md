## 引言

在前五篇文章中，我们学习了Java的基本语法、数据类型、运算符、流程控制和数组。这些内容属于**面向过程编程**的范畴——我们将程序分解为一系列步骤，数据和处理数据的操作是分离的。

然而，Java本质上是一门**面向对象**（Object-Oriented Programming, OOP）的语言。面向对象编程将现实世界中的事物抽象为**对象**，通过对象之间的交互来解决问题。这种编程范式更贴近人类的自然思维方式，使得程序更易于理解、扩展和维护。

从本文开始，我们将正式进入Java面向对象编程的世界。本文将系统讲解类与对象的基本概念、类的定义与实例化、构造方法、`this` 关键字以及成员变量与局部变量的区别。

## 第一章 面向对象编程概述

### 1.1 什么是面向对象

**面向对象编程**（Object-Oriented Programming）是一种编程范式，它将现实世界中的事物抽象为**对象**，每个对象包含**属性**（数据）和**行为**（方法）。通过对象之间的交互来构建程序。

**对比两种编程范式**：

| 对比维度 | 面向过程（如C语言） | 面向对象（如Java） |
|---------|-------------------|-------------------|
| 基本单元 | 函数（方法） | 对象（类） |
| 数据与操作 | 分离 | 封装在一起 |
| 关注点 | “怎么做”（步骤） | “做什么”（对象交互） |
| 代码复用 | 函数复用 | 继承、多态 |
| 扩展性 | 修改困难 | 易于扩展 |
| 典型应用 | 系统编程、嵌入式 | 大型企业应用、GUI |

### 1.2 面向对象的三大特征

面向对象编程有三大核心特征：

1. **封装（Encapsulation）** ：将数据和操作数据的方法绑定在一起，隐藏内部实现细节，对外只暴露必要的接口。
2. **继承（Inheritance）** ：子类可以继承父类的属性和方法，实现代码复用，建立类之间的层次关系。
3. **多态（Polymorphism）** ：同一个方法在不同对象上可以有不同的行为表现，提高代码的灵活性和可扩展性。

### 1.3 类与对象的关系

**类（Class）** 是对象的蓝图或模板，定义了对象应该具有的属性和方法。

**对象（Object）** 是根据类创建的具体实例，每个对象都有自己的状态（属性值）。

```
类 = 蓝图 / 模具
对象 = 根据蓝图制造出来的具体产品
```

```text
┌─────────────────────────────┐
│          类（Class）         │
│  ┌─────────────────────────┐│
│  │    属性（成员变量）      ││

│  └─────────────────────────┘│

│  │    方法（行为）          ││
│  │    eat(), sleep(), work()││
│  └─────────────────────────┘│

              │
              ▼
┌─────────────────────────────┐

│   ┌───────────────────────┐ │
│   │  对象1：张三，25岁     │ │
│   └───────────────────────┘ │

│   │  对象2：李四，30岁     │ │
│   └───────────────────────┘ │
└─────────────────────────────┘
```

## 第二章 类的定义

### 2.1 类的基本结构

一个类通常包含以下组成部分：

```java
[访问修饰符] class 类名 {
    // 1. 成员变量（属性/字段）
    // 2. 构造方法（Constructor）
    // 3. 成员方法（行为）
    // 4. 初始化块（可选）
    // 5. 内部类（可选）
}
```

### 2.2 定义一个简单的类

下面以 `Student` 类为例，展示类的定义方式。

```java
/**
 * 学生类 - 用于描述学生信息
 */
public class Student {
    // 1. 成员变量（属性）
    // 学生的姓名
    private String name;
    // 学生的年龄
    private int age;
    // 学生的学号
    private String studentId;

    // 2. 构造方法（稍后详细讲解）

    // 3. 成员方法（行为）
    // 学习
    public void study() {
        System.out.println(name + "正在学习...");
    }

    // 自我介绍
    public void introduce() {
        System.out.println("大家好，我是" + name + "，今年" + age + "岁，学号是" + studentId);
    }

    // 获取姓名（Getter）
    public String getName() {
        return name;
    }

    // 设置姓名（Setter）
    public void setName(String name) {
        this.name = name;
    }

    // 获取年龄
    public int getAge() {
        return age;
    }

    // 设置年龄（可添加业务逻辑校验）
    public void setAge(int age) {
        if (age < 0 || age > 150) {
            System.out.println("年龄不合法！");
        } else {
            this.age = age;
        }
    }

    // 获取学号
    public String getStudentId() {
        return studentId;
    }

    // 设置学号
    public void setStudentId(String studentId) {
        this.studentId = studentId;
    }
}
```

### 2.3 命名规范

| 元素 | 命名规范 | 示例 |
|------|---------|------|
| **类名** | 大驼峰（PascalCase） | `Student`、`StudentManager` |
| **成员变量** | 小驼峰（camelCase） | `studentName`、`age` |
| **方法名** | 小驼峰，动词开头 | `getName()`、`setAge()`、`study()` |
| **常量** | 全大写，下划线分隔 | `MAX_STUDENTS`、`PI` |

## 第三章 对象的创建与使用

定义类之后，需要通过 `new` 关键字创建该类的对象。

### 3.1 创建对象

```java
public class StudentTest {
    public static void main(String[] args) {
        // 创建 Student 对象
        Student student1 = new Student();

        // 另一种写法：先声明再实例化
        Student student2;
        student2 = new Student();

        // 使用对象
        student1.setName("张三");
        student1.setAge(20);
        student1.setStudentId("S001");

        student1.introduce(); // 大家好，我是张三，今年20岁，学号是S001
        student1.study();     // 张三正在学习...
    }
}
```

### 3.2 对象的内存分析

理解对象在内存中的存储方式，有助于理解Java的内存管理机制。

```text
栈内存 (Stack)                    堆内存 (Heap)
┌─────────────────────┐          ┌─────────────────────────┐
│     main()          │          │      Student对象         │
│  ┌─────────────────┐│          │  ┌─────────────────────┐│
│  │ student1 ───────┼┼──────────┼→│ name = "张三"        ││
│  └─────────────────┘│          │  │ age = 20             ││
│                     │          │  │ studentId = "S001"   ││
│                     │          │  └─────────────────────┘│
│                     │          │                         │
│                     │          │      Student对象         │
│                     │          │  ┌─────────────────────┐│
│                     │          │  │ name = "李四"        ││
│                     │          │  │ age = 22             ││
│                     │          │  │ studentId = "S002"   ││
│                     │          │  └─────────────────────┘│
└─────────────────────┘          └─────────────────────────┘
```

**内存分配说明**：

1. **栈内存**：存储局部变量和方法调用的执行环境。`student1` 和 `student2` 是引用变量，存储的是堆内存中对象的地址。
2. **堆内存**：存储对象实例。每个对象都占据堆内存中的一块空间，包含成员变量的值。
3. **方法区**：存储类信息（字节码）、静态变量等。

## 第四章 构造方法

**构造方法**（Constructor）是一种特殊的方法，用于在创建对象时初始化对象的状态。构造方法在 `new` 对象时自动调用。

### 4.1 构造方法的定义

构造方法与普通方法有以下区别：

1. 构造方法的名称**必须与类名完全相同**。
2. 构造方法**没有返回值类型**（连 `void` 也不能写）。
3. 构造方法**不能显式调用**，只能在 `new` 对象时被自动调用。
4. 构造方法**可以重载**（定义多个参数列表不同的构造方法）。

```java
public class Person {
    private String name;
    private int age;

    // 无参构造方法（默认构造方法）
    public Person() {
        System.out.println("无参构造方法被调用");
    }

    // 带一个参数的构造方法
    public Person(String name) {
        this.name = name;
        System.out.println("带一个参数的构造方法被调用");
    }

    // 带两个参数的构造方法
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
        System.out.println("带两个参数的构造方法被调用");
    }

    // 普通方法（不是构造方法）
    public void display() {
        System.out.println("姓名：" + name + "，年龄：" + age);
    }

    public static void main(String[] args) {
        Person p1 = new Person();              // 调用无参构造方法
        Person p2 = new Person("张三");        // 调用单参构造方法
        Person p3 = new Person("李四", 25);     // 调用双参构造方法

        p1.display(); // 姓名：null，年龄：0
        p2.display(); // 姓名：张三，年龄：0
        p3.display(); // 姓名：李四，年龄：25
    }
}
```

### 4.2 默认构造方法

如果类中**没有定义任何构造方法**，Java编译器会自动提供一个**默认无参构造方法**，其方法体为空。

```java
public class DefaultConstructorDemo {
    private int value;

    // 没有定义任何构造方法，编译器提供默认无参构造方法
    // 等效于：
    // public DefaultConstructorDemo() {
    //     super();
    // }

    public static void main(String[] args) {
        // 可以调用默认构造方法
        DefaultConstructorDemo demo = new DefaultConstructorDemo();
        System.out.println("value = " + demo.value); // 0
    }
}
```

**重要规则**：如果类中**定义了任何构造方法**（无论是否有参），编译器就**不再提供默认无参构造方法**。

```java
public class NoDefaultDemo {
    private String name;

    // 定义了有参构造方法，编译器不再提供默认无参构造方法
    public NoDefaultDemo(String name) {
        this.name = name;
    }

    public static void main(String[] args) {
        // NoDefaultDemo demo = new NoDefaultDemo(); // 错误！没有无参构造方法
        NoDefaultDemo demo = new NoDefaultDemo("张三"); // 正确
    }
}
```

### 4.3 构造方法的优点

使用构造方法初始化对象比使用 setter 方法更具优势：

1. **简洁性**：一行代码即可完成对象的初始化和赋值。
2. **原子性**：对象创建和初始化是一个整体操作，避免对象处于“半成品”状态。
3. **不可变性**：配合 `final` 字段，可以创建不可变对象。
4. **强制约束**：通过参数校验，确保对象在创建时就满足业务规则。

```java
// 使用无参构造 + setter
Student student = new Student();
student.setName("张三");
student.setAge(20);
student.setStudentId("S001");

// 使用有参构造（一行完成）
Student student = new Student("张三", 20, "S001");
```

### 4.4 构造方法重载

构造方法也支持重载，即定义多个参数列表不同的构造方法，以适应不同的初始化场景。

```java
public class Book {
    private String title;
    private String author;
    private double price;

    // 无参构造
    public Book() {}

    // 只初始化书名
    public Book(String title) {
        this.title = title;
    }

    // 初始化书名和作者
    public Book(String title, String author) {
        this.title = title;
        this.author = author;
    }

    // 初始化所有属性
    public Book(String title, String author, double price) {
        this.title = title;
        this.author = author;
        this.price = price;
    }

    // ... getter / setter 方法
}
```

### 4.5 构造方法的链式调用（this()）

在一个构造方法中，可以使用 `this()` 调用本类的其他构造方法，避免重复代码。

```java
public class Product {
    private String name;
    private double price;
    private String category;

    // 三个参数的构造方法（最完整的构造方法）
    public Product(String name, double price, String category) {
        this.name = name;
        this.price = price;
        this.category = category;
    }

    // 两个参数的构造方法，调用三个参数的构造方法
    public Product(String name, double price) {
        this(name, price, "未分类"); // 调用上面的构造方法
    }

    // 一个参数的构造方法，调用两个参数的构造方法
    public Product(String name) {
        this(name, 0.0); // 调用上面的构造方法
    }

    public void display() {
        System.out.println("商品：" + name + "，价格：" + price + "，分类：" + category);
    }

    public static void main(String[] args) {
        Product p1 = new Product("苹果手机");
        p1.display(); // 商品：苹果手机，价格：0.0，分类：未分类

        Product p2 = new Product("笔记本电脑", 5999.0);
        p2.display(); // 商品：笔记本电脑，价格：5999.0，分类：未分类

        Product p3 = new Product("平板电脑", 2999.0, "数码产品");
        p3.display(); // 商品：平板电脑，价格：2999.0，分类：数码产品
    }
}
```

> **`this()` 调用规则**：必须放在构造方法的第一行，且只能调用一次。

## 第五章 this 关键字

`this` 关键字在 Java 中代表“当前对象”的引用，它指向正在执行方法的对象。

### 5.1 this 的常见用途

**1. 区分成员变量和局部变量（参数重名）**

当参数名称与成员变量名称相同时，使用 `this` 来区分。

```java
public class Person {
    private String name;

    // 参数名与成员变量名相同
    public void setName(String name) {
        // 左侧的 this.name 是成员变量
        // 右侧的 name 是方法参数（局部变量）
        this.name = name;
    }
}
```

**2. 在构造方法中调用其他构造方法（this()）**

参见 4.5 节。

**3. 作为方法的返回值（链式调用）**

```java
public class Calculator {
    private int value;

    public Calculator add(int num) {
        this.value += num;
        return this; // 返回当前对象
    }

    public Calculator subtract(int num) {
        this.value -= num;
        return this;
    }

    public int getResult() {
        return this.value;
    }

    public static void main(String[] args) {
        // 链式调用（方法链）
        int result = new Calculator()
            .add(5)
            .add(3)
            .subtract(2)
            .getResult();
        System.out.println(result); // 6
    }
}
```

**4. 作为参数传递给其他方法**

```java
public class Printer {
    public void print(Student student) {
        System.out.println("打印学生信息：" + student.getName());
    }

    public void printSelf() {
        // 将当前对象作为参数传递
        print(this);
    }
}
```

### 5.2 this 的注意事项

- `this` 只能在**非静态方法**中使用，不能出现在 `static` 方法中。
- `this` 代表当前对象，在构造方法中，它指向正在被初始化的对象。
- `this()` 调用本类其他构造方法时，必须放在构造方法的第一行。

## 第六章 成员变量与局部变量

### 6.1 定义与区别

| 对比维度 | 成员变量 | 局部变量 |
|---------|---------|---------|
| **定义位置** | 类中，方法外 | 方法内部或方法参数 |
| **作用域** | 整个类（所有非静态方法可访问） | 仅限声明它的方法或代码块 |
| **默认值** | 有默认值（0、null、false等） | 必须显式初始化，无默认值 |
| **生命周期** | 随对象的创建而创建，随对象的销毁而销毁 | 随方法调用而创建，方法结束后销毁 |
| **存储位置** | 堆内存（对象中） | 栈内存 |
| **修饰符** | 可用 `private`、`public` 等 | 不能使用 `private`、`public` 等访问修饰符 |

```java
public class VariableDemo {
    // 成员变量（实例变量）
    private int instanceVar = 10;
    // 静态成员变量（类变量）
    private static int staticVar = 20;

    public void method1() {
        // 局部变量
        int localVar = 30;
        System.out.println("局部变量：" + localVar);
        System.out.println("成员变量：" + instanceVar);
        System.out.println("静态变量：" + staticVar);
    }

    public void method2() {
        // System.out.println(localVar); // 错误！localVar在method2中不可见
        System.out.println("成员变量：" + instanceVar); // 正确
        System.out.println("静态变量：" + staticVar);   // 正确
    }
}
```

### 6.2 变量冲突与优先级

当局部变量与成员变量同名时，就近原则（局部变量优先）。

```java
public class VariableConflict {
    private int value = 100; // 成员变量

    public void test(int value) { // 参数也是局部变量
        System.out.println(value);       // 输出参数值（局部变量优先）
        System.out.println(this.value);  // 输出成员变量（使用this区分）
    }

    public static void main(String[] args) {
        VariableConflict demo = new VariableConflict();
        demo.test(50); // 50, 100
    }
}
```

## 第七章 综合示例

以下是一个完整的学生管理系统示例，综合运用了类、对象、构造方法、封装等知识。

```java
/**
 * 学生类
 */
class Student {
    private String id;
    private String name;
    private int age;
    private String major;

    // 无参构造
    public Student() {}

    // 全参构造
    public Student(String id, String name, int age, String major) {
        this.id = id;
        this.name = name;
        this.age = age;
        this.major = major;
    }

    // getter / setter 方法
    public String getId() { return id; }
    public void setId(String id) { this.id = id; }

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }

    public int getAge() { return age; }
    public void setAge(int age) {
        if (age >= 0 && age <= 150) {
            this.age = age;
        } else {
            System.out.println("年龄不合法！");
        }
    }

    public String getMajor() { return major; }
    public void setMajor(String major) { this.major = major; }

    // 学习行为
    public void study() {
        System.out.println(name + "正在学习" + major + "专业课程...");
    }

    // 展示信息
    public void display() {
        System.out.println("学号：" + id + "，姓名：" + name +
                          "，年龄：" + age + "，专业：" + major);
    }

    // toString 方法
    @Override
    public String toString() {
        return "Student{id='" + id + "', name='" + name +
               "', age=" + age + ", major='" + major + "'}";
    }
}

/**
 * 学生管理系统测试
 */
public class StudentManagement {
    public static void main(String[] args) {
        // 创建学生对象
        Student s1 = new Student("S001", "张三", 20, "计算机科学");
        Student s2 = new Student("S002", "李四", 22, "软件工程");

        // 使用对象
        s1.display();
        s1.study();
        System.out.println(s1);

        System.out.println();

        s2.display();
        s2.study();
        System.out.println(s2);

        // 使用setter修改信息
        s1.setAge(21);
        System.out.println("\n修改后：");
        s1.display();
    }
}
```

| **对象** | 类的实例，通过 `new` 创建 |
| **封装** | `private` 成员变量 + `public` getter/setter |
| **构造方法** | 初始化对象，名称与类名相同，无返回值 |
| **构造方法重载** | 多个构造方法适应不同初始化场景 |
| **this** | 当前对象引用，用于区分成员变量和局部变量 |
| **成员变量 vs 局部变量** | 定义位置、作用域、默认值、生命周期等区别 |
