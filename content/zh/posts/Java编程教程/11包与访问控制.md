## 引言

随着应用程序规模的增长，代码量会迅速膨胀。如果没有有效的组织方式，所有的类就会像散落的文件一样难以管理。同时，类与类之间的访问权限也需要精确控制，以保障代码的安全性和可维护性。

Java通过**包（Package）** 和**访问控制（Access Control）** 两套机制来解决这两个问题。

**包**是类的容器，用于将相关的类组织在一起，避免命名冲突，提高代码的可维护性。**访问控制**则是通过四种访问修饰符（`private`、默认、`protected`、`public`）来精确控制类、方法和变量的可见范围。

本文将系统讲解Java中的包机制与访问控制，包括包的声明与使用、`import` 语句、四种访问修饰符的详细对比、包的组织结构以及 `CLASSPATH` 的概念与配置。

## 第一章 包（Package）

### 1.1 什么是包

**包**（Package）是Java中用于组织类和接口的命名空间机制。它类似于操作系统中的文件夹，可以将相关的类放在同一个包中，便于管理和使用。

**包的主要作用**：

1. **避免命名冲突**：不同包中的类可以有相同的名字。
2. **实现访问控制**：包是访问修饰符的边界之一（默认访问权限只能在同一个包内访问）。
3. **组织代码结构**：将相关的类组织在一起，提高代码的可读性和可维护性。
4. **便于分发**：包可以打包成 `.jar` 文件发布。

### 1.2 包的定义

使用 `package` 关键字声明包，它必须是源文件中的**第一行非注释代码**。

```java
// 声明包
package com.example.myproject;

// 导入其他包
import java.util.ArrayList;
import java.util.List;

// 类定义
public class MyClass {
    // ...
}
```

**包命名规范**：

- 通常使用**小写字母**。
- 采用**域名倒置**的方式，以确保全球唯一性。
- 例如：`com.example.project`、`org.apache.commons`。

```text
com
  └── example
        └── myproject
              ├── model
              │   ├── User.java
              │   └── Product.java
              ├── service
              │   ├── UserService.java
              │   └── ProductService.java
              └── util
                    └── StringUtils.java
```

### 1.3 导入包

使用 `import` 语句可以导入其他包中的类，避免使用完全限定名。

**完全限定名（Fully Qualified Name）** = 包名 + 类名，例如 `java.util.ArrayList`。

#### 单类型导入

```java
import java.util.ArrayList;
import java.util.List;

public class ImportDemo {
    public static void main(String[] args) {
        // 可以直接使用类名，不需要写完整的包名
        List<String> list = new ArrayList<>();
        list.add("Hello");
        System.out.println(list);
    }
}
```

#### 通配符导入

使用 `*` 可以导入包中的所有类，但不推荐（降低代码可读性）。

```java
import java.util.*;   // 导入 java.util 包中的所有类
import java.io.*;     // 导入 java.io 包中的所有类

public class WildcardImportDemo {
    public static void main(String[] args) {
        List<String> list = new ArrayList<>();
        File file = new File("test.txt");
        // 注意：如果有同名的类，会产生冲突
    }
}
```

#### 静态导入

`import static` 用于导入类的静态成员（静态变量和静态方法），允许直接使用静态成员而不需要类名前缀。

```java
import static java.lang.Math.*;
import static java.lang.System.out;

public class StaticImportDemo {
    public static void main(String[] args) {
        // 使用静态导入后，不需要写 Math. 或 System.out.
        out.println("PI = " + PI);
        out.println("sqrt(16) = " + sqrt(16));
        out.println("max(10, 20) = " + max(10, 20));
    }
}
```

### 1.4 包命名冲突与解决

当两个包中有同名的类时，会产生命名冲突。解决方法：

1. 使用**完全限定名**。
2. 只导入一个包中的类，另一个使用完全限定名。
3. 使用 `import` 时注意避免歧义。

```java
import java.util.Date;        // 导入 java.util.Date
// import java.sql.Date;      // 冲突！不能同时导入两个同名类

public class DateDemo {
    public static void main(String[] args) {
        // 使用完全限定名访问 java.sql.Date
        java.sql.Date sqlDate = new java.sql.Date(System.currentTimeMillis());
        // 使用导入的 java.util.Date
        Date utilDate = new Date();

        System.out.println("SQL Date: " + sqlDate);
        System.out.println("Util Date: " + utilDate);
    }
}
```

## 第二章 访问修饰符

Java提供了四种访问修饰符，用于控制类、方法和变量的可见范围。

### 2.1 四种访问修饰符总览

| 修饰符 | 同一类 | 同一包 | 子类（不同包） | 所有类 |
|--------|--------|--------|---------------|--------|
| `private` | ✅ | ❌ | ❌ | ❌ |
| 默认（无修饰符） | ✅ | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ | ✅ |

### 2.2 详细说明

#### private（私有）

`private` 是最严格的访问修饰符，被修饰的成员**只能在当前类内部访问**。

```java
public class BankAccount {
    private double balance;       // 私有变量
    private String accountNumber; // 私有变量

    public BankAccount(String accountNumber, double initialBalance) {
        this.accountNumber = accountNumber;
        this.balance = initialBalance;
    }

    // 通过公共方法访问私有成员
    public double getBalance() {
        return balance;
    }

    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    // 私有方法：类内部使用
    private void logTransaction(String type, double amount) {
        System.out.println(type + ": " + amount + "，余额：" + balance);
    }
}

class Test {
    public static void main(String[] args) {
        BankAccount account = new BankAccount("123456", 1000);
        // account.balance = 2000;   // 错误！private 不可访问
        // account.logTransaction("测试", 100); // 错误！private 不可访问
        account.deposit(500);          // 正确：通过公共方法访问
        System.out.println(account.getBalance()); // 1500.0
    }
}
```

#### 默认访问（包级私有）

没有写任何访问修饰符时，成员**只能在同一个包内访问**。

```java
// File: com/example/package1/DefaultDemo.java
package com.example.package1;

class DefaultDemo {           // 默认访问：只有同一包可以访问
    int value = 10;           // 默认访问
    void method() {}          // 默认访问
}

// File: com/example/package1/TestSamePackage.java（同一包）
package com.example.package1;

class TestSamePackage {
    public static void main(String[] args) {
        DefaultDemo demo = new DefaultDemo(); // ✅ 可以访问（同一包）
        demo.value = 20;                       // ✅ 可以访问
        demo.method();                         // ✅ 可以访问
    }
}

// File: com/example/package2/TestDifferentPackage.java（不同包）
package com.example.package2;

import com.example.package1.DefaultDemo; // 错误！DefaultDemo 类不是 public

class TestDifferentPackage {
    public static void main(String[] args) {
        // DefaultDemo demo = new DefaultDemo(); // ❌ 不可访问（不同包）
    }
}
```

#### protected（受保护）

`protected` 修饰的成员可以在**同一包内的任何类**以及**不同包的子类**中访问。

```java
// File: com/example/parent/Parent.java
package com.example.parent;

public class Parent {
    protected int value = 100;
    protected void method() {
        System.out.println("Parent method");
    }

    // protected 构造方法
    protected Parent() {
        System.out.println("Parent constructor");
    }
}

// File: com/example/parent/TestSamePackage.java（同一包）
package com.example.parent;

class TestSamePackage {
    public static void main(String[] args) {
        Parent p = new Parent();      // ✅ protected 构造方法在包内可访问
        p.value = 200;                // ✅ 可访问
        p.method();                   // ✅ 可访问
    }
}

// File: com/example/child/Child.java（不同包，子类）
package com.example.child;

import com.example.parent.Parent;

public class Child extends Parent {
    public Child() {
        // 子类构造方法可以调用 protected 父类构造方法
        super();                      // ✅ 可访问
        this.value = 300;             // ✅ 可访问（子类继承了 protected 成员）
        this.method();                // ✅ 可访问

        Parent p = new Parent();
        // p.value = 400;             // ❌ 错误！不是通过子类引用访问
    }
}

// File: com/example/other/OtherClass.java（不同包，非子类）
package com.example.other;

import com.example.parent.Parent;

class OtherClass {
    public static void main(String[] args) {
        Parent p = new Parent();
        // p.value = 500;             // ❌ 错误！protected 成员不可访问
        // p.method();                // ❌ 错误！
    }
}
```

#### public（公共）

`public` 是最宽松的修饰符，**所有类都可以访问**。

```java
// File: com/example/utils/PublicUtils.java
package com.example.utils;

public class PublicUtils {
    public static final String VERSION = "1.0.0";

    public static void printMessage(String msg) {
        System.out.println(msg);
    }

    private static void internalHelper() {
        // 类内部私有方法
    }
}

// 任何包中的类都可以访问
import com.example.utils.PublicUtils;

public class AnyClass {
    public static void main(String[] args) {
        PublicUtils.printMessage("Hello, World!");
        System.out.println(PublicUtils.VERSION);
    }
}
```

### 2.3 访问修饰符的使用建议

| 场景 | 推荐修饰符 | 理由 |
|------|-----------|------|
| 成员变量（字段） | `private` | 封装数据，防止外部直接修改 |
| 类内部使用的方法 | `private` | 隐藏实现细节 |
| 被同一包内其他类调用的方法 | 默认（包级私有） | 限制在包内使用 |
| 需要被子类继承的方法 | `protected` | 为子类提供扩展接口 |
| 对外公开的API | `public` | 供所有调用者使用 |
| 工具类中的常量 | `public static final` | 全局可用 |
| 工具类的构造方法 | `private` | 防止实例化 |
| 框架或库的SPI接口 | `public` | 供外部实现 |

### 2.4 类和接口的访问修饰符

**类和接口**也可以使用访问修饰符：

```java
// public 类：任何地方都可以访问
public class PublicClass {
    // ...
}

// 默认类：只能在同一个包内访问
class PackageClass {
    // ...
}

// 接口通常使用 public
public interface PublicInterface {
    // ...
}
```

## 第三章 包的组织与设计

### 3.1 包的层次结构

Java包的层次结构通常反映项目的架构层次：

```text
com.example.myapp
├── controller          // 控制器层（MVC）
│   └── UserController.java
├── service             // 服务层（业务逻辑）
│   ├── UserService.java
│   └── impl
│       └── UserServiceImpl.java
├── repository          // 数据访问层
│   └── UserRepository.java
├── model               // 数据模型
│   ├── User.java
│   └── Product.java
├── util                // 工具类
│   └── StringUtils.java
├── config              // 配置类
│   └── AppConfig.java
└── exception           // 异常类
    └── BusinessException.java
```

### 3.2 包设计原则

1. **单一职责**：一个包中的类应该负责相关的功能。
2. **高内聚、低耦合**：包内部类之间紧密协作，包之间依赖关系尽量简单。
3. **避免循环依赖**：包之间不应形成循环依赖关系。
4. **按功能划分**：而非按类型划分（如将所有模型放在一起，所有服务放在一起）。

### 3.3 CLASSPATH

**CLASSPATH** 是Java运行时查找类和包的搜索路径。当JVM需要加载一个类时，它会在CLASSPATH中依次查找。

#### 配置方式

**1. 系统环境变量**：设置 `CLASSPATH` 环境变量。

```bash
# Windows
set CLASSPATH=C:\myapp\lib\*;.;

# Linux/Mac
export CLASSPATH=/home/user/myapp/lib/*:.
```

**2. 命令行参数**：使用 `-cp` 或 `-classpath` 参数。

```bash
java -cp .:lib/* com.example.Main
```

**3. 在IDE中配置**：通过项目结构设置类路径。

#### 默认CLASSPATH

如果未设置CLASSPATH，JVM默认会在当前目录（`.`）中查找类和包。

```text
CLASSPATH = . （当前目录）
```

> **注意**：在生产环境中，CLASSPATH通常由构建工具（如Maven、Gradle）或IDE管理，手动配置的需求较少。

// File: com/example/banking/model/Account.java
package com.example.banking.model;

public class Account {
    private String accountNumber;
    private String accountHolder;
    private double balance;
    private boolean active;

    public Account(String accountNumber, String accountHolder, double initialBalance) {
        this.accountNumber = accountNumber;
        this.accountHolder = accountHolder;
        this.balance = initialBalance;
        this.active = true;
    }

    public String getAccountNumber() { return accountNumber; }
    public String getAccountHolder() { return accountHolder; }
    public double getBalance() { return balance; }
    public boolean isActive() { return active; }

    public void deposit(double amount) {
        if (amount > 0 && active) {
            balance += amount;
        }
    }

    public boolean withdraw(double amount) {
        if (amount > 0 && active && balance >= amount) {
            balance -= amount;
            return true;
        }
        return false;
    }

    public void close() {
        this.active = false;
    }

    @Override
    public String toString() {
        return "Account{" +
                "accountNumber='" + accountNumber + '\'' +
                ", accountHolder='" + accountHolder + '\'' +
                ", balance=" + balance +
                ", active=" + active +
                '}';
    }
}

// File: com/example/banking/model/Transaction.java
package com.example.banking.model;

import java.time.LocalDateTime;

public class Transaction {
    public enum Type { DEPOSIT, WITHDRAWAL }

    private String id;
    private String accountNumber;
    private Type type;
    private double amount;
    private LocalDateTime timestamp;

    public Transaction(String id, String accountNumber, Type type, double amount) {
        this.id = id;
        this.accountNumber = accountNumber;
        this.type = type;
        this.amount = amount;
        this.timestamp = LocalDateTime.now();
    }

    // getters...
    public String getId() { return id; }
    public String getAccountNumber() { return accountNumber; }
    public Type getType() { return type; }
    public double getAmount() { return amount; }
    public LocalDateTime getTimestamp() { return timestamp; }

    @Override
    public String toString() {
        return "Transaction{" +
                "id='" + id + '\'' +
                ", accountNumber='" + accountNumber + '\'' +
                ", type=" + type +
                ", amount=" + amount +
                ", timestamp=" + timestamp +
                '}';
    }
}

// File: com/example/banking/service/AccountService.java
package com.example.banking.service;

import com.example.banking.model.Account;
import com.example.banking.model.Transaction;

public interface AccountService {
    Account createAccount(String accountNumber, String accountHolder, double initialBalance);
    Account findAccount(String accountNumber);
    boolean deposit(String accountNumber, double amount);
    boolean withdraw(String accountNumber, double amount);
    void closeAccount(String accountNumber);
    Transaction[] getTransactionHistory(String accountNumber);
}

// File: com/example/banking/service/impl/AccountServiceImpl.java
package com.example.banking.service.impl;

import com.example.banking.model.Account;
import com.example.banking.model.Transaction;
import com.example.banking.service.AccountService;
import com.example.banking.util.EncryptionUtils;

import java.util.*;

public class AccountServiceImpl implements AccountService {
    private Map<String, Account> accounts = new HashMap<>();
    private Map<String, List<Transaction>> transactionHistory = new HashMap<>();
    private int transactionCounter = 0;

    @Override
    public Account createAccount(String accountNumber, String accountHolder, double initialBalance) {
        if (accounts.containsKey(accountNumber)) {
            throw new RuntimeException("账户已存在");
        }
        Account account = new Account(accountNumber, accountHolder, initialBalance);
        accounts.put(accountNumber, account);
        transactionHistory.put(accountNumber, new ArrayList<>());
        return account;
    }

    @Override
    public Account findAccount(String accountNumber) {
        return accounts.get(accountNumber);
    }

    @Override
    public boolean deposit(String accountNumber, double amount) {
        Account account = accounts.get(accountNumber);
        if (account == null) return false;
        account.deposit(amount);
        addTransaction(accountNumber, Transaction.Type.DEPOSIT, amount);
        return true;
    }

    @Override
    public boolean withdraw(String accountNumber, double amount) {
        Account account = accounts.get(accountNumber);
        if (account == null) return false;
        boolean success = account.withdraw(amount);
        if (success) {
            addTransaction(accountNumber, Transaction.Type.WITHDRAWAL, amount);
        }
        return success;
    }

    @Override
    public void closeAccount(String accountNumber) {
        Account account = accounts.get(accountNumber);
        if (account != null) {
            account.close();
        }
    }

    @Override
    public Transaction[] getTransactionHistory(String accountNumber) {
        List<Transaction> history = transactionHistory.get(accountNumber);
        if (history == null) return new Transaction[0];
        return history.toArray(new Transaction[0]);
    }

    private void addTransaction(String accountNumber, Transaction.Type type, double amount) {
        String id = "TXN" + String.format("%08d", ++transactionCounter);
        Transaction t = new Transaction(id, accountNumber, type, amount);
        transactionHistory.computeIfAbsent(accountNumber, k -> new ArrayList<>()).add(t);
    }
}

// File: com/example/banking/util/EncryptionUtils.java
package com.example.banking.util;

public class EncryptionUtils {
    private static final String SALT = "Banking2026";

    // 仅包内使用
    static String encrypt(String data) {
        // 简化示例：实际应用中使用更复杂的加密
        return data + "_encrypted_" + SALT;
    }

    // 仅包内使用
    static String decrypt(String encryptedData) {
        if (encryptedData == null) return null;
        return encryptedData.replace("_encrypted_" + SALT, "");
    }

    // 公共方法：可被其他包调用
    public static String hashPassword(String password) {
        return "HASH_" + password + "_" + SALT.hashCode();
    }

    // 私有方法：仅类内部使用
    private static void validateSalt() {
        System.out.println("Salt validation: " + SALT);
    }
}

// File: com/example/banking/Main.java
package com.example.banking;

import com.example.banking.model.Account;
import com.example.banking.model.Transaction;
import com.example.banking.service.AccountService;
import com.example.banking.service.impl.AccountServiceImpl;

public class Main {
    public static void main(String[] args) {
        AccountService service = new AccountServiceImpl();

        // 创建账户
        service.createAccount("A001", "张三", 1000.0);
        service.createAccount("A002", "李四", 500.0);

        // 存款
        service.deposit("A001", 200.0);
        service.deposit("A002", 100.0);

        // 取款
        service.withdraw("A001", 150.0);

        // 查看账户
        Account account1 = service.findAccount("A001");
        Account account2 = service.findAccount("A002");

        System.out.println("=== 账户信息 ===");
        System.out.println(account1);
        System.out.println(account2);

        // 查看交易记录
        System.out.println("\n=== 交易记录 ===");
        for (Transaction t : service.getTransactionHistory("A001")) {
            System.out.println(t);
        }

        // 关闭账户
        service.closeAccount("A001");
        System.out.println("\n关闭账户后：" + service.findAccount("A001"));
    }
}

|--------|---------|
| **包（Package）** | 组织类的命名空间，`package` 声明必须在文件第一行 |
| **导入（import）** | 简化类引用，`import static` 导入静态成员 |
| **private** | 同一类内可访问，最严格的访问控制 |
| **默认（包级私有）** | 同一包内可访问 |
| **protected** | 同一包 + 不同包的子类可访问 |
| **public** | 所有类可访问，最宽松的访问控制 |
| **CLASSPATH** | JVM 查找类和包的搜索路径 |

## 练习与思考题

1. 创建一个多包项目：`com.example.math` 包中的 `Calculator` 类和 `com.example.test` 包中的 `Test` 类，演示访问控制。
2. 解释 `protected` 和默认访问修饰符的区别，并举例说明。
3. 什么是完全限定名（FQN）？什么时候需要使用完全限定名？
4. 静态导入和普通导入有什么区别？分别适用于什么场景？
5. 设计一个小型图书馆管理系统，使用合适的包结构组织代码。
6. 理解 CLASSPATH 的作用，配置 CLASSPATH 并运行一个简单的程序。
