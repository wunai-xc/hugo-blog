## 引言

在上一篇文章中，我们学习了 `File` 类和字节流（`InputStream` / `OutputStream`）的使用。字节流可以处理任何类型的文件数据，但当我们处理**文本数据**时，字节流存在一个明显的问题——**字符编码**。

不同的操作系统和平台使用不同的字符编码（如 GBK、UTF-8、ISO-8859-1 等），如果直接使用字节流读取文本文件，可能会出现乱码。为了解决这个问题，Java 提供了专门用于处理文本数据的**字符流**（`Reader` / `Writer`），它们自动处理字符编码转换，确保文本数据的正确读写。

此外，Java 还提供了**对象序列化**机制，允许将 Java 对象转换为字节流进行存储或网络传输，实现对象的持久化和远程通信。

本文将系统讲解字符流、转换流以及对象序列化的使用。

## 第一章 字符流概述

### 1.1 为什么需要字符流

字节流以字节为单位处理数据，而字符流以**字符**（char，16位 Unicode）为单位处理数据。字符流自动处理字符编码转换，使得文本数据的读写更加方便、安全。

| 对比项 | 字节流 | 字符流 |
|--------|--------|--------|
| **基本单位** | 字节（byte） | 字符（char） |
| **父类** | `InputStream` / `OutputStream` | `Reader` / `Writer` |
| **适用数据** | 二进制数据（图片、视频等） | 文本数据 |
| **编码处理** | 不处理（直接传输字节） | 自动处理字符编码 |
| **典型子类** | `FileInputStream`、`FileOutputStream` | `FileReader`、`FileWriter` |

### 1.2 字符流的继承体系

```text
Reader（抽象类）
├── BufferedReader（缓冲字符输入流）      // 带缓冲，支持按行读取
├── InputStreamReader（转换流）          // 字节→字符的桥梁
│   └── FileReader（文件字符输入流）      // 读取文本文件
├── StringReader（字符串输入流）          // 从字符串读取
└── PipedReader（管道输入流）

Writer（抽象类）
├── BufferedWriter（缓冲字符输出流）      // 带缓冲
├── OutputStreamWriter（转换流）          // 字符→字节的桥梁
│   └── FileWriter（文件字符输出流）      // 写入文本文件
├── StringWriter（字符串输出流）          // 写入到字符串
├── PrintWriter（打印字符流）             // 格式化输出
└── PipedWriter（管道输出流）
```

## 第二章 字符输入流（Reader）

### 2.1 Reader 的核心方法

| 方法 | 说明 |
|------|------|
| `int read()` | 读取一个字符（返回0-65535，-1表示结束） |
| `int read(char[] cbuf)` | 读取字符到数组，返回实际读取的字符数 |
| `int read(char[] cbuf, int off, int len)` | 读取字符到数组的指定位置 |
| `long skip(long n)` | 跳过指定数量的字符 |
| `boolean ready()` | 判断流是否准备好被读取 |
| `void close()` | 关闭流，释放资源 |

### 2.2 FileReader 的使用

```java
import java.io.*;

public class FileReaderDemo {
    public static void main(String[] args) {
        // 方式一：读取单个字符
        try (FileReader reader = new FileReader("test.txt")) {
            int ch;
            while ((ch = reader.read()) != -1) {
                System.out.print((char) ch);
            }
        } catch (IOException e) {
            System.out.println("读取失败：" + e.getMessage());
        }

        // 方式二：读取到字符数组
        try (FileReader reader = new FileReader("test.txt")) {
            char[] buffer = new char[1024];
            int charsRead;
            while ((charsRead = reader.read(buffer)) != -1) {
                System.out.print(new String(buffer, 0, charsRead));
            }
        } catch (IOException e) {
            System.out.println("读取失败：" + e.getMessage());
        }

        // 方式三：指定字符编码（使用 InputStreamReader）
        try (InputStreamReader reader = new InputStreamReader(
                new FileInputStream("test.txt"), "UTF-8")) {
            char[] buffer = new char[1024];
            int charsRead;
            while ((charsRead = reader.read(buffer)) != -1) {
                System.out.print(new String(buffer, 0, charsRead));
            }
        } catch (IOException e) {
            System.out.println("读取失败：" + e.getMessage());
        }
    }
}
```

## 第三章 字符输出流（Writer）

### 3.1 Writer 的核心方法

| 方法 | 说明 |
|------|------|
| `void write(int c)` | 写入一个字符 |
| `void write(char[] cbuf)` | 写入字符数组 |
| `void write(char[] cbuf, int off, int len)` | 写入字符数组的指定部分 |
| `void write(String str)` | 写入字符串 |
| `void write(String str, int off, int len)` | 写入字符串的指定部分 |
| `void append(char c)` | 追加一个字符 |
| `void append(CharSequence csq)` | 追加字符序列 |
| `void flush()` | 刷新缓冲区 |
| `void close()` | 关闭流，释放资源 |

### 3.2 FileWriter 的使用

```java
import java.io.*;

public class FileWriterDemo {
    public static void main(String[] args) {

        }

            writer.write("\n第二行内容");

        } catch (IOException e) {
            System.out.println("写入失败：" + e.getMessage());
        }

        // 方式三：追加模式
        try (FileWriter writer = new FileWriter("output2.txt", true)) {
            writer.write("\n追加的内容");
        } catch (IOException e) {
            System.out.println("写入失败：" + e.getMessage());
        }

        // 方式四：写入字符数组
        try (FileWriter writer = new FileWriter("output3.txt")) {
            char[] chars = {'H', 'e', 'l', 'l', 'o'};
            writer.write(chars);
            writer.write(chars, 0, 3); // 写入 "Hel"
        } catch (IOException e) {
            System.out.println("写入失败：" + e.getMessage());
        }
    }
}
```

## 第四章 缓冲字符流

### 4.1 BufferedReader

`BufferedReader` 提供了**按行读取**的能力（`readLine()` 方法），这是处理文本文件时最常用的功能。

```java
import java.io.*;

public class BufferedReaderDemo {
    public static void main(String[] args) {
        // 使用 BufferedReader 按行读取
        try (BufferedReader reader = new BufferedReader(new FileReader("test.txt"))) {
            String line;
            int lineNum = 0;
            while ((line = reader.readLine()) != null) {
                lineNum++;
                System.out.println(lineNum + ": " + line);
            }
        } catch (IOException e) {
            System.out.println("读取失败：" + e.getMessage());
        }

        // 从标准输入读取（System.in 是字节流，需要转换）
        try (BufferedReader reader = new BufferedReader(
                new InputStreamReader(System.in))) {
            System.out.print("请输入内容：");
            String input = reader.readLine();
            System.out.println("你输入了：" + input);
        } catch (IOException e) {
            System.out.println("读取失败：" + e.getMessage());
        }
    }
}
```

### 4.2 BufferedWriter

```java
import java.io.*;

public class BufferedWriterDemo {
    public static void main(String[] args) {
        // 使用 BufferedWriter 写入
        try (BufferedWriter writer = new BufferedWriter(new FileWriter("buffered_output.txt"))) {
            writer.write("第一行内容");
            writer.newLine(); // 写入换行（跨平台）
            writer.write("第二行内容");
            writer.newLine();
            writer.write("第三行内容");
            writer.flush(); // 刷新缓冲区
        } catch (IOException e) {
            System.out.println("写入失败：" + e.getMessage());
        }

        // 大量数据写入（性能对比）
        long start = System.currentTimeMillis();
        try (BufferedWriter writer = new BufferedWriter(new FileWriter("large_output.txt"))) {
            for (int i = 0; i < 10000; i++) {
                writer.write("Line " + i);
                writer.newLine();
            }
        } catch (IOException e) {
            System.out.println("写入失败：" + e.getMessage());
        }
        long end = System.currentTimeMillis();
        System.out.println("BufferedWriter 写入10000行耗时：" + (end - start) + "ms");
    }
}
```

## 第五章 转换流

### 5.1 什么是转换流

**转换流**是字节流和字符流之间的桥梁：
- `InputStreamReader`：将字节输入流转换为字符输入流
- `OutputStreamWriter`：将字符输出流转换为字节输出流

转换流的核心作用是**指定字符编码**，解决中文乱码问题。

```text
字节流（FileInputStream）──→ InputStreamReader ──→ 字符流（Reader）
字符流（Writer）         ──→ OutputStreamWriter ──→ 字节流（FileOutputStream）
```

### 5.2 InputStreamReader

```java
import java.io.*;

public class InputStreamReaderDemo {
    public static void main(String[] args) {
        // 默认编码（系统默认）
        try (InputStreamReader reader = new InputStreamReader(
                new FileInputStream("test.txt"))) {
            char[] buffer = new char[1024];
            int charsRead;
            while ((charsRead = reader.read(buffer)) != -1) {
                System.out.print(new String(buffer, 0, charsRead));
            }
        } catch (IOException e) {
            System.out.println("读取失败：" + e.getMessage());
        }

        // 指定编码 UTF-8
        try (InputStreamReader reader = new InputStreamReader(
                new FileInputStream("utf8.txt"), "UTF-8")) {
            char[] buffer = new char[1024];
            int charsRead;
            while ((charsRead = reader.read(buffer)) != -1) {
                System.out.print(new String(buffer, 0, charsRead));
            }
        } catch (IOException e) {
            System.out.println("读取失败：" + e.getMessage());
        }

        // 指定编码 GBK
        try (InputStreamReader reader = new InputStreamReader(
                new FileInputStream("gbk.txt"), "GBK")) {
            char[] buffer = new char[1024];
            int charsRead;
            while ((charsRead = reader.read(buffer)) != -1) {
                System.out.print(new String(buffer, 0, charsRead));
            }
        } catch (IOException e) {
            System.out.println("读取失败：" + e.getMessage());
        }

        // 使用 StandardCharsets（Java 7+）
        try (InputStreamReader reader = new InputStreamReader(

            char[] buffer = new char[1024];

            while ((charsRead = reader.read(buffer)) != -1) {
                System.out.print(new String(buffer, 0, charsRead));
            }
        } catch (IOException e) {
            System.out.println("读取失败：" + e.getMessage());
        }
    }
```

### 5.4 解决中文乱码问题

```java
import java.io.*;

public class EncodingDemo {
    /**
     * 正确读取UTF-8编码的文件
     */
    public static String readUTF8File(String filename) throws IOException {
        StringBuilder content = new StringBuilder();
        try (BufferedReader reader = new BufferedReader(
                new InputStreamReader(new FileInputStream(filename), "UTF-8"))) {
            String line;
            while ((line = reader.readLine()) != null) {
                content.append(line).append("\n");
            }
        }
        return content.toString();
    }

    /**
     * 正确写入UTF-8编码的文件
     */
    public static void writeUTF8File(String filename, String content) throws IOException {
        try (BufferedWriter writer = new BufferedWriter(
                new OutputStreamWriter(new FileOutputStream(filename), "UTF-8"))) {
            writer.write(content);
        }
    }

    public static void main(String[] args) {
        try {
            // 写入中文
            writeUTF8File("utf8_demo.txt", "这是中文内容\n第二行\n第三行");
            System.out.println("写入成功");

            // 读取中文
            String content = readUTF8File("utf8_demo.txt");
            System.out.println("读取内容：\n" + content);

        } catch (IOException e) {
            System.out.println("操作失败：" + e.getMessage());
        }
    }
}
```

## 第六章 打印字符流（PrintWriter）

`PrintWriter` 是字符输出流的增强版，提供了 `print()` 和 `println()` 方法，支持各种数据类型的格式化输出。

```java
import java.io.*;

public class PrintWriterDemo {
    public static void main(String[] args) {
        // 方式一：直接写入文件
        try (PrintWriter pw = new PrintWriter("print_writer.txt")) {
            pw.println("Hello, World!");
            pw.println(100);
            pw.println(3.14);
            pw.println(true);
            pw.printf("格式化输出：%s，年龄：%d，成绩：%.2f%n", "张三", 25, 92.5);
            pw.println("-------------------");
        } catch (IOException e) {
            System.out.println("写入失败：" + e.getMessage());
        }

        // 方式二：自动 flush（构造方法第二个参数为 true）
        try (PrintWriter pw = new PrintWriter(
                new BufferedWriter(new FileWriter("auto_flush.txt")), true)) {
            pw.println("这行会自动 flush");
            pw.println("这行也会自动 flush");
        } catch (IOException e) {
            System.out.println("写入失败：" + e.getMessage());
        }

        // 方式三：使用文件对象
        try (PrintWriter pw = new PrintWriter(new File("file_obj.txt"))) {
            pw.println("使用 File 对象创建");
        } catch (FileNotFoundException e) {
            System.out.println("文件创建失败：" + e.getMessage());
        }

        // 方式四：输出到控制台（System.out 就是 PrintStream）
        // PrintWriter 可以包装 System.out
        PrintWriter consoleWriter = new PrintWriter(System.out);
        consoleWriter.println("输出到控制台");
        consoleWriter.flush(); // System.out 需要 flush
    }
}
```

## 第七章 对象序列化

### 7.1 什么是序列化

**对象序列化**（Serialization）是将 Java 对象转换为字节流的过程，反序列化（Deserialization）是将字节流恢复为 Java 对象的过程。

**序列化的用途**：
1. **持久化存储**：将对象保存到文件中
2. **网络传输**：通过 Socket 传输对象
3. **分布式系统**：RMI（远程方法调用）
4. **缓存**：将对象缓存到磁盘

### 7.2 实现 Serializable 接口

要实现序列化，类必须实现 `java.io.Serializable` 接口（标记接口，没有方法）。

```java
import java.io.*;
import java.util.*;

/**
 * 用户类 - 实现 Serializable 接口
 */
class User implements Serializable {
    // serialVersionUID 用于版本控制（建议显式声明）
    private static final long serialVersionUID = 1L;

    private String id;
    private String name;
    private int age;
    private transient String password; // transient 字段不会被序列化
    private List<String> roles;

    public User(String id, String name, int age, String password) {
        this.id = id;
        this.name = name;
        this.age = age;
        this.password = password;
        this.roles = new ArrayList<>();
    }

    // Getters and Setters
    public String getId() { return id; }
    public void setId(String id) { this.id = id; }
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public int getAge() { return age; }
    public void setAge(int age) { this.age = age; }
    public String getPassword() { return password; }
    public void setPassword(String password) { this.password = password; }
    public List<String> getRoles() { return roles; }
    public void setRoles(List<String> roles) { this.roles = roles; }

    public void addRole(String role) {
        roles.add(role);
    }

    @Override
    public String toString() {
        return "User{id='" + id + "', name='" + name + "', age=" + age +
               ", password='" + password + "', roles=" + roles + "}";
    }
}
```

### 7.3 对象序列化与反序列化

```java
import java.io.*;

public class SerializationDemo {
    public static void main(String[] args) {
        // 1. 创建对象
        User user = new User("U001", "张三", 25, "123456");
        user.addRole("管理员");
        user.addRole("编辑");
        user.addRole("普通用户");

        System.out.println("原始对象：" + user);

        // 2. 序列化（写入文件）
        try (ObjectOutputStream oos = new ObjectOutputStream(
                new FileOutputStream("user.ser"))) {
            oos.writeObject(user);
            System.out.println("序列化成功！");
        } catch (IOException e) {
            System.out.println("序列化失败：" + e.getMessage());
            return;
        }

        // 3. 反序列化（从文件读取）
        try (ObjectInputStream ois = new ObjectInputStream(
                new FileInputStream("user.ser"))) {
            User deserializedUser = (User) ois.readObject();
            System.out.println("反序列化成功！");
            System.out.println("反序列化对象：" + deserializedUser);
            System.out.println("transient 字段 password 的值为：" + deserializedUser.getPassword());
            // password 为 null（transient 字段不会被序列化）
        } catch (IOException | ClassNotFoundException e) {
            System.out.println("反序列化失败：" + e.getMessage());
        }
    }
}
```

### 7.4 序列化版本控制（serialVersionUID）

`serialVersionUID` 用于验证序列化对象和反序列化类的版本一致性。如果类的定义发生变化（如添加了新字段），`serialVersionUID` 不匹配会导致 `InvalidClassException`。

```java
// 建议显式声明 serialVersionUID
class Product implements Serializable {
    private static final long serialVersionUID = 2L; // 版本号

    private String id;
    private String name;
    private double price;
    // private String description; // 添加新字段时，需要更新 serialVersionUID
}
```

**版本控制策略**：
- 如果类发生了**不兼容的修改**（如删除字段、改变字段类型），应更新 `serialVersionUID`
- 如果类发生了**兼容的修改**（如添加新字段），可以保持 `serialVersionUID` 不变

### 7.5 transient 关键字

`transient` 关键字用于标记不需要序列化的字段（如密码、敏感信息等）。

```java
class Employee implements Serializable {
    private static final long serialVersionUID = 1L;

    private String name;
    private int age;
    private transient String password;      // 不序列化
    private transient Session session;      // 不序列化（运行时状态）

    // 反序列化时的特殊处理
    private void readObject(ObjectInputStream ois)
            throws IOException, ClassNotFoundException {
        ois.defaultReadObject();
        // 反序列化后初始化 transient 字段
        this.password = "defaultPassword";
    }

    private void writeObject(ObjectOutputStream oos) throws IOException {
        oos.defaultWriteObject();
        // 可以自定义序列化逻辑
    }
}
```

### 7.6 序列化集合

```java
import java.io.*;
import java.util.*;

public class SerializeCollectionDemo {
    public static void main(String[] args) {
        // 创建并序列化列表
        List<User> users = new ArrayList<>();
        users.add(new User("U001", "张三", 25, "pwd1"));
        users.add(new User("U002", "李四", 30, "pwd2"));
        users.add(new User("U003", "王五", 28, "pwd3"));

        try (ObjectOutputStream oos = new ObjectOutputStream(
                new FileOutputStream("users.ser"))) {
            oos.writeObject(users);
            System.out.println("序列化列表成功，共 " + users.size() + " 个用户");
        } catch (IOException e) {
            System.out.println("序列化失败：" + e.getMessage());
        }

        // 反序列化列表
        try (ObjectInputStream ois = new ObjectInputStream(
                new FileInputStream("users.ser"))) {
            List<User> deserializedUsers = (List<User>) ois.readObject();
            System.out.println("反序列化成功，共 " + deserializedUsers.size() + " 个用户");
            for (User u : deserializedUsers) {
                System.out.println("  " + u);
            }
        } catch (IOException | ClassNotFoundException e) {
            System.out.println("反序列化失败：" + e.getMessage());
        }
    }
}
```

## 第八章 综合示例

```java
import java.io.*;
import java.util.*;
import java.text.SimpleDateFormat;

/**
 * 日志工具类 - 综合运用字符流、转换流和序列化
 */
public class LogUtils {
    private static final String LOG_FILE = "application.log";
    private static final SimpleDateFormat DATE_FORMAT =
            new SimpleDateFormat("yyyy-MM-dd HH:mm:ss.SSS");

    /**
     * 写入日志（使用 BufferedWriter）
     */
    public static void log(String level, String message) {
        String timestamp = DATE_FORMAT.format(new Date());
        String logLine = String.format("[%s] [%s] %s%n", timestamp, level, message);

        // 使用 try-with-resources 自动关闭
        try (BufferedWriter writer = new BufferedWriter(
                new OutputStreamWriter(new FileOutputStream(LOG_FILE, true), "UTF-8"))) {
            writer.write(logLine);
            writer.flush();
        } catch (IOException e) {
            System.err.println("日志写入失败：" + e.getMessage());
        }
    }

    /**
     * 读取日志（使用 BufferedReader）
     */
    public static List<String> readLogs() {
        List<String> lines = new ArrayList<>();
        try (BufferedReader reader = new BufferedReader(
                new InputStreamReader(new FileInputStream(LOG_FILE), "UTF-8"))) {
            String line;
            while ((line = reader.readLine()) != null) {
                lines.add(line);
            }
        } catch (IOException e) {
            System.err.println("日志读取失败：" + e.getMessage());
        }
        return lines;
    }

    /**
     * 按关键字搜索日志
     */
    public static List<String> searchLogs(String keyword) {
        List<String> result = new ArrayList<>();
        try (BufferedReader reader = new BufferedReader(
                new InputStreamReader(new FileInputStream(LOG_FILE), "UTF-8"))) {
            String line;
            while ((line = reader.readLine()) != null) {
                if (line.contains(keyword)) {
                    result.add(line);
                }
            }
        } catch (IOException e) {
            System.err.println("日志搜索失败：" + e.getMessage());
        }
        return result;
    }

    /**
     * 导出日志到文件（使用 PrintWriter）
     */
    public static void exportLogs(String outputFile) {
        List<String> logs = readLogs();
        try (PrintWriter pw = new PrintWriter(
                new BufferedWriter(new OutputStreamWriter(
                        new FileOutputStream(outputFile), "UTF-8")))) {
            for (String log : logs) {
                pw.println(log);
            }
            System.out.println("导出完成，共 " + logs.size() + " 条日志");
        } catch (IOException e) {
            System.err.println("导出失败：" + e.getMessage());
        }
    }

    public static void main(String[] args) {
        // 写入日志
        log("INFO", "应用程序启动");
        log("INFO", "加载配置文件成功");
        log("WARN", "连接超时，重试中...");
        log("ERROR", "数据库连接失败");
        log("INFO", "应用程序关闭");

        // 读取日志
        System.out.println("=== 所有日志 ===");
        for (String line : readLogs()) {
            System.out.println(line);
        }

        // 搜索日志
        System.out.println("\n=== 搜索 'ERROR' ===");
        for (String line : searchLogs("ERROR")) {
            System.out.println(line);
        }

        // 导出日志
        exportLogs("logs_backup.txt");
    }
}

class AppConfig implements Serializable {
    private static final long serialVersionUID = 1L;

    private String appName;
    private String version;
    private int maxConnections;
    private int timeout;
    private transient String secretKey; // 敏感信息不序列化

    public AppConfig(String appName, String version, int maxConnections, int timeout) {
        this.appName = appName;
        this.version = version;
        this.maxConnections = maxConnections;
        this.timeout = timeout;
    }

    // Getters and Setters
    public String getAppName() { return appName; }
    public void setAppName(String appName) { this.appName = appName; }
    public String getVersion() { return version; }
    public void setVersion(String version) { this.version = version; }
    public int getMaxConnections() { return maxConnections; }
    public void setMaxConnections(int maxConnections) { this.maxConnections = maxConnections; }
    public int getTimeout() { return timeout; }
    public void setTimeout(int timeout) { this.timeout = timeout; }
    public String getSecretKey() { return secretKey; }
    public void setSecretKey(String secretKey) { this.secretKey = secretKey; }

    @Override
    public String toString() {
        return "AppConfig{appName='" + appName + "', version='" + version +
               "', maxConnections=" + maxConnections + ", timeout=" + timeout +
               ", secretKey='" + secretKey + "'}";
    }

    /**
     * 保存配置到文件（序列化）
     */
    public void saveToFile(String filename) throws IOException {
        try (ObjectOutputStream oos = new ObjectOutputStream(
                new FileOutputStream(filename))) {
            oos.writeObject(this);
        }
    }

    /**
     * 从文件加载配置（反序列化）
     */
    public static AppConfig loadFromFile(String filename) throws IOException, ClassNotFoundException {
        try (ObjectInputStream ois = new ObjectInputStream(
                new FileInputStream(filename))) {
            return (AppConfig) ois.readObject();
        }
    }

    public static void main(String[] args) {
        try {
            // 创建并保存配置
            AppConfig config = new AppConfig("MyApp", "2.1.0", 100, 30000);
            config.setSecretKey("super-secret-key");
            System.out.println("原始配置：" + config);
            config.saveToFile("app_config.ser");

            // 加载配置
            AppConfig loadedConfig = AppConfig.loadFromFile("app_config.ser");
            System.out.println("加载配置：" + loadedConfig);
            // secretKey 为 null（transient 字段）

        }
    }
```

## 总结

本文系统讲解了Java中的字符流、转换流与对象序列化：

| 知识点 | 核心要点 |
|--------|---------|
| **Reader/Writer** | 字符流的基类，处理文本数据 |
| **FileReader/FileWriter** | 读写文本文件的字符流 |
| **BufferedReader/BufferedWriter** | 带缓冲的字符流，支持按行读写 |
| **InputStreamReader** | 字节流→字符流的桥梁，可指定编码 |
| **OutputStreamWriter** | 字符流→字节流的桥梁，可指定编码 |
| **PrintWriter** | 打印字符流，支持格式化输出 |
| **Serializable** | 标记接口，标识类可序列化 |
| **ObjectOutputStream** | 对象序列化流 |
| **ObjectInputStream** | 对象反序列化流 |
| **transient** | 标记不需要序列化的字段 |
