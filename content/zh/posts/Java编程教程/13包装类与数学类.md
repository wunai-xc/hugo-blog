## 引言

在Java中，基本数据类型（如 `int`、`double`、`boolean`）不是对象，无法直接参与面向对象的操作——它们不能被放入集合（如 `ArrayList`），不能调用方法，也不能作为泛型参数。

为了解决这个问题，Java为每种基本数据类型都提供了一个对应的**包装类**（Wrapper Class），将基本类型“包装”成对象，使其能够参与面向对象的操作。

此外，Java还提供了丰富的数学工具类：`Math` 类提供了基础的数学运算方法，`BigInteger` 和 `BigDecimal` 则支持任意精度的整数和浮点数运算，弥补了基本类型在精度和范围上的限制。

本文将系统讲解Java中的包装类与数学类，帮助读者掌握这些核心工具的使用。

## 第一章 包装类概述

### 1.1 什么是包装类

**包装类**（Wrapper Class）是Java为每种基本数据类型提供的对应引用类型。它们将基本类型值包装在对象中，使其能够参与面向对象的操作。

| 基本类型 | 包装类 | 父类 |
|---------|--------|------|
| `byte` | `Byte` | Number |
| `short` | `Short` | Number |
| `int` | `Integer` | Number |
| `long` | `Long` | Number |
| `float` | `Float` | Number |
| `double` | `Double` | Number |
| `char` | `Character` | Object |
| `boolean` | `Boolean` | Object |

### 1.2 为什么需要包装类

1. **集合框架**：`ArrayList`、`HashMap` 等集合只能存储对象，不能存储基本类型。
2. **泛型参数**：泛型只能使用引用类型，不能使用基本类型。
3. **对象方法**：包装类提供了许多实用方法，如类型转换、进制转换等。
4. **空值表示**：包装类可以为 `null`，表示“无值”状态。

```java
// 集合不能存储基本类型
// ArrayList<int> list = new ArrayList<>(); // 错误！

// 使用包装类
ArrayList<Integer> list = new ArrayList<>();
list.add(10);  // 自动装箱
int value = list.get(0); // 自动拆箱
```

### 2.3 Integer 缓存池

Java 对 `Integer` 对象做了特殊优化：对于 -128 到 127 之间的值，`Integer.valueOf()` 会返回缓存池中的同一个对象。

```java
public class IntegerCacheDemo {
    public static void main(String[] args) {
        // 缓存范围内的值
        Integer a1 = Integer.valueOf(10);
        Integer a2 = Integer.valueOf(10);
        System.out.println(a1 == a2);  // true（同一个对象）

        // 超出缓存范围
        Integer b1 = Integer.valueOf(200);
        Integer b2 = Integer.valueOf(200);
        System.out.println(b1 == b2);  // false（不同对象）

        // 自动装箱也会使用缓存
        Integer c1 = 10;
        Integer c2 = 10;
        System.out.println(c1 == c2);  // true

        // 超出缓存范围
        Integer d1 = 200;
        Integer d2 = 200;
        System.out.println(d1 == d2);  // false

        // 使用 new 创建不会使用缓存
        Integer e1 = new Integer(10);
        Integer e2 = new Integer(10);
        System.out.println(e1 == e2);  // false
    }
}
```

## 第三章 自动装箱与拆箱

### 3.1 自动装箱（Autoboxing）

**自动装箱**是编译器自动将基本类型转换为对应的包装类对象。

```java
public class AutoboxingDemo {
    public static void main(String[] args) {
        // 基本类型 → 包装类（编译器自动调用 valueOf）
        Integer a = 10;        // 自动装箱
        Double b = 3.14;       // 自动装箱
        Boolean c = true;      // 自动装箱
        Character d = 'A';     // 自动装箱

        // 在集合中使用
        List<Integer> list = new ArrayList<>();
        list.add(10);          // 自动装箱为 Integer
        list.add(20);          // 自动装箱

        // 在方法调用中使用
        printNumber(100);      // 自动装箱
    }

    public static void printNumber(Integer num) {
        System.out.println(num);
    }
}
```

### 3.2 自动拆箱（Unboxing）

**自动拆箱**是编译器自动将包装类对象转换为对应的基本类型。

```java
public class UnboxingDemo {
    public static void main(String[] args) {
        // 包装类 → 基本类型（编译器自动调用 xxxValue）
        Integer a = Integer.valueOf(10);
        int b = a;             // 自动拆箱

        Double d = Double.valueOf(3.14);
        double e = d;          // 自动拆箱

        // 在运算中使用
        Integer x = 5;
        Integer y = 3;
        int sum = x + y;       // 拆箱后相加，再自动装箱

        // 在条件判断中使用
        Boolean flag = true;
        if (flag) {            // 自动拆箱
            System.out.println("true");
        }
    }
}
```

### 3.3 自动装箱/拆箱的注意事项

```java
public class AutoBoxingCaution {
    public static void main(String[] args) {
        // 1. 空指针异常（NullPointerException）
        // Integer num = null;
        // int value = num; // 自动拆箱 → NullPointerException

        // 2. 比较时的坑
        Integer a = 100;
        Integer b = 100;
        System.out.println(a == b);  // true（缓存池）
        System.out.println(a.equals(b)); // true

        Integer c = 200;
        Integer d = 200;
        System.out.println(c == d);  // false（超出缓存范围）
        System.out.println(c.equals(d)); // true

        // 3. 性能问题（循环中频繁装箱）
        // 低效
        long start = System.currentTimeMillis();
        Integer sum = 0;
        for (int i = 0; i < 10000; i++) {
            sum += i; // 每次拆箱和装箱
        }
        long end = System.currentTimeMillis();
        System.out.println("耗时：" + (end - start) + "ms");

        // 高效
        start = System.currentTimeMillis();
        int sum2 = 0;
        for (int i = 0; i < 10000; i++) {
            sum2 += i;
        }
        end = System.currentTimeMillis();
        System.out.println("耗时：" + (end - start) + "ms");
    }
}
```

## 第五章 BigInteger 与 BigDecimal

基本类型 `long` 和 `double` 有精度和范围限制。`BigInteger` 和 `BigDecimal` 提供了任意精度的整数和浮点数运算。

### 5.1 BigInteger

`BigInteger` 支持**任意精度**的整数运算，适用于需要处理超大整数的场景（如加密、大数计算）。

```java
import java.math.BigInteger;

public class BigIntegerDemo {
    public static void main(String[] args) {
        // 创建 BigInteger
        BigInteger a = BigInteger.valueOf(100);
        BigInteger b = new BigInteger("12345678901234567890");

        // 运算（返回新的 BigInteger，不可变）
        BigInteger sum = a.add(b);
        BigInteger diff = b.subtract(a);
        BigInteger product = a.multiply(b);
        BigInteger quotient = b.divide(a);
        BigInteger remainder = b.remainder(a);

        System.out.println("a = " + a);
        System.out.println("b = " + b);
        System.out.println("sum = " + sum);
        System.out.println("diff = " + diff);
        System.out.println("product = " + product);
        System.out.println("quotient = " + quotient);
        System.out.println("remainder = " + remainder);

        // 比较
        System.out.println("a.compareTo(b): " + a.compareTo(b)); // -1

        // 幂运算
        BigInteger power = BigInteger.valueOf(2).pow(100);
        System.out.println("2^100 = " + power);

        // 最大公约数
        BigInteger gcd = a.gcd(b);
        System.out.println("gcd(100, b): " + gcd);

        // 进制转换
        BigInteger num = new BigInteger("255");
        System.out.println("255的二进制: " + num.toString(2));
        System.out.println("255的十六进制: " + num.toString(16));
    }
}
```

### 5.2 BigDecimal

`BigDecimal` 提供任意精度的**十进制**运算，解决了 `float` 和 `double` 的精度丢失问题。

```java
import java.math.BigDecimal;
import java.math.RoundingMode;

public class BigDecimalDemo {
    public static void main(String[] args) {
        // 问题：float 和 double 的精度丢失
        System.out.println("0.1 + 0.2 = " + (0.1 + 0.2)); // 0.30000000000000004

        // 创建 BigDecimal（使用字符串构造，避免精度丢失）
        BigDecimal a = new BigDecimal("0.1");
        BigDecimal b = new BigDecimal("0.2");
        BigDecimal c = new BigDecimal("0.3");

        // 运算
        BigDecimal sum = a.add(b);
        System.out.println("0.1 + 0.2 = " + sum); // 0.3

        // 比较
        System.out.println("sum.equals(0.3): " + sum.equals(c)); // true
        System.out.println("sum.compareTo(c): " + sum.compareTo(c)); // 0

        // 乘除运算
        BigDecimal d = new BigDecimal("10.5");
        BigDecimal e = new BigDecimal("3.0");

        BigDecimal product = d.multiply(e);
        System.out.println("10.5 * 3 = " + product);

        // 除法需要指定精度和舍入模式
        BigDecimal quotient = d.divide(e, 2, RoundingMode.HALF_UP);
        System.out.println("10.5 / 3 = " + quotient); // 3.50

        // 常用方法
        BigDecimal num = new BigDecimal("123.456");
        System.out.println("setScale(2, HALF_UP): " + num.setScale(2, RoundingMode.HALF_UP)); // 123.46
        System.out.println("setScale(2, HALF_DOWN): " + num.setScale(2, RoundingMode.HALF_DOWN)); // 123.46
        System.out.println("setScale(2, FLOOR): " + num.setScale(2, RoundingMode.FLOOR)); // 123.45
        System.out.println("setScale(2, CEILING): " + num.setScale(2, RoundingMode.CEILING)); // 123.46

        // 获取整数部分
        System.out.println("intValue: " + num.intValue()); // 123

        // 绝对值
        System.out.println("abs(-10.5): " + new BigDecimal("-10.5").abs());
    }
}
```

### 5.3 舍入模式

| 舍入模式 | 说明 |
|---------|------|
| `HALF_UP` | 四舍五入（常见） |
| `HALF_DOWN` | 五舍六入 |
| `HALF_EVEN` | 银行家舍入（四舍六入五成双） |
| `CEILING` | 向正无穷方向舍入 |
| `FLOOR` | 向负无穷方向舍入 |
| `UP` | 向远离0的方向舍入 |
| `DOWN` | 向靠近0的方向舍入 |

## 第六章 综合示例

```java
import java.math.BigDecimal;
import java.math.BigInteger;
import java.math.RoundingMode;
import java.text.DecimalFormat;

/**
 * 计算工具类
 */
public class MathUtils {
    /**
     * 计算阶乘（使用 BigInteger 处理大数）
     */
    public static BigInteger factorial(int n) {
        if (n < 0) {
            throw new IllegalArgumentException("n must be >= 0");
        }
        BigInteger result = BigInteger.ONE;
        for (int i = 2; i <= n; i++) {
            result = result.multiply(BigInteger.valueOf(i));
        }
        return result;
    }

    /**
     * 判断一个数是否为质数（使用 BigInteger）
     */
    public static boolean isPrime(int n) {
        if (n < 2) return false;
        if (n == 2) return true;
        if (n % 2 == 0) return false;
        int sqrt = (int) Math.sqrt(n);
        for (int i = 3; i <= sqrt; i += 2) {
            if (n % i == 0) return false;
        }
        return true;
    }

    /**
     * 货币计算（使用 BigDecimal）
     */
    public static BigDecimal calculateInterest(BigDecimal principal, BigDecimal rate, int years) {
        BigDecimal amount = principal;
        for (int i = 0; i < years; i++) {
            amount = amount.multiply(BigDecimal.ONE.add(rate))
                           .setScale(2, RoundingMode.HALF_UP);
        }
        return amount;
    }

    /**
     * 格式化金额
     */
    public static String formatCurrency(BigDecimal amount) {
        DecimalFormat df = new DecimalFormat("#,##0.00");
        return "¥" + df.format(amount);
    }

    public static void main(String[] args) {
        // 阶乘计算
        System.out.println("=== 阶乘计算 ===");
        System.out.println("10! = " + factorial(10));
        System.out.println("50! = " + factorial(50));

        // 质数判断
        System.out.println("\n=== 质数判断 ===");
        System.out.println("17 is prime: " + isPrime(17));
        System.out.println("18 is prime: " + isPrime(18));

        // 货币计算
        System.out.println("\n=== 货币计算 ===");
        BigDecimal principal = new BigDecimal("10000");
        BigDecimal rate = new BigDecimal("0.05");
        int years = 3;
        BigDecimal result = calculateInterest(principal, rate, years);
        System.out.println("本金：¥10,000.00，年利率：5%");
        System.out.println("3年后本息合计：" + formatCurrency(result));

        // 精确的货币比较
        BigDecimal price1 = new BigDecimal("19.99");
        BigDecimal price2 = new BigDecimal("19.99");
        System.out.println("\nprice1 == price2: " + price1.equals(price2));

        // 生成随机数
        System.out.println("\n=== 随机数 ===");
        System.out.println("1-100的随机数: " + (int)(Math.random() * 100) + 1);

        // 基本数学运算
        System.out.println("\n=== 基本数学运算 ===");
        System.out.println("sin(30°) = " + Math.sin(Math.PI / 6));
        System.out.println("log2(8) = " + (Math.log(8) / Math.log(2)));
        System.out.println("√2 = " + Math.sqrt(2));
    }
}
```
