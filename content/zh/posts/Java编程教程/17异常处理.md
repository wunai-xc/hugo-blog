## 引言

没有任何一个程序是完美无缺的。在程序运行过程中，总会有各种各样的意外情况发生：用户输入了无效数据、网络连接中断、文件不存在、内存不足、数组越界……这些意外情况在Java中统称为**异常**（Exception）。

优秀的程序员不仅要会编写“正确”的代码，更要会处理“出错”的代码。一个健壮的程序，应该在遇到异常时能够优雅地处理，而不是直接崩溃。

Java提供了完善的**异常处理机制**，通过 `try-catch-finally`、`throws`、`throw` 等关键字，让开发者能够编写出健壮、可靠的程序。本文将系统讲解Java中的异常处理机制，帮助读者掌握异常处理的核心知识。

## 第一章 异常概述

### 1.1 什么是异常

**异常**（Exception）是程序运行过程中发生的、干扰正常执行流程的事件。当异常发生时，程序的正常执行流程被打断，Java会创建一个异常对象并抛出（throw），然后在异常处理代码中捕获（catch）并进行处理。

### 1.2 异常与错误的区别

Java中的异常体系分为两类：`Exception`（异常）和 `Error`（错误）。

| 类型 | 说明 | 示例 | 是否需要处理 |
|------|------|------|-------------|
| **Exception** | 程序可以捕获和处理的异常情况 | IOException、SQLException、NullPointerException | 必须处理（受检异常）或可选择处理（非受检异常） |
| **Error** | 程序无法处理的严重问题 | OutOfMemoryError、StackOverflowError、VirtualMachineError | 无法处理，只能尽量避免 |

### 1.3 异常体系结构

```text
Throwable（类）
├── Error（严重错误）
│   ├── OutOfMemoryError
│   ├── StackOverflowError
│   ├── NoSuchMethodError
│   └── ...
└── Exception（异常）
    ├── RuntimeException（非受检异常，运行时异常）
    │   ├── NullPointerException
    │   ├── ArrayIndexOutOfBoundsException
    │   ├── ArithmeticException（除零异常）
    │   ├── ClassCastException
    │   ├── IllegalArgumentException
    │   └── ...
    └── 受检异常（Checked Exception）
        ├── IOException
        ├── SQLException
        ├── ClassNotFoundException
        ├── InterruptedException
        └── ...
```

### 1.4 受检异常与非受检异常

**受检异常（Checked Exception）** ：编译器强制要求处理的异常。如果方法可能抛出受检异常，要么用 `try-catch` 捕获，要么用 `throws` 声明抛出。代表：`IOException`、`SQLException`、`ClassNotFoundException`。

**非受检异常（Unchecked Exception）** ：编译器不强制要求处理的异常。通常由程序逻辑错误引起，可以通过改进代码来避免。代表：`NullPointerException`、`ArrayIndexOutOfBoundsException`、`ArithmeticException`。

```text
┌─────────────────────────────────────────────────────────┐
│              受检异常 vs 非受检异常                     │
├─────────────────────────────────────────────────────────┤
│  受检异常（Checked Exception）                         │
│  ├── 编译器强制处理                                    │
│  ├── 必须 try-catch 或 throws                         │
│  ├── 代表：IOException, SQLException                 │
│  └── 用于可恢复的外部条件                              │
├─────────────────────────────────────────────────────────┤
│  非受检异常（Unchecked Exception）                     │
│  ├── 编译器不强制处理                                  │
│  ├── 可以不处理，但建议处理                           │
│  ├── 代表：NullPointerException, ArithmeticException  │
│  └── 用于程序逻辑错误                                  │
└─────────────────────────────────────────────────────────┘
```

## 第二章 异常处理的基本语法

### 2.1 try-catch 基本结构

```java
public class TryCatchDemo {
    public static void main(String[] args) {
        try {
            // 可能抛出异常的代码
            int result = 10 / 0; // ArithmeticException
            System.out.println("结果：" + result);
        } catch (ArithmeticException e) {
            // 捕获并处理异常
            System.out.println("发生算术异常：" + e.getMessage());
        }
        System.out.println("程序继续执行...");
    }
}
```

### 2.2 多个 catch 块

```java
public class MultipleCatchDemo {
    public static void main(String[] args) {
        try {
            String str = null;
            System.out.println(str.length()); // NullPointerException

            int[] arr = {1, 2, 3};
            System.out.println(arr[5]); // ArrayIndexOutOfBoundsException

        } catch (NullPointerException e) {
            System.out.println("空指针异常：" + e.getMessage());
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("数组越界异常：" + e.getMessage());
        } catch (Exception e) {
            // 捕获所有其他异常（通常放在最后）
            System.out.println("其他异常：" + e.getMessage());
        }
    }
}
```

### 2.3 多异常捕获（Java 7+）

```java
public class MultiCatchDemo {
    public static void main(String[] args) {
        try {
            // 可能抛出多种异常的代码
            processInput("abc");
        } catch (NumberFormatException | NullPointerException e) {
            // 使用 | 分隔多个异常
            System.out.println("输入错误：" + e.getMessage());
            // e 是 final 的，不能重新赋值
        }
    }

    public static void processInput(String input) {
        if (input == null) {
            throw new NullPointerException("输入为 null");
        }
        int num = Integer.parseInt(input); // 可能抛出 NumberFormatException
        System.out.println("数字：" + num);
    }
}
```

### 2.4 try-catch-finally

`finally` 块中的代码**无论是否发生异常都会执行**，通常用于释放资源。

```java
import java.io.*;

public class FinallyDemo {
    public static void main(String[] args) {
        FileInputStream fis = null;
        try {
            fis = new FileInputStream("test.txt");
            int data = fis.read();
            System.out.println("读取到：" + data);
        } catch (IOException e) {
            System.out.println("IO异常：" + e.getMessage());
        } finally {
            // 总是执行，用于释放资源
            if (fis != null) {
                try {
                    fis.close();
                } catch (IOException e) {
                    System.out.println("关闭流异常：" + e.getMessage());
                }
            }
            System.out.println("finally 块执行完毕");
        }
    }
}
```

### 2.5 try-with-resources（Java 7+）

Java 7 引入了 `try-with-resources`，自动管理实现了 `AutoCloseable` 接口的资源。

```java
import java.io.*;

public class TryWithResourcesDemo {
    public static void main(String[] args) {
        // 自动关闭资源（需要实现 AutoCloseable 接口）
        try (FileInputStream fis = new FileInputStream("test.txt");
             FileOutputStream fos = new FileOutputStream("output.txt")) {

            int data;
            while ((data = fis.read()) != -1) {
                fos.write(data);
            }
            System.out.println("文件复制成功！");
        } catch (IOException e) {
            System.out.println("IO异常：" + e.getMessage());
        }
        // 不需要显式关闭资源，try-with-resources 自动处理
    }
}
```

## 第三章 throw 与 throws

### 3.1 throw 关键字

`throw` 用于**手动抛出异常**。

```java
public class ThrowDemo {
    public static void main(String[] args) {
        try {
            validateAge(-5);
        } catch (IllegalArgumentException e) {
            System.out.println("捕获异常：" + e.getMessage());
        }
    }

    public static void validateAge(int age) {
        if (age < 0) {
            // 手动抛出异常
            throw new IllegalArgumentException("年龄不能为负数：" + age);
        }
        if (age > 150) {
            throw new IllegalArgumentException("年龄不能超过150：" + age);
        }
        System.out.println("年龄有效：" + age);
    }
}
```

### 3.2 throws 关键字

`throws` 用于**声明方法可能抛出的异常**，将异常的处理责任传递给调用者。

```java
import java.io.*;

public class ThrowsDemo {
    public static void main(String[] args) {
        try {
            readFile("test.txt");
        } catch (FileNotFoundException e) {
            System.out.println("文件未找到：" + e.getMessage());
        } catch (IOException e) {
            System.out.println("读取异常：" + e.getMessage());
        }
    }

    // 声明可能抛出 IOException
    public static void readFile(String filename) throws IOException {
        // 如果文件不存在，抛出 FileNotFoundException（IOException 的子类）
        FileInputStream fis = new FileInputStream(filename);
        int data = fis.read();
        System.out.println("读取到：" + data);
        fis.close();
    }
}
```

### 3.3 throw vs throws

| 对比项 | throw | throws |
|--------|-------|--------|
| **位置** | 方法体内 | 方法签名上 |
| **作用** | 实际抛出异常 | 声明可能抛出异常 |
| **数量** | 只能抛出一个异常对象 | 可以声明多个异常类型 |
| **执行** | 立即执行，中断方法 | 不执行，只是声明 |

```java
public class ThrowVsThrows {
    // throws：声明可能抛出 IOException
    public static void method1() throws IOException {
        // 不抛出异常，只是声明
    }

    // throw：实际抛出异常
    public static void method2() {
        throw new IllegalArgumentException("参数错误");
    }

    // 同时使用：声明并抛出
    public static void method3() throws IOException {
        if (true) {
            throw new IOException("IO错误");
        }
    }
}
```

## 第四章 自定义异常

### 4.1 为什么要自定义异常

1. **提供更清晰的错误信息**：系统异常无法准确描述业务错误。
2. **统一异常处理**：自定义异常可以统一处理业务异常。
3. **提高代码可读性**：业务异常比系统异常更直观。

### 4.2 创建自定义异常

自定义异常需要继承 `Exception`（受检异常）或 `RuntimeException`（非受检异常）。

```java
/**
 * 自定义受检异常 - 业务异常
 */
public class BusinessException extends Exception {
    private String errorCode;

    // 构造方法
    public BusinessException() {
        super();
    }

    public BusinessException(String message) {
        super(message);
    }

    public BusinessException(String message, Throwable cause) {
        super(message, cause);
    }

    public BusinessException(String errorCode, String message) {
        super(message);
        this.errorCode = errorCode;
    }

    public String getErrorCode() {
        return errorCode;
    }
}

/**
 * 自定义非受检异常 - 校验异常
 */
public class ValidationException extends RuntimeException {
    private String field;

    public ValidationException(String message) {
        super(message);
    }

    public ValidationException(String field, String message) {
        super(message);
        this.field = field;
    }

    public String getField() {
        return field;
    }
}
```

### 4.3 自定义异常的使用

```java
public class CustomExceptionDemo {
    public static void main(String[] args) {
        // 处理受检异常
        try {
            registerUser(null, "123456");
        } catch (BusinessException e) {
            System.out.println("业务异常：" + e.getErrorCode() + " - " + e.getMessage());
        }

        // 处理非受检异常
        try {
            validatePassword("123");
        } catch (ValidationException e) {
            System.out.println("校验异常：" + e.getField() + "：" + e.getMessage());
        }
    }

    /**
     * 注册用户 - 抛出受检异常
     */
    public static void registerUser(String username, String password) throws BusinessException {
        if (username == null || username.isEmpty()) {
            throw new BusinessException("USER_001", "用户名不能为空");
        }
        if (password == null || password.length() < 6) {
            throw new BusinessException("USER_002", "密码长度不能少于6位");
        }
        System.out.println("注册成功：" + username);
    }

    /**
     * 校验密码 - 抛出非受检异常
     */
    public static void validatePassword(String password) {
        if (password == null || password.length() < 6) {
            throw new ValidationException("password", "密码长度不能少于6位");
        }
        System.out.println("密码有效");
    }
}
```

## 第五章 异常链

### 5.1 异常链的概念

**异常链**（Exception Chaining）是在捕获一个异常后，将其包装成另一个异常再抛出的技术。它保留了原始异常的信息，方便调试。

```java
public class ExceptionChainDemo {
    public static void main(String[] args) {
        try {
            processData();
        } catch (Exception e) {
            System.out.println("顶级异常：" + e.getMessage());
            System.out.println("原始异常：" + e.getCause().getMessage());
            e.printStackTrace();
        }
    }

    public static void processData() throws Exception {
        try {
            readData();
        } catch (IOException e) {
            // 将 IOException 包装成 Exception
            throw new Exception("数据读取失败", e);
        }
    }

    public static void readData() throws IOException {
        throw new IOException("文件不存在");
    }
}
```

### 5.2 异常链的使用方式

```java
public class ExceptionChainMethods {
    public static void main(String[] args) {
        try {
            method1();
        } catch (Exception e) {
            System.out.println("错误：" + e.getMessage());
            System.out.println("原因：" + e.getCause());
        }
    }

    public static void method1() throws Exception {
        try {
            method2();
        } catch (SQLException e) {
            // 方式一：通过构造方法传递原因
            throw new Exception("业务处理失败", e);
        }
    }

    public static void method2() throws SQLException {
        try {
            method3();
        } catch (IOException e) {
            // 方式二：通过 initCause() 设置原因
            SQLException sqlException = new SQLException("数据库错误");
            sqlException.initCause(e);
            throw sqlException;
        }
    }

    public static void method3() throws IOException {
        throw new IOException("IO错误");
    }
}
```

## 第六章 异常处理的最佳实践

### 6.1 不要吞掉异常

```java
// ❌ 错误：吞掉异常
try {
    // 可能抛出异常的代码
} catch (Exception e) {
    // 什么都不做，异常被吞掉
}

// ❌ 错误：只打印日志不处理
try {
    // 可能抛出异常的代码
} catch (Exception e) {
    e.printStackTrace();
    // 没有进一步处理
}

// ✅ 正确：记录日志并适当处理
try {
    // 可能抛出异常的代码
} catch (IOException e) {
    logger.error("文件读取失败", e);
    // 重新抛出或返回错误信息
    throw new BusinessException("文件读取失败", e);
}
```

### 6.2 捕获最具体的异常

```java
// ❌ 错误：捕获过于宽泛
try {
    // 可能抛出多种异常的代码
} catch (Exception e) {
    // 处理所有异常，但丢失了具体信息
}

// ✅ 正确：先捕获具体异常，再捕获宽泛异常
try {
    // 可能抛出多种异常的代码
} catch (FileNotFoundException e) {
    System.out.println("文件未找到：" + e.getMessage());
} catch (IOException e) {
    System.out.println("IO异常：" + e.getMessage());
} catch (Exception e) {
    System.out.println("其他异常：" + e.getMessage());
}
```

### 6.3 使用 finally 释放资源

```java
// ✅ 正确：使用 finally 释放资源
Connection conn = null;
try {
    conn = DriverManager.getConnection(url, user, password);
    // 使用连接...
} catch (SQLException e) {
    System.out.println("数据库异常：" + e.getMessage());
} finally {
    if (conn != null) {
        try {
            conn.close();
        } catch (SQLException e) {
            System.out.println("关闭连接异常：" + e.getMessage());
        }
    }
}

// ✅ 更好：使用 try-with-resources
try (Connection conn = DriverManager.getConnection(url, user, password)) {
    // 使用连接，自动关闭
} catch (SQLException e) {
    System.out.println("数据库异常：" + e.getMessage());
}
```

### 6.4 不要使用异常控制流程

```java
// ❌ 错误：使用异常控制流程
try {
    while (true) {
        // 读取数据，直到抛出异常
    }
} catch (Exception e) {
    // 结束循环
}

// ✅ 正确：使用正常条件判断
while (hasNext()) {
    // 读取数据
}
```

### 6.5 异常信息应该有意义

```java
// ❌ 错误：异常信息不明确
throw new Exception("error");

// ✅ 正确：异常信息清晰明确
throw new IllegalArgumentException("年龄必须在 0-150 之间，当前值：" + age);
throw new BusinessException("USER_001", "用户名不能为空");
```

### 6.6 选择合适的异常类型

```java
// 参数校验失败 → IllegalArgumentException 或自定义校验异常
public void setName(String name) {
    if (name == null || name.isEmpty()) {
        throw new IllegalArgumentException("姓名不能为空");
    }
    this.name = name;
}

// 资源不可用 → IOException 或自定义业务异常
public byte[] readFile(String path) throws IOException {
    // 读取文件
}

// 业务规则违反 → 自定义业务异常
public void withdraw(double amount) throws BusinessException {
    if (amount > balance) {
        throw new BusinessException("余额不足");
    }
    balance -= amount;
}
```

## 第七章 综合示例

```java
import java.io.*;
import java.util.*;

/**
 * 学生成绩管理系统 - 异常处理综合示例
 */
public class StudentScoreSystem {
    private Map<String, Student> students = new HashMap<>();

    /**
     * 添加学生
     */
    public void addStudent(String id, String name, double score) throws ValidationException {
        // 参数校验
        if (id == null || id.trim().isEmpty()) {
            throw new ValidationException("id", "学号不能为空");
        }
        if (name == null || name.trim().isEmpty()) {
            throw new ValidationException("name", "姓名不能为空");
        }
        if (score < 0 || score > 100) {
            throw new ValidationException("score", "成绩必须在0-100之间：" + score);
        }
        if (students.containsKey(id)) {
            throw new ValidationException("id", "学号已存在：" + id);
        }

        students.put(id, new Student(id, name, score));
        System.out.println("添加成功：" + name + "，成绩：" + score);
    }

    /**
     * 查找学生
     */
    public Student findStudent(String id) throws BusinessException {
        if (id == null || id.trim().isEmpty()) {
            throw new BusinessException("STU_001", "学号不能为空");
        }
        Student student = students.get(id);
        if (student == null) {
            throw new BusinessException("STU_002", "学生不存在：" + id);
        }
        return student;
    }

    /**
     * 删除学生
     */
    public boolean deleteStudent(String id) throws BusinessException {
        Student student = findStudent(id);
        students.remove(id);
        System.out.println("删除成功：" + student.getName());
        return true;
    }

    /**
     * 从文件加载数据
     */
    public void loadFromFile(String filename) throws BusinessException {
        try (BufferedReader reader = new BufferedReader(new FileReader(filename))) {
            String line;
            int lineNum = 0;
            while ((line = reader.readLine()) != null) {
                lineNum++;
                try {
                    String[] parts = line.split(",");
                    if (parts.length != 3) {
                        System.err.println("第 " + lineNum + " 行格式错误，跳过：" + line);
                        continue;
                    }
                    String id = parts[0].trim();
                    String name = parts[1].trim();
                    double score = Double.parseDouble(parts[2].trim());
                    addStudent(id, name, score);
                } catch (NumberFormatException e) {
                    System.err.println("第 " + lineNum + " 行成绩格式错误，跳过：" + line);
                } catch (ValidationException e) {
                    System.err.println("第 " + lineNum + " 行数据校验失败：" + e.getMessage());
                }
            }
            System.out.println("数据加载完成，共处理 " + lineNum + " 行");
        } catch (FileNotFoundException e) {
            throw new BusinessException("FILE_001", "文件不存在：" + filename, e);
        } catch (IOException e) {
            throw new BusinessException("FILE_002", "文件读取失败：" + filename, e);
        }
    }

    /**
     * 保存数据到文件
     */
    public void saveToFile(String filename) throws BusinessException {
        try (PrintWriter writer = new PrintWriter(new FileWriter(filename))) {
            for (Student s : students.values()) {
                writer.println(s.getId() + "," + s.getName() + "," + s.getScore());
            }
            System.out.println("数据保存成功，共 " + students.size() + " 条记录");
        } catch (IOException e) {
            throw new BusinessException("FILE_003", "文件保存失败：" + filename, e);
        }
    }

    /**
     * 统计信息
     */
    public void printStatistics() {
        if (students.isEmpty()) {
            System.out.println("暂无学生数据");
            return;
        }

        double sum = 0;
        double max = Double.MIN_VALUE;
        double min = Double.MAX_VALUE;

        for (Student s : students.values()) {
            sum += s.getScore();
            max = Math.max(max, s.getScore());
            min = Math.min(min, s.getScore());
        }

        System.out.println("\n=== 统计信息 ===");
        System.out.println("总人数：" + students.size());
        System.out.println("平均分：" + String.format("%.2f", sum / students.size()));
        System.out.println("最高分：" + max);
        System.out.println("最低分：" + min);
        System.out.println("================");
    }

    /**
     * 显示所有学生
     */
    public void displayAll() {
        if (students.isEmpty()) {
            System.out.println("暂无学生数据");
            return;
        }
        System.out.println("\n=== 学生列表 ===");
        for (Student s : students.values()) {
            System.out.println(s);
        }
        System.out.println("==============");
    }

/**
 * 自定义校验异常（非受检）
 */
class ValidationException extends RuntimeException {
    private String field;

    public ValidationException(String field, String message) {
        super(message);
        this.field = field;
    }

    public String getField() {
        return field;
    }
}

/**
 * 自定义业务异常（受检）
 */
class BusinessException extends Exception {
    private String errorCode;

    public BusinessException(String errorCode, String message) {
        super(message);
        this.errorCode = errorCode;
    }

    public BusinessException(String errorCode, String message, Throwable cause) {
        super(message, cause);
        this.errorCode = errorCode;
    }

    public String getErrorCode() {
        return errorCode;
    }
}

    public double getScore() { return score; }
```

## 总结

本文系统讲解了Java中的异常处理机制：

| 知识点 | 核心要点 |
|--------|---------|
| **Throwable** | 所有异常和错误的父类 |
| **Exception** | 可处理的异常，分为受检和非受检 |
| **Error** | 严重错误，无法处理 |
| **try-catch** | 捕获并处理异常 |
| **finally** | 总是执行，释放资源 |
| **try-with-resources** | 自动管理资源（Java 7+） |
| **throw** | 手动抛出异常 |
| **throws** | 声明可能抛出的异常 |
| **自定义异常** | 继承 Exception 或 RuntimeException |
| **异常链** | 保留原始异常信息 |
