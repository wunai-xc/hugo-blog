## 引言

在程序开发中，我们经常需要存储和操作一组数据——比如一个班级的所有学生、一个订单中的所有商品、一个用户的所有好友。数组虽然可以存储多个数据，但它有几个局限性：长度固定、删除和插入操作不便、缺少现成的工具方法。

Java集合框架（Collection Framework）提供了一套完整的容器类，用于存储和操作一组对象。它是Java中最重要、最常用的工具库之一，几乎每个Java程序都离不开它。

本文将系统讲解Java集合框架中的List和Set接口及其实现类，包括ArrayList、LinkedList、HashSet、TreeSet等常用集合，以及集合的遍历方式。

## 第一章 集合框架概述

### 1.1 集合与数组的对比

| 对比维度 | 数组 | 集合 |
|---------|------|------|
| **长度** | 固定，不可变 | 动态，自动扩容 |
| **存储类型** | 基本类型和引用类型 | 只能存储引用类型（泛型） |
| **操作方法** | 简单（`length`、下标访问） | 丰富（添加、删除、查找、排序等） |
| **性能** | 直接访问，效率最高 | 略有开销，但提供了更多功能 |

### 1.2 集合框架体系结构

```text
Collection（接口）
├── List（接口）
│   ├── ArrayList（实现类）
│   ├── LinkedList（实现类）
│   └── Vector（实现类，旧）
│       └── Stack（实现类，旧）
├── Set（接口）
│   ├── HashSet（实现类）
│   │   └── LinkedHashSet（实现类）
│   └── TreeSet（实现类）
└── Queue（接口）
    └── ...

Map（接口）
├── HashMap（实现类）
│   └── LinkedHashMap（实现类）
├── TreeMap（实现类）
└── Hashtable（实现类，旧）
```

### 1.3 核心接口说明

| 接口 | 说明 |
|------|------|
| `Collection` | 所有单列集合的根接口 |
| `List` | 有序、可重复的集合（有索引） |
| `Set` | 无序、不可重复的集合（无索引） |
| `Queue` | 队列（FIFO，先进先出） |
| `Map` | 键值对映射关系（双列集合） |

## 第二章 Collection 接口

`Collection` 是所有单列集合的父接口，定义了集合的通用方法。

### 2.1 Collection 常用方法

```java
import java.util.*;

public class CollectionMethods {
    public static void main(String[] args) {
        // 使用 ArrayList 演示 Collection 的方法
        Collection<String> collection = new ArrayList<>();

        // 添加元素
        collection.add("A");
        collection.add("B");
        collection.add("C");
        System.out.println("添加后：" + collection); // [A, B, C]

        // 获取集合大小
        System.out.println("size = " + collection.size()); // 3

        // 判断是否为空
        System.out.println("isEmpty = " + collection.isEmpty()); // false

        // 判断是否包含某元素
        System.out.println("contains('A'): " + collection.contains("A")); // true
        System.out.println("contains('D'): " + collection.contains("D")); // false

        // 删除元素
        collection.remove("B");
        System.out.println("删除 B 后：" + collection); // [A, C]

        // 转换为数组
        Object[] arr = collection.toArray();
        System.out.println("数组：" + Arrays.toString(arr));

        // 批量添加
        Collection<String> another = Arrays.asList("D", "E", "F");
        collection.addAll(another);
        System.out.println("批量添加后：" + collection); // [A, C, D, E, F]

        // 批量删除
        collection.removeAll(Arrays.asList("C", "D"));
        System.out.println("批量删除后：" + collection); // [A, E, F]

        // 清空集合
        collection.clear();
        System.out.println("清空后：" + collection); // []
        System.out.println("size = " + collection.size()); // 0
    }
}
```

## 第三章 List 接口

### 3.1 List 接口的特点

`List` 是有序的集合，元素可以重复，允许 `null` 元素，可以通过索引访问。

**List 的特有方法**：

| 方法 | 说明 |
|------|------|
| `add(index, element)` | 在指定位置插入元素 |
| `get(index)` | 获取指定位置的元素 |
| `set(index, element)` | 替换指定位置的元素 |
| `remove(index)` | 删除指定位置的元素 |
| `indexOf(element)` | 返回元素的第一次出现的索引 |
| `lastIndexOf(element)` | 返回元素的最后一次出现的索引 |
| `subList(from, to)` | 截取子列表 |

### 3.2 ArrayList

`ArrayList` 是 List 接口最常用的实现类，底层是**动态数组**。

```java
import java.util.*;

public class ArrayListDemo {
    public static void main(String[] args) {
        // 创建 ArrayList
        // 默认初始容量为10，当元素超过容量时会自动扩容
        List<String> list = new ArrayList<>();

        // 指定初始容量
        List<String> list2 = new ArrayList<>(20);

        // 从已有集合创建
        List<String> list3 = new ArrayList<>(Arrays.asList("A", "B", "C"));

        // 添加元素
        list.add("Apple");
        list.add("Banana");
        list.add("Orange");
        list.add("Apple"); // 允许重复
        System.out.println("添加后：" + list); // [Apple, Banana, Orange, Apple]

        // 在指定位置插入
        list.add(1, "Grape");
        System.out.println("插入后：" + list); // [Apple, Grape, Banana, Orange, Apple]

        // 访问元素
        System.out.println("get(0) = " + list.get(0)); // Apple
        System.out.println("get(2) = " + list.get(2)); // Banana

        // 修改元素
        list.set(2, "Watermelon");
        System.out.println("修改后：" + list); // [Apple, Grape, Watermelon, Orange, Apple]

        // 删除元素（按索引）
        list.remove(1);
        System.out.println("删除索引1后：" + list); // [Apple, Watermelon, Orange, Apple]

        // 删除元素（按对象）
        list.remove("Apple");
        System.out.println("删除 'Apple' 后：" + list); // [Watermelon, Orange, Apple]
        // 注意：只删除第一个匹配的元素

        // 查找元素
        System.out.println("indexOf('Orange'): " + list.indexOf("Orange")); // 1
        System.out.println("lastIndexOf('Apple'): " + list.lastIndexOf("Apple")); // 2

        // 判断是否包含
        System.out.println("contains('Watermelon'): " + list.contains("Watermelon")); // true

        // 获取子列表
        List<String> sub = list.subList(0, 2);
        System.out.println("子列表：[0,2) = " + sub); // [Watermelon, Orange]

        // 遍历 ArrayList
        System.out.println("=== 遍历 ===");
        // 方式一：普通 for 循环
        for (int i = 0; i < list.size(); i++) {
            System.out.println(list.get(i));
        }

        // 方式二：增强 for 循环
        for (String s : list) {
            System.out.println(s);
        }

        // 方式三：迭代器（后面讲解）
        // 方式四：forEach + Lambda（Java 8+）
        list.forEach(System.out::println);
    }
}
```

**扩容机制**：当元素数量超过数组容量时，ArrayList 会自动扩容，新容量约为原来的 1.5 倍。

```java
public class ArrayListCapacityDemo {
    public static void main(String[] args) {
        ArrayList<Integer> list = new ArrayList<>();
```

### 3.4 LinkedList

`LinkedList` 底层是**双向链表**，它同时实现了 `List` 和 `Deque` 接口。

```java
import java.util.*;

public class LinkedListDemo {
    public static void main(String[] args) {
        // 创建 LinkedList
        LinkedList<String> list = new LinkedList<>();

        // 作为 List 使用
        list.add("A");
        list.add("B");
        list.add("C");
        System.out.println("List 操作：" + list); // [A, B, C]

        // 作为 Deque（双端队列）使用
        // 在头部添加
        list.addFirst("First");
        System.out.println("addFirst 后：" + list); // [First, A, B, C]

        // 在尾部添加
        list.addLast("Last");
        System.out.println("addLast 后：" + list); // [First, A, B, C, Last]

        // 获取头部和尾部元素
        System.out.println("getFirst = " + list.getFirst()); // First
        System.out.println("getLast = " + list.getLast()); // Last

        // 弹出头部和尾部元素
        String head = list.pollFirst();
        String tail = list.pollLast();
        System.out.println("pollFirst = " + head); // First
        System.out.println("pollLast = " + tail); // Last
        System.out.println("poll 后：" + list); // [A, B, C]

        // 作为栈使用（push/pop）
        LinkedList<String> stack = new LinkedList<>();
        stack.push("A");
        stack.push("B");
        stack.push("C");
        System.out.println("栈：" + stack); // [C, B, A]
        System.out.println("pop = " + stack.pop()); // C
        System.out.println("栈：" + stack); // [B, A]
    }
}
```

### 3.5 ArrayList vs LinkedList

| 特性 | ArrayList | LinkedList |
|------|-----------|------------|
| **底层结构** | 动态数组 | 双向链表 |
| **随机访问（get/set）** | **O(1)**，极快 | O(n)，较慢 |
| **末尾添加（add）** | 均摊 O(1) | O(1) |
| **中间插入/删除** | O(n)，较慢 | O(n)，但节点操作只需 O(1) |
| **内存占用** | 连续内存，略有浪费 | 节点额外存储指针，内存开销大 |
| **实现接口** | List | List + Deque |
| **适用场景** | 频繁访问、末尾操作 | 频繁插入/删除、双端操作 |

```java
public class ListCompareDemo {
    public static void main(String[] args) {
        // 高频读取场景：使用 ArrayList
        List<Integer> arrayList = new ArrayList<>();
        // 添加大量数据...
        // 随机访问效率高

        // 高频插入删除（头尾）场景：使用 LinkedList
        LinkedList<Integer> linkedList = new LinkedList<>();
        linkedList.addFirst(1);
        linkedList.addLast(2);

        // 低频中间插入：两者差别不大
    }
}
```

## 第四章 Set 接口

### 4.1 Set 接口的特点

`Set` 是无序、不可重复的集合（数学意义上的“集合”）。Set 中没有索引，不能通过索引访问元素。

**Set 的核心特征**：
- 元素唯一性（不允许重复）
- 无序性（不保证元素的顺序）
- 允许一个 `null` 元素（某些实现可能有不同的顺序保证）

### 4.2 HashSet

`HashSet` 是最常用的 Set 实现，底层使用 `HashMap`，通过哈希表存储元素。

```java
import java.util.*;

public class HashSetDemo {
    public static void main(String[] args) {
        // 创建 HashSet
        Set<String> set = new HashSet<>();

        // 添加元素
        set.add("Apple");
        set.add("Banana");
        set.add("Orange");
        set.add("Apple"); // 重复元素，不会添加
        System.out.println("添加后：" + set); // [Apple, Banana, Orange]（顺序不固定）

        // 判断是否包含
        System.out.println("contains('Banana'): " + set.contains("Banana")); // true

        // 删除元素
        set.remove("Banana");
        System.out.println("删除后：" + set); // [Apple, Orange]

        // 元素个数
        System.out.println("size = " + set.size()); // 2

        // 遍历 Set（无索引，只能用增强 for 或迭代器）
        System.out.println("=== 遍历 ===");
        for (String s : set) {
            System.out.println(s);
        }

        // Set 常用操作：并集、交集、差集
        Set<Integer> set1 = new HashSet<>(Arrays.asList(1, 2, 3, 4));
        Set<Integer> set2 = new HashSet<>(Arrays.asList(3, 4, 5, 6));

        // 并集
        Set<Integer> union = new HashSet<>(set1);
        union.addAll(set2);
        System.out.println("并集：" + union); // [1, 2, 3, 4, 5, 6]

        // 交集
        Set<Integer> intersection = new HashSet<>(set1);
        intersection.retainAll(set2);
        System.out.println("交集：" + intersection); // [3, 4]

        // 差集（set1 - set2）
        Set<Integer> diff = new HashSet<>(set1);
        diff.removeAll(set2);
        System.out.println("差集：" + diff); // [1, 2]
    }
}
```

### 4.3 HashSet 的底层原理

`HashSet` 底层使用 `HashMap` 存储元素，元素作为 `HashMap` 的键，值是一个固定的 `Object`。

```text
┌────────────────────────────────────────────┐
│              HashSet 内部结构              │
├────────────────────────────────────────────┤
│  底层：HashMap<E, Object>                 │
│  ┌──────────────────────────────────────┐ │
│  │  key（元素）  │  value（固定对象）   │ │
│  ├──────────────────────────────────────┤ │
│  │  "Apple"      │  PRESENT            │ │
│  │  "Banana"     │  PRESENT            │ │
│  │  "Orange"     │  PRESENT            │ │
│  └──────────────────────────────────────┘ │
├────────────────────────────────────────────┤
│  操作特点：                               │
│  - 添加/删除/查找：O(1)（均摊）           │
│  - 元素必须正确实现 hashCode() 和 equals()│
│  - 不保证顺序                             │
└────────────────────────────────────────────┘
```

**HashSet 的元素去重依赖于 `hashCode()` 和 `equals()`**：

```java
public class HashSetEqualsDemo {
    public static void main(String[] args) {
        class Person {
            String name;
            int age;

            Person(String name, int age) {
                this.name = name;
                this.age = age;
            }

            @Override
            public boolean equals(Object o) {
                if (this == o) return true;
                if (o == null || getClass() != o.getClass()) return false;
                Person person = (Person) o;
                return age == person.age && Objects.equals(name, person.name);
            }

            @Override
            public int hashCode() {
                return Objects.hash(name, age);
            }

            @Override
            public String toString() {
                return name + "(" + age + ")";
            }
        }

        Set<Person> set = new HashSet<>();
        set.add(new Person("张三", 20));
        set.add(new Person("张三", 20)); // 重复（equals 返回 true）
        set.add(new Person("李四", 20));

        System.out.println("set = " + set);
        // 输出：[张三(20), 李四(20)]（张三只出现一次）
    }
}
```

### 4.4 TreeSet

`TreeSet` 使用红黑树（平衡二叉搜索树）存储元素，具有**排序**功能。

```java
import java.util.*;

public class TreeSetDemo {
    public static void main(String[] args) {
        // 自然排序（元素必须实现 Comparable 接口）
        Set<Integer> numbers = new TreeSet<>();
        numbers.add(5);
        numbers.add(1);
        numbers.add(8);
        numbers.add(3);
        System.out.println("TreeSet 排序后：" + numbers); // [1, 3, 5, 8]

        // 字符串按字典序排序
        Set<String> words = new TreeSet<>();
        words.add("Banana");
        words.add("Apple");
        words.add("Orange");
        words.add("Grape");
        System.out.println("字符串排序：" + words); // [Apple, Banana, Grape, Orange]

        // 自定义排序（使用 Comparator）
        Set<String> customOrder = new TreeSet<>(Comparator.reverseOrder());
        customOrder.add("Banana");
        customOrder.add("Apple");
        customOrder.add("Orange");
        System.out.println("降序排序：" + customOrder); // [Orange, Banana, Apple]

        // 自定义对象排序
        class Student implements Comparable<Student> {
            String name;
            int score;

            Student(String name, int score) {
                this.name = name;
                this.score = score;
            }

            @Override
            public int compareTo(Student other) {
                // 按分数降序排序
                return Integer.compare(other.score, this.score);
            }

            @Override
            public String toString() {
                return name + ":" + score;
            }
        }

        TreeSet<Student> students = new TreeSet<>();
        students.add(new Student("张三", 85));
        students.add(new Student("李四", 92));
        students.add(new Student("王五", 78));
        students.add(new Student("赵六", 88));

        System.out.println("按分数降序：" + students);
        // [李四:92, 赵六:88, 张三:85, 王五:78]
    }
}
```

### 4.5 HashSet vs TreeSet

| 特性 | HashSet | TreeSet |
|------|---------|---------|
| **底层结构** | 哈希表（HashMap） | 红黑树 |
| **元素顺序** | 无序 | 有序（自然顺序或比较器） |
| **性能** | 添加/删除/查找 O(1) | 添加/删除/查找 O(log n) |
| **是否允许 null** | 允许一个 null | 不允许 null（需比较） |
| **元素要求** | 需正确实现 hashCode/equals | 需实现 Comparable 或传入 Comparator |
| **适用场景** | 需要快速查找去重 | 需要排序或有范围查询 |

## 第五章 集合的遍历

### 5.1 三种遍历方式

```java
import java.util.*;

public class IterationDemo {
    public static void main(String[] args) {
        List<String> list = new ArrayList<>(Arrays.asList("A", "B", "C", "D"));

        // 方式一：普通 for 循环（仅 List 可用）
        System.out.println("=== 普通 for 循环 ===");
        for (int i = 0; i < list.size(); i++) {
            System.out.println(list.get(i));
        }

        // 方式二：增强 for 循环（所有 Collection 可用）
        System.out.println("=== 增强 for 循环 ===");
        for (String s : list) {
            System.out.println(s);
        }

        // 方式三：Iterator 迭代器（所有 Collection 可用）
        System.out.println("=== Iterator ===");
        Iterator<String> iterator = list.iterator();
        while (iterator.hasNext()) {
            String s = iterator.next();
            System.out.println(s);
        }

        // 方式四：forEach + Lambda（Java 8+）
        System.out.println("=== forEach + Lambda ===");
        list.forEach(s -> System.out.println(s));
        // 或使用方法引用
        list.forEach(System.out::println);
    }
}
```

### 5.2 Iterator 的使用

`Iterator` 是集合的标准迭代器，提供了统一的遍历接口。

```java
import java.util.*;

public class IteratorDemo {
    public static void main(String[] args) {
        List<Integer> list = new ArrayList<>(Arrays.asList(1, 2, 3, 4, 5));

        Iterator<Integer> it = list.iterator();

        // 遍历
        while (it.hasNext()) {
            Integer num = it.next();
            System.out.println(num);
        }

        // 重置迭代器
        it = list.iterator();

        // 迭代过程中删除元素
        while (it.hasNext()) {
            Integer num = it.next();
            if (num % 2 == 0) {
                it.remove(); // 删除偶数
            }
        }
        System.out.println("删除偶数后：" + list); // [1, 3, 5]

        // 注意：在迭代过程中不能直接使用集合的删除方法
        // 否则会抛出 ConcurrentModificationException
        List<String> list2 = new ArrayList<>(Arrays.asList("A", "B", "C"));
        // for (String s : list2) {
        //     if (s.equals("B")) {
        //         list2.remove(s); // 错误！ConcurrentModificationException
        //     }
        // }

        // 正确方式：使用 Iterator
        Iterator<String> it2 = list2.iterator();
        while (it2.hasNext()) {
            if (it2.next().equals("B")) {
                it2.remove();
            }
        }
        System.out.println(list2); // [A, C]
    }
}
```

### 5.3 ListIterator

`ListIterator` 是 `Iterator` 的子接口，专门用于 List，支持双向遍历和元素修改。

```java
import java.util.*;

public class ListIteratorDemo {
    public static void main(String[] args) {
        List<String> list = new ArrayList<>(Arrays.asList("A", "B", "C", "D"));

        // 正向遍历
        System.out.println("=== 正向遍历 ===");
        ListIterator<String> it = list.listIterator();
        while (it.hasNext()) {
            System.out.println("index: " + it.nextIndex() + ", value: " + it.next());
        }

        // 反向遍历
        System.out.println("=== 反向遍历 ===");
        while (it.hasPrevious()) {
            System.out.println("index: " + it.previousIndex() + ", value: " + it.previous());
        }

        // 添加元素
        it = list.listIterator(2); // 从索引2开始
        it.add("X");
        System.out.println("插入 X 后：" + list); // [A, B, X, C, D]

        // 修改元素
        it = list.listIterator();
        while (it.hasNext()) {
            String s = it.next();
            if (s.equals("X")) {
                it.set("Y");
            }
        }
        System.out.println("修改后：" + list); // [A, B, Y, C, D]
    }
}
```

## 总结

本文系统讲解了 Java 集合框架中的 List 和 Set：

| 知识点 | 核心要点 |
|--------|---------|
| **Collection** | 所有单列集合的根接口 |
| **List** | 有序、可重复、有索引 |
| **ArrayList** | 动态数组，随机访问快，中间插入/删除慢 |
| **LinkedList** | 双向链表，头尾操作快，随机访问慢 |
| **Set** | 无序、不可重复 |
| **HashSet** | 哈希表，O(1) 操作，不保证顺序 |
| **TreeSet** | 红黑树，有序，O(log n) 操作 |
| **Iterator** | 集合遍历的标准方式 |
| **ListIterator** | List 专用的双向迭代器 |
