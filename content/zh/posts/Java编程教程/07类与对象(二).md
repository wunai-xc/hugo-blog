## 引言

在上一篇文章中，我们学习了类与对象的基本概念、构造方法以及 `this` 关键字的使用。掌握了这些知识后，我们已经能够定义简单的类并创建对象了。

然而，面向对象编程的精髓远不止于此。**封装**、**继承**和**多态**是面向对象的三大特征，其中封装是最基础也是最重要的一环。此外，`static` 关键字、代码块和内部类等机制，进一步丰富了Java的面向对象能力。

本文将深入讲解这些核心概念，帮助读者真正理解面向对象编程的设计思想。

## 第一章 封装（Encapsulation）

### 1.1 什么是封装

**封装**是面向对象编程的三大特征之一，它将数据（成员变量）和操作数据的方法（成员方法）绑定在一起，形成一个独立的单元——对象。同时，封装通过**信息隐藏**机制，对外部隐藏对象的内部实现细节，只暴露必要的接口供外部使用。

封装的核心理念可以概括为：**“高内聚，低耦合”**。

- **高内聚**：一个类应该只做一件事，并且把相关的数据和操作集中在一起。
- **低耦合**：类与类之间的依赖关系应该尽可能简单和清晰。

### 1.2 封装的好处

1. **安全性**：通过限制外部对内部数据的直接访问，防止数据被意外修改。
2. **可维护性**：内部实现细节的改变不影响外部调用者，降低了修改代码的风险。
3. **可控性**：通过 setter 方法可以添加业务逻辑校验，确保数据的合法性。
4. **简化使用**：外部调用者只需要知道如何调用方法，而不需要了解内部实现。

### 1.3 如何实现封装

在Java中，封装通过以下方式实现：

1. 使用 `private` 修饰成员变量，限制外部直接访问。
2. 提供 `public` 的 getter 和 setter 方法，让外部通过方法访问和修改数据。
3. 在 setter 方法中添加校验逻辑，确保数据的合法性。

```java
/**
 * 封装示例：Person类
 */
public class Person {
    // 1. 私有化成员变量（外部无法直接访问）
    private String name;
    private int age;
    private String idCard;

    // 2. 提供公共的 getter / setter 方法

    // Getter：返回数据
    public String getName() {
        return name;
    }

    // Setter：可以添加校验逻辑
    public void setName(String name) {
        if (name != null && !name.trim().isEmpty()) {
            this.name = name;
        } else {
            System.out.println("姓名不能为空！");
        }
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        // 添加业务校验
        if (age >= 0 && age <= 150) {
            this.age = age;
        } else {
            System.out.println("年龄必须在0-150之间！");
        }
    }

    public String getIdCard() {
        // 敏感信息可以部分隐藏（返回脱敏数据）
        if (idCard == null || idCard.length() < 8) {
            return idCard;
        }
        return idCard.substring(0, 6) + "********";
    }

    public void setIdCard(String idCard) {
        // 身份证号格式校验（简化版）
        if (idCard != null && idCard.matches("\\d{17}[\\dXx]")) {
            this.idCard = idCard;
        } else {
            System.out.println("身份证号格式不正确！");
        }
    }

    // 业务方法
    public void display() {
        System.out.println("姓名：" + name + "，年龄：" + age);
    }
}
```

### 1.4 封装的最佳实践

1. **字段尽量使用 `private`**：除非有充分理由，否则所有成员变量都应该是 `private` 的。
2. **提供合理的 getter/setter**：并非所有字段都需要 getter/setter，根据业务需求决定。
3. **在 setter 中添加校验**：确保数据的合法性，避免对象处于无效状态。
4. **返回不可变数据**：如果返回的是可变对象（如集合），考虑返回副本或不可修改的版本。

## 第二章 访问修饰符

访问修饰符用于控制类、方法和成员变量的可见范围。Java提供了四种访问修饰符。

### 2.1 四种访问修饰符

| 修饰符 | 同一类 | 同一包 | 子类（不同包） | 任何类 |
|--------|--------|--------|---------------|--------|
| `private` | ✅ | ❌ | ❌ | ❌ |
| 默认（无修饰符） | ✅ | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ | ✅ |

### 2.2 详细说明

#### private（私有）

`private` 是最严格的访问修饰符，被修饰的成员**只能在当前类内部访问**。

```java
public class PrivateDemo {
    private int secret = 100;

    private void secretMethod() {
        System.out.println("私有方法");
    }

    public void accessPrivate() {
        // 类内部可以访问私有成员
        System.out.println(secret);
        secretMethod();
    }
}

class Test {
    public static void main(String[] args) {
        PrivateDemo demo = new PrivateDemo();
        // demo.secret = 200;     // 错误！private 成员不可访问
        // demo.secretMethod();   // 错误！private 方法不可访问
        demo.accessPrivate();     // 正确！通过公共方法访问
    }
}
```

#### 默认（包级私有，package-private）

没有写任何修饰符时，成员**只能在同一个包内访问**。

```java
// File: com/example/DefaultDemo.java
package com.example;

class DefaultDemo {
    int value = 10; // 默认访问权限
    void method() {} // 默认访问权限
}

// File: com/example/Test.java（同一包）
package com.example;

class Test {
    public static void main(String[] args) {
        DefaultDemo demo = new DefaultDemo();
        demo.value = 20; // 可访问（同一包）
        demo.method();   // 可访问（同一包）
    }
}

// File: com/other/Test2.java（不同包）
package com.other;

class Test2 {
    public static void main(String[] args) {
        // DefaultDemo demo = new DefaultDemo(); // 错误！类本身默认，不可访问
    }
}
```

#### protected（受保护）

`protected` 修饰的成员可以在**同一包内的任何类**以及**不同包的子类**中访问。

```java
// File: com/example/Parent.java
package com.example;

public class Parent {
    protected int value = 100;
    protected void method() {
        System.out.println("Parent method");
    }
}

// File: com/example/Child.java（同一包，子类）
package com.example;

public class Child extends Parent {
    public void test() {
        value = 200;   // 可访问
        method();      // 可访问
    }
}

// File: com/other/Child2.java（不同包，子类）
package com.other;

import com.example.Parent;

public class Child2 extends Parent {
    public void test() {
        value = 300;   // 可访问（不同包但子类）
        method();      // 可访问（不同包但子类）

        Parent p = new Parent();
        // p.value = 400; // 错误！不是通过子类引用访问
    }
}
```

#### public（公共）

`public` 是最宽松的修饰符，**所有类都可以访问**。

```java
public class PublicDemo {
    public int value = 100;
    public void method() {
        System.out.println("公共方法");
    }
}

// 任何类都可以访问
class AnyClass {
    public void test() {
        PublicDemo demo = new PublicDemo();
        demo.value = 200; // 可访问
        demo.method();    // 可访问
    }
}
```

### 2.3 选择建议

| 场景 | 推荐修饰符 |
|------|-----------|
| 成员变量（字段） | `private`（几乎总是） |
| 类内部使用的方法 | `private` |
| 被同一个包内其他类调用的方法 | 默认（包级私有） |
| 需要被子类继承的方法 | `protected` |
| 对外公开的API | `public` |
| 工具类中的常量 | `public static final` |

## 第三章 static 关键字

`static` 是Java中一个非常重要的关键字，用于修饰**类成员**（成员变量和方法）。被 `static` 修饰的成员属于**类本身**，而不是属于类的某个对象。

### 3.1 静态变量（类变量）

静态变量使用 `static` 修饰，属于类，所有对象共享同一个静态变量。

```java
public class StaticVariableDemo {
    // 实例变量（属于对象）
    private int instanceVar = 0;
    // 静态变量（属于类）
    private static int staticVar = 0;

    public void increment() {
        instanceVar++;
        staticVar++;
    }

    public void display() {
        System.out.println("实例变量：" + instanceVar + "，静态变量：" + staticVar);
    }

    public static void main(String[] args) {
        StaticVariableDemo obj1 = new StaticVariableDemo();
        StaticVariableDemo obj2 = new StaticVariableDemo();

        obj1.increment(); // 实例变量:1, 静态变量:1
        obj1.display();

        obj2.increment(); // 实例变量:1, 静态变量:2
        obj2.display();

        // 通过类名访问静态变量
        System.out.println("通过类名访问：" + StaticVariableDemo.staticVar);
    }
}
```

**静态变量的特点**：

1. 在类加载时初始化（只初始化一次）。
2. 所有对象共享同一个静态变量。
3. 可以通过类名直接访问（`ClassName.staticVar`）。

### 3.2 静态方法（类方法）

静态方法属于类，可以直接通过类名调用，不需要创建对象。

```java
public class MathUtils {
    // 静态方法：计算两个数的最大值
    public static int max(int a, int b) {
        return a > b ? a : b;
    }

    // 静态方法：计算两个数的最小值
    public static int min(int a, int b) {
        return a < b ? a : b;
    }

    // 静态方法：计算数组的和
    public static int sum(int[] numbers) {
        int total = 0;
        for (int num : numbers) {
            total += num;
        }
        return total;
    }

    public static void main(String[] args) {
        // 直接通过类名调用，无需创建对象
        System.out.println(MathUtils.max(10, 20));   // 20
        System.out.println(MathUtils.min(10, 20));   // 10

        int[] numbers = {1, 2, 3, 4, 5};
        System.out.println(MathUtils.sum(numbers));  // 15
    }
}
```

**静态方法的特点**：

1. 可以直接通过类名调用（`ClassName.methodName()`）。
2. 不能直接访问实例变量和实例方法（因为它们属于对象）。
3. 不能使用 `this` 关键字（`this` 代表当前对象，静态方法中没有当前对象）。

```java
public class StaticMethodRule {
    private int instanceVar = 10;
    private static int staticVar = 20;

    // 静态方法
    public static void staticMethod() {
        // System.out.println(instanceVar); // 错误！不能访问实例变量
        System.out.println(staticVar);      // 可以访问静态变量
        // instanceMethod();                 // 错误！不能调用实例方法
        staticMethod2();                    // 可以调用静态方法
        // System.out.println(this);         // 错误！不能使用 this
    }

    public static void staticMethod2() {
        System.out.println("另一个静态方法");
    }

    public void instanceMethod() {
        System.out.println("实例方法");
    }
}
```

### 3.3 静态代码块

静态代码块在**类加载时执行**，且只执行一次。常用于初始化静态变量。

```java
public class StaticBlockDemo {
    private static int value;
    private static String message;

    // 静态代码块
    static {
        // 在类加载时执行
        value = 100;
        message = "静态代码块初始化";
        System.out.println("静态代码块执行了");
    }

    // 实例代码块（每次创建对象时执行）
    {
        System.out.println("实例代码块执行了");
    }

    public StaticBlockDemo() {
        System.out.println("构造方法执行了");
    }

    public static void display() {
        System.out.println("value = " + value + "，message = " + message);
    }

    public static void main(String[] args) {
        System.out.println("main方法开始");
        StaticBlockDemo.display();

        System.out.println("创建第一个对象：");
        StaticBlockDemo obj1 = new StaticBlockDemo();

        System.out.println("创建第二个对象：");
        StaticBlockDemo obj2 = new StaticBlockDemo();
    }
}
```

**执行顺序**：

```text
静态代码块执行了
main方法开始
value = 100，message = 静态代码块初始化
创建第一个对象：
实例代码块执行了
构造方法执行了
创建第二个对象：
实例代码块执行了
构造方法执行了
```

> **总结**：静态代码块在类加载时执行（只一次），实例代码块在每次创建对象时执行（优先于构造方法）。

### 3.4 静态导入

Java 5 引入了静态导入（`import static`），允许直接使用其他类的静态成员，而不需要写类名。

```java
// 普通导入
import java.lang.Math;

public class NormalImport {
    public static void main(String[] args) {
        double result = Math.sqrt(16); // 需要写类名
        System.out.println(result);
    }
}

// 静态导入
import static java.lang.Math.*;

public class StaticImportDemo {
    public static void main(String[] args) {
        // 直接使用，不需要写 Math.
        double result = sqrt(16);
        double pi = PI;
        System.out.println("平方根：" + result);
        System.out.println("圆周率：" + pi);
    }
}
```

> **注意**：静态导入虽然方便，但过度使用会降低代码的可读性，建议谨慎使用。

## 第四章 代码块

代码块是在类中直接使用花括号 `{}` 包裹的代码段。根据位置和修饰符的不同，可分为四种类型。

### 4.1 代码块类型对比

| 类型 | 修饰符 | 执行时机 | 执行次数 |
|------|--------|---------|---------|
| **静态代码块** | `static` | 类加载时 | 一次 |
| **实例代码块** | 无 | 构造方法之前 | 每次创建对象 |
| **局部代码块** | 无（在方法中） | 方法执行到该代码块时 | 每次调用方法 |
| **构造方法** | 无 | 创建对象时 | 每次创建对象 |

### 4.2 执行顺序示例

```java
public class BlockOrderDemo {
    // 静态变量
    private static int staticVar = initStaticVar();
    // 实例变量
    private int instanceVar = initInstanceVar();

    // 静态方法
    private static int initStaticVar() {
        System.out.println("1. 静态变量初始化");
        return 10;
    }

    // 实例方法
    private int initInstanceVar() {
        System.out.println("3. 实例变量初始化");
        return 20;
    }

    // 静态代码块
    static {
        System.out.println("2. 静态代码块执行");
    }

    // 实例代码块
    {
        System.out.println("4. 实例代码块执行");
    }

    // 构造方法
    public BlockOrderDemo() {
        System.out.println("5. 构造方法执行");
    }

    public static void main(String[] args) {
        System.out.println("main方法开始");
        BlockOrderDemo obj = new BlockOrderDemo();
        System.out.println("main方法结束");
    }
}
```

**执行结果**：

```text
1. 静态变量初始化
2. 静态代码块执行
main方法开始
3. 实例变量初始化
4. 实例代码块执行
5. 构造方法执行
main方法结束
```

## 第五章 内部类

**内部类**（Inner Class）是定义在另一个类内部的类。内部类可以访问外部类的私有成员，是实现封装和代码组织的有效工具。

### 5.1 成员内部类

成员内部类是最常见的内部类，它作为外部类的成员存在。

```java
public class OuterClass {
    private String name = "外部类";

    // 成员内部类
    public class InnerClass {
        private String innerName = "内部类";

        public void display() {
            // 内部类可以直接访问外部类的私有成员
            System.out.println("访问外部类成员：" + name);
            System.out.println("内部类成员：" + innerName);
        }
    }

    public void test() {
        // 外部类方法中创建内部类对象
        InnerClass inner = new InnerClass();
        inner.display();
    }

    public static void main(String[] args) {
        OuterClass outer = new OuterClass();
        // 通过外部类对象创建内部类对象
        OuterClass.InnerClass inner = outer.new InnerClass();
        inner.display();
    }
}
```

### 5.2 静态内部类

使用 `static` 修饰的内部类称为静态内部类。它不持有外部类的引用，因此不能访问外部类的非静态成员。

```java
public class OuterWithStatic {
    private static String staticName = "静态外部成员";
    private String instanceName = "实例外部成员";

    // 静态内部类
    public static class StaticInner {
        private String innerName = "静态内部类";

        public void display() {
            // 可以访问外部类的静态成员
            System.out.println(staticName);
            // System.out.println(instanceName); // 错误！不能访问非静态成员
            System.out.println(innerName);
        }
    }

    public static void main(String[] args) {
        // 创建静态内部类对象：不需要外部类对象
        OuterWithStatic.StaticInner inner = new OuterWithStatic.StaticInner();
        inner.display();
    }
}
```

### 5.3 方法内部类（局部内部类）

定义在方法内部的类，只能在该方法中访问。

```java
public class MethodInnerClass {
    public void test() {
        // 方法内部类（局部内部类）
        class LocalInner {
            private int value = 10;

            public void display() {
                System.out.println("方法内部类：" + value);
            }
        }

        // 只能在方法内部创建和使用
        LocalInner inner = new LocalInner();
        inner.display();
    }

    public static void main(String[] args) {
        MethodInnerClass obj = new MethodInnerClass();
        obj.test();
    }
}
```

### 5.4 匿名内部类

匿名内部类是没有名字的内部类，通常用于实现接口或继承抽象类，一次性使用。

```java
import java.util.Arrays;
import java.util.Comparator;

public class AnonymousInnerClass {
    public static void main(String[] args) {
        String[] names = {"Bob", "Alice", "David", "Charlie"};

        // 使用匿名内部类实现 Comparator 接口
        Arrays.sort(names, new Comparator<String>() {
            @Override
            public int compare(String o1, String o2) {
                return o1.compareTo(o2);
            }
        });

        System.out.println(Arrays.toString(names)); // [Alice, Bob, Charlie, David]

        // 使用 Lambda 表达式（Java 8+）简化匿名内部类
        Arrays.sort(names, (a, b) -> b.compareTo(a));
        System.out.println(Arrays.toString(names)); // [David, Charlie, Bob, Alice]
    }
}
```

### 5.5 内部类总结

| 内部类类型 | 修饰符 | 访问外部类成员 | 创建方式 |
|-----------|--------|---------------|---------|
| **成员内部类** | 无 | 可以访问所有成员 | `outer.new Inner()` |
| **静态内部类** | `static` | 只能访问静态成员 | `new Outer.StaticInner()` |
| **方法内部类** | 无（在方法中） | 可以访问外部类成员 | 在方法内 `new` |
| **匿名内部类** | 无（一次性） | 可以访问外部类成员 | `new 接口/父类() { ... }` |

## 总结

本文深入讲解了面向对象编程的核心机制：

| 知识点 | 核心要点 |
|--------|---------|
| **封装** | `private` 字段 + `public` getter/setter，信息隐藏 |
| **访问修饰符** | `private` < 默认 < `protected` < `public` |
| **static** | 类成员（变量、方法、代码块），属于类而非对象 |
| **代码块** | 静态代码块（类加载）、实例代码块（构造前）、局部代码块 |
| **内部类** | 成员内部类、静态内部类、方法内部类、匿名内部类 |
