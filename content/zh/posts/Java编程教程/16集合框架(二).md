## 引言

在前一篇文章中，我们学习了 `List` 和 `Set` 这两种单列集合。然而，在实际开发中，我们经常需要存储**键值对**（Key-Value）形式的数据——比如一个学生ID对应一个学生对象、一个用户名对应一个用户信息、一个商品编码对应一个商品详情。

`Map` 接口就是专门用于存储键值对映射关系的容器。它提供了一种通过键来快速查找值的数据结构，是Java集合框架中最重要的组成部分之一。

此外，**泛型**（Generics）是Java 5引入的一个重要特性，它让集合能够指定存储的元素类型，从而在编译期进行类型检查，增强了程序的类型安全性和可读性。

本文将系统讲解Map接口及其实现类、泛型机制以及Collections工具类的使用。

## 第一章 Map 接口概述

### 1.1 Map 的特点

`Map` 是Java集合框架中的双列集合接口，用于存储键值对（Key-Value）映射关系。

**Map 的核心特征**：

1. **键值对存储**：每个元素包含一个键（Key）和一个值（Value）。
2. **键唯一性**：键（Key）不能重复，值（Value）可以重复。
3. **键值对应**：通过键可以唯一地找到对应的值。
4. **支持 null**：某些实现允许 null 键和 null 值。

### 1.2 Map 的体系结构

```text
Map（接口）
├── HashMap（实现类）            // 基于哈希表，无序
│   └── LinkedHashMap（实现类）  // 基于哈希表+链表，有序（插入顺序）
├── TreeMap（实现类）            // 基于红黑树，有序（键的自然顺序/比较器）
├── Hashtable（实现类）          // 旧版，线程安全，不允许null
│   └── Properties（实现类）     // 属性文件
└── ConcurrentHashMap（实现类）  // 线程安全的高性能Map
```

### 1.3 Map 与 Collection 的区别

| 对比维度 | Collection | Map |
|---------|-----------|-----|
| **存储内容** | 单个元素 | 键值对（Key-Value） |
| **元素唯一性** | Set 不允许重复，List 允许重复 | 键不允许重复，值可以重复 |
| **访问方式** | 通过索引（List）或迭代 | 通过键（Key）访问 |
| **典型实现** | ArrayList、HashSet | HashMap、TreeMap |

## 第二章 Map 的常用方法

### 2.1 Map 核心方法

```java
import java.util.*;

public class MapMethodsDemo {
    public static void main(String[] args) {
        // 创建 HashMap
        Map<String, Integer> map = new HashMap<>();

        // 1. 添加元素（put）
        map.put("张三", 85);
        map.put("李四", 92);
        map.put("王五", 78);
        System.out.println("put 后：" + map); // {张三=85, 李四=92, 王五=78}

        // 2. 获取元素（get）
        System.out.println("get('张三'): " + map.get("张三")); // 85
        System.out.println("get('赵六'): " + map.get("赵六")); // null

        // 3. 获取默认值（getOrDefault，Java 8+）
        System.out.println("getOrDefault('赵六', 0): " + map.getOrDefault("赵六", 0)); // 0

        // 4. 判断是否包含键
        System.out.println("containsKey('李四'): " + map.containsKey("李四")); // true
        System.out.println("containsKey('赵六'): " + map.containsKey("赵六")); // false

        // 5. 判断是否包含值
        System.out.println("containsValue(92): " + map.containsValue(92)); // true
        System.out.println("containsValue(100): " + map.containsValue(100)); // false

        // 6. 删除元素（remove）
        Integer removed = map.remove("王五");
        System.out.println("remove('王五'): " + removed); // 78
        System.out.println("remove 后：" + map); // {张三=85, 李四=92}

        // 7. 替换元素（replace）
        map.replace("张三", 90);
        System.out.println("replace 后：" + map); // {张三=90, 李四=92}

        // 8. 获取所有键
        Set<String> keys = map.keySet();
        System.out.println("keys: " + keys); // [张三, 李四]

        // 9. 获取所有值
        Collection<Integer> values = map.values();
        System.out.println("values: " + values); // [90, 92]

        // 10. 获取所有键值对（Entry）
        Set<Map.Entry<String, Integer>> entries = map.entrySet();
        System.out.println("entries: " + entries); // [张三=90, 李四=92]

        // 11. 元素个数
        System.out.println("size: " + map.size()); // 2

        // 12. 判断是否为空
        System.out.println("isEmpty: " + map.isEmpty()); // false

        // 13. 清空
        map.clear();
        System.out.println("clear 后：" + map); // {}
        System.out.println("size: " + map.size()); // 0
    }
}
```

### 2.2 Map 的遍历方式

```java
import java.util.*;

public class MapIterationDemo {
    public static void main(String[] args) {
        Map<String, Integer> scores = new HashMap<>();
        scores.put("张三", 85);
        scores.put("李四", 92);
        scores.put("王五", 78);

        // 方式一：遍历 KeySet（获取所有键，再通过键获取值）
        System.out.println("=== 方式一：遍历 KeySet ===");
        for (String name : scores.keySet()) {
            System.out.println(name + " = " + scores.get(name));
        }

        // 方式二：遍历 EntrySet（获取所有键值对，推荐）
        System.out.println("=== 方式二：遍历 EntrySet ===");
        for (Map.Entry<String, Integer> entry : scores.entrySet()) {
            System.out.println(entry.getKey() + " = " + entry.getValue());
        }

        // 方式三：遍历 Values（只遍历值）
        System.out.println("=== 方式三：遍历 Values ===");
        for (Integer score : scores.values()) {
            System.out.println(score);
        }

        // 方式四：使用 Iterator（迭代 EntrySet）
        System.out.println("=== 方式四：使用 Iterator ===");
        Iterator<Map.Entry<String, Integer>> it = scores.entrySet().iterator();
        while (it.hasNext()) {
            Map.Entry<String, Integer> entry = it.next();
            System.out.println(entry.getKey() + " = " + entry.getValue());
        }

        // 方式五：forEach + Lambda（Java 8+）
        System.out.println("=== 方式五：forEach + Lambda ===");
        scores.forEach((key, value) -> System.out.println(key + " = " + value));
    }
}
```

### 2.3 Map 的高级操作

```java
import java.util.*;

public class MapAdvancedDemo {
    public static void main(String[] args) {
        Map<String, Integer> map = new HashMap<>();
        map.put("A", 1);
        map.put("B", 2);
        map.put("C", 3);

        // 1. computeIfAbsent：如果键不存在，则计算并放入
        map.computeIfAbsent("D", k -> k.length());
        System.out.println("computeIfAbsent 后：" + map); // {A=1, B=2, C=3, D=1}

        // 2. computeIfPresent：如果键存在，则计算并更新
        map.computeIfPresent("A", (k, v) -> v * 10);
        System.out.println("computeIfPresent 后：" + map); // {A=10, B=2, C=3, D=1}

        // 3. merge：合并值
        map.merge("A", 5, Integer::sum);
        System.out.println("merge 后：" + map); // {A=15, B=2, C=3, D=1}

        // 4. putIfAbsent：如果键不存在才放入
        map.putIfAbsent("E", 5);
        map.putIfAbsent("A", 100);
        System.out.println("putIfAbsent 后：" + map); // {A=15, B=2, C=3, D=1, E=5}

        // 5. replaceAll：替换所有值
        map.replaceAll((k, v) -> v + 1);
        System.out.println("replaceAll 后：" + map); // {A=16, B=3, C=4, D=2, E=6}
    }
}
```

## 第三章 HashMap 详解

### 3.1 HashMap 的特点

`HashMap` 是最常用的 Map 实现，底层基于**哈希表**（数组 + 链表/红黑树）。

```java
import java.util.*;

public class HashMapDemo {
    public static void main(String[] args) {
        // 创建 HashMap
        Map<String, Integer> map = new HashMap<>();

        // 指定初始容量和负载因子
        Map<String, Integer> map2 = new HashMap<>(16); // 初始容量16
        Map<String, Integer> map3 = new HashMap<>(16, 0.75f); // 负载因子0.75

        // 从已有 Map 创建
        Map<String, Integer> map4 = new HashMap<>(map);

        // 添加元素（key 不能重复）
        map.put("A", 1);
        map.put("B", 2);
        map.put("C", 3);
        map.put("A", 100); // 替换 A 的值

        System.out.println("HashMap: " + map); // {A=100, B=2, C=3}

        // 允许 null 键和 null 值
        map.put(null, 0);
        map.put("D", null);
        System.out.println("包含 null：" + map); // {null=0, A=100, B=2, C=3, D=null}
    }
}
```

### 3.2 HashMap 的底层原理

```text
┌─────────────────────────────────────────────────────────────────┐
│                      HashMap 内部结构                          │
├─────────────────────────────────────────────────────────────────┤
│  底层：数组 + 链表 + 红黑树                                   │
│  ┌─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐   │
│  │  0  │  1  │  2  │  3  │  4  │  5  │  6  │  7  │ ... │   │
│  └──┬──┴─────┴──┬──┴─────┴──┬──┴─────┴──┬──┴─────┴─────┘   │
│     │           │           │           │                    │
│   ┌──▼──┐    ┌──▼──┐    ┌──▼──┐    ┌──▼──┐                 │
│   │Node │    │Node │    │Node │    │Node │                 │
│   │key=A│    │key=C│    │key=B│    │key=D│                 │
│   │val=1│    │val=3│    │val=2│    │val=4│                 │
│   │next→│    │next→│    │next→│    │next→│                 │
│   └─────┘    └─────┘    └─────┘    └─────┘                 │
│                                                             │
│  操作特点：                                                 │
│  - put/get/remove：O(1)（均摊）                            │
│  - 初始容量：16                                            │
│  - 负载因子：0.75                                         │
│  - 扩容阈值：容量 × 负载因子                              │
│  - 链表长度 > 8 时转为红黑树（Java 8+）                   │
└─────────────────────────────────────────────────────────────┘
```

**插入流程**：

```text
1. 计算 key 的 hashCode()
2. 通过 hashCode 计算数组索引
3. 如果该位置为空，直接插入
4. 如果该位置有元素，比较 key 是否相等
   - 相等：替换 value
   - 不相等：插入链表/红黑树
```

### 3.3 哈希冲突与处理

当两个不同的 key 计算出相同的数组索引时，称为**哈希冲突**。HashMap 通过**链地址法**解决冲突。

```java
public class HashConflictDemo {
    public static void main(String[] args) {
        // 自定义类，让 hashCode 产生冲突
        class Key {
            private String value;

            Key(String value) {
                this.value = value;
            }

            @Override
            public int hashCode() {
                return 1; // 所有对象返回相同的 hashCode
            }

            @Override
            public boolean equals(Object o) {
                if (this == o) return true;
                if (o == null || getClass() != o.getClass()) return false;
                Key key = (Key) o;
                return Objects.equals(value, key.value);
            }

            @Override
            public String toString() {
                return value;
            }
        }

        Map<Key, Integer> map = new HashMap<>();
        map.put(new Key("A"), 1);
        map.put(new Key("B"), 2);
        map.put(new Key("C"), 3);

        System.out.println("HashMap 大小：" + map.size()); // 3
        // 虽然所有 key 的 hashCode 相同，但通过 equals 区分不同 key
        // 它们存储在同一数组位置的链表/红黑树中
    }
}
```

## 第四章 TreeMap 详解

### 4.1 TreeMap 的特点

`TreeMap` 基于**红黑树**（自平衡二叉搜索树）实现，具有**排序**功能。

```java
import java.util.*;

public class TreeMapDemo {
    public static void main(String[] args) {
        // 自然排序（键必须实现 Comparable）
        Map<Integer, String> treeMap = new TreeMap<>();
        treeMap.put(5, "E");
        treeMap.put(1, "A");
        treeMap.put(3, "C");
        treeMap.put(4, "D");
        treeMap.put(2, "B");

        System.out.println("TreeMap（按键升序）：" + treeMap);
        // {1=A, 2=B, 3=C, 4=D, 5=E}

        // 自定义排序（Comparator）
        Map<String, String> reverseMap = new TreeMap<>(Comparator.reverseOrder());
        reverseMap.put("Apple", "苹果");
        reverseMap.put("Banana", "香蕉");
        reverseMap.put("Orange", "橙子");
        System.out.println("降序排序：" + reverseMap);
        // {Orange=橙子, Banana=香蕉, Apple=苹果}

        // TreeMap 特有的方法
        TreeMap<Integer, String> tm = new TreeMap<>();
        tm.put(10, "A");
        tm.put(20, "B");
        tm.put(30, "C");
        tm.put(40, "D");
        tm.put(50, "E");

        System.out.println("firstKey: " + tm.firstKey()); // 10
        System.out.println("lastKey: " + tm.lastKey());   // 50
        System.out.println("lowerKey(25): " + tm.lowerKey(25));  // 20（小于25的最大键）
        System.out.println("higherKey(25): " + tm.higherKey(25)); // 30（大于25的最小键）
        System.out.println("floorKey(25): " + tm.floorKey(25));   // 20（小于等于25的最大键）
        System.out.println("ceilingKey(25): " + tm.ceilingKey(25)); // 30（大于等于25的最小键）

        // 子视图
        System.out.println("subMap(15, 45): " + tm.subMap(15, 45)); // {20=B, 30=C, 40=D}
        System.out.println("headMap(25): " + tm.headMap(25));       // {10=A, 20=B}
        System.out.println("tailMap(35): " + tm.tailMap(35));       // {40=D, 50=E}
    }
}
```

### 4.2 HashMap vs TreeMap

| 特性 | HashMap | TreeMap |
|------|---------|---------|
| **底层结构** | 哈希表（数组+链表+红黑树） | 红黑树（平衡二叉搜索树） |
| **元素顺序** | 无序 | 有序（键的自然顺序或比较器） |
| **性能** | put/get/remove O(1) | put/get/remove O(log n) |
| **是否允许 null 键** | 允许一个 null 键 | 不允许 null 键（需比较） |
| **线程安全** | 不安全 | 不安全 |
| **适用场景** | 频繁查找、插入 | 需要排序、范围查找 |

## 第五章 LinkedHashMap 与 Hashtable

### 5.1 LinkedHashMap

`LinkedHashMap` 是 `HashMap` 的子类，通过双向链表维护元素的**插入顺序**。

```java
import java.util.*;

public class LinkedHashMapDemo {
    public static void main(String[] args) {
        // 按插入顺序访问
        Map<String, Integer> linkedMap = new LinkedHashMap<>();
        linkedMap.put("C", 3);
        linkedMap.put("A", 1);
        linkedMap.put("B", 2);

        System.out.println("LinkedHashMap（插入顺序）：" + linkedMap);
        // {C=3, A=1, B=2}

        // 普通 HashMap（无序）
        Map<String, Integer> hashMap = new HashMap<>();
        hashMap.put("C", 3);
        hashMap.put("A", 1);
        hashMap.put("B", 2);
        System.out.println("HashMap（无序）：" + hashMap);
        // 顺序不确定

        // 访问顺序模式（LRU 缓存基础）
        LinkedHashMap<String, Integer> lruMap = new LinkedHashMap<>(16, 0.75f, true);
        lruMap.put("A", 1);
        lruMap.put("B", 2);
        lruMap.put("C", 3);
        System.out.println("初始：" + lruMap); // {A=1, B=2, C=3}

        // 访问 A
        lruMap.get("A");
        System.out.println("访问 A 后：" + lruMap); // {B=2, C=3, A=1}
        // A 被移到末尾（最近访问）
    }
}
```

### 5.2 Hashtable

`Hashtable` 是旧版 Map 实现，所有方法都同步（线程安全），但不允许 null 键和 null 值。

```java
import java.util.*;

public class HashtableDemo {
    public static void main(String[] args) {
        // 创建 Hashtable
        Hashtable<String, Integer> table = new Hashtable<>();

        // 添加元素
        table.put("A", 1);
        table.put("B", 2);

        // 不允许 null 键或 null 值
        // table.put(null, 3);   // NullPointerException
        // table.put("C", null); // NullPointerException

        System.out.println("Hashtable：" + table);

        // 线程安全的替代方案
        // 使用 Collections.synchronizedMap 包装 HashMap
        Map<String, Integer> syncMap = Collections.synchronizedMap(new HashMap<>());

        // 或使用 ConcurrentHashMap（更高效）
        Map<String, Integer> concurrentMap = new java.util.concurrent.ConcurrentHashMap<>();
    }
}
```

## 第六章 泛型（Generics）

### 6.1 什么是泛型

**泛型**（Generics）是Java 5引入的一个重要特性，它允许在类、接口、方法定义时使用**类型参数**，在使用时再指定具体的类型。

泛型的主要好处：
1. **类型安全**：在编译期进行类型检查，避免 ClassCastException。
2. **消除强制转换**：代码更简洁。
3. **代码复用**：通过泛型可以编写通用的代码。

```java
import java.util.*;

public class GenericDemo {
    public static void main(String[] args) {
        // 没有泛型（Java 5之前）
        List list = new ArrayList();
        list.add("Hello");
        list.add(100); // 可以添加任何类型

        // 需要强制转换，容易出错
        String str = (String) list.get(0);
        // Integer num = (Integer) list.get(0); // 如果是字符串会报错

        // 使用泛型（类型安全）
        List<String> stringList = new ArrayList<>();
        stringList.add("Hello");
        // stringList.add(100); // 编译错误！类型不匹配

        String s = stringList.get(0); // 不需要强制转换
        System.out.println(s);
    }
}
```

### 6.2 泛型类

```java
/**
 * 泛型类示例
 * @param <T> 类型参数
 */
public class GenericClass<T> {
    private T data;

    public GenericClass(T data) {
        this.data = data;
    }

    public T getData() {
        return data;
    }

    public void setData(T data) {
        this.data = data;
    }

    public void display() {
        System.out.println("Type: " + data.getClass().getName());
        System.out.println("Value: " + data);
    }

    public static void main(String[] args) {
        // 使用泛型类
        GenericClass<String> stringObj = new GenericClass<>("Hello");
        stringObj.display();

        GenericClass<Integer> intObj = new GenericClass<>(100);
        intObj.display();

        GenericClass<Double> doubleObj = new GenericClass<>(3.14);
        doubleObj.display();
    }
}

/**
 * 多类型参数的泛型类
 */
class Pair<K, V> {
    private K key;
    private V value;

    public Pair(K key, V value) {
        this.key = key;
        this.value = value;
    }

    public K getKey() { return key; }
    public V getValue() { return value; }

    @Override
    public String toString() {
        return "Pair{" + key + "=" + value + "}";
    }

    public static void main(String[] args) {
        Pair<String, Integer> pair = new Pair<>("年龄", 25);
        System.out.println(pair);
    }
}
```

### 6.3 泛型方法

```java
public class GenericMethodDemo {
    /**
     * 泛型方法 - 交换数组中的两个元素
     */
    public static <T> void swap(T[] array, int i, int j) {
        T temp = array[i];
        array[i] = array[j];
        array[j] = temp;
    }

    /**
     * 泛型方法 - 获取数组中的最大值（需要 Comparable）
     */
    public static <T extends Comparable<T>> T max(T[] array) {
        if (array == null || array.length == 0) {
            return null;
        }
        T max = array[0];
        for (int i = 1; i < array.length; i++) {
            if (array[i].compareTo(max) > 0) {
                max = array[i];
            }
        }
        return max;
    }

    public static void main(String[] args) {
        // 交换
        Integer[] numbers = {1, 2, 3, 4, 5};
        System.out.println("交换前：" + Arrays.toString(numbers));
        swap(numbers, 0, 4);
        System.out.println("交换后：" + Arrays.toString(numbers));

        // 最大值
        Integer[] ints = {3, 7, 1, 9, 5};
        System.out.println("最大值：" + max(ints));

        String[] strs = {"Apple", "Banana", "Orange"};
        System.out.println("最大值：" + max(strs));
    }
}
```

```java
 * 实现泛型接口
 */
class StringProcessor implements Processor<String> {
    @Override
    public String process(String input) {
        return input.toUpperCase();
    }
}

class IntegerProcessor implements Processor<Integer> {
    @Override
    public Integer process(Integer input) {
        return input * 2;
    }
}

/**
 * 泛型接口的通用实现
 */
class GenericProcessor<T> implements Processor<T> {
    private final java.util.function.Function<T, T> function;

    public GenericProcessor(java.util.function.Function<T, T> function) {
        this.function = function;
    }

    @Override
    public T process(T input) {
        return function.apply(input);
    }

    public static void main(String[] args) {
        Processor<String> upper = new StringProcessor();
        System.out.println(upper.process("hello")); // HELLO

        Processor<Integer> doubleInt = new IntegerProcessor();
        System.out.println(doubleInt.process(5)); // 10

        // 使用 Lambda 表达式
        Processor<String> reverse = new GenericProcessor<>(s -> new StringBuilder(s).reverse().toString());
        System.out.println(reverse.process("hello")); // olleh
    }
}
```

### 6.5 泛型通配符

```java
import java.util.*;

public class WildcardDemo {
    /**
     * ?：任意类型（不能修改集合）
     */
    public static void printList(List<?> list) {
        for (Object obj : list) {
            System.out.print(obj + " ");
        }
        System.out.println();
        // list.add("Hello"); // 错误！不能添加元素
    }

    /**
     * ? extends T：T 或 T 的子类（上界通配符）
     */
    public static double sum(List<? extends Number> list) {
        double sum = 0;
        for (Number n : list) {
            sum += n.doubleValue();
        }
        return sum;
    }

    /**
     * ? super T：T 或 T 的父类（下界通配符）
     */
    public static void addIntegers(List<? super Integer> list) {
        list.add(1);
        list.add(2);
        list.add(3);
        // list.add("Hello"); // 错误！只能添加 Integer 及其子类
    }

    public static void main(String[] args) {
        // 无界通配符
        List<String> strings = Arrays.asList("A", "B", "C");
        List<Integer> integers = Arrays.asList(1, 2, 3);
        printList(strings);
        printList(integers);

        // 上界通配符
        List<Integer> intList = Arrays.asList(1, 2, 3, 4, 5);
        List<Double> doubleList = Arrays.asList(1.1, 2.2, 3.3);
        System.out.println("sum(intList): " + sum(intList));
        System.out.println("sum(doubleList): " + sum(doubleList));

        // 下界通配符
        List<Number> numberList = new ArrayList<>();
        addIntegers(numberList);
        System.out.println("numberList: " + numberList);

        List<Object> objectList = new ArrayList<>();
        addIntegers(objectList);
        System.out.println("objectList: " + objectList);
    }
}
```

### 6.6 泛型中的 PECS 原则

**PECS**：Producer Extends, Consumer Super（生产者用 extends，消费者用 super）。

```java
import java.util.*;

public class PecsDemo {
    /**
     * 生产者（读取数据）：使用 <? extends T>
     */
    public static <T> void copy(List<? extends T> src, List<? super T> dest) {
        for (T item : src) {
            dest.add(item);
        }
    }

    public static void main(String[] args) {
        // 从 Integer 列表复制到 Number 列表
        List<Integer> intList = Arrays.asList(1, 2, 3, 4, 5);
        List<Number> numList = new ArrayList<>();

        copy(intList, numList);
        System.out.println("复制后：" + numList); // [1, 2, 3, 4, 5]

        // 从 String 列表复制到 Object 列表
        List<String> strList = Arrays.asList("A", "B", "C");
        List<Object> objList = new ArrayList<>();

        copy(strList, objList);
        System.out.println("复制后：" + objList); // [A, B, C]
    }
}
```

```java
import java.util.*;

public class CollectionsDemo {
    public static void main(String[] args) {

        // 2. 查找

        Collections.reverse(list);

        // 4. 打乱

        // 5. 最大值/最小值

        List<String> strList = Arrays.asList("A", "B", "A", "C", "A", "D");
```

## 第八章 综合示例

```java
import java.util.*;

/**
 * 图书管理系统 - 综合运用 Map 和泛型
 */
public class LibrarySystem {
    // 使用 Map 存储图书：ISBN -> Book
    private Map<String, Book> books = new HashMap<>();

    // 使用 Map 存储用户：用户ID -> 用户
    private Map<String, User> users = new HashMap<>();

    // 使用 Map 存储借阅记录：ISBN -> 借阅用户ID
    private Map<String, String> borrowRecords = new HashMap<>();

    /**
     * 添加图书
     */
    public void addBook(Book book) {
        if (books.containsKey(book.getIsbn())) {
            System.out.println("图书已存在：" + book.getTitle());
            return;
        }
        books.put(book.getIsbn(), book);
        System.out.println("添加成功：" + book);
    }

    /**
     * 删除图书
     */
    public boolean removeBook(String isbn) {
        if (borrowRecords.containsKey(isbn)) {
            System.out.println("该书已被借出，无法删除！");
            return false;
        }
        Book removed = books.remove(isbn);
        if (removed != null) {
            System.out.println("删除成功：" + removed.getTitle());
            return true;
        }
        System.out.println("未找到 ISBN 为 " + isbn + " 的图书");
        return false;
    }

    /**
     * 查找图书
     */
    public Book findBook(String isbn) {
        return books.get(isbn);
    }

    /**
     * 按书名搜索
     */
    public List<Book> searchByTitle(String keyword) {
        List<Book> result = new ArrayList<>();
        for (Book book : books.values()) {
            if (book.getTitle().contains(keyword)) {
                result.add(book);
            }
        }
        return result;
    }

    /**
     * 按作者搜索
     */
    public List<Book> searchByAuthor(String author) {
        List<Book> result = new ArrayList<>();
        for (Book book : books.values()) {
            if (book.getAuthor().contains(author)) {
                result.add(book);
            }
        }
        return result;
    }

    /**
     * 借书
     */
    public boolean borrowBook(String isbn, String userId) {
        // 检查图书是否存在
        Book book = books.get(isbn);
        if (book == null) {
            System.out.println("图书不存在！");
            return false;
        }

        // 检查是否已被借出
        if (borrowRecords.containsKey(isbn)) {
            System.out.println("该书已被借出！");
            return false;
        }

        // 检查用户是否存在
        if (!users.containsKey(userId)) {
            System.out.println("用户不存在！");
            return false;
        }

        borrowRecords.put(isbn, userId);
        book.setBorrowed(true);
        System.out.println("借书成功：" + book.getTitle() + " -> " + users.get(userId).getName());
        return true;
    }

    /**
     * 还书
     */
    public boolean returnBook(String isbn) {
        if (!borrowRecords.containsKey(isbn)) {
            System.out.println("该书未被借出！");
            return false;
        }

        Book book = books.get(isbn);
        if (book != null) {
            book.setBorrowed(false);
        }
        String userId = borrowRecords.remove(isbn);
        System.out.println("还书成功：" + book.getTitle() + " <- " + users.get(userId).getName());
        return true;
    }

    /**
     * 添加用户
     */
    public void addUser(User user) {
        users.put(user.getId(), user);
        System.out.println("用户添加成功：" + user.getName());
    }

    /**
     * 获取所有图书
     */
    public List<Book> getAllBooks() {
        return new ArrayList<>(books.values());
    }

    /**
     * 获取所有可借图书
     */
    public List<Book> getAvailableBooks() {
        List<Book> result = new ArrayList<>();
        for (Book book : books.values()) {
            if (!book.isBorrowed()) {
                result.add(book);
            }
        }
        return result;
    }

    /**
     * 获取当前借阅记录
     */
    public Map<String, String> getBorrowRecords() {
        return new HashMap<>(borrowRecords);
    }

    public static void main(String[] args) {
        LibrarySystem library = new LibrarySystem();

        // 添加用户
        library.addUser(new User("U001", "张三"));
        library.addUser(new User("U002", "李四"));

        // 添加图书
        library.addBook(new Book("978-7-111-12345-6", "Java核心技术", "Cay S. Horstmann", 2));
        library.addBook(new Book("978-7-111-67890-1", "Head First Java", "Kathy Sierra", 1));
        library.addBook(new Book("978-7-121-34567-8", "Python编程", "Eric Matthes", 3));
        library.addBook(new Book("978-7-302-56789-0", "数据结构与算法", "Robert Sedgewick", 2));

        // 搜索
        System.out.println("\n=== 搜索 Java 相关图书 ===");
        for (Book b : library.searchByTitle("Java")) {
            System.out.println(b);
        }

        // 借书
        System.out.println("\n=== 借书操作 ===");
        library.borrowBook("978-7-111-12345-6", "U001");
        library.borrowBook("978-7-111-12345-6", "U002"); // 已被借出

        // 查看所有图书
        System.out.println("\n=== 所有图书 ===");
        for (Book b : library.getAllBooks()) {
            System.out.println(b);
        }

        // 查看可借图书
        System.out.println("\n=== 可借图书 ===");
        for (Book b : library.getAvailableBooks()) {
            System.out.println(b);
        }

        // 还书
        System.out.println("\n=== 还书操作 ===");
        library.returnBook("978-7-111-12345-6");

        // 查看借阅记录
        System.out.println("\n=== 借阅记录 ===");
        System.out.println(library.getBorrowRecords());
    }
}

 * 图书类

class Book {
    private String isbn;
    private String title;
    private String author;
    private int copies;
    private int borrowedCopies;

    public Book(String isbn, String title, String author, int copies) {
        this.isbn = isbn;
        this.title = title;
        this.author = author;
        this.copies = copies;
        this.borrowedCopies = 0;
    }

    // Getters and Setters
    public String getIsbn() { return isbn; }
    public String getTitle() { return title; }
    public String getAuthor() { return author; }
    public int getCopies() { return copies; }
    public boolean isBorrowed() { return borrowedCopies >= copies; }
    public void setBorrowed(boolean borrowed) {
        if (borrowed && borrowedCopies < copies) {
            borrowedCopies++;
        } else if (!borrowed && borrowedCopies > 0) {
            borrowedCopies--;
        }
    }

    @Override
    public String toString() {
        return "Book{isbn='" + isbn + "', title='" + title + "', author='" + author +
               "', copies=" + copies + ", borrowedCopies=" + borrowedCopies + "}";
    }
}
```

## 总结

本文系统讲解了Map接口与泛型机制：

| 知识点 | 核心要点 |
|--------|---------|
| **Map** | 键值对存储，键唯一，通过键快速查找值 |
| **HashMap** | 哈希表实现，O(1) 操作，无序 |
| **TreeMap** | 红黑树实现，有序，O(log n) 操作 |
| **LinkedHashMap** | 插入顺序或访问顺序，哈希+链表 |
| **Hashtable** | 线程安全，不允许null，不推荐使用 |
| **泛型** | 类型参数，编译期类型检查 |
| **泛型类/接口** | 类或接口定义时使用类型参数 |
| **泛型方法** | 方法定义时使用类型参数 |
| **通配符** | `?`、`? extends T`、`? super T` |
| **PECS** | Producer Extends, Consumer Super |
| **Collections** | 集合工具类，提供排序、查找等方法 |
