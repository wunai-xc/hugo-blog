## 引言

在面向对象编程中，**继承**（Inheritance）是三大核心特征之一，也是实现代码复用的最重要手段。通过继承，子类可以继承父类的属性和方法，避免重复编写相同的代码，同时还可以在不修改父类代码的前提下扩展或重写父类的行为。

现实世界中，继承关系无处不在：学生是人的一种，猫是动物的一种，轿车是汽车的一种。在程序中，继承帮助我们建立类之间的层次关系，使代码结构更加清晰、易于维护和扩展。

本文将系统讲解Java中的继承机制，包括继承的语法与使用、方法重写、`super` 关键字、构造方法链、`final` 关键字以及继承中的访问控制规则。

## 第一章 继承的基本概念

### 1.1 什么是继承

**继承**是面向对象编程中一种建立类之间层次关系的机制。通过继承，一个类（子类）可以自动获得另一个类（父类）的属性和方法，从而实现代码复用。

**继承的核心术语**：

- **父类（Superclass）** ：被继承的类，也称为超类或基类。
- **子类（Subclass）** ：继承父类的类，也称为派生类。
- **继承关系**：子类“是一种”（is-a）父类的关系。

```text
┌──────────────────────────────────────────────────┐
│                    Animal（父类）                 │
│  - name: String                                  │
│  + eat(): void                                   │
│  + sleep(): void                                 │
└──────────────────────────────────────────────────┘
                          ▲
                          │ 继承
          ┌───────────────┼───────────────┐
          │               │               │
┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐
│   Dog（子类）    │ │  Cat（子类）     │ │  Bird（子类）   │
│  + bark(): void  │ │  + meow(): void  │ │  + fly(): void  │
└─────────────────┘ └─────────────────┘ └─────────────────┘
```

### 1.2 继承的语法

Java中使用 `extends` 关键字实现继承。

```java
// 父类
public class Animal {
    protected String name;
    protected int age;

    public Animal(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void eat() {
        System.out.println(name + "正在吃东西...");
    }

    public void sleep() {
        System.out.println(name + "正在睡觉...");
    }

    public void display() {
        System.out.println("名字：" + name + "，年龄：" + age);
    }
}

// 子类继承父类
public class Dog extends Animal {
    private String breed; // 子类特有的属性

    public Dog(String name, int age, String breed) {
        super(name, age); // 调用父类构造方法
        this.breed = breed;
    }

    // 子类特有的方法
    public void bark() {
        System.out.println(name + "汪汪叫！");
    }

    // 子类特有的方法
    public void wagTail() {
        System.out.println(name + "摇尾巴！");
    }
}
```

### 1.3 继承的特点

1. **单继承**：Java只支持单继承，即一个子类只能有一个直接父类。但一个父类可以有多个子类。
2. **传递性**：继承关系是可传递的。子类不仅继承父类的成员，还间接继承父类父类的成员。
3. **私有成员不可继承**：父类中的 `private` 成员在子类中不可见。
4. **构造方法不可继承**：构造方法不能被继承，但子类可以通过 `super()` 调用父类构造方法。

```java
// 继承链：Grandparent → Parent → Child
class Grandparent {
    public void method1() {
        System.out.println("Grandparent method1");
    }
}

class Parent extends Grandparent {
    public void method2() {
        System.out.println("Parent method2");
    }
}

class Child extends Parent {
    public void method3() {
        System.out.println("Child method3");
    }
}

// 测试继承传递性
public class InheritanceChain {
    public static void main(String[] args) {
        Child child = new Child();
        child.method1(); // 继承自 Grandparent
        child.method2(); // 继承自 Parent
        child.method3(); // Child 自己的方法
    }
}
```

## 第二章 方法重写（Override）

**方法重写**（Override）是指子类重新定义父类中已有的方法，以提供自己特定的实现。

### 2.1 重写的规则

方法重写必须遵循以下规则：

1. **方法名和参数列表必须与父类方法完全相同**。
2. **返回类型**必须与父类方法相同，或者是父类返回类型的子类型（协变返回类型）。
3. **访问权限**不能比父类方法更严格（可以更宽松）。
4. **不能重写 `final` 方法**。
5. **不能重写 `static` 方法**（但可以隐藏）。
6. **抛出的异常**不能比父类方法更多或更大（可以更少或更小）。

```java
public class Animal {
    protected String name;

    public Animal(String name) {
        this.name = name;
    }

    // 父类方法
    public void makeSound() {
        System.out.println(name + "发出声音...");
    }

    // 父类方法：final 方法不能被子类重写
    public final void finalMethod() {
        System.out.println("不能被重写的 final 方法");
    }

    // 父类方法：static 方法不能被子类重写（但可以隐藏）
    public static void staticMethod() {
        System.out.println("父类的静态方法");
    }
}

public class Dog extends Animal {
    public Dog(String name) {
        super(name);
    }

    // 重写父类的 makeSound 方法
    @Override
    public void makeSound() {
        System.out.println(name + "汪汪叫！");
    }

    // 错误示例：不能重写 final 方法
    // @Override
    // public void finalMethod() { } // 编译错误！

    // 错误示例：不能重写 static 方法
    // @Override
    // public static void staticMethod() { } // 编译错误！

    // 可以“隐藏”静态方法（不是重写）
    public static void staticMethod() {
        System.out.println("子类的静态方法");
    }
}
```

### 2.2 @Override 注解

`@Override` 是一个注解（Annotation），用于标记方法是重写父类的方法。使用 `@Override` 有以下好处：

1. **编译器检查**：如果方法没有正确重写父类方法，编译器会报错。
2. **提高可读性**：明确标识该方法是对父类方法的重写。

```java
public class Cat extends Animal {
    public Cat(String name) {
        super(name);
    }

    // 使用 @Override 注解
    @Override
    public void makeSound() {
        System.out.println(name + "喵喵叫！");
    }

    // 错误示例：参数列表不匹配，编译器报错
    // @Override
    // public void makeSound(String extra) { } // 编译错误！不是重写
}
```

### 2.3 重写 vs 重载

| 对比维度 | 重写（Override） | 重载（Overload） |
|---------|-----------------|-----------------|
| **定义位置** | 子类中 | 同一个类中或子类中 |
| **方法名** | 必须相同 | 必须相同 |
| **参数列表** | 必须相同 | 必须不同 |
| **返回类型** | 必须相同或是其子类型 | 可以不同 |
| **访问修饰符** | 不能更严格 | 没有限制 |
| **关系** | 父子类之间 | 同一个类内部或不同类 |

## 第三章 super 关键字

`super` 是Java中的一个引用关键字，用于访问父类的成员（变量、方法和构造方法）。

### 3.1 super 的用途

**1. 调用父类的构造方法（`super()`）**

```java
public class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

public class Student extends Person {
    private String studentId;

    public Student(String name, int age, String studentId) {
        super(name, age); // 必须放在第一行
        this.studentId = studentId;
    }

    // 如果父类没有无参构造方法，子类必须显式调用 super(参数)
}
```

**2. 访问父类的成员变量**

```java
public class Parent {
    protected String value = "父类的值";
}

public class Child extends Parent {
    private String value = "子类的值";

    public void display() {
        System.out.println("子类 value：" + value);
        System.out.println("父类 value：" + super.value); // 使用 super 访问父类成员
    }
}
```

**3. 调用父类的方法**

```java
public class Animal {
    public void makeSound() {
        System.out.println("动物发出声音");
    }
}

public class Dog extends Animal {
    @Override
    public void makeSound() {
        // 调用父类的方法
        super.makeSound();
        System.out.println("狗汪汪叫");
    }
}
```

### 3.2 super 的注意事项

1. `super()` 调用父类构造方法必须放在子类构造方法的第一行。
2. `super` 不能出现在 `static` 方法中。
3. `super` 和 `this` 不能同时出现在构造方法的第一行（因为 `this()` 也会调用构造方法）。

## 第四章 构造方法链（Constructor Chaining）

### 4.1 构造方法调用顺序

在Java中，创建子类对象时，构造方法的调用顺序是**从父类到子类**的。

```java
public class Grandparent {
    public Grandparent() {
        System.out.println("Grandparent 构造方法");
    }
}

public class Parent extends Grandparent {
    public Parent() {
        System.out.println("Parent 构造方法");
    }
}

public class Child extends Parent {
    public Child() {
        System.out.println("Child 构造方法");
    }

    public static void main(String[] args) {
        Child child = new Child();
        // 输出顺序：
        // Grandparent 构造方法
        // Parent 构造方法
        // Child 构造方法
    }
}
```

### 4.2 构造方法链的规则

1. **所有构造方法的第一行**：隐式或显式调用父类构造方法（`super()`）。
2. **如果子类构造方法没有显式调用 `super()`**：编译器会自动插入 `super()`。
3. **如果父类没有无参构造方法**：子类必须显式调用父类的有参构造方法。

```java
public class Animal {
    private String name;

    // 只有有参构造方法，没有无参构造方法
    public Animal(String name) {
        this.name = name;
        System.out.println("Animal 构造方法：" + name);
    }
}

public class Dog extends Animal {
    private String breed;

    // 必须显式调用父类的有参构造方法
    public Dog(String name, String breed) {
        super(name); // 必须手动调用
        this.breed = breed;
        System.out.println("Dog 构造方法：" + breed);
    }

    public static void main(String[] args) {
        Dog dog = new Dog("旺财", "金毛");
        // 输出：
        // Animal 构造方法：旺财
        // Dog 构造方法：金毛
    }
}
```

## 第五章 final 关键字

`final` 关键字在继承中有特殊的意义，它用于限制继承和修改。

### 5.1 final 的作用范围

| 用途 | 说明 | 示例 |
|------|------|------|
| **final 变量** | 常量，赋值后不能修改 | `final int MAX = 100;` |
| **final 方法** | 不能被子类重写 | `public final void method() {}` |
| **final 类** | 不能被继承 | `public final class String {}` |

### 5.2 final 类

```java
// final 类不能被继承
public final class FinalClass {
    // 类体
}

// 错误！不能继承 final 类
// class SubClass extends FinalClass { } // 编译错误！
```

### 5.3 final 方法

```java
public class Parent {
    // final 方法不能被子类重写
    public final void cannotOverride() {
        System.out.println("不能重写的方法");
    }

    public void canOverride() {
        System.out.println("可以重写的方法");
    }
}

public class Child extends Parent {
    // 错误！不能重写 final 方法
    // @Override
    // public void cannotOverride() { } // 编译错误！

    @Override
    public void canOverride() {
        System.out.println("子类重写的方法");
    }
}
```

### 5.4 final 与 static 组合

`public static final` 组合常用于定义常量：

```java
public class Constants {
    // 编译时常量
    public static final double PI = 3.14159;
    public static final int MAX_USERS = 1000;
    public static final String APP_NAME = "MyApp";

    // 运行时常量（在静态代码块中初始化）
    public static final String CONFIG_PATH;

    static {
        CONFIG_PATH = System.getProperty("user.home") + "/config";
    }
}

// 使用常量
public class UseConstants {
    public static void main(String[] args) {
        System.out.println("PI = " + Constants.PI);
        System.out.println("应用名称：" + Constants.APP_NAME);
        // Constants.PI = 3.14; // 错误！不能修改 final 变量
    }
}
```

## 第六章 Object 类

在Java中，所有类都直接或间接地继承自 `java.lang.Object` 类。`Object` 是Java类层次结构的**根类**。

### 6.1 Object 类的常用方法

| 方法 | 说明 |
|------|------|
| `toString()` | 返回对象的字符串表示 |
| `equals(Object obj)` | 判断两个对象是否相等 |
| `hashCode()` | 返回对象的哈希码值 |
| `getClass()` | 返回对象的运行时类 |
| `clone()` | 创建并返回对象的副本 |
| `finalize()` | 对象被垃圾回收前调用 |

### 6.2 重写 toString() 方法

`toString()` 方法默认返回 `类名@哈希码` 的格式，通常需要重写以提供更有意义的信息。

```java
public class Student {
    private String name;
    private int age;

    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 重写 toString() 方法
    @Override
    public String toString() {
        return "Student{name='" + name + "', age=" + age + "}";
    }

    public static void main(String[] args) {
        Student s = new Student("张三", 20);
        System.out.println(s); // Student{name='张三', age=20}
        // 如果不重写 toString()，输出：Student@15db9742
    }
}
```

### 6.3 重写 equals() 和 hashCode()

在Java中，如果重写 `equals()` 方法，**必须同时重写 `hashCode()`**，否则会导致使用 `HashMap`、`HashSet` 等集合时出现异常行为。

```java
public class Person {
    private String id;
    private String name;

    public Person(String id, String name) {
        this.id = id;
        this.name = name;
    }

    // 重写 equals()：判断对象的内容是否相等
    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;
        if (obj == null || getClass() != obj.getClass()) return false;

        Person person = (Person) obj;
        return id != null ? id.equals(person.id) : person.id == null;
    }

    // 重写 hashCode()：必须与 equals() 保持一致
    @Override
    public int hashCode() {
        return id != null ? id.hashCode() : 0;
    }

    public static void main(String[] args) {
        Person p1 = new Person("001", "张三");
        Person p2 = new Person("001", "张三");
        Person p3 = new Person("002", "李四");

        System.out.println(p1.equals(p2)); // true
        System.out.println(p1.equals(p3)); // false
    }
}
```

> **`equals()` 与 `hashCode()` 的契约**：如果两个对象的 `equals()` 返回 `true`，它们的 `hashCode()` 必须相同。如果两个对象的 `hashCode()` 相同，它们的 `equals()` 不一定返回 `true`。

## 第七章 综合示例

以下是一个完整的继承层次结构示例，展示动物、狗、猫和鸟的继承关系。

```java
/**
 * 动物（父类）
 */
class Animal {
    protected String name;
    protected int age;

    public Animal(String name, int age) {
        this.name = name;
        this.age = age;
        System.out.println("Animal 构造方法被调用");
    }

    public void eat() {
        System.out.println(name + "正在吃东西...");
    }

    public void sleep() {
        System.out.println(name + "正在睡觉...");
    }

    public void makeSound() {
        System.out.println(name + "发出声音...");
    }

    @Override
    public String toString() {
        return "Animal{name='" + name + "', age=" + age + "}";
    }
}

/**
 * 狗（子类）
 */
class Dog extends Animal {
    private String breed;

    public Dog(String name, int age, String breed) {
        super(name, age);
        this.breed = breed;
        System.out.println("Dog 构造方法被调用");
    }

    @Override
    public void makeSound() {
        System.out.println(name + "汪汪叫！");
    }

    public void wagTail() {
        System.out.println(name + "摇尾巴！");
    }

    public void fetch() {
        System.out.println(name + "叼回球！");
    }

    @Override
    public String toString() {
        return "Dog{name='" + name + "', age=" + age + ", breed='" + breed + "'}";
    }
}

/**
 * 猫（子类）
 */
class Cat extends Animal {
    public Cat(String name, int age) {
        super(name, age);
        System.out.println("Cat 构造方法被调用");
    }

    @Override
    public void makeSound() {
        System.out.println(name + "喵喵叫！");
    }

    public void scratch() {
        System.out.println(name + "抓沙发！");
    }

    @Override
    public String toString() {
        return "Cat{name='" + name + "', age=" + age + "}";
    }
}

/**
 * 鸟（子类）
 */
class Bird extends Animal {
    private double wingSpan;

    public Bird(String name, int age, double wingSpan) {
        super(name, age);
        this.wingSpan = wingSpan;
        System.out.println("Bird 构造方法被调用");
    }

    @Override
    public void makeSound() {
        System.out.println(name + "叽叽喳喳！");
    }

    public void fly() {
        System.out.println(name + "正在飞翔，翼展 " + wingSpan + " 米");
    }

    @Override
    public String toString() {
        return "Bird{name='" + name + "', age=" + age + ", wingSpan=" + wingSpan + "}";
    }
}

/**
 * 测试类
 */
public class AnimalTest {
    public static void main(String[] args) {
        System.out.println("=== 创建狗对象 ===");
        Dog dog = new Dog("旺财", 3, "金毛");
        dog.eat();
        dog.sleep();
        dog.makeSound();
        dog.wagTail();
        dog.fetch();
        System.out.println(dog);

        System.out.println("\n=== 创建猫对象 ===");
        Cat cat = new Cat("咪咪", 2);
        cat.eat();
        cat.sleep();
        cat.makeSound();
        cat.scratch();
        System.out.println(cat);

        System.out.println("\n=== 创建鸟对象 ===");
        Bird bird = new Bird("小翠", 1, 0.5);
        bird.eat();
        bird.sleep();
        bird.makeSound();
        bird.fly();
        System.out.println(bird);

        // 多态：使用父类引用指向子类对象
        System.out.println("\n=== 多态演示 ===");
        Animal animal1 = new Dog("小黑", 2, "拉布拉多");
        Animal animal2 = new Cat("小花", 1);

        animal1.makeSound(); // 实际调用 Dog 的 makeSound()
        animal2.makeSound(); // 实际调用 Cat 的 makeSound()
    }
}
```

## 总结

本文系统讲解了Java中的继承机制：

| 知识点 | 核心要点 |
|--------|---------|
| **继承定义** | `extends` 关键字，子类继承父类的成员 |
| **单继承** | Java只支持单继承，但支持多层继承 |
| **方法重写** | 子类重新定义父类方法，使用 `@Override` 注解 |
| **super** | 访问父类成员、调用父类构造方法 |
| **构造方法链** | 从父类到子类的构造方法调用顺序 |
| **final** | 禁止继承、禁止重写、定义常量 |
| **Object类** | 所有类的根类，`toString()`、`equals()`、`hashCode()` |
