## 引言

在前两篇文章中，我们学习了线程的创建、生命周期、同步机制和线程通信。然而，在实际项目开发中，我们很少直接创建和管理线程——频繁的线程创建和销毁会带来巨大的性能开销，而且手动管理线程的生命周期非常繁琐且容易出错。

为了解决这些问题，Java提供了**线程池**（Thread Pool）和**并发工具类**。线程池通过复用线程来减少创建和销毁的开销，提高系统性能。而 `java.util.concurrent` 包中的并发工具类则提供了丰富的线程协作机制，让并发编程变得更加简单和安全。

本文将系统讲解线程池的配置与使用，以及常用的并发工具类。

## 第一章 线程池概述

### 1.1 为什么需要线程池

在Java中，每当需要执行异步任务时，我们通常会创建一个新的线程。但这种方式存在几个问题：

1. **创建和销毁线程的开销大**：每次创建线程都需要操作系统分配资源，销毁线程也需要回收资源。
2. **资源限制**：线程数量受操作系统限制，创建过多线程会导致系统资源耗尽。
3. **管理复杂**：线程的生命周期管理、异常处理等都需要手动处理。
4. **性能下降**：大量线程竞争CPU时间片，会导致频繁的上下文切换。

**线程池的优势**：

1. **降低资源消耗**：通过复用已有线程，减少创建和销毁的开销。
2. **提高响应速度**：任务到达时，无需等待线程创建，立即执行。
3. **提高线程可管理性**：统一管理线程的创建、分配和监控。
4. **提供任务队列**：当线程池满时，任务可以在队列中等待。

### 1.2 Executor 框架体系

```text
Executor（接口）
├── ExecutorService（接口）
│   ├── AbstractExecutorService（抽象类）
│   │   └── ThreadPoolExecutor（实现类）← 最核心
│   │       ├── ScheduledThreadPoolExecutor（实现类）
│   │       └── ForkJoinPool（实现类）
│   └── ScheduledExecutorService（接口）
│       └── ScheduledThreadPoolExecutor（实现类）
└── Executors（工具类，用于创建线程池）
```

## 第二章 Executors 工厂类

`Executors` 提供了快速创建线程池的静态方法。

### 2.1 常用线程池创建方法

```java
import java.util.concurrent.*;

public class ExecutorsDemo {
    public static void main(String[] args) {
        // 1. 固定大小线程池
        // 核心线程数和最大线程数都是 n
        ExecutorService fixedPool = Executors.newFixedThreadPool(5);

        // 2. 单线程线程池
        // 只有一个线程，任务按顺序执行
        ExecutorService singlePool = Executors.newSingleThreadExecutor();

        // 3. 可缓存线程池
        // 核心线程数为0，最大线程数为 Integer.MAX_VALUE
        // 空闲线程存活时间60秒，适合短期任务
        ExecutorService cachedPool = Executors.newCachedThreadPool();

        // 4. 定时任务线程池
        // 支持定时和周期性任务
        ScheduledExecutorService scheduledPool = Executors.newScheduledThreadPool(3);

        // 5. 工作窃取线程池（Java 7+）
        // 每个线程都有自己的任务队列
        ExecutorService workStealingPool = Executors.newWorkStealingPool();

        // 使用完成后关闭线程池
        fixedPool.shutdown();
        singlePool.shutdown();
        cachedPool.shutdown();
        scheduledPool.shutdown();
        workStealingPool.shutdown();
    }
}
```

### 2.2 各线程池的特点对比

| 线程池类型 | 核心线程 | 最大线程 | 空闲存活时间 | 任务队列 | 适用场景 |
|-----------|---------|---------|-------------|---------|---------|
| **newFixedThreadPool** | n | n | 0 | 无界队列 | 固定并发数的任务 |
| **newSingleThreadExecutor** | 1 | 1 | 0 | 无界队列 | 顺序执行的任务 |
| **newCachedThreadPool** | 0 | 无限 | 60s | 无界队列 | 大量短期任务 |
| **newScheduledThreadPool** | n | 无限 | 无 | 延迟队列 | 定时/周期任务 |
| **newWorkStealingPool** | CPU核心数 | — | — | — | 递归/分治任务 |

### 2.3 使用线程池执行任务

```java
import java.util.concurrent.*;

public class ThreadPoolUsage {
    public static void main(String[] args) {
        // 创建固定大小线程池
        ExecutorService executor = Executors.newFixedThreadPool(3);

        // 方式一：execute() 执行 Runnable 任务（无返回值）
        executor.execute(() -> {
            System.out.println(Thread.currentThread().getName() + " 执行任务1");
        });

        // 方式二：submit() 执行 Runnable 任务（返回 Future）
        Future<?> future1 = executor.submit(() -> {
            System.out.println(Thread.currentThread().getName() + " 执行任务2");
        });

        // 方式三：submit() 执行 Callable 任务（有返回值）
        Future<String> future2 = executor.submit(() -> {
            Thread.sleep(1000);
            return Thread.currentThread().getName() + " 任务完成";
        });

        try {
            // 获取任务结果（会阻塞）
            String result = future2.get();
            System.out.println("任务结果: " + result);

            // 带超时的获取
            // String result2 = future2.get(500, TimeUnit.MILLISECONDS);
        } catch (InterruptedException | ExecutionException e) {
            System.out.println("任务执行异常: " + e.getMessage());
        }

        // 关闭线程池
        executor.shutdown();
        try {
            // 等待所有任务完成（最多等待5秒）
            if (!executor.awaitTermination(5, TimeUnit.SECONDS)) {
                executor.shutdownNow(); // 强制关闭
            }
        } catch (InterruptedException e) {
            executor.shutdownNow();
        }
    }
}
```

### 2.4 定时任务

```java
import java.util.concurrent.*;
import java.util.Date;

public class ScheduledTaskDemo {
    public static void main(String[] args) {
        ScheduledExecutorService scheduler = Executors.newScheduledThreadPool(2);

        // 1. schedule()：延迟执行（只执行一次）
        scheduler.schedule(() -> {
            System.out.println("延迟2秒后执行: " + new Date());
        }, 2, TimeUnit.SECONDS);

        // 2. scheduleAtFixedRate()：固定频率执行
        // 从任务开始时间计算间隔
        scheduler.scheduleAtFixedRate(() -> {
            System.out.println("固定频率执行: " + new Date());
        }, 1, 3, TimeUnit.SECONDS);

        // 3. scheduleWithFixedDelay()：固定延迟执行
        // 从任务结束时间计算间隔
        scheduler.scheduleWithFixedDelay(() -> {
            System.out.println("固定延迟执行: " + new Date());
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }, 1, 2, TimeUnit.SECONDS);

        // 停止定时任务（演示运行5秒后停止）
        scheduler.schedule(() -> {
            System.out.println("关闭定时任务线程池");
            scheduler.shutdown();
        }, 10, TimeUnit.SECONDS);
    }
}
```

## 第三章 ThreadPoolExecutor 详解

`ThreadPoolExecutor` 是 Java 线程池的核心实现，理解它的工作原理对于优化线程池配置至关重要。

### 3.1 ThreadPoolExecutor 的构造参数

```java
public ThreadPoolExecutor(
    int corePoolSize,      // 核心线程数
    int maximumPoolSize,   // 最大线程数
    long keepAliveTime,    // 空闲线程存活时间
    TimeUnit unit,         // 时间单位
    BlockingQueue<Runnable> workQueue, // 任务队列
    ThreadFactory threadFactory,       // 线程工厂
    RejectedExecutionHandler handler   // 拒绝策略
)
```

**参数详解**：

1. **corePoolSize**：核心线程数。即使线程空闲，也会保留。
2. **maximumPoolSize**：最大线程数。当任务队列满时，会创建新线程直到达到此值。
3. **keepAliveTime**：非核心线程的空闲存活时间。
4. **workQueue**：任务队列，存放等待执行的任务。
5. **threadFactory**：用于创建新线程的工厂。
6. **handler**：任务拒绝策略，当线程池和队列都满时使用。

### 3.2 任务队列的类型

| 队列类型 | 特点 | 适用场景 |
|---------|------|---------|
| **ArrayBlockingQueue** | 有界数组队列 | 固定大小的任务缓冲 |
| **LinkedBlockingQueue** | 可选有界链表队列（默认无界） | newFixedThreadPool 使用 |
| **SynchronousQueue** | 无容量的直接传递队列 | newCachedThreadPool 使用 |
| **PriorityBlockingQueue** | 优先级队列 | 需要优先级排序的任务 |
| **DelayQueue** | 延迟队列 | 定时任务 |

### 3.3 线程池的执行流程

当提交一个任务时，线程池的处理流程如下：

```text
提交任务
    ↓
┌───────────────────────────────────────────────────────────────┐
│ 1. 当前线程数 < corePoolSize？                              │
│    → 是：创建新线程执行任务                                  │
│    → 否：进入步骤2                                          │
├───────────────────────────────────────────────────────────────┤
│ 2. 任务队列是否已满？                                        │
│    → 否：将任务放入队列                                      │
│    → 是：进入步骤3                                          │
├───────────────────────────────────────────────────────────────┤
│ 3. 当前线程数 < maximumPoolSize？                           │
│    → 是：创建新线程执行任务（非核心线程）                    │
│    → 否：执行拒绝策略                                        │
└───────────────────────────────────────────────────────────────┘
```

### 3.4 自定义线程池

```java
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicInteger;

public class CustomThreadPool {
    public static void main(String[] args) {
        // 自定义线程工厂
        ThreadFactory threadFactory = new ThreadFactory() {
            private final AtomicInteger threadNumber = new AtomicInteger(1);

            @Override
            public Thread newThread(Runnable r) {
                Thread t = new Thread(r, "MyPool-Thread-" + threadNumber.getAndIncrement());
                t.setDaemon(false);
                t.setPriority(Thread.NORM_PRIORITY);
                System.out.println("创建线程: " + t.getName());
                return t;
            }
        };

        // 自定义拒绝策略：AbortPolicy（默认）、CallerRunsPolicy、DiscardPolicy、DiscardOldestPolicy
        RejectedExecutionHandler handler = new ThreadPoolExecutor.AbortPolicy();

        // 创建自定义线程池
        ThreadPoolExecutor executor = new ThreadPoolExecutor(
            2,                  // corePoolSize
            4,                  // maximumPoolSize
            60,                 // keepAliveTime
            TimeUnit.SECONDS,   // timeUnit
            new ArrayBlockingQueue<>(10), // 有界队列
            threadFactory,
            handler
        );

        // 提交任务
        for (int i = 0; i < 20; i++) {
            final int taskId = i;
            executor.execute(() -> {
                System.out.println(Thread.currentThread().getName() + " 执行任务: " + taskId);
                try {
                    Thread.sleep(500);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            });
        }

        // 监控线程池状态
        while (executor.getActiveCount() > 0 || !executor.getQueue().isEmpty()) {
            System.out.println("线程池状态:");
            System.out.println("  任务总数: " + executor.getTaskCount());
            System.out.println("  完成任务: " + executor.getCompletedTaskCount());
            System.out.println("  活动线程: " + executor.getActiveCount());
            System.out.println("  队列大小: " + executor.getQueue().size());
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                break;
            }
        }

        executor.shutdown();
    }
}
```

### 3.5 拒绝策略

| 拒绝策略 | 说明 |
|---------|------|
| **AbortPolicy** | 抛出 RejectedExecutionException（默认） |
| **CallerRunsPolicy** | 由调用者线程执行任务 |
| **DiscardPolicy** | 直接丢弃任务，不抛出异常 |
| **DiscardOldestPolicy** | 丢弃队列中最旧的任务，然后重试提交 |

```java
public class RejectPolicyDemo {
    public static void main(String[] args) {
        // CallerRunsPolicy：让调用者执行
        ThreadPoolExecutor executor = new ThreadPoolExecutor(
            1, 1, 60, TimeUnit.SECONDS,
            new ArrayBlockingQueue<>(1),
            new ThreadPoolExecutor.CallerRunsPolicy()
        );

        for (int i = 0; i < 10; i++) {
            final int taskId = i;
            executor.execute(() -> {
                System.out.println(Thread.currentThread().getName() + " 执行任务: " + taskId);
                try {
                    Thread.sleep(100);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            });
        }

        executor.shutdown();
    }
}
```

## 第四章 Callable 与 Future

### 4.1 Callable 接口

`Callable` 是 `Runnable` 的增强版，支持返回值和抛出异常。

```java
import java.util.concurrent.*;

public class CallableFutureDemo {
    public static void main(String[] args) throws Exception {
        ExecutorService executor = Executors.newFixedThreadPool(3);

        // 创建 Callable 任务
        Callable<Integer> task = () -> {
            int sum = 0;
            for (int i = 1; i <= 100; i++) {
                sum += i;
                Thread.sleep(1); // 模拟耗时
            }
            return sum;
        };

        // 提交任务，返回 Future
        Future<Integer> future = executor.submit(task);

        // 其他操作...
        System.out.println("主线程继续执行其他任务...");

        // 获取结果（会阻塞直到任务完成）
        try {
            // get() 会阻塞
            Integer result = future.get();
            System.out.println("1+2+...+100 = " + result);

            // get(timeout) 带超时
            // Integer result2 = future.get(5, TimeUnit.SECONDS);
        } catch (InterruptedException | ExecutionException e) {
            System.out.println("任务执行失败: " + e.getMessage());
        } catch (TimeoutException e) {
            System.out.println("任务执行超时");
            future.cancel(true);
        }

        executor.shutdown();
    }
}
```

### 4.2 Future 的常用方法

```java
import java.util.concurrent.*;

public class FutureMethods {
    public static void main(String[] args) throws Exception {
        ExecutorService executor = Executors.newSingleThreadExecutor();

        Future<String> future = executor.submit(() -> {
            Thread.sleep(3000);
            return "Task completed";
        });

        // 检查任务是否完成
        System.out.println("isDone: " + future.isDone()); // false

        // 获取结果（阻塞）
        // String result = future.get();

        // 带超时的获取
        try {
            String result = future.get(1, TimeUnit.SECONDS);
            System.out.println("结果: " + result);
        } catch (TimeoutException e) {
            System.out.println("任务超时，取消任务");
            future.cancel(true);
        }

        // 检查是否被取消
        System.out.println("isCancelled: " + future.isCancelled());

        // 取消任务
        future.cancel(true);

        executor.shutdown();
    }
}
```

### 4.3 CompletionService：批量处理任务

`CompletionService` 用于提交多个任务，并按完成顺序获取结果。

```java
import java.util.concurrent.*;

public class CompletionServiceDemo {
    public static void main(String[] args) throws Exception {
        ExecutorService executor = Executors.newFixedThreadPool(3);
        CompletionService<Integer> cs = new ExecutorCompletionService<>(executor);

        // 提交多个任务
        for (int i = 0; i < 5; i++) {
            final int taskId = i;
            cs.submit(() -> {
                int sleepTime = (int) (Math.random() * 2000) + 500;
                Thread.sleep(sleepTime);
                return taskId * 100;
            });
        }

        // 按完成顺序获取结果
        for (int i = 0; i < 5; i++) {
            Future<Integer> future = cs.take(); // 阻塞直到有任务完成
            System.out.println("任务" + i + " 结果: " + future.get());
        }

        executor.shutdown();
    }
}
```

## 第五章 并发工具类

### 5.1 CountDownLatch：门闩

`CountDownLatch` 允许一个或多个线程等待其他线程完成操作。

```java
import java.util.concurrent.*;

public class CountDownLatchDemo {
    public static void main(String[] args) throws InterruptedException {
        int taskCount = 5;
        CountDownLatch latch = new CountDownLatch(taskCount);

        System.out.println("主线程: 等待 " + taskCount + " 个任务完成...");

        ExecutorService executor = Executors.newFixedThreadPool(taskCount);

        for (int i = 0; i < taskCount; i++) {
            final int taskId = i;
            executor.execute(() -> {
                try {
                    Thread.sleep((int) (Math.random() * 1000) + 500);
                    System.out.println("任务 " + taskId + " 完成");
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                } finally {
                    latch.countDown(); // 计数器减1
                }
            });
        }

        // 等待所有任务完成
        latch.await();
        System.out.println("主线程: 所有任务已完成！");

        executor.shutdown();
    }
}
```

### 5.2 CyclicBarrier：循环栅栏

`CyclicBarrier` 允许多个线程互相等待，直到所有线程都到达某个屏障点，然后一起继续执行。与 `CountDownLatch` 不同的是，`CyclicBarrier` 可以重复使用。

```java
import java.util.concurrent.*;

public class CyclicBarrierDemo {
    public static void main(String[] args) {
        int threadCount = 3;
        CyclicBarrier barrier = new CyclicBarrier(threadCount, () -> {
            System.out.println("所有线程已到达，继续执行下一阶段");
        });

        ExecutorService executor = Executors.newFixedThreadPool(threadCount);

        for (int i = 0; i < threadCount; i++) {
            final int taskId = i;
            executor.execute(() -> {
                try {
                    System.out.println("线程 " + taskId + " 正在执行阶段1...");
                    Thread.sleep((int) (Math.random() * 1000) + 500);
                    System.out.println("线程 " + taskId + " 到达阶段1屏障");
                    barrier.await(); // 等待其他线程

                    System.out.println("线程 " + taskId + " 正在执行阶段2...");
                    Thread.sleep((int) (Math.random() * 1000) + 500);
                    System.out.println("线程 " + taskId + " 到达阶段2屏障");
                    barrier.await();

                    System.out.println("线程 " + taskId + " 执行完成");
                } catch (InterruptedException | BrokenBarrierException e) {
                    Thread.currentThread().interrupt();
                }
            });
        }

        executor.shutdown();
    }
}
```

### 5.3 Semaphore：信号量

`Semaphore` 用于控制同时访问特定资源的线程数量。

```java
import java.util.concurrent.*;

public class SemaphoreDemo {
    private static final int MAX_CONNECTIONS = 3;
    private static final Semaphore semaphore = new Semaphore(MAX_CONNECTIONS);

    public static void main(String[] args) {
        ExecutorService executor = Executors.newFixedThreadPool(10);

        for (int i = 0; i < 10; i++) {
            final int taskId = i;
            executor.execute(() -> {
                try {
                    System.out.println("线程 " + taskId + " 尝试获取连接...");
                    semaphore.acquire(); // 获取许可
                    System.out.println("线程 " + taskId + " 成功获取连接，当前可用许可: " + semaphore.availablePermits());

                    // 模拟使用连接
                    Thread.sleep(1000);

                    semaphore.release(); // 释放许可
                    System.out.println("线程 " + taskId + " 释放连接，当前可用许可: " + semaphore.availablePermits());
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            });
        }

        executor.shutdown();
    }
}
```

### 5.4 Exchanger：交换器

`Exchanger` 用于两个线程之间交换数据。

```java
import java.util.concurrent.*;

public class ExchangerDemo {
    public static void main(String[] args) {
        Exchanger<String> exchanger = new Exchanger<>();

        Thread t1 = new Thread(() -> {
            try {
                String data = "线程1的数据";
                System.out.println("线程1 准备发送: " + data);
                String received = exchanger.exchange(data);
                System.out.println("线程1 收到: " + received);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        });

        Thread t2 = new Thread(() -> {
            try {
                String data = "线程2的数据";
                System.out.println("线程2 准备发送: " + data);
                String received = exchanger.exchange(data);
                System.out.println("线程2 收到: " + received);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        });

        t1.start();
        t2.start();
    }
}
```

### 5.5 并发工具类对比

| 工具类 | 作用 | 特点 |
|--------|------|------|
| **CountDownLatch** | 等待多个任务完成 | 计数器只能使用一次 |
| **CyclicBarrier** | 多个线程互相等待 | 可重复使用（reset） |
| **Semaphore** | 控制并发访问数量 | 可动态调整许可数量 |
| **Exchanger** | 两个线程交换数据 | 仅适用于两个线程 |

## 第六章 综合示例

```java
import java.util.*;
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicInteger;

/**
 * 并发任务调度器
 */
public class TaskScheduler {
    private final ThreadPoolExecutor executor;
    private final ScheduledExecutorService scheduler;
    private final ConcurrentHashMap<String, TaskStatus> taskStatus = new ConcurrentHashMap<>();
    private final AtomicInteger taskIdGenerator = new AtomicInteger(0);

    public TaskScheduler() {
        // 核心线程数 = CPU核心数
        int coreSize = Runtime.getRuntime().availableProcessors();
        this.executor = new ThreadPoolExecutor(
            coreSize,
            coreSize * 2,
            60,
            TimeUnit.SECONDS,
            new LinkedBlockingQueue<>(100),
            new CustomThreadFactory("Worker"),
            new ThreadPoolExecutor.CallerRunsPolicy()
        );
        this.scheduler = Executors.newScheduledThreadPool(2, new CustomThreadFactory("Scheduler"));
    }

    /**
     * 提交异步任务
     */
    public Future<?> submitTask(Runnable task, String taskName) {
        int id = taskIdGenerator.incrementAndGet();
        String taskId = "TASK-" + String.format("%04d", id);
        TaskStatus status = new TaskStatus(taskId, taskName);
        taskStatus.put(taskId, status);

        Future<?> future = executor.submit(() -> {
            status.setStartTime(System.currentTimeMillis());
            status.setStatus("RUNNING");
            System.out.println("[" + taskId + "] " + taskName + " 开始执行");

            try {
                task.run();
                status.setStatus("COMPLETED");
                System.out.println("[" + taskId + "] " + taskName + " 执行完成");
            } catch (Exception e) {
                status.setStatus("FAILED");
                status.setError(e.getMessage());
                System.err.println("[" + taskId + "] " + taskName + " 执行失败: " + e.getMessage());
            } finally {
                status.setEndTime(System.currentTimeMillis());
            }
        });

        return future;
    }

    /**
     * 提交定时任务
     */
    public ScheduledFuture<?> scheduleTask(Runnable task, String taskName, long delay, long period, TimeUnit unit) {
        return scheduler.scheduleAtFixedRate(() -> {
            System.out.println("[定时任务] " + taskName + " 执行");
            task.run();
        }, delay, period, unit);
    }

    /**
     * 获取所有任务状态
     */
    public Map<String, TaskStatus> getAllTaskStatus() {
        return new HashMap<>(taskStatus);
    }

    /**
     * 获取任务状态
     */
    public TaskStatus getTaskStatus(String taskId) {
        return taskStatus.get(taskId);
    }

    /**
     * 关闭调度器
     */
    public void shutdown() {
        System.out.println("正在关闭任务调度器...");
        executor.shutdown();
        scheduler.shutdown();
        try {
            if (!executor.awaitTermination(30, TimeUnit.SECONDS)) {
                executor.shutdownNow();
            }
            if (!scheduler.awaitTermination(10, TimeUnit.SECONDS)) {
                scheduler.shutdownNow();
            }
        } catch (InterruptedException e) {
            executor.shutdownNow();
            scheduler.shutdownNow();
            Thread.currentThread().interrupt();
        }
        System.out.println("任务调度器已关闭");
    }

    public static void main(String[] args) throws InterruptedException {
        TaskScheduler scheduler = new TaskScheduler();

        // 1. 提交多个任务
        CountDownLatch latch = new CountDownLatch(10);
        for (int i = 0; i < 10; i++) {
            final int taskNum = i;
            scheduler.submitTask(() -> {
                try {
                    Thread.sleep((long) (Math.random() * 2000) + 500);
                    System.out.println("  - 任务 " + taskNum + " 业务逻辑执行中");
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            }, "业务任务-" + (i + 1));
        }

        // 2. 提交定时任务
        scheduler.scheduleTask(() -> {
            System.out.println("  定时任务执行: " + new Date());
        }, "心跳检测", 1, 3, TimeUnit.SECONDS);

        // 3. 监控任务状态
        Thread monitor = new Thread(() -> {
            while (true) {
                try {
                    Thread.sleep(2000);
                    System.out.println("\n=== 任务状态 ===");
                    Map<String, TaskStatus> statusMap = scheduler.getAllTaskStatus();
                    int running = 0, completed = 0, failed = 0;
                    for (TaskStatus status : statusMap.values()) {
                        switch (status.getStatus()) {
                            case "RUNNING": running++; break;
                            case "COMPLETED": completed++; break;
                            case "FAILED": failed++; break;
                        }
                    }
                    System.out.println("运行中: " + running + ", 已完成: " + completed + ", 失败: " + failed);
                    System.out.println("总任务数: " + statusMap.size());
                } catch (InterruptedException e) {
                    break;
                }
            }
        });
        monitor.setDaemon(true);
        monitor.start();

        // 等待所有任务完成（最多15秒）
        Thread.sleep(15000);

        // 关闭调度器
        scheduler.shutdown();
    }
}

/**
 * 任务状态类
 */
class TaskStatus {
    private final String taskId;
    private final String taskName;
    private volatile String status = "PENDING";
    private volatile long startTime;
    private volatile long endTime;
    private volatile String error;

    public TaskStatus(String taskId, String taskName) {
        this.taskId = taskId;
        this.taskName = taskName;
    }

    public String getTaskId() { return taskId; }
    public String getTaskName() { return taskName; }
    public String getStatus() { return status; }
    public long getStartTime() { return startTime; }
    public long getEndTime() { return endTime; }
    public String getError() { return error; }
    public long getDuration() {
        if (startTime == 0) return 0;
        long end = endTime > 0 ? endTime : System.currentTimeMillis();
        return end - startTime;
    }

    public void setStatus(String status) { this.status = status; }
    public void setStartTime(long startTime) { this.startTime = startTime; }
    public void setEndTime(long endTime) { this.endTime = endTime; }
    public void setError(String error) { this.error = error; }
}

/**
 * 自定义线程工厂
 */
class CustomThreadFactory implements ThreadFactory {
    private final AtomicInteger counter = new AtomicInteger(1);
    private final String prefix;

    public CustomThreadFactory(String prefix) {
        this.prefix = prefix;
    }

    @Override
    public Thread newThread(Runnable r) {
        Thread t = new Thread(r, prefix + "-" + counter.getAndIncrement());
        t.setDaemon(false);
        return t;
    }
}
```

## 总结

本文系统讲解了Java线程池与并发工具类：

| 知识点 | 核心要点 |
|--------|---------|
| **线程池** | 复用线程，减少创建销毁开销 |
| **Executors** | 快速创建常用线程池的工厂方法 |
| **ThreadPoolExecutor** | 核心线程池实现，可自定义配置 |

| **Callable** | 有返回值的任务接口 |

| **CountDownLatch** | 等待多个任务完成 |
| **CyclicBarrier** | 多个线程互相等待 |
| **Semaphore** | 控制并发访问数量 |
