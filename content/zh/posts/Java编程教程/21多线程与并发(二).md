## 引言

在上一篇文章中，我们学习了线程的创建、生命周期和常用方法。然而，多线程编程中最核心、最复杂的问题——**线程安全**——尚未涉及。

当多个线程同时访问共享资源时，如果缺乏适当的同步机制，就会出现数据不一致、脏读、丢失更新等问题。这些问题通常难以复现和调试，是并发编程中最棘手的挑战。

Java提供了多种线程同步机制来保证线程安全：`synchronized` 关键字、`Lock` 接口、`volatile` 关键字、`wait/notify` 机制等。本文将系统讲解这些同步机制的工作原理和使用方法。

## 第一章 线程安全问题

### 1.1 什么是线程安全

**线程安全**是指当多个线程访问同一个对象时，如果不用考虑这些线程在运行时环境下的调度和交替执行，也不需要进行额外的同步，调用这个对象的行为都可以获得正确的结果。

### 1.2 线程安全问题的产生

当多个线程**同时**对共享变量进行**写操作**时，由于线程的执行顺序不可控，可能导致数据不一致。

```java
public class ThreadSafetyDemo {
    public static void main(String[] args) throws InterruptedException {
        Counter counter = new Counter();

        // 创建10个线程，每个线程执行1000次自增
        Thread[] threads = new Thread[10];
        for (int i = 0; i < 10; i++) {
            threads[i] = new Thread(() -> {
                for (int j = 0; j < 1000; j++) {
                    counter.increment();
                }
            });
            threads[i].start();
        }

        // 等待所有线程完成
        for (Thread t : threads) {
            t.join();
        }

        // 期望结果是 10000，但实际结果可能小于 10000
        System.out.println("最终结果: " + counter.getCount());
        // 输出可能是 9856、9912、9768 等
    }
}

class Counter {
    private int count = 0;

    public void increment() {
        // 这不是一个原子操作！
        // 1. 读取 count 的值
        // 2. 计算 count + 1
        // 3. 将结果写回 count
        count++;
    }

    public int getCount() {
        return count;
    }
}
```

### 1.3 问题分析

`count++` 在底层实际上包含三个步骤：

1. 读取 `count` 的当前值
2. 将值加 1
3. 将新值写回 `count`

当多个线程同时执行这三个步骤时，可能出现以下情况：

```text
时间 → 线程A             线程B
│      读取 count=5      │
│      计算 5+1=6        │
│                        读取 count=5
│      写入 count=6      │
│                        计算 5+1=6
│                        写入 count=6
│      最终结果为6，丢失了一次更新！
```

## 第二章 synchronized 同步机制

`synchronized` 是Java提供的最基本的同步机制，它通过**监视器锁**（Monitor）实现线程互斥访问。

### 2.1 synchronized 的三种用法

```java
public class SynchronizedDemo {
    private int count = 0;
    private static int staticCount = 0;

    // 1. 同步实例方法：锁是当前对象实例 (this)
    public synchronized void method1() {
        count++;
        System.out.println(Thread.currentThread().getName() + " 执行 method1");
    }

    // 2. 同步静态方法：锁是当前类的 Class 对象
    public static synchronized void method2() {
        staticCount++;
        System.out.println(Thread.currentThread().getName() + " 执行 method2");
    }

    // 3. 同步代码块：指定锁对象
    public void method3() {
        // 锁是 this
        synchronized (this) {
            count--;
            System.out.println(Thread.currentThread().getName() + " 执行 method3");
        }

        // 锁是其他对象
        Object lock = new Object();
        synchronized (lock) {
            System.out.println(Thread.currentThread().getName() + " 执行其他锁");
        }
    }

    public static void main(String[] args) throws InterruptedException {
        SynchronizedDemo demo = new SynchronizedDemo();

        // 测试同步方法
        Thread t1 = new Thread(() -> {
            for (int i = 0; i < 1000; i++) {
                demo.method1();
            }
        });

        Thread t2 = new Thread(() -> {
            for (int i = 0; i < 1000; i++) {
                demo.method1();
            }
        });

        t1.start();
        t2.start();
        t1.join();
        t2.join();

        System.out.println("最终 count: " + demo.count); // 2000
    }
}
```

### 2.2 使用 synchronized 修复线程安全问题

```java
public class SafeCounter {
    private int count = 0;

    // 使用 synchronized 保证线程安全
    public synchronized void increment() {
        count++;
    }

    public synchronized int getCount() {
        return count;
    }

    public static void main(String[] args) throws InterruptedException {
        SafeCounter counter = new SafeCounter();

        Thread[] threads = new Thread[10];
        for (int i = 0; i < 10; i++) {
            threads[i] = new Thread(() -> {
                for (int j = 0; j < 1000; j++) {
                    counter.increment();
                }
            });
            threads[i].start();
        }

        for (Thread t : threads) {
            t.join();
        }

        System.out.println("最终结果: " + counter.getCount()); // 总是 10000
    }
}
```

### 2.3 synchronized 的底层原理

`synchronized` 通过 **对象头中的监视器锁（Monitor）** 实现。每个对象都有一个 Monitor，当线程进入 `synchronized` 块时，会尝试获取对象的 Monitor，成功则持有锁；失败则进入阻塞队列。

```text
┌─────────────────────────────────────────────────────────────┐
│               synchronized 执行流程                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  线程尝试获取锁                                             │
│       ↓                                                     │
│  ┌───────────┐                                             │
│  │ 锁是否被?│                                             │
│  └─────┬─────┘                                             │
│        │                                                    │
│    ┌───┴───┐                                                │
│    │  否    │    ┌─────────────┐                            │
│    └───┬───┘    │  进入阻塞队列│                            │
│        ↓        │  等待锁释放  │                            │
│  持有锁，执行    └─────────────┘                            │
│  同步代码                                                    │
│        ↓                                                     │
│  释放锁，唤醒等待线程                                       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.4 可重入性

`synchronized` 是**可重入锁**，即同一个线程可以多次获取同一把锁，不会造成死锁。

```java
public class ReentrantDemo {
    public synchronized void method1() {
        System.out.println(Thread.currentThread().getName() + " 进入 method1");
        // 调用另一个 synchronized 方法，同一个线程可以再次获取锁
        method2();
    }

    public synchronized void method2() {
        System.out.println(Thread.currentThread().getName() + " 进入 method2");
    }

    public static void main(String[] args) {
        ReentrantDemo demo = new ReentrantDemo();
        demo.method1();
    }
}
```

## 第三章 Lock 接口

Java 5 引入了 `java.util.concurrent.locks.Lock` 接口，提供了比 `synchronized` 更灵活的锁机制。

### 3.1 Lock 与 synchronized 的对比

| 特性 | synchronized | Lock |
|------|-------------|------|
| **获取锁的方式** | 隐式（进入同步块时获取） | 显式（调用 `lock()` 方法） |
| **释放锁的方式** | 隐式（退出同步块时释放） | 显式（调用 `unlock()` 方法） |
| **是否可中断** | 不可中断 | 可通过 `lockInterruptibly()` 中断 |
| **是否可超时** | 不可超时 | 可通过 `tryLock(timeout)` 超时获取 |
| **公平性** | 非公平锁 | 可配置公平/非公平 |
| **性能** | 早期较差，现在已优化 | 高并发下性能更好 |

### 3.2 ReentrantLock 的使用

```java
import java.util.concurrent.locks.Lock;
import java.util.concurrent.locks.ReentrantLock;

public class LockDemo {
    private int count = 0;
    private final Lock lock = new ReentrantLock();

    public void increment() {
        lock.lock(); // 获取锁
        try {
            count++;
        } finally {
            lock.unlock(); // 必须在 finally 中释放锁
        }
    }

    public int getCount() {
        lock.lock();
        try {
            return count;
        } finally {
            lock.unlock();
        }
    }

    public static void main(String[] args) throws InterruptedException {
        LockDemo demo = new LockDemo();

        Thread[] threads = new Thread[10];
        for (int i = 0; i < 10; i++) {
            threads[i] = new Thread(() -> {
                for (int j = 0; j < 1000; j++) {
                    demo.increment();
                }
            });
            threads[i].start();
        }

        for (Thread t : threads) {
            t.join();
        }

        System.out.println("最终结果: " + demo.getCount()); // 10000
    }
}
```

### 3.3 tryLock() 非阻塞获取锁

```java
import java.util.concurrent.TimeUnit;
import java.util.concurrent.locks.Lock;
import java.util.concurrent.locks.ReentrantLock;

public class TryLockDemo {
    private final Lock lock = new ReentrantLock();

    public void tryExecute() {
        // 尝试获取锁，获取不到立即返回 false
        if (lock.tryLock()) {
            try {
                System.out.println(Thread.currentThread().getName() + " 获取到锁");
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            } finally {
                lock.unlock();
                System.out.println(Thread.currentThread().getName() + " 释放锁");
            }
        } else {
            System.out.println(Thread.currentThread().getName() + " 获取锁失败，执行其他操作");
        }
    }

    public void tryExecuteWithTimeout() throws InterruptedException {
        // 尝试获取锁，等待1秒
        if (lock.tryLock(1, TimeUnit.SECONDS)) {
            try {
                System.out.println(Thread.currentThread().getName() + " 获取到锁（超时版本）");
                Thread.sleep(2000);
            } finally {
                lock.unlock();
            }
        } else {
            System.out.println(Thread.currentThread().getName() + " 获取锁超时");
        }
    }

    public static void main(String[] args) throws InterruptedException {
        TryLockDemo demo = new TryLockDemo();

        Thread t1 = new Thread(() -> demo.tryExecute(), "线程A");
        Thread t2 = new Thread(() -> demo.tryExecute(), "线程B");

        t1.start();
        Thread.sleep(100);
        t2.start();

        t1.join();
        t2.join();

        // 测试超时版本
        Thread t3 = new Thread(() -> {
            try {
                demo.tryExecuteWithTimeout();
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }, "线程C");
        Thread t4 = new Thread(() -> {
            try {
                demo.tryExecuteWithTimeout();
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }, "线程D");

        Thread.sleep(1000);
        t3.start();
        Thread.sleep(100);
        t4.start();
    }
}
```

### 3.4 公平锁 vs 非公平锁

```java
public class FairnessDemo {
    public static void main(String[] args) {
        // 非公平锁（默认）：性能更高，可能造成线程饥饿
        Lock unfairLock = new ReentrantLock();

        // 公平锁：按请求顺序获取锁，性能稍差
        Lock fairLock = new ReentrantLock(true);

        System.out.println("非公平锁: " + unfairLock);
        System.out.println("公平锁: " + fairLock);
    }
}
```

## 第四章 volatile 关键字

### 4.1 volatile 的作用

`volatile` 关键字保证**可见性**和**有序性**，但不保证**原子性**。

- **可见性**：当一个线程修改了 `volatile` 变量，其他线程能立即看到修改后的值。
- **有序性**：禁止指令重排序。

```java
public class VolatileDemo {
    // 不使用 volatile，可能造成死循环
    private static boolean running = true;

    // 使用 volatile，保证可见性
    private static volatile boolean running2 = true;

    public static void main(String[] args) throws InterruptedException {
        // 问题示例：不使用 volatile
        Thread t1 = new Thread(() -> {
            System.out.println("线程1 开始运行...");
            while (running) {
                // 空循环，可能永远不会停止
                // 因为 running 的值可能被缓存
            }
            System.out.println("线程1 停止");
        });

        t1.start();
        Thread.sleep(1000);
        running = false;
        System.out.println("主线程设置 running = false");

        // 使用 volatile 正确示例
        Thread t2 = new Thread(() -> {
            System.out.println("线程2 开始运行...");
            while (running2) {
                // 每次都会从主内存读取 running2 的值
            }
            System.out.println("线程2 停止");
        });

        t2.start();
        Thread.sleep(1000);
        running2 = false;
        System.out.println("主线程设置 running2 = false");
    }
}
```

### 4.2 volatile 的使用场景

`volatile` 适用于以下场景：

1. **状态标志**：如上述的 `running` 标志。
2. **双重检查锁（DCL）** 中的单例模式。

```java
public class VolatileSingleton {
    // 使用 volatile 防止指令重排序
    private static volatile VolatileSingleton instance;

    private VolatileSingleton() {}

    public static VolatileSingleton getInstance() {
        if (instance == null) {
            synchronized (VolatileSingleton.class) {
                if (instance == null) {
                    // 1. 分配内存
                    // 2. 初始化对象
                    // 3. 将引用赋值给 instance
                    // volatile 禁止步骤 2 和 3 重排序
                    instance = new VolatileSingleton();
                }
            }
        }
        return instance;
    }
}
```

### 4.3 volatile 与 synchronized 的对比

| 特性 | volatile | synchronized |
|------|----------|--------------|
| **原子性** | ❌ 不保证 | ✅ 保证 |
| **可见性** | ✅ 保证 | ✅ 保证 |
| **有序性** | ✅ 保证部分 | ✅ 保证 |
| **性能** | 开销小 | 开销大 |
| **适用场景** | 简单状态标志 | 复合操作 |

## 第五章 wait/notify 线程通信

`wait()`、`notify()`、`notifyAll()` 是 Object 类的方法，用于线程间的通信。

### 5.1 基本用法

```java
import java.util.LinkedList;
import java.util.Queue;

public class WaitNotifyDemo {
    private static final Queue<String> queue = new LinkedList<>();
    private static final int MAX_SIZE = 5;
    private static final Object lock = new Object();

    // 生产者
    static class Producer implements Runnable {
        @Override
        public void run() {
            int count = 0;
            while (true) {
                synchronized (lock) {
                    while (queue.size() == MAX_SIZE) {
                        try {
                            System.out.println("队列已满，生产者等待...");
                            lock.wait();
                        } catch (InterruptedException e) {
                            Thread.currentThread().interrupt();
                            return;
                        }
                    }
                    String item = "Item-" + count++;
                    queue.offer(item);
                    System.out.println("生产者生产: " + item + "，队列大小: " + queue.size());
                    lock.notify(); // 唤醒消费者
                }
                try {
                    Thread.sleep(500);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    return;
                }
            }
        }
    }

    // 消费者
    static class Consumer implements Runnable {
        @Override
        public void run() {
            while (true) {
                synchronized (lock) {
                    while (queue.isEmpty()) {
                        try {
                            System.out.println("队列为空，消费者等待...");
                            lock.wait();
                        } catch (InterruptedException e) {
                            Thread.currentThread().interrupt();
                            return;
                        }
                    }
                    String item = queue.poll();
                    System.out.println("消费者消费: " + item + "，队列大小: " + queue.size());
                    lock.notify(); // 唤醒生产者
                }
                try {
                    Thread.sleep(1000);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    return;
                }
            }
        }
    }

    public static void main(String[] args) {
        Thread producer = new Thread(new Producer(), "生产者");
        Thread consumer = new Thread(new Consumer(), "消费者");

        producer.start();
        consumer.start();
    }
}
```

### 5.2 wait/notify 的核心规则

1. **必须持有锁**：调用 `wait()`、`notify()`、`notifyAll()` 必须在 `synchronized` 块内。
2. **使用 while 循环**：检查条件时使用 `while` 而非 `if`，防止**虚假唤醒**。
3. **wait() 释放锁**：调用 `wait()` 会释放当前持有的锁，进入等待状态。
4. **notify() 不释放锁**：`notify()` 只是唤醒等待线程，但不会立即释放锁，需要等同步块执行完毕。

### 5.3 虚假唤醒

```java
// ❌ 错误：使用 if
if (queue.isEmpty()) {
    lock.wait();
}
// 可能被虚假唤醒（即使队列仍为空）

// ✅ 正确：使用 while
while (queue.isEmpty()) {
    lock.wait();
}
// 每次唤醒都重新检查条件
```

## 第六章 死锁

### 6.1 什么是死锁

**死锁**是指两个或多个线程互相持有对方所需的资源，导致所有线程都无法继续执行。

```java
public class DeadlockDemo {
    private static final Object RESOURCE_A = new Object();
    private static final Object RESOURCE_B = new Object();

    public static void main(String[] args) {
        // 线程1：先锁A再锁B
        Thread t1 = new Thread(() -> {
            synchronized (RESOURCE_A) {
                System.out.println("线程1 持有资源 A");
                try {
                    Thread.sleep(100);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
                System.out.println("线程1 尝试获取资源 B");
                synchronized (RESOURCE_B) {
                    System.out.println("线程1 持有资源 A 和 B");
                }
            }
        });

        // 线程2：先锁B再锁A（与线程1顺序相反）
        Thread t2 = new Thread(() -> {
            synchronized (RESOURCE_B) {
                System.out.println("线程2 持有资源 B");
                try {
                    Thread.sleep(100);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
                System.out.println("线程2 尝试获取资源 A");
                synchronized (RESOURCE_A) {
                    System.out.println("线程2 持有资源 A 和 B");
                }
            }
        });

        t1.start();
        t2.start();
    }
}
```

### 6.2 死锁的四个必要条件

1. **互斥**：资源不能被共享，只能由一个线程持有。
2. **持有并等待**：线程持有至少一个资源，并等待获取其他线程持有的资源。
3. **不可抢占**：资源不能被强行抢占，只能由持有者释放。
4. **循环等待**：线程之间形成循环等待资源的关系。

### 6.3 预防死锁

**破坏循环等待**是预防死锁最常用的方法：**所有线程按照固定的顺序获取锁**。

```java
public class DeadlockPrevention {
    private static final Object RESOURCE_A = new Object();
    private static final Object RESOURCE_B = new Object();

    public static void main(String[] args) {
        // 统一使用相同的锁顺序：先 A 后 B
        Thread t1 = new Thread(() -> {
            synchronized (RESOURCE_A) {
                System.out.println("线程1 持有资源 A");
                try {
                    Thread.sleep(100);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
                synchronized (RESOURCE_B) {
                    System.out.println("线程1 持有资源 A 和 B");
                }
            }
        });

        // 线程2 也先 A 后 B（与线程1顺序相同）
        Thread t2 = new Thread(() -> {
            synchronized (RESOURCE_A) {
                System.out.println("线程2 持有资源 A");
                try {
                    Thread.sleep(100);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
                synchronized (RESOURCE_B) {
                    System.out.println("线程2 持有资源 A 和 B");
                }
            }
        });

        t1.start();
        t2.start();
    }
}
```

### 6.4 死锁检测与解决

```java
import java.util.concurrent.locks.ReentrantLock;

public class DeadlockDetection {
    public static void main(String[] args) {
        ReentrantLock lock1 = new ReentrantLock();
        ReentrantLock lock2 = new ReentrantLock();

        Thread t1 = new Thread(() -> {
            try {
                // 尝试获取锁1，等待2秒
                if (lock1.tryLock(2, java.util.concurrent.TimeUnit.SECONDS)) {
                    try {
                        System.out.println("线程1 获取锁1");
                        Thread.sleep(100);
                        // 尝试获取锁2，等待2秒
                        if (lock2.tryLock(2, java.util.concurrent.TimeUnit.SECONDS)) {
                            try {
                                System.out.println("线程1 获取锁2");
                            } finally {
                                lock2.unlock();
                            }
                        } else {
                            System.out.println("线程1 获取锁2超时，放弃操作");
                        }
                    } finally {
                        lock1.unlock();
                    }
                } else {
                    System.out.println("线程1 获取锁1超时");
                }
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        });

        Thread t2 = new Thread(() -> {
            try {
                if (lock2.tryLock(2, java.util.concurrent.TimeUnit.SECONDS)) {
                    try {
                        System.out.println("线程2 获取锁2");
                        Thread.sleep(100);
                        if (lock1.tryLock(2, java.util.concurrent.TimeUnit.SECONDS)) {
                            try {
                                System.out.println("线程2 获取锁1");
                            } finally {
                                lock1.unlock();
                            }
                        } else {
                            System.out.println("线程2 获取锁1超时，放弃操作");
                        }
                    } finally {
                        lock2.unlock();
                    }
                } else {
                    System.out.println("线程2 获取锁2超时");
                }
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        });

        t1.start();
        t2.start();
    }
}
```

## 第七章 综合示例

```java
import java.util.*;
import java.util.concurrent.locks.*;
import java.util.concurrent.atomic.*;

/**
 * 线程安全的银行账户系统
 */
public class BankSystem {
    private final Map<String, Account> accounts = new HashMap<>();
    private final ReentrantLock systemLock = new ReentrantLock();

    public void createAccount(String id, String name, double balance) {
        systemLock.lock();
        try {
            if (accounts.containsKey(id)) {
                throw new IllegalArgumentException("账户已存在: " + id);
            }
            accounts.put(id, new Account(id, name, balance));
            System.out.println("创建账户成功: " + name);
        } finally {
            systemLock.unlock();
        }
    }

    /**
     * 转账 - 使用锁顺序避免死锁
     */
    public void transfer(String fromId, String toId, double amount) {
        Account from = getAccount(fromId);
        Account to = getAccount(toId);

        if (from == null || to == null) {
            System.out.println("账户不存在");
            return;
        }

        if (fromId.equals(toId)) {
            System.out.println("不能给自己转账");
            return;
        }

        // 按账户ID排序获取锁，避免死锁
        Account first = fromId.compareTo(toId) < 0 ? from : to;
        Account second = fromId.compareTo(toId) < 0 ? to : from;

        synchronized (first) {
            synchronized (second) {
                if (from.withdraw(amount)) {
                    to.deposit(amount);
                    System.out.println("转账成功: " + fromId + " -> " + toId + ", 金额: " + amount);
                } else {
                    System.out.println("转账失败: " + fromId + " 余额不足");
                }
            }
        }
    }

    public Account getAccount(String id) {
        systemLock.lock();
        try {
            return accounts.get(id);
        } finally {
            systemLock.unlock();
        }
    }

    public void printAllAccounts() {
        systemLock.lock();
        try {
            System.out.println("\n=== 所有账户 ===");
            for (Account acc : accounts.values()) {
                System.out.println(acc);
            }
            System.out.println("===============\n");
        } finally {
            systemLock.unlock();
        }
    }

    /**
     * 账户类
     */
    static class Account {
        private final String id;
        private final String name;
        private double balance;
        private final List<Transaction> transactions = new ArrayList<>();

        public Account(String id, String name, double balance) {
            this.id = id;
            this.name = name;
            this.balance = balance;
            addTransaction("初始化", balance);
        }

        public synchronized boolean withdraw(double amount) {
            if (amount <= 0 || amount > balance) {
                return false;
            }
            balance -= amount;
            addTransaction("取款", -amount);
            return true;
        }

        public synchronized void deposit(double amount) {
            if (amount <= 0) return;
            balance += amount;
            addTransaction("存款", amount);
        }

        public synchronized double getBalance() {
            return balance;
        }

        private void addTransaction(String type, double amount) {
            transactions.add(new Transaction(type, amount, new Date()));
        }

        public synchronized List<Transaction> getTransactions() {
            return new ArrayList<>(transactions);
        }

        public String getId() { return id; }
        public String getName() { return name; }

        @Override
        public synchronized String toString() {
            return String.format("Account{id='%s', name='%s', balance=%.2f}", id, name, balance);
        }
    }

    /**
     * 交易记录
     */
    static class Transaction {
        private final String type;
        private final double amount;
        private final Date timestamp;

        public Transaction(String type, double amount, Date timestamp) {
            this.type = type;
            this.amount = amount;
            this.timestamp = timestamp;
        }

        @Override
        public String toString() {
            return String.format("[%s] %s: %.2f", timestamp, type, amount);
        }
    }

    /**
     * 并发转账测试
     */
    public static void main(String[] args) throws InterruptedException {
        BankSystem bank = new BankSystem();

        // 创建账户
        bank.createAccount("A001", "张三", 10000);
        bank.createAccount("A002", "李四", 5000);
        bank.createAccount("A003", "王五", 3000);

        bank.printAllAccounts();

        // 启动多个转账线程
        List<Thread> threads = new ArrayList<>();

        // 张三 -> 李四
        threads.add(new Thread(() -> {
            for (int i = 0; i < 10; i++) {
                bank.transfer("A001", "A002", 100);
                try {
                    Thread.sleep(50);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            }
        }));

        // 李四 -> 王五
        threads.add(new Thread(() -> {
            for (int i = 0; i < 10; i++) {
                bank.transfer("A002", "A003", 50);
                try {
                    Thread.sleep(50);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            }
        }));

        // 王五 -> 张三
        threads.add(new Thread(() -> {
            for (int i = 0; i < 10; i++) {
                bank.transfer("A003", "A001", 30);
                try {
                    Thread.sleep(50);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            }
        }));

        // 启动所有线程
        for (Thread t : threads) {
            t.start();
        }

        // 等待所有线程完成
        for (Thread t : threads) {
            t.join();
        }

        bank.printAllAccounts();

        // 查看交易记录
        System.out.println("=== 张三的交易记录 ===");
        Account zhang = bank.getAccount("A001");
        if (zhang != null) {
            for (Transaction t : zhang.getTransactions()) {
                System.out.println(t);
            }
        }
    }
}
```

## 总结

本文系统讲解了Java线程同步的核心机制：

| 知识点 | 核心要点 |
|--------|---------|
| **线程安全** | 多线程访问共享资源时的数据一致性问题 |
| **synchronized** | Java内置同步机制，隐式获取/释放锁 |
| **Lock接口** | 显式锁，支持可中断、超时、公平锁 |
| **volatile** | 保证可见性和有序性，不保证原子性 |
| **wait/notify** | 线程通信机制，必须在同步块中使用 |
| **死锁** | 互斥、持有并等待、不可抢占、循环等待 |
| **死锁预防** | 统一锁获取顺序，使用 `tryLock` 超时机制 |
