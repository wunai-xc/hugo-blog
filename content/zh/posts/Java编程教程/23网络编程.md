## 第一章 网络编程概述

### 1.1 网络编程基础概念

**IP地址**：用于唯一标识网络中的每一台计算机。IPv4地址格式为4组数字（如 `192.168.1.1`），IPv6为更长的十六进制格式。

**端口号**：用于标识同一台计算机上的不同进程。取值范围0-65535，0-1023为公认端口（如HTTP的80、HTTPS的443）。

**协议**：通信双方约定的数据格式和传输规则。常见协议包括TCP、UDP、HTTP等。

### 1.2 TCP 与 UDP 的对比

| 对比维度 | TCP | UDP |
|---------|-----|-----|
| **连接方式** | 面向连接（三次握手） | 无连接 |
| **可靠性** | 可靠传输，保证数据到达 | 不可靠，可能丢包 |
| **顺序保证** | 保证数据顺序 | 不保证顺序 |
| **流量控制** | 有 | 无 |
| **速度** | 较慢 | 较快 |
| **应用场景** | HTTP、FTP、文件传输 | DNS、视频直播、实时游戏 |

### 1.3 OSI 七层模型与 TCP/IP 四层模型

## 第二章 InetAddress 类

`InetAddress` 类用于表示IP地址，提供了获取主机名、IP地址等操作。

```java
import java.net.*;

public class InetAddressDemo {
    public static void main(String[] args) {
        try {
            // 获取本机地址
            InetAddress local = InetAddress.getLocalHost();
            System.out.println("本机主机名: " + local.getHostName());
            System.out.println("本机IP地址: " + local.getHostAddress());

            // 通过主机名获取地址
            InetAddress google = InetAddress.getByName("www.google.com");
            System.out.println("Google主机名: " + google.getHostName());
            System.out.println("GoogleIP地址: " + google.getHostAddress());

            // 获取所有地址（多IP）
            InetAddress[] addresses = InetAddress.getAllByName("www.baidu.com");
            System.out.println("百度所有IP:");
            for (InetAddress addr : addresses) {
                System.out.println("  " + addr.getHostAddress());
            }

            // 通过IP地址获取InetAddress
            byte[] ip = { (byte) 192, (byte) 168, 1, 1 };
            InetAddress byIP = InetAddress.getByAddress(ip);
            System.out.println("IP地址: " + byIP.getHostAddress());

            // 判断是否可达
            boolean reachable = byIP.isReachable(3000);
            System.out.println("是否可达: " + reachable);

        } catch (UnknownHostException e) {
            System.out.println("主机名未知: " + e.getMessage());
        } catch (Exception e) {
            System.out.println("错误: " + e.getMessage());
        }
    }
}
```

## 第三章 TCP Socket 编程

TCP通信需要建立连接，通过 `Socket` 和 `ServerSocket` 实现。

### 3.1 服务端（Server）

```java
import java.io.*;
import java.net.*;

public class TCPServer {
    private static final int PORT = 8888;

    public static void main(String[] args) {
        System.out.println("TCP服务器启动，监听端口: " + PORT);

        try (ServerSocket serverSocket = new ServerSocket(PORT)) {
            while (true) {
                // 接受客户端连接
                Socket clientSocket = serverSocket.accept();
                System.out.println("客户端连接: " + clientSocket.getInetAddress() + ":" + clientSocket.getPort());

                // 为每个客户端创建独立线程处理
                new Thread(new ClientHandler(clientSocket)).start();
            }
        } catch (IOException e) {
            System.out.println("服务器异常: " + e.getMessage());
        }
    }

    /**
     * 客户端处理器
     */
    static class ClientHandler implements Runnable {
        private final Socket socket;

        public ClientHandler(Socket socket) {
            this.socket = socket;
        }

        @Override
        public void run() {
            try (BufferedReader reader = new BufferedReader(
                    new InputStreamReader(socket.getInputStream()));
                 PrintWriter writer = new PrintWriter(
                         new OutputStreamWriter(socket.getOutputStream()), true)) {

                String line;
                while ((line = reader.readLine()) != null) {
                    System.out.println("收到消息: " + line);
                    // 回显消息（加上服务器前缀）
                    writer.println("服务器收到: " + line);

                    // 如果客户端发送 "bye"，断开连接
                    if ("bye".equalsIgnoreCase(line.trim())) {
                        System.out.println("客户端请求断开连接");
                        break;
                    }
                }

                System.out.println("客户端断开: " + socket.getRemoteSocketAddress());

            } catch (IOException e) {
                System.out.println("客户端处理器异常: " + e.getMessage());
            } finally {
                try {
                    socket.close();
                } catch (IOException e) {
                    System.out.println("关闭socket异常: " + e.getMessage());
                }
            }
        }
    }
}
```

### 3.2 客户端（Client）

```java
import java.io.*;
import java.net.*;

public class TCPClient {
    private static final String SERVER_HOST = "localhost";
    private static final int SERVER_PORT = 8888;

    public static void main(String[] args) {
        try (Socket socket = new Socket(SERVER_HOST, SERVER_PORT);
             BufferedReader reader = new BufferedReader(
                     new InputStreamReader(socket.getInputStream()));
             PrintWriter writer = new PrintWriter(
                     new OutputStreamWriter(socket.getOutputStream()), true);
             BufferedReader consoleReader = new BufferedReader(
                     new InputStreamReader(System.in))) {

            System.out.println("连接到服务器: " + SERVER_HOST + ":" + SERVER_PORT);

            // 启动接收线程
            Thread receiveThread = new Thread(() -> {
                try {
                    String response;
                    while ((response = reader.readLine()) != null) {
                        System.out.println("服务器响应: " + response);

                } catch (IOException e) {
                    System.out.println("接收线程结束");
                }
            });
            receiveThread.setDaemon(true);
            receiveThread.start();

            // 发送消息
            String line;
            while ((line = consoleReader.readLine()) != null) {
                writer.println(line);
                if ("bye".equalsIgnoreCase(line.trim())) {
                    break;
                }
            }

            System.out.println("客户端退出");

        } catch (UnknownHostException e) {
            System.out.println("服务器地址错误: " + e.getMessage());
        } catch (IOException e) {
            System.out.println("连接服务器失败: " + e.getMessage());
        }
    }
}
```

### 3.3 多线程聊天服务器

```java
import java.io.*;
import java.net.*;
import java.util.*;
import java.util.concurrent.*;

public class ChatServer {
    private static final int PORT = 8889;
    private static final Set<ClientConnection> clients = ConcurrentHashMap.newKeySet();
    private static int clientIdCounter = 0;

    public static void main(String[] args) {
        System.out.println("聊天服务器启动，监听端口: " + PORT);

        try (ServerSocket serverSocket = new ServerSocket(PORT)) {
            while (true) {
                Socket socket = serverSocket.accept();
                int clientId = ++clientIdCounter;
                ClientConnection client = new ClientConnection(clientId, socket);
                clients.add(client);
                new Thread(client).start();
                broadcast("系统通知", "用户 " + clientId + " 加入聊天室");
                System.out.println("当前在线人数: " + clients.size());
            }
        } catch (IOException e) {
            System.out.println("服务器异常: " + e.getMessage());
        }
    }

    /**
     * 广播消息给所有客户端
     */
    public static void broadcast(String sender, String message) {
        String fullMessage = "[" + sender + "] " + message;
        System.out.println(fullMessage);
        for (ClientConnection client : clients) {
            client.sendMessage(fullMessage);
        }
    }

    /**
     * 客户端连接
     */
    static class ClientConnection implements Runnable {
        private final int clientId;
        private final Socket socket;
        private final PrintWriter writer;
        private String nickname;

        public ClientConnection(int clientId, Socket socket) throws IOException {
            this.clientId = clientId;
            this.socket = socket;
            this.writer = new PrintWriter(
                    new OutputStreamWriter(socket.getOutputStream()), true);
        }

        public void sendMessage(String message) {
            writer.println(message);
        }

        @Override
        public void run() {
            try (BufferedReader reader = new BufferedReader(
                    new InputStreamReader(socket.getInputStream()))) {

                // 设置昵称
                writer.println("欢迎 " + clientId + " 号用户！请输入你的昵称：");
                nickname = reader.readLine();
                if (nickname == null || nickname.trim().isEmpty()) {
                    nickname = "用户" + clientId;
                }
                broadcast("系统通知", nickname + " 加入聊天室");

                String line;
                while ((line = reader.readLine()) != null) {
                    if (line.startsWith("/")) {
                        handleCommand(line);
                    } else {
                        broadcast(nickname, line);
                    }
                }

            } catch (IOException e) {
                System.out.println("客户端 " + clientId + " 异常断开");
            } finally {
                clients.remove(this);
                broadcast("系统通知", (nickname != null ? nickname : "用户" + clientId) + " 离开聊天室");
                try {
                    socket.close();
                } catch (IOException e) {
                    System.out.println("关闭连接异常");
                }
                System.out.println("当前在线人数: " + clients.size());
            }
        }

        private void handleCommand(String command) {
            if (command.startsWith("/nick ")) {
                String newNick = command.substring(6).trim();
                if (!newNick.isEmpty()) {
                    broadcast("系统通知", nickname + " 改名为 " + newNick);
                    nickname = newNick;
                }
            } else if (command.equals("/online")) {
                writer.println("当前在线: " + clients.size() + " 人");
            } else if (command.equals("/help")) {
                writer.println("命令列表:");
                writer.println("  /nick 新昵称 - 修改昵称");
                writer.println("  /online - 查看在线人数");
                writer.println("  /help - 显示帮助");
            } else {
                writer.println("未知命令: " + command + "，输入 /help 查看帮助");
            }
        }
    }
}
```

## 第四章 UDP 通信

UDP是无连接的传输协议，使用 `DatagramSocket` 和 `DatagramPacket`。

### 4.1 UDP 服务端

```java
import java.net.*;

public class UDPServer {
    private static final int PORT = 9999;
    private static final int BUFFER_SIZE = 1024;

    public static void main(String[] args) {
        System.out.println("UDP服务器启动，监听端口: " + PORT);

        try (DatagramSocket socket = new DatagramSocket(PORT)) {
            byte[] buffer = new byte[BUFFER_SIZE];

            while (true) {
                // 接收数据
                DatagramPacket packet = new DatagramPacket(buffer, buffer.length);
                socket.receive(packet);

                String message = new String(packet.getData(), 0, packet.getLength());
                InetAddress clientAddress = packet.getAddress();
                int clientPort = packet.getPort();

                System.out.println("收到来自 " + clientAddress + ":" + clientPort + " 的消息: " + message);

                // 回复消息
                String response = "服务器收到: " + message + " (长度: " + message.length() + ")";
                byte[] responseData = response.getBytes();
                DatagramPacket responsePacket = new DatagramPacket(
                        responseData, responseData.length,
                        clientAddress, clientPort);
                socket.send(responsePacket);
            }
        } catch (Exception e) {
            System.out.println("UDP服务器异常: " + e.getMessage());
        }
    }
}
```

### 4.2 UDP 客户端

```java
import java.net.*;
import java.io.*;

public class UDPClient {
    private static final String SERVER_HOST = "localhost";
    private static final int SERVER_PORT = 9999;
    private static final int BUFFER_SIZE = 1024;

    public static void main(String[] args) {
        try (DatagramSocket socket = new DatagramSocket();
             BufferedReader consoleReader = new BufferedReader(
                     new InputStreamReader(System.in))) {

            InetAddress serverAddress = InetAddress.getByName(SERVER_HOST);

            // 启动接收线程
            Thread receiveThread = new Thread(() -> {
                try {
                    byte[] buffer = new byte[BUFFER_SIZE];
                    while (true) {
                        DatagramPacket packet = new DatagramPacket(buffer, buffer.length);
                        socket.receive(packet);
                        String response = new String(packet.getData(), 0, packet.getLength());
                        System.out.println("服务器响应: " + response);
                    }
                } catch (SocketException e) {
                    System.out.println("连接已关闭");
                } catch (Exception e) {
                    System.out.println("接收异常: " + e.getMessage());
                }
            });
            receiveThread.setDaemon(true);
            receiveThread.start();

            System.out.println("UDP客户端启动，输入消息发送，输入 'bye' 退出");

            String line;
            while ((line = consoleReader.readLine()) != null) {
                if ("bye".equalsIgnoreCase(line.trim())) {
                    break;
                }
                byte[] data = line.getBytes();
                DatagramPacket packet = new DatagramPacket(
                        data, data.length,
                        serverAddress, SERVER_PORT);
                socket.send(packet);
            }

            System.out.println("UDP客户端退出");

        } catch (Exception e) {
            System.out.println("UDP客户端异常: " + e.getMessage());
        }
    }
}
```

## 第六章 综合示例

```java
import java.io.*;
import java.net.*;
import java.nio.file.*;
import java.util.*;
import java.util.concurrent.*;

/**
 * 简易文件服务器
 */
public class FileServer {
    private static final int PORT = 7777;
    private static final String BASE_DIR = "./server_files";
    private final ExecutorService executor = Executors.newCachedThreadPool();

    public static void main(String[] args) {
        // 创建文件存储目录
        try {
            Files.createDirectories(Paths.get(BASE_DIR));
        } catch (IOException e) {
            System.out.println("创建目录失败: " + e.getMessage());
            return;
        }

        new FileServer().start();
    }

    public void start() {
        System.out.println("文件服务器启动，端口: " + PORT);
        System.out.println("文件目录: " + BASE_DIR);
        System.out.println("命令: LIST, GET <文件名>, PUT <文件名>, DELETE <文件名>, EXIT");

        try (ServerSocket serverSocket = new ServerSocket(PORT)) {
            while (true) {
                Socket socket = serverSocket.accept();
                executor.execute(() -> handleClient(socket));
            }
        } catch (IOException e) {
            System.out.println("服务器异常: " + e.getMessage());
        } finally {
            executor.shutdown();
        }
    }

    private void handleClient(Socket socket) {
        try (BufferedReader reader = new BufferedReader(
                new InputStreamReader(socket.getInputStream()));
             PrintWriter writer = new PrintWriter(
                     new OutputStreamWriter(socket.getOutputStream()), true);
             DataOutputStream dataOut = new DataOutputStream(socket.getOutputStream())) {

            writer.println("=== 文件服务器 ===");
            writer.println("可用命令: LIST, GET <文件名>, PUT <文件名>, DELETE <文件名>, EXIT");

            String line;
            while ((line = reader.readLine()) != null) {
                if ("EXIT".equalsIgnoreCase(line.trim())) {
                    break;
                }

                String[] parts = line.split(" ", 2);
                String command = parts[0].toUpperCase();

                switch (command) {
                    case "LIST":
                        handleList(writer);
                        break;
                    case "GET":
                        if (parts.length < 2) {
                            writer.println("错误: 缺少文件名");
                        } else {
                            handleGet(writer, dataOut, parts[1]);
                        }
                        break;
                    case "PUT":
                        if (parts.length < 2) {
                            writer.println("错误: 缺少文件名");
                        } else {
                            handlePut(writer, reader, dataOut, parts[1]);
                        }
                        break;
                    case "DELETE":
                        if (parts.length < 2) {
                            writer.println("错误: 缺少文件名");
                        } else {
                            handleDelete(writer, parts[1]);
                        }
                        break;
                    default:
                        writer.println("未知命令: " + command);
                        writer.println("可用命令: LIST, GET, PUT, DELETE, EXIT");
                        break;
                }
                writer.println("READY"); // 命令结束标记
            }

        } catch (IOException e) {
            System.out.println("客户端处理异常: " + e.getMessage());
        } finally {
            try {
                socket.close();
            } catch (IOException e) {
                System.out.println("关闭连接异常: " + e.getMessage());
            }
        }
    }

    private void handleList(PrintWriter writer) {
        File dir = new File(BASE_DIR);
        File[] files = dir.listFiles();
        if (files == null || files.length == 0) {
            writer.println("文件列表为空");
            return;
        }

        writer.println("文件列表 (共 " + files.length + " 个):");
        for (File file : files) {
            if (file.isFile()) {
                String size = getReadableSize(file.length());
                writer.println("  " + file.getName() + " (" + size + ")");
            }
        }
    }

    private void handleGet(PrintWriter writer, DataOutputStream dataOut, String filename) {
        File file = new File(BASE_DIR, filename);
        if (!file.exists() || !file.isFile()) {
            writer.println("错误: 文件不存在");
            return;
        }

        try {
            long fileSize = file.length();
            writer.println("FILE_START:" + fileSize);
            writer.flush();

            // 发送文件内容
            try (FileInputStream fis = new FileInputStream(file)) {
                byte[] buffer = new byte[8192];
                int bytesRead;
                while ((bytesRead = fis.read(buffer)) != -1) {
                    dataOut.write(buffer, 0, bytesRead);
                }
                dataOut.flush();
            }

            writer.println("FILE_END");
            writer.println("下载成功: " + filename + " (" + getReadableSize(fileSize) + ")");
        } catch (IOException e) {
            writer.println("错误: 读取文件失败 - " + e.getMessage());
        }
    }

    private void handlePut(PrintWriter writer, BufferedReader reader, DataOutputStream dataOut, String filename) {
        // 防文件名攻击
        if (filename.contains("..") || filename.contains("/") || filename.contains("\\")) {
            writer.println("错误: 文件名包含非法字符");
            return;
        }

        try {
            writer.println("等待文件内容... (发送 'END' 结束)");
            writer.flush();

            File file = new File(BASE_DIR, filename);
            try (FileOutputStream fos = new FileOutputStream(file);
                 DataInputStream dis = new DataInputStream(
                         reader instanceof DataInputStream ? 
                         (DataInputStream) reader : 
                         new DataInputStream(reader))) {

                // 简单实现：逐行读取内容
                // 注意：生产环境应使用Base64或分块传输
                String line;
                boolean firstLine = true;
                while ((line = reader.readLine()) != null) {
                    if ("END".equalsIgnoreCase(line.trim())) {
                        break;
                    }
                    if (firstLine) {
                        firstLine = false;
                    } else {
                        fos.write('\n');
                    }
                    fos.write(line.getBytes());
                }
            }

            writer.println("上传成功: " + filename + " (" + getReadableSize(file.length()) + ")");
        } catch (IOException e) {
            writer.println("错误: 上传失败 - " + e.getMessage());
        }
    }

    private void handleDelete(PrintWriter writer, String filename) {
        File file = new File(BASE_DIR, filename);
        if (!file.exists()) {
            writer.println("错误: 文件不存在");
            return;
        }

        if (file.delete()) {
            writer.println("删除成功: " + filename);
        } else {
            writer.println("错误: 删除失败");
        }
    }

    private String getReadableSize(long size) {
        String[] units = {"B", "KB", "MB", "GB"};
        int i = 0;
        double sizeD = size;
        while (sizeD >= 1024 && i < units.length - 1) {
            sizeD /= 1024;
            i++;
        }
        return String.format("%.1f %s", sizeD, units[i]);
    }
```
