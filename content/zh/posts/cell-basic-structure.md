## 引言

细胞是生命的基本单位——是生物体结构、功能和繁殖的最小单元。从直径 $0.1–5\ \mu\text{m}$ 的细菌，到直径可达 $100\ \mu\text{m}$ 的植物薄壁细胞，再到长度超过 $1\ \text{m}$ 的坐骨神经细胞，细胞世界的多样性令人叹为观止。

根据细胞结构的复杂度，现代生物学将所有细胞划分为两大类：**原核细胞**（Prokaryote）和**真核细胞**（Eukaryote）。

![原核 vs 真核细胞对比](https://upload.wikimedia.org/wikipedia/commons/thumb/a/aa/Prokaryotic_vs_eukaryotic_cell.png/1024px-Prokaryotic_vs_eukaryotic_cell.png)
*图 1：原核（左）与真核（右）细胞结构对比。两者共有：细胞膜、核糖体、DNA、细胞质。核心差异：细胞核与膜结构细胞器。*

## 一、原核细胞（Prokaryotic Cell）

**"原核"的含义**：希腊文 *pro-*（在…之前）+ *karyon*（核/坚果）——"在有核之前"。原核细胞没有由双层核膜包裹的真正细胞核，DNA 直接游离于细胞质中的拟核区。

> **进化地位**：原核生物在地球上已存在约 **35 亿年**，是最早出现的生命形式；而真核生物约在 **15–20 亿年前** 才出现。

### 1.1 结构总览

![典型原核（细菌）细胞结构（中文标注）](https://upload.wikimedia.org/wikipedia/commons/5/51/Average_prokaryote_cell-_zh-cn.svg)
*图 2：典型原核细胞（细菌）结构。注意无细胞核、无膜结构细胞器。*
<small>图源：LadyofHats 原图 / Mariana Ruiz Villarreal，CC0 / 中文标注版，Wikimedia Commons</small>

### 1.2 各结构功能详解

| 结构 | 是否存在 | 功能说明 |
|------|---------|---------|
| **拟核（Nucleoid）** | ✓ | 无膜，裸露的环状双链 DNA 折叠区域，无组蛋白（古菌例外，有组蛋白类似物） |
| **质粒（Plasmid）** | 常有 | 小型环状 DNA，携带抗生素抗性等额外基因，基因工程常用载体 |
| **核糖体** | ✓ | 沉降系数 **70S**（由 50S + 30S 亚基组成），真核为 80S，这是抗生素选择性毒性的靶点（如链霉素） |
| **细胞质膜** | ✓ | 磷脂双分子层 + 蛋白质，选择性通透；细菌呼吸链电子传递链位于此膜上（因为原核无线粒体） |
| **肽聚糖细胞壁** | 细菌✓，古菌✗ | 细菌细胞壁含 **肽聚糖**（N-乙酰葡糖胺 + N-乙酰胞壁酸通过β-1,4糖苷键连接，四肽侧链交联）；革兰氏阳性菌壁厚多层，革兰氏阴性菌壁薄但外覆 LPS 脂多糖外膜 |
| **荚膜/黏液层** | 部分有 | 多糖或多肽层，抗吞噬、抗干燥、生物膜形成（如肺炎链球菌荚膜是毒力因子） |
| **鞭毛（Flagellum）** | 部分有 | 由 **鞭毛蛋白（Flagellin）** 组成的螺旋丝 + 钩 + 基体，转动式马达（质子动力势驱动），不同于真核"9+2"微管鞭毛 |
| **菌毛（Pili/Fimbriae）** | 部分有 | 附着、接合生殖（性菌毛 F-pilus 传递质粒）、致病菌黏附 |
| **芽孢（Endospore）** | 部分杆菌 | 度过不良环境的休眠体，高度抗热/抗辐射，如炭疽、破伤风梭菌 |
| **类囊体** | 蓝藻有 | 光合作用膜结构，类似叶绿体类囊体但不被膜包裹 |

### 1.3 原核生物两域：细菌 vs 古菌

原核生物并非单系群，1977 年 Woese 依据 rRNA 序列提出**三域学说**，将原核生物分为：

| 特征 | 细菌（Bacteria） | 古菌（Archaea） |
|------|----------------|----------------|
| 细胞壁 | 含肽聚糖 | 无肽聚糖，含假肽聚糖或糖蛋白 S 层 |
| 膜脂键 | **酯键**连接脂肪酸 → 甘油 | **醚键**连接异戊二烯链 → 甘油（更耐极端环境） |
| RNA 聚合酶 | 1 种（4 亚基，类似真核 Pol II 简化版） | 多亚基复杂型，类似真核 Pol II |
| 起始 tRNA | 甲酰甲硫氨酸 | 甲硫氨酸（和真核一样） |
| 内含子 | 极罕见 | 部分 tRNA、rRNA 有 |
| 生境 | 广泛 | 许多嗜极：嗜热嗜酸（如 *Thermoplasma*）、嗜盐（如 *Halobacterium*）、产甲烷 |

## 二、真核细胞（Eukaryotic Cell）概述

**"真核"的含义**：希腊文 *eu-*（真正的）+ *karyon*（核）——真正的细胞核。

### 2.1 区别于原核的核心特征

1. **核膜包被的真正细胞核**：双层核膜，上有**核孔复合体（NPC）** 控制大分子进出
2. **膜结构细胞器**：线粒体、内质网、高尔基体、溶酶体、过氧化物酶体、叶绿体（植物）等
3. **内膜系统（Endomembrane System）**：核膜-内质网-高尔基体-溶酶体-细胞膜相互连续或通过囊泡联系
4. **细胞骨架**：微管（tubulin）、微丝（actin）、中间丝，维持形态、运输、分裂
5. **80S 核糖体**：60S（含 5S/5.8S/28S rRNA）+ 40S（18S rRNA）亚基
6. **染色体结构**：DNA 缠绕组蛋白八聚体形成核小体 → 染色质 → 染色体
7. **细胞分裂方式**：有丝分裂（mitosis）+ 减数分裂（meiosis），而非简单二分裂

### 2.2 内共生学说（Endosymbiosis Theory）

> 线粒体和叶绿体不是细胞"自己长出的"，而是被吞入的原核生物与宿主共生演化而成。

证据链条：
- 线粒体拥有自己的**环状 DNA**（类似细菌）
- 拥有独立的 **70S 核糖体**（抗生素可抑制其蛋白合成）
- 双层膜结构（外膜来自宿主吞噬泡，内膜来自细菌质膜）
- 独立增殖（二分裂）
- 基因序列比对：线粒体近 α-变形菌门；叶绿体近蓝藻门
- 罕见的**核质体（Nucleomorph）**：二次内共生遗迹（隐藻、绿蛛藻）

![内共生假说示意：线粒体和叶绿体的演化来源](https://upload.wikimedia.org/wikipedia/commons/thumb/0/0e/Endosymbiosis.svg/1024px-Endosymbiosis.svg.png)
*图 3：内共生学说示意。一次内共生产生线粒体（所有真核）与叶绿体（植物祖先）；二次内共生产生复杂质体（如褐藻、甲藻）。*

### 3.2 细胞器详解

#### ① 细胞核（Nucleus）
- **核膜**：双层单位膜，外膜与粗面内质网（RER）连续
- **核仁**：rRNA 转录 + 核糖体亚基装配的工厂
- **染色质**：常染色质（松散，活跃转录）/ 异染色质（致密，沉默）
- **核基质 / 核纤层**：核膜下的 lamin 中间丝，维持形态

#### ② 内质网（Endoplasmic Reticulum）
- **粗面内质网（RER）**：膜上附着核糖体，合成分泌蛋白、膜蛋白、驻留蛋白；N-链接糖基化
- **光面内质网（SER）**：脂质合成、类固醇激素合成、肝细胞解毒（CYP450 酶系）、肌细胞储存 Ca²⁺（肌浆网）

#### ③ 高尔基体（Golgi Apparatus / Dictyosome）
- **顺面（cis）**：接收 RER 囊泡
- **中间膜囊**：O-链接糖基化、糖链修剪
- **反面（trans）/ TGN**：分选蛋白质到溶酶体/质膜/分泌泡
- 极性结构：**顺面堆** → **反面堆**（类似"邮局"）

#### ④ 溶酶体（Lysosome）
- 单层膜，内含 **50+ 酸性水解酶**（pH ≈ 5.0，依赖 V-ATPase 泵入 H⁺）
- 功能：内吞消化、自噬（Autophagy）清除衰老细胞器
- 溶酶体贮积病：如 Tay-Sachs（己糖胺酶 A 缺陷 → 神经节苷脂 GM2 堆积）

#### ⑤ 过氧化物酶体（Peroxisome）
- 含氧化酶（产生 H₂O₂）和**过氧化氢酶（Catalase）**：
  $$
  \ce{2 H2O2 ->[Catalase] 2 H2O + O2 ^}
  $$
- 分解长链脂肪酸（β-氧化），合成缩醛磷脂

#### ⑥ 线粒体（Mitochondrion）
- 外膜（孔蛋白通透）+ 内膜（高度折叠成嵴 *Cristae*）——电子传递链位点
- 基质：三羧酸循环（TCA）酶系、mtDNA、70S 核糖体
- 半自主细胞器

#### ⑦ 核糖体：游离 vs RER 结合型
- 游离：合成胞质蛋白、核蛋白、线粒体基质蛋白
- RER 结合：信号肽引导，合成分泌/膜/溶酶体蛋白

#### ⑧ 中心体（Centrosome）+ 中心粒（Centriole）
- MTOC（微管组织中心）：动物细胞特有（植物无中心体）
- "9+0"三联微管结构；有丝分裂时纺锤体极
- 基体：鞭毛/纤毛的微管锚定结构（"9+2"二联微管轴丝）

#### ⑨ 细胞骨架（Cytoskeleton）
| 骨架纤维 | 亚基蛋白 | 直径 | 功能 |
|---------|---------|------|------|
| 微丝（MF） | 肌动蛋白 Actin | ~7 nm | 变形运动、胞质分裂、肌肉收缩 |
| 微管（MT） | 微管蛋白 Tubulin α/β | ~25 nm | 有丝分裂纺锤体、囊泡运输（驱动蛋白/动力蛋白） |
| 中间丝（IF） | Lamin / Keratin / Vimentin… | ~10 nm | 抗张力、维持组织完整性 |

#### ⑩ 细胞膜 / 胞外基质（ECM）
- 流动镶嵌模型：磷脂双分子层 + 整合蛋白 + 外周蛋白 + 糖萼
- 动物无细胞壁，靠 ECM（胶原蛋白、弹性蛋白、纤连蛋白）维持组织结构
- 细胞连接：紧密连接、黏着连接、桥粒、间隙连接

### 4.2 动物细胞不具备的三大结构

#### Ⅰ. 细胞壁（Cell Wall）

```
中胶层（胞间层）：含果胶，相邻细胞粘连
    │
初生壁（Primary Wall）：纤维素微纤丝 + 半纤维素 + 果胶，松散可伸展
    │
次生壁（Secondary Wall）：部分细胞成熟后沉积内壁，纤维素 + **木质素（Lignin）**，坚硬
```

- 功能：机械强度、抗渗透压（细胞吸水膨胀不破裂）
- 真菌细胞壁：几丁质（Chitin，N-乙酰葡糖胺 β-1,4 线性聚合物）
- **注意**：细胞壁非选择性屏障（分子自由通过），真正选择透过的还是质膜

#### Ⅱ. 质体家族（Plastids）

质体是植物/藻类特有的半自主细胞器家族：

| 质体类型 | 色素 | 功能 |
|---------|------|------|
| **前质体（Proplastid）** | 无 | 分生组织干细胞，分化为其他质体 |
| **叶绿体（Chloroplast）** | 叶绿素 a/b + 类胡萝卜素 | **光合作用**：类囊体垛叠形成基粒（Grana），基质中卡尔文循环（暗反应） |
| **有色体（Chromoplast）** | 类胡萝卜素 | 花/果实呈橙红色，吸引传粉者/传播者 |
| **白色体（Leucoplast）** | 无 | 储藏型：造粉体（淀粉，如马铃薯块茎）、造油体、造蛋白体 |
| **衰老质体（Gerontoplast）** | 叶绿素降解 | 叶片衰老黄化 |

**叶绿体超微结构**：
- 双层被膜 + 内部类囊体膜系统
- 拥有自己的环状 DNA、70S 核糖体
- 起源于一次蓝藻内共生（初级内共生）

#### Ⅲ. 中央大液泡（Central Vacuole）

- 占成熟植物细胞体积 **90%** 以上
- 膜称为**液泡膜（Tonoplast）**
- 含细胞液：水、可溶性糖、有机酸、花色素苷（花瓣/果实颜色）、生物碱（防御）、储存蛋白
- 维持细胞膨压（Turgor pressure）——植物硬挺的原因；萎蔫即膨压丧失

### 4.3 植物细胞的其他差异

| 特征 | 动物细胞 | 植物细胞 |
|------|---------|---------|
| 中心体 | 有 | **无**（有丝分裂纺锤体由其他 MTOC 组织） |
| 溶酶体 | 明显 | 功能由**液泡**承担（含酸性水解酶） |
| 胞外基质 | 复杂（胶原蛋白等） | 无 ECM，以细胞壁代替 |
| 通讯连接 | 间隙连接 | **胞间连丝（Plasmodesmata）**——穿过细胞壁的细胞质通道，允许小分子、甚至 mRNA/蛋白胞间转运 |
| 细胞分裂方式 | 收缩环（Actin-Myosin）缢裂 | **细胞板（Cell Plate）**形成：高尔基体囊泡沿 phragmoplast 微管在赤道面融合成新细胞壁 |

## 五、动植物细胞对比表

| 类别 | 共 有 结 构 | 动 物 细 胞 特 有 | 植 物 细 胞 特 有 |
|------|------------|------------------|------------------|
| 膜结构 | 质膜、核膜、RER、SER、高尔基体、线粒体、过氧化物酶体、囊泡 | 溶酶体 | 叶绿体/质体、中央大液泡（Tonoplast） |
| 非膜结构 | 核糖体（80S）、细胞骨架（3 种纤维）、核仁、染色质 | 中心体/中心粒 | 细胞壁（纤维素 + 果胶 + 次生木质素） |
| 连接方式 | — | 紧密连接、黏着连接、桥粒、**间隙连接** | 无中心体依赖结构；**胞间连丝** |
| 分裂 | 有丝分裂 + 胞质分裂 | 收缩环缢裂 | 成膜体 + 细胞板 |
| 渗透压适应 | 等渗（否则溶血） | 高渗不破裂（细胞壁支持，产生膨压） |
| 营养方式 | 异养（吞噬/内吞） | 自养（光合）+ 渗透营养 |
| 储存物质 | 糖原 | 淀粉（造粉体） |
| 分化能力 | 干细胞系统，但成体高度受限 | 多数细胞保留**全能性**（植物组织培养依据） |

## 六、打破常规的特殊细胞（特例集）

课本里的"典型细胞"只是为了教学简化，真实世界中有许多"规则破坏者"——考试常考、科研有趣。

### 6.1 原核世界的特例

#### 特例 1：支原体（*Mycoplasma*）—— 没有细胞壁的原核生物
- 原核生物几乎都有细胞壁，支原体却**完全丢失了肽聚糖合成基因**
- 直径仅 **0.1–0.3 μm**，是最小的可独立生存细胞
- 质膜中富含**甾醇**（从宿主获取），增加机械强度——这是真核细胞膜的典型特征
- 无细胞壁 → **对青霉素、头孢等 β-内酰胺类完全耐药**（因为β-内酰胺类作用于肽聚糖合成）
- 病原体：*M. pneumoniae* → 非典型肺炎（"支原体肺炎"）

#### 特例 2：放线菌（*Streptomyces* 等）—— 长得像真菌的原核生物
- 细菌域，但营养体呈**分支菌丝体**，产生分生孢子链——形态酷似霉菌（真菌）
- **不是真核**：70S 核糖体、无核膜、肽聚糖细胞壁
- 90% 以上的医用抗生素来自链霉菌属（链霉素、四环素、红霉素、氯霉素……前文"抗生素发展史"的主角）

#### 特例 3：蓝藻（Cyanobacteria）—— "无叶绿体但能光合"
- 原核，但拥有**类囊体膜**、叶绿素 a、放氧型光合作用
- 地球历史上的**大氧化事件（Great Oxidation Event, ~24 亿年前）** 制造者，改变了整个大气组成
- 叶绿体就是远古蓝藻内共生的后代

#### 特例 4：蛭弧菌（*Bdellovibrio*）—— 吃细菌的细菌
- 小型革兰氏阴性菌，**攻击并进入其他革兰氏阴性菌周质空间**，从内部消化宿主
- 可能作为未来的"活体抗生素"研究方向

### 6.2 真核（动物）特例

#### 特例 5：哺乳动物成熟红细胞—— 无核、无线粒体、无内膜系统
- **人类 RBC：** 成熟过程中（骨髓发育到网织红细胞阶段）**主动排出细胞核、线粒体、RER/Golgi 等全部细胞器**
- 结果：
  - 不能合成蛋白、不能有氧呼吸（只靠糖酵解供能，从葡萄糖 → 乳酸）
  - 不能自我修复 → 寿命仅 **120 天**（由脾脏巨噬细胞清除衰老 RBC）
  - 双凹圆盘形态完全为气体交换优化：极高表面积/体积比
- **例外**：鸟类、爬行类、两栖类的红细胞**有核**（骆驼 RBC 也无核，但红细胞呈椭圆）
- **医学意义**：提取 RBC 纯细胞质膜做"血影（Ghost）"是膜生物学经典模型

#### 特例 6：骨骼肌细胞—— 多核巨大合胞体
- 成肌细胞（单核）在胚胎发育时**细胞融合**形成长管状多核肌纤维
- 一条肌纤维可含 **数百个细胞核**，都贴在质膜下方（因为中间被肌丝占满）
- 属于"合胞体（Syncytium）"—— 多核但不分隔

#### 特例 7：破骨细胞—— 融合产生的多核巨细胞
- 单核造血系前体融合 → 单核/巨噬系 → 形成可达 **5–20 个核** 的破骨细胞
- 功能：酸化骨基质微环境（质子泵）+ 分泌组织蛋白酶 K，溶解羟基磷灰石和骨胶原，骨吸收

#### 特例 8：血小板—— 没有细胞核但不是细胞
- 由**巨核细胞（Megakaryocyte）**胞质碎裂产生的**圆盘状小体**（2–3 μm）
- 不含核（但含 mRNA、线粒体、致密颗粒、α 颗粒）
- 止血核心参与者：黏附暴露胶原 → 聚集 → 释放颗粒 → 收缩血块

#### 特例 9：成熟脂肪细胞—— 几乎全是脂滴
- 90% 以上体积被单一大脂滴占据，细胞核和胞质被挤到边缘形成窄环
- 极度特化：储能 + 内分泌（分泌瘦素 Leptin、脂联素 Adiponectin）

### 6.3 真核（植物）特例

#### 特例 10：成熟筛管分子（Sieve Tube Element, STE）—— 无核仍存活的植物细胞
- 韧皮部负责运输有机物（蔗糖等）的管道
- 成熟时**丢失细胞核、液泡、核糖体、高尔基体、微管**—— 完全放弃"自身维护"
- 旁边有**伴胞（Companion Cell）**，通过胞间连丝持续提供 mRNA/蛋白和代谢支持，维持筛管分子的存活和功能
- 筛板（Sieve Plate）：端壁上有大量筛孔，允许汁液通过（"压力流学说"）

#### 特例 11：木质部导管分子—— 死亡的细胞管道
- 运输水和无机盐的管道
- 成熟时**程序性细胞死亡（PCD）**，胞质完全消失，只留下细胞壁（木质化次生壁）构成的中空管道
- 端壁完全溶解 → 贯通的长管；**管胞（Tracheid）**端壁不溶解，靠纹孔对相连（裸子植物只有管胞）

#### 特例 12：保卫细胞（Guard Cell）—— 唯一含叶绿体的表皮细胞
- 植物表皮绝大多数细胞无叶绿体（透明，便于透光给叶肉），**只有保卫细胞有**
- 通过 K⁺ 流入/流出调节膨压，控制气孔开合
- 形态：双子叶为"肾脏形"，禾本科（水稻、玉米、小麦）为**哑铃形**

#### 特例 13：根毛细胞—— 顶端生长 + 巨大表面积
- 表皮细胞外凸形成 1–2 mm 长的管状结构，极大增加根系吸收面积
- 单细胞，寿命短（数天），不断由根毛区新细胞补充

### 6.4 跨分类的"模糊边界"细胞

#### 特例 14：眼虫（*Euglena*）—— 既是"植物"又是"动物"
- 原生生物界（真核但非植/动/真菌）
- 有叶绿体（三次内共生，被三层膜包被）→ 光合自养
- 无光时能**异养吸收**有机物
- 有**鞭毛（9+2）**游动 + **眼点（Stigma）**感光
- 无细胞壁（支持动物特征），有**表膜（Pellicle）**支持

#### 特例 15：黏菌（Slime Mold）—— 会走的"一群细胞"
- **原生质团黏菌（Plasmodial Slime Molds）**：核不断分裂但不胞质分裂，形成数米宽的**单个多核巨细胞**，能做简单迷宫路径优化（细胞生物学研究模型）
- **细胞性黏菌（Cellular Slime Molds, *Dictyostelium*）**：平时是独立的变形虫单细胞，食物匮乏时聚集成"伪原质团"多细胞体 → 分化为柄和孢子 → 完成生活史

#### 特例 16：病毒（Virus）—— 是不是生物？是不是细胞？
- **不是细胞**：没有细胞质、没有核糖体、没有独立代谢
- 仅由**遗传物质（DNA 或 RNA）+ 蛋白质衣壳**（+ 部分有囊膜）组成
- 必须侵入活细胞利用其核糖体和能量系统才能复制
- 教科书对"生物"的定义在病毒处模糊：有基因、能演化，但不能独立繁殖

## 结语

从 1665 年 Robert Hooke 在《Micrographia》中第一次用"Cell"命名软木塞死细胞壁腔，到今天冷冻电镜（Cryo-EM）看清核孔复合体的原子结构——人类对细胞的认知走过了近 360 年。

"典型细胞"是教学简化，真正的生命多样性体现在**例外**中：
- 支原体告诉我们"细胞壁并非原核标配"
- 红细胞和筛管分子告诉我们"没有核也可以活（至少一段时间）"
- 眼虫和黏菌告诉我们"动植物分类并非泾渭分明"
- 病毒则挑战着"生命的定义本身"
