## 引言

在上一篇文章中，我们学习了函数的基本概念、三要素和基本初等函数。然而，仅仅知道函数是什么还不够——真正重要的是**理解函数如何变化**，以及**函数具有哪些内在规律**。

函数的性质，就是描述函数“行为”的语言。如果把函数比作一个人，那么**定义域和值域**是他的“身份信息”，而**单调性、奇偶性、周期性、对称性**则是他的“性格特征”。理解了这些性质，你就能预测函数在什么情况下变大、变小、重复、对称——从而在面对复杂问题时游刃有余。

函数的四大性质在高考中占据了**极其重要的地位**。直接考查性质的题目每年都有，而间接运用性质解题更是贯穿了导数、不等式、数列等几乎所有板块。可以说，**性质是函数的灵魂，也是高考数学的命脉**。

本文将从定义出发，系统讲解函数的四大性质，并结合高考真题和典型例题，帮助读者建立完整而深入的理解。

## 第一章 单调性——函数变化的“节奏”

### 1.1 单调性的定义

**定义**：设函数 $f(x)$ 的定义域为 $I$，区间 $D \subseteq I$。对于区间 $D$ 上的任意两个值 $x_1$、$x_2$：

- 若 $x_1 < x_2$ 时，**总有** $f(x_1) < f(x_2)$，则称 $f(x)$ 在区间 $D$ 上**单调递增**（或称“严格递增”）。
- 若 $x_1 < x_2$ 时，**总有** $f(x_1) > f(x_2)$，则称 $f(x)$ 在区间 $D$ 上**单调递减**（或称“严格递减”）。
- 若 $x_1 < x_2$ 时，总有 $f(x_1) \leq f(x_2)$，则称 $f(x)$ 在区间 $D$ 上**单调不减**（或称“广义递增”）。
- 若 $x_1 < x_2$ 时，总有 $f(x_1) \geq f(x_2)$，则称 $f(x)$ 在区间 $D$ 上**单调不增**（或称“广义递减”）。

> **通俗理解**：
> - 单调递增：随着 $x$ 增大，$y$ 也**不断变大**。
> - 单调递减：随着 $x$ 增大，$y$ 反而**不断变小**。
> - 单调性描述的是函数值随自变量变化的**趋势**。

### 1.2 判断单调性的方法

判断函数的单调性有四种主要方法：

**方法一：定义法（作差法）**

这是最根本的方法，适用于所有函数。步骤：

1. 在定义域内取任意 $x_1 < x_2$。
2. 计算 $f(x_1) - f(x_2)$。
3. 判断符号：若 $f(x_1) - f(x_2) < 0$，则递增；若 $> 0$，则递减。

**例1**：用定义法证明 $f(x) = 2x + 1$ 在 $\mathbb{R}$ 上单调递增。

证明：任取 $x_1 < x_2$，则

$$ f(x_1) - f(x_2) = (2x_1 + 1) - (2x_2 + 1) = 2(x_1 - x_2) < 0 $$

所以 $f(x_1) < f(x_2)$，故 $f(x)$ 在 $\mathbb{R}$ 上单调递增。

**方法二：图像法**

画出函数图像，直观判断。图像从左到右上升则递增，下降则递减。

**方法三：导数法**（高等数学方法，高中选修内容）

若 $f'(x) > 0$，则 $f(x)$ 单调递增；若 $f'(x) < 0$，则单调递减。

**方法四：复合函数法（“同增异减”）**

若 $y = f(u)$ 与 $u = g(x)$ 的单调性：

| $f(u)$ | $g(x)$ | $f[g(x)]$ |
|--------|--------|-----------|
| 增 | 增 | **增** |
| 增 | 减 | **减** |
| 减 | 增 | **减** |
| 减 | 减 | **增** |

> **记忆口诀**：“同增异减”——内外函数单调性相同则复合后递增，相异则递减。

**方法五：四则运算的单调性规律**

| 运算 | 规律 |
|------|------|
| $f(x) + g(x)$ | 同增则增，同减则减 |
| $-f(x)$ | 与 $f(x)$ 单调性**相反** |
| $f(x) \cdot g(x)$（正函数） | 同正同增则增；一正一负另算 |
| $\dfrac{1}{f(x)}$（正值函数） | 与 $f(x)$ 单调性**相反** |

### 1.3 高考常见题型：已知单调性求参数范围

这是高考的**高频考点**，通常在选择题或填空题中出现。

**例2**：已知函数 $f(x) = x^2 + 2ax + 3$ 在区间 $(-\infty, 1]$ 上单调递减，求 $a$ 的取值范围。

解：$f(x) = (x + a)^2 + 3 - a^2$，对称轴为 $x = -a$。

要使 $f(x)$ 在 $(-\infty, 1]$ 上单调递减，需要对称轴在区间的右端点右侧，即：

$$ -a \geq 1 \Rightarrow a \leq -1 $$

所以 $a \in (-\infty, -1]$。

**例3**：已知函数 $f(x) = \begin{cases} (a-2)x, & x \geq 1 \\ x^2 - 4x + 3, & x < 1 \end{cases}$ 在 $\mathbb{R}$ 上单调递减，求 $a$ 的取值范围。

解：两段分别递减：

- 左段 $x^2 - 4x + 3 = (x-2)^2 - 1$，在 $(-\infty, 2)$ 上递减，在 $(2, +\infty)$ 上递增。在区间 $(-\infty, 1)$ 上递减，满足。
- 右段 $(a-2)x$ 在 $[1, +\infty)$ 上递减，需要 $a - 2 < 0 \Rightarrow a < 2$。

在分界点 $x = 1$ 处，需满足**左段函数值 ≥ 右段函数值**（因为递减意味着 $x$ 越大，$y$ 越小）：

$$ f(1^-) = 1^2 - 4 \times 1 + 3 = 0 $$
$$ f(1^+) = (a-2) \times 1 = a-2 $$

需要 $f(1^-) \geq f(1^+)$：

$$ 0 \geq a - 2 \Rightarrow a \leq 2 $$

综合 $a < 2$ 和 $a \leq 2$，得 $a < 2$。

> **关键结论**：分段函数的单调性问题，**必须检查分段点处的衔接**。

## 第二章 奇偶性——函数的“对称基因”

### 2.1 奇偶性的定义

**定义**：对于函数 $f(x)$ 定义域内的**任意** $x$：

- 若 $f(-x) = f(x)$，则 $f(x)$ 为**偶函数**。
- 若 $f(-x) = -f(x)$，则 $f(x)$ 为**奇函数**。

**几何意义**：
- 偶函数的图像关于 **$y$ 轴**对称。
- 奇函数的图像关于 **原点**对称。

> **必要条件**：奇函数和偶函数的定义域必须**关于原点对称**。如果定义域不对称，函数一定是非奇非偶的。

### 2.2 判断奇偶性的步骤

1. **检查定义域**是否关于原点对称。若不对称 → **非奇非偶**。
2. 计算 $f(-x)$。
3. 比较 $f(-x)$ 与 $f(x)$：
   - $f(-x) = f(x)$ → 偶函数
   - $f(-x) = -f(x)$ → 奇函数
   - 两者都不满足 → 非奇非偶

**例4**：判断 $f(x) = x^3 - x$ 的奇偶性。

解：定义域为 $\mathbb{R}$，关于原点对称。

$$ f(-x) = (-x)^3 - (-x) = -x^3 + x = -(x^3 - x) = -f(x) $$

所以 $f(x)$ 是**奇函数**。

**例5**：判断 $f(x) = |x|$ 的奇偶性。

解：定义域 $\mathbb{R}$ 对称。

$$ f(-x) = |-x| = |x| = f(x) $$

所以 $f(x)$ 是**偶函数**。

### 2.3 奇偶性的运算规律

| 运算 | 结论 |
|------|------|
| 奇函数 ± 奇函数 | 奇函数 |
| 偶函数 ± 偶函数 | 偶函数 |
| 奇函数 ± 偶函数 | **非奇非偶**（一般情况下） |
| 奇函数 × 奇函数 | 偶函数 |
| 偶函数 × 偶函数 | 偶函数 |
| 奇函数 × 偶函数 | 奇函数 |
| 奇函数 / 奇函数 | 偶函数（分母不为0） |
| 偶函数 / 偶函数 | 偶函数（分母不为0） |
| 奇函数 / 偶函数 | 奇函数（分母不为0） |

### 2.4 奇偶性与单调性的关系

奇函数和偶函数的单调性具有特殊的对称性：

| 性质 | 奇函数 | 偶函数 |
|------|--------|--------|
| 在对称区间上的单调性 | **相同**（如 $(-\infty,0)$ 与 $(0,+\infty)$ 同增减） | **相反**（如 $(-\infty,0)$ 与 $(0,+\infty)$ 增减相反） |
| 示例 | $y = x^3$ 在 $\mathbb{R}$ 上单调递增 | $y = x^2$ 在 $(-\infty,0)$ 递减，在 $(0,+\infty)$ 递增 |

> **推论**：
> - 偶函数在 $(-\infty,0)$ 和 $(0,+\infty)$ 的单调性相反。
> - 奇函数在 $(-\infty,0)$ 和 $(0,+\infty)$ 的单调性相同。

### 2.5 高考热点：利用奇偶性求参数

**例6**：已知函数 $f(x) = \dfrac{x^2 + a}{x}$ 是奇函数，求 $a$ 的值。

解：$f(-x) = \dfrac{(-x)^2 + a}{-x} = \dfrac{x^2 + a}{-x} = -\dfrac{x^2 + a}{x}$

由 $f(-x) = -f(x)$：

$$ -\dfrac{x^2 + a}{x} = -\dfrac{x^2 + a}{x} $$

恒成立，所以 $a$ 为**任意实数**？不对，需要检查特例。

实际上，直接由奇函数定义：$f(-x) = -f(x)$，任意 $x \neq 0$ 均成立，所以这个函数本身就是奇函数，与 $a$ 无关。$a \in \mathbb{R}$。

> **注意**：有些题目中 $a$ 是通过特定条件求出的。比如 $f(1) = 2$ 时，由奇函数 $f(-1) = -2$，代入可求 $a$。

## 第三章 周期性——函数的“循环节拍”

### 3.1 周期性的定义

**定义**：若存在一个非零常数 $T$，使得对于函数 $f(x)$ 定义域内的**任意** $x$，都有：

$$ f(x + T) = f(x) $$

则称 $f(x)$ 为**周期函数**，$T$ 称为它的一个**周期**。如果所有周期中有一个最小的正周期，称为**最小正周期**。

**几何意义**：函数图像每隔 $T$ 个单位长度**完全重复**。

### 3.2 常见函数的周期

| 函数 | 最小正周期 |
|------|-----------|
| $\sin x$ | $2\pi$ |
| $\cos x$ | $2\pi$ |
| $\tan x$ | $\pi$ |
| $\cot x$ | $\pi$ |
| $\sin(\omega x + \varphi)$ | $\dfrac{2\pi}{|\omega|}$ |
| $\cos(\omega x + \varphi)$ | $\dfrac{2\pi}{|\omega|}$ |
| $\tan(\omega x + \varphi)$ | $\dfrac{\pi}{|\omega|}$ |
| 常数函数 | 任意非零实数都是周期（无最小正周期） |

### 3.3 周期性的重要推论

若 $T$ 是 $f(x)$ 的周期，则：

- 对任意整数 $k$，$kT$ 也是 $f(x)$ 的周期。
- 若 $f(x)$ 有两个周期 $T_1$ 和 $T_2$，则 $T_1 + T_2$ 也是周期。

### 3.4 高考热点：利用周期性求值

**例7**：已知 $f(x)$ 是定义在 $\mathbb{R}$ 上的周期为 2 的函数，且 $f(1) = 3$，求 $f(2025)$ 的值。

解：周期为 2，所以 $f(x + 2k) = f(x)$，其中 $k \in \mathbb{Z}$。

$$ 2025 = 1 + 2 \times 1012 $$

所以 $f(2025) = f(1) = 3$。

### 3.5 抽象函数中的周期性条件

在高考中，周期性常常以抽象函数形式给出，需要学生从给定的关系式中判断周期。

| 已知条件 | 周期 | 证明思路 |
|---------|------|---------|
| $f(x + a) = f(x)$ | $a$ | 直接由定义 |
| $f(x + a) = -f(x)$ | $2a$ | $f(x+2a) = -f(x+a) = f(x)$ |
| $f(x + a) = \dfrac{1}{f(x)}$ | $2a$ | $f(x+2a) = \dfrac{1}{f(x+a)} = f(x)$ |
| $f(x + a) = -\dfrac{1}{f(x)}$ | $2a$ | 同上 |
| $f(x + a) = f(x + b)$ | $\|b-a\|$ | 直接由定义 |
| $f(x + a) = f(b - x)$ | $2(a+b)$？ | 需结合对称性分析 |

**例8**：已知 $f(x)$ 在 $\mathbb{R}$ 上满足 $f(x + 2) = -f(x)$，且 $f(1) = 2$，求 $f(2023)$。

解：由 $f(x+2) = -f(x)$，则 $f(x+4) = -f(x+2) = f(x)$。

所以 $4$ 是函数的一个周期。

$$ 2023 = 3 + 4 \times 505 $$

所以 $f(2023) = f(3)$。

而 $f(3) = f(1+2) = -f(1) = -2$。

所以 $f(2023) = -2$。

## 第四章 对称性——函数的“镜像之美”

### 4.1 对称性的定义

**轴对轴**：若函数 $f(x)$ 的图像关于直线 $x = a$ 对称，则对定义域内任意 $x$，有：

$$ f(a + x) = f(a - x) $$

**中心对称**：若函数 $f(x)$ 的图像关于点 $(a, b)$ 对称，则对定义域内任意 $x$，有：

$$ f(a + x) + f(a - x) = 2b $$

### 4.2 常见对称性结论

| 对称性 | 等式条件 |
|--------|---------|
| 关于 $y$ 轴对称 | $f(x) = f(-x)$ |
| 关于原点对称 | $f(x) = -f(-x)$ |
| 关于 $x = a$ 对称 | $f(x) = f(2a - x)$ |
| 关于 $(a, 0)$ 对称 | $f(x) + f(2a - x) = 0$ |
| 关于 $(a, b)$ 对称 | $f(x) + f(2a - x) = 2b$ |

### 4.3 对称性与周期的关系

对称性和周期性之间存在深刻的内在联系：

| 已知条件 | 结论（周期） |
|---------|-------------|
| $f(x)$ 关于 $x = a$ 和 $x = b$ 对称 | $T = 2\|b-a\|$ |
| $f(x)$ 关于 $(a,0)$ 和 $(b,0)$ 中心对称 | $T = 2\|b-a\|$ |
| $f(x)$ 关于 $x = a$ 对称，且关于 $(b,0)$ 中心对称 | $T = 4\|b-a\|$ |

**例9**：已知函数 $f(x)$ 是偶函数，且关于 $x = 2$ 对称，求证 $f(x)$ 是周期函数，并求周期。

证明：偶函数 $\Rightarrow f(x) = f(-x)$。

关于 $x = 2$ 对称 $\Rightarrow f(x) = f(4 - x)$。

于是：

$$ f(x) = f(4 - x) = f(-(x - 4)) = f(x - 4) $$

所以 $f(x) = f(x - 4)$，即 $f(x + 4) = f(x)$。

因此 $f(x)$ 是周期为 4 的周期函数。

> **重要结论**：如果一个函数既是偶函数（或奇函数），又关于另一条竖直线对称，那么它一定是周期函数。

## 第五章 四大性质的综合应用

### 5.1 性质综合题（高考压轴方向）

在高考中，函数的四大性质经常**综合出现**，考查学生的综合分析能力。

**例10**（经典综合题）：已知定义在 $\mathbb{R}$ 上的函数 $f(x)$ 满足：

1. $f(x)$ 是偶函数；
2. $f(x + 2) = f(x - 2)$；
3. 在区间 $[0, 2]$ 上，$f(x) = x^2 - 2x$。

求 $f(2025)$ 的值。

解：由 $f(x+2) = f(x-2)$，令 $t = x-2$，则 $f(t+4) = f(t)$，所以 4 是周期。

偶函数意味着 $f(x) = f(-x)$。

将 $2025$ 化到已知区间：

$$ 2025 = 1 + 4 \times 506 $$

所以 $f(2025) = f(1)$。

在 $[0,2]$ 上，$f(x) = x^2 - 2x$，所以 $f(1) = 1 - 2 = -1$。

因此 $f(2025) = -1$。

**例11**：已知 $f(x)$ 的定义域为 $\mathbb{R}$，且满足：

1. $f(x)$ 是奇函数；
2. $f(x) = f(2-x)$。

求证：$f(x)$ 是周期函数，并求周期。

证明：由 $f(x) = f(2-x)$，得图像关于 $x = 1$ 对称。

由奇函数 $f(x) = -f(-x)$。

于是：

$$ f(x) = f(2-x) = -f(x-2) $$

$$ \Rightarrow f(x-2) = -f(x) $$

令 $t = x-2$，则 $f(t) = -f(t+2)$，即 $f(x+2) = -f(x)$。

于是 $f(x+4) = -f(x+2) = f(x)$。

所以周期为 4。

### 5.2 利用性质解不等式

**例12**：已知定义在 $\mathbb{R}$ 上的偶函数 $f(x)$ 在区间 $[0, +\infty)$ 上单调递增，且 $f(2) = 0$，解不等式 $f(x) > 0$。

解：偶函数在对称区间上单调性相反，所以 $f(x)$ 在 $(-\infty, 0]$ 上单调递减。

$f(2) = 0$，由偶函数性质 $f(-2) = 0$。

由于在 $[0, +\infty)$ 上递增，所以 $x > 2$ 时 $f(x) > 0$。

由于在 $(-\infty, 0]$ 上递减，所以 $x < -2$ 时 $f(x) > 0$。

因此解集为：$(-\infty, -2) \cup (2, +\infty)$。

## 第六章 总结

函数的四大性质是高中数学的核心内容，也是高考的必考点。

| 性质 | 判断方法 | 几何意义 | 关键应用 |
|------|---------|---------|---------|
| **单调性** | 定义法、导数法、图像法 | 图像的升降趋势 | 求最值、解不等式 |
| **奇偶性** | 定义法（$f(-x)$ 与 $f(x)$ 的关系） | 图像关于 $y$ 轴或原点对称 | 简化计算、求参数 |
| **周期性** | 定义法（$f(x+T) = f(x)$） | 图像的循环重复 | 求函数值、求周期 |
| **对称性** | 定义法（$f(a+x) = f(a-x)$） | 图像的镜像对称 | 与周期性的联系 |
