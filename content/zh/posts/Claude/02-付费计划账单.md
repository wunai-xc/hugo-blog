# 付费计划账单常见问题

本文涵盖在网络上购买的 Pro 和 Max 订阅。如果您通过 Claude for iOS 或 Claude for Android 订阅，您的付款由 Apple App Store 或 Google Play 处理，您将通过应用商店账户管理您的付款方式和收据。要取消或管理应用商店订阅，请参阅**[取消您的 Pro 或 Max 订阅](https://support.claude.com/en/articles/8325617)**。

## 我在哪里可以找到我的 Pro 或 Max 计划付款的发票或收据？

如果您订阅了付费计划（Pro 或 Max），请按照以下步骤访问您的发票：

1. 点击左下角的您的首字母或名称，然后从菜单中选择"设置"。

2. 导航到**[设置 > 账单](https://claude.ai/settings/billing)**。

3. 找到**发票**部分。

4. 点击您要打开的发票旁边的"查看"按钮。

此外，所有发票都会自动发送到您的账单电子邮件地址。要在您的收件箱中查找之前发送的发票，请按主题行"您来自 Anthropic 的收据"搜索。

## 我如何编辑现有付费 Claude 订阅的账单详情？

1. 点击左下角的您的首字母或名称，然后从菜单中选择"设置"。

2. 导航到**[设置 > 账单](https://claude.ai/settings/billing)**。

3. 点击您的付款方式旁边的"更新"按钮。

4. 在付款更新表单中输入您的新账单详情。

5. 点击"更新"以保存您的更改。

6. 您更新的付款方式将在您的订阅下次续订时被扣费。

## 我如何更改或移除我的 Pro 或 Max 订阅上的卡？

要更改您的 Pro 或 Max 订阅上的卡：

1. 导航到**[设置 > 账单](https://claude.ai/settings/billing)**。

2. 点击您的付款方式旁边的"更新"按钮。

3. 输入您的新卡详情。

4. 点击"更新"以保存您的更改。

新卡成为您的默认付款方式，所有未来的订阅续订都将扣费到该卡。您之前的卡将不再被扣费。

没有单独的选项来移除卡，更新到新卡会为账单目的替换旧卡。账单页面仅显示您当前的默认卡。之前使用的卡将不再被扣费，但它们可能仍然存储在我们的支付处理器中。如果您需要从您的账户中完全移除之前的卡，请联系**[我们的支持团队](https://support.claude.com/en/articles/9015913-how-to-get-support)**。

## 我如何在我的发票上使用不同的名称？

如果您想使用与您的付款方式关联的名称不同的名称，在**[设置 > 账单](https://claude.ai/settings/billing)**中添加或更新您的付款方式时，勾选"在发票上使用不同的名称"复选框。

## 我如何编辑已付发票？

一旦发票已支付，就没有办法编辑最终发票上的信息。此外，我们的内部团队无法重新发行已支付的发票或修改以前发票上的信息。

## 我可以更改我的 Pro 或 Max 订阅的扣费日期吗？

不，没有直接的方法来更改您的订阅账单日期。但是，您可以取消订阅您当前的计划，然后在您首选的账单日期重新订阅，以在不同的日期建立您的新月度账单周期。

## 有哪些替代付款方式可用？

对于在网络上购买的订阅，我们仅接受信用卡或借记卡。如果您通过 Claude for iOS 或 Claude for Android 订阅，可用的付款选项由 Apple App Store 或 Google Play 决定。

## 我有一个付费计划，但我的账户显示为免费；我如何访问我的付费账户？

如果您已为 Pro 或 Max 计划付费，但在您的账户中看不到这一点，您应该检查两件事：

1. 您使用了不同的电子邮件登录。我们建议尝试使用您可能用来创建付费账户的任何替代电子邮件登录。

2. 您的付款方式失败，您的账户被降级。要检查这一点，导航到**[设置 > 账单](https://claude.ai/settings/billing)**以确认您最近的付款状态，并在需要时更新您的付款方式或账单详情。
