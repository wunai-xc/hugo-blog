## 引言

你身边可能有人对花生过敏，沾一点就会呼吸困难；也可能有人得过水痘，痊愈后再也不会得第二次。这些现象的背后，都是同一个系统在工作——**免疫系统**。

免疫系统是人体的"国防军"。它24小时不间断地巡逻，识别并清除入侵的病原体（细菌、病毒、真菌、寄生虫），同时监视并清除体内异常增殖的肿瘤细胞。它还要学会容忍自身组织，避免"自己人打自己人"——这就是免疫耐受。

更令人惊叹的是，免疫系统具有**记忆能力**：一次感染后，它能"记住"入侵者的特征，下次再遇到时能在几天内发起毁灭性打击。疫苗正是利用了这一特性。

本文将从解剖结构、细胞组分、两层防御体系、免疫应答过程到临床应用，系统解析这个精密而强大的生物防御网络。

## 第一章 免疫系统的解剖学基础

免疫系统不像循环系统或呼吸系统那样有明确的"器官集合"，它的"部队"分散在全身各处，通过血液和淋巴系统联络和调动。

### 1.1 初级淋巴器官：免疫细胞的"训练营"

| 器官 | 功能 |
|------|------|
| **骨髓** | 所有血细胞（包括免疫细胞）的发源地。B淋巴细胞在此成熟 |
| **胸腺** | T淋巴细胞的"训练营"。T细胞在此学习区分"自己"与"非己" |

### 1.2 次级淋巴器官：免疫应答的"战场"

| 器官/组织 | 功能 |
|------|------|
| **淋巴结** | 过滤淋巴液，捕获抗原，激活T细胞和B细胞 |
| **脾脏** | 过滤血液，清除衰老红细胞，激活针对血源性病原体的免疫应答 |
| **黏膜相关淋巴组织（MALT）** | 呼吸道、消化道、泌尿生殖道的免疫防御前线 |

### 1.3 免疫细胞在全身的分布

免疫细胞并非静止在淋巴器官中，而是通过**血液和淋巴循环**不断巡逻全身。这种"流动性"使得免疫系统能够对任何部位的入侵迅速做出反应。

## 第二章 免疫系统的两层防御体系

免疫系统通过**两层防御**来对抗病原体，根据反应速度和特异性分为先天免疫和适应性免疫。

### 2.1 先天免疫（非特异性免疫）

先天免疫是**第一道防线**，也是反应最快的防线，在感染后数分钟内即开始工作。

**特点**：
- 反应速度快（分钟级）
- 特异性低（识别病原体的共性特征，而非特定抗原）
- 无免疫记忆（每次遇到病原体都是"第一次"）

**主要组分**：

| 防线 | 组分 | 功能 |
|------|------|------|
| **物理屏障** | 皮肤、黏膜 | 阻挡病原体物理侵入 |
| **化学屏障** | 胃酸、溶菌酶、抗菌肽 | 杀灭或抑制病原体 |
| **生物屏障** | 肠道正常菌群 | 竞争性排斥病原体 |
| **细胞组分** | 巨噬细胞、中性粒细胞、自然杀伤细胞（NK细胞） | 吞噬病原体、杀伤被感染细胞 |
| **体液组分** | 补体系统、干扰素 | 直接裂解病原体、抑制病毒复制 |

### 2.2 适应性免疫（特异性免疫）

适应性免疫是**第二道防线**，专门针对特定病原体，反应较慢但高度特异且具有记忆。

**特点**：
- 反应速度慢（初次应答需数天至数周）
- 特异性高（识别特定的抗原表位）
- 有免疫记忆（再次遇到同一病原体时反应更快更强）

**两大分支**：

| 分支 | 负责细胞 | 主要功能 |
|------|---------|---------|
| **体液免疫** | B淋巴细胞 | 产生抗体，中和病原体和毒素 |
| **细胞免疫** | T淋巴细胞 | 直接杀伤被感染细胞和肿瘤细胞 |

### 2.3 两层防御的协作

先天免疫和适应性免疫并非独立工作。先天免疫的细胞（如巨噬细胞和树突状细胞）在吞噬病原体后，会将其抗原片段呈递给T细胞，**启动适应性免疫应答**。先天免疫的炎症信号也会促进适应性免疫细胞的活化。

> 可以这样理解：先天免疫是"**哨兵和保安**"——快速反应但不精准；适应性免疫是"**特种部队**"——反应慢但能精确清除特定目标，并能记住敌人的特征。

## 第三章 核心免疫细胞

免疫系统拥有多种不同类型的细胞，各司其职，协同作战。

### 3.1 髓系细胞（先天免疫主力）

| 细胞类型 | 功能 |
|---------|------|
| **巨噬细胞** | 吞噬病原体和细胞碎片，呈递抗原，释放细胞因子 |
| **中性粒细胞** | 最丰富的白细胞，吞噬细菌，释放NETs（中性粒细胞胞外陷阱） |
| **树突状细胞** | 最强大的抗原呈递细胞，连接先天免疫和适应性免疫 |
| **自然杀伤细胞（NK细胞）** | 杀伤病毒感染的细胞和肿瘤细胞，无需预先致敏 |
| **肥大细胞** | 释放组胺等炎症介质，参与过敏反应 |

### 3.2 淋巴系细胞（适应性免疫主力）

| 细胞类型 | 亚型 | 功能 |
|---------|------|------|
| **T细胞** | CD4+辅助T细胞（Th） | 激活其他免疫细胞（"指挥官"） |
| | CD8+细胞毒性T细胞（CTL） | 直接杀伤被感染细胞和肿瘤细胞（"杀手"） |
| | 调节性T细胞（Treg） | 抑制免疫应答，维持免疫耐受 |
| **B细胞** | — | 产生抗体，呈递抗原 |
| **浆细胞** | — | B细胞的终末分化形式，大量产生抗体 |
| **记忆B/T细胞** | — | 长期存活，提供免疫记忆 |

### 3.3 抗原呈递细胞（APC）

抗原呈递细胞是连接先天免疫与适应性免疫的桥梁。它们吞噬病原体后，将抗原片段呈递在细胞表面的MHC分子上，供T细胞识别。

主要的抗原呈递细胞包括：
- **树突状细胞**（最强大）
- **巨噬细胞**
- **B细胞**

## 第四章 核心免疫分子

### 4.1 抗体（免疫球蛋白，Ig）

抗体是B细胞产生的Y形蛋白质分子，能特异性结合抗原。

| 类别 | 结构 | 功能 |
|------|------|------|
| **IgG** | 单体 | 最主要的中和抗体，穿过胎盘，激活补体 |
| **IgA** | 二聚体 | 黏膜免疫（唾液、泪液、乳汁） |
| **IgM** | 五聚体 | 初次免疫应答的主要抗体，高效激活补体 |
| **IgE** | 单体 | 过敏反应，抗寄生虫 |
| **IgD** | 单体 | B细胞表面的受体，功能尚不完全清楚 |

### 4.2 补体系统

补体是由肝脏合成的一组血清蛋白，以非活性形式存在于血液中，被激活后通过级联反应发挥多种功能。

| 功能 | 说明 |
|------|------|
| **细胞裂解** | 形成膜攻击复合物（MAC），裂解细菌和病毒感染细胞 |
| **调理作用** | 包被病原体，促进吞噬 |
| **趋化作用** | 吸引炎症细胞到感染部位 |

### 4.3 主要组织相容性复合体（MHC）

MHC分子是细胞表面蛋白，用于将抗原片段呈递给T细胞。

| 类型 | 表达位置 | 呈递的抗原来源 |
|------|---------|--------------|
| **MHC I类** | 所有有核细胞 | 细胞内抗原（病毒、肿瘤抗原） |
| **MHC II类** | 抗原呈递细胞（APC） | 细胞外抗原（细菌、寄生虫） |

> MHC分子是人类**器官移植配型**的核心依据。MHC不匹配会导致移植排斥。

### 4.4 细胞因子

细胞因子是免疫细胞之间的"通信分子"，调控免疫应答的强度、类型和持续时间。

| 类型 | 示例 | 主要功能 |
|------|------|---------|
| **白细胞介素（IL）** | IL-2、IL-4、IL-10 | 调节T/B细胞增殖和分化 |
| **干扰素（IFN）** | IFN-α、IFN-β、IFN-γ | 抗病毒、激活巨噬细胞 |
| **肿瘤坏死因子（TNF）** | TNF-α | 炎症、细胞凋亡诱导 |
| **趋化因子** | CXCL8、CCL2 | 吸引免疫细胞到感染部位 |

## 第五章 免疫应答过程

当病原体入侵时，免疫系统按照特定程序做出反应。

### 5.1 先天免疫应答

1. **病原体识别**：模式识别受体（PRR）识别病原体相关分子模式（PAMP）
2. **炎症反应**：释放细胞因子和趋化因子，血管扩张，免疫细胞浸润
3. **吞噬清除**：巨噬细胞和中性粒细胞吞噬病原体
4. **抗原呈递**：树突状细胞迁移至淋巴结，启动适应性免疫

### 5.2 适应性免疫应答

#### 体液免疫（B细胞）

1. **抗原识别**：B细胞通过表面BCR识别抗原
2. **Th细胞协助**：活化B细胞需要CD4+ T细胞的帮助
3. **克隆扩增**：B细胞大量增殖
4. **分化**：分化为浆细胞（大量产生抗体）和记忆B细胞

#### 细胞免疫（T细胞）

1. **抗原呈递**：APC在MHC上呈递抗原
2. **T细胞活化**：TCR识别抗原-MHC复合物，共刺激信号提供第二信号
3. **克隆扩增**：T细胞大量增殖
4. **分化**：分化为效应T细胞（CTL杀伤靶细胞、Th协助其他细胞）和记忆T细胞

### 5.3 免疫记忆

免疫记忆是疫苗接种的原理基础。初次感染后，记忆B细胞和记忆T细胞长期存活。再次遇到同一病原体时：

- 反应更快（数天 vs 数周）
- 反应更强（抗体滴度更高）
- 反应更特异（抗体亲和力更高）

> 这解释了为什么得过水痘的人不会再得第二次——他们的免疫系统"记住了"水痘病毒。

## 第六章 免疫失调

免疫系统精密的平衡一旦被打破，就会导致疾病。

### 6.1 免疫缺陷

免疫系统功能不足，导致反复、严重或机会性感染。

| 类型 | 示例 | 原因 |
|------|------|------|
| **原发性免疫缺陷** | 重症联合免疫缺陷（SCID） | 遗传因素 |
| **继发性免疫缺陷** | AIDS（获得性免疫缺陷综合征） | HIV病毒感染 |

### 6.2 自身免疫病

免疫系统错误攻击自身组织，失去对自身抗原的耐受性。

| 疾病 | 靶向组织/分子 | 典型表现 |
|------|--------------|---------|
| **类风湿关节炎** | 关节滑膜 | 关节肿痛、畸形 |
| **1型糖尿病** | 胰岛β细胞 | 胰岛素缺乏、高血糖 |
| **系统性红斑狼疮（SLE）** | DNA、核蛋白等 | 多系统损伤（皮肤、肾脏、关节） |
| **多发性硬化（MS）** | 中枢神经系统髓鞘 | 神经功能缺损 |
| **桥本甲状腺炎** | 甲状腺组织 | 甲状腺功能减退 |

### 6.3 超敏反应（过敏）

免疫系统对无害抗原产生过度反应。

| 类型 | 机制 | 示例 |
|------|------|------|
| **I型（速发型）** | IgE介导，肥大细胞脱颗粒 | 过敏性鼻炎、哮喘、食物过敏、过敏性休克 |
| **II型（细胞毒型）** | IgG/IgM介导，补体激活 | 自身免疫性溶血性贫血 |
| **III型（免疫复合物型）** | 抗原-抗体复合物沉积 | 血清病、狼疮性肾炎 |
| **IV型（迟发型）** | T细胞介导 | 接触性皮炎（如毒藤）、结核菌素反应 |

### 6.4 肿瘤免疫

免疫系统具有**免疫监视**功能，可以识别并清除早期肿瘤细胞。肿瘤细胞可通过多种机制逃避免疫攻击（免疫逃逸）。

**肿瘤免疫治疗的策略**：
- **免疫检查点抑制剂**（PD-1/PD-L1抑制剂、CTLA-4抑制剂）：解除T细胞的"刹车"
- **CAR-T细胞治疗**：改造患者自身T细胞以特异性攻击肿瘤
- **肿瘤疫苗**：激活针对肿瘤抗原的免疫应答
- **单克隆抗体**：直接靶向肿瘤细胞表面抗原

## 第七章 免疫学的临床意义

### 7.1 疫苗：利用免疫记忆预防疾病

疫苗通过模拟感染来训练免疫系统，不引起疾病但能产生保护性记忆。

| 疫苗类型 | 代表疫苗 | 原理 |
|---------|---------|------|
| **灭活疫苗** | 流感疫苗、甲肝疫苗 | 使用被杀死的病原体 |
| **减毒活疫苗** | MMR、水痘疫苗 | 使用弱化的活病原体 |
| **亚单位/重组蛋白疫苗** | 乙肝疫苗、HPV疫苗 | 仅使用病原体的特定抗原 |
| **mRNA疫苗** | 新冠疫苗（辉瑞/Moderna） | 提供制造抗原的遗传指令 |
| **病毒载体疫苗** | 新冠疫苗（阿斯利康/强生） | 利用无害病毒递送抗原基因 |

### 7.2 器官移植与免疫抑制

器官移植面临的核心挑战是**移植排斥**——受者的免疫系统将移植器官识别为"非己"并发起攻击。

**应对策略**：
- **组织配型**：尽量匹配供者和受者的HLA（人白细胞抗原）
- **免疫抑制剂**：环孢素、他克莫司等药物抑制T细胞活化
- **诱导耐受**：研究方向——使免疫系统接受移植器官而不影响整体免疫功能

### 7.3 免疫学检测

| 检测方法 | 用途 |
|---------|------|
| **全血细胞计数** | 评估各种免疫细胞数量 |
| **ELISA** | 检测抗体或抗原 |
| **流式细胞术** | 分型和计数免疫细胞亚群 |
| **皮肤试验** | 检测迟发型超敏反应（如结核菌素试验） |

## 第八章 免疫识别的分子机制与定量推导

前几章以描述性语言勾勒了免疫系统的工作流程。本章将把若干核心环节——T 细胞识别、胸腺选择、B 细胞亲和力成熟与细胞因子信号——抽象为可定量分析的分子—动力学系统，以揭示"看似松散"的免疫识别背后严密的物理化学逻辑。

### 8.1 TCR–pMHC 结合的亲和力与动力学

T 细胞受体（TCR）识别抗原呈递细胞表面的肽–MHC 复合物（pMHC）是适应性免疫的基石。与抗体–抗原结合（$K_D \sim 10^{-9}$–$10^{-10}\ \text{M}$）相比，TCR–pMHC 的亲和力异常低，典型 $K_D$ 在 $1$–$100\ \mu\text{M}$ 量级（Davis & Bjorkman, 1988；Stone et al., 2009）。这种"低效"设计实为免疫识别"灵敏度–特异性权衡"的结果。

**结合动力学方程**：TCR（$T$）与 pMHC（$P$）的可逆结合遵循质量作用定律：

$$T + P \underset{k_{\text{off}}}{\overset{k_{\text{on}}}{\rightleftharpoons}} TP$$

平衡解离常数定义为：

$$K_D = \frac{[T][P]}{[TP]} = \frac{k_{\text{off}}}{k_{\text{on}}}$$

其中 $k_{\text{on}}$（结合速率，$\text{M}^{-1}\text{s}^{-1}$）通常在 $10^3$–$10^5$，$k_{\text{off}}$（解离速率，$\text{s}^{-1}$）在 $10^{-3}$–$10^{-1}$。TCR 亲和力成熟主要通过降低 $k_{\text{off}}$（即延长半衰期 $t_{1/2} = \ln 2 / k_{\text{off}}$）实现，而非提高 $k_{\text{on}}$（Takahashi et al., 2001；Govern et al., 2010）。

**动力学校对与信号判别**：T 细胞活化需 TCR–pMHC 信号经过串联激酶反馈环路放大。McKeithan（1995）提出"动力学校对（kinetic proofreading）"模型：每一步磷酸化修饰要求 TCR–pMHC 维持结合状态，中途解离则信号重置。设共 $N$ 步校对，则有效特异性放大为：

$$\text{Specificity amplification} \sim \left(\frac{k_{\text{on}}[\text{pMHC}]}{k_{\text{off}}}\right)^{N}$$

代价是反应时间延长 $\sim N/k_{\text{off}}$。该模型解释了 TCR 在 $K_D$ 仅 $\mu\text{M}$ 级时仍能实现极高辨别精度。

**动力学编辑（kinetic editing）与胸腺选择**：胸腺选择中 DP 胸腺细胞与自身 pMHC 的相互作用时长 $\tau \approx 1/k_{\text{off}}$ 决定其命运（Mayer & Bruyns, 2004）：

- $\tau < \tau_{\text{min}}$：忽略信号 → 忽略死亡（阳性选择失败）
- $\tau_{\text{min}} < \tau < \tau_{\text{max}}$：阳性选择（存活）
- $\tau > \tau_{\text{max}}$：阴性选择（凋亡）

选择窗口 $(\tau_{\text{min}}, \tau_{\text{max}})$ 约对应 $K_D$ 在 $1$–$10\ \mu\text{M}$。这一基于动力学的判别机制解释了胸腺如何区分"自我"与"强自我"。

### 8.2 胸腺负选择与 AIRE 依赖的旁泌调控

**AIRE 与外周组织抗原（TRA）表达**：胸腺髓质上皮细胞（mTEC）通过自身免疫调节因子（Autoimmune Regulator, AIRE）异位表达外周组织限制性抗原（tissue-restricted antigens, TRAs），如胰岛素、唾液蛋白等，使发育中的 T 细胞在胸腺内即接触这些"外周专属"抗原，删除针对它们的自身反应性克隆（Anderson et al., 2002；Kyewski & Klein, 2006）。AIRE 基因突变导致 APECED/APS-1（自身免疫性多内分泌病–念珠菌病–外胚层营养不良）。

**AIRE 的工作机制**：AIRE 不直接结合启动子，而是通过其 PHD1/PHD2 锌指结构域识别组蛋白 H3 未甲基化的 K4（H3K4me0）——这是转录沉默染色质的标志（Koh et al., 2008；Org et al., 2008）。AIRE 招募 P-TEFb（正性转录延长因子 b）、BRD4、TOP2A 等，从转录延长受阻的基因座释放 RNA Pol II，使数千个 TRA 基因得以低水平异位转录。

**旁泌调控（paracrine regulation）**：AIRE 阳性 mTEC 还通过分泌 RANKL、CD40L、LTα 等旁泌信号调控邻近 mTEC 的成熟与 AIRE 表达（Roberts et al., 2012；Aaltonen et al., 2024）。设 mTEC$_{\text{AIRE}+}$ 在位置 $\mathbf{x}$ 的数为 $M(\mathbf{x})$，其分泌的 TRA 浓度场 $C(\mathbf{x})$ 满足扩散–产生–降解方程：

$$D \nabla^2 C(\mathbf{x}) - \lambda C(\mathbf{x}) + \rho M(\mathbf{x}) = 0$$

其中 $D$ 为扩散系数，$\lambda$ 为降解速率，$\rho$ 为单细胞产生速率。特征扩散长度 $L_D = \sqrt{D/\lambda}$ 约 $50$–$200\ \mu\text{m}$，与胸腺髓质小叶尺度相当，意味着每个 AIRE+ mTEC 簇可建立局部抗原"暴露场"。

**负选择的克隆删除概率**：设某 T 细胞克隆的 TCR 与某 TRA–pMHC 的亲和力为 $K_D$，其被删除的概率近似为 Hill 函数：

$$P_{\text{delete}}(K_D) = \frac{[TP]^{n}}{K_{\text{sel}}^{n} + [TP]^{n}}, \quad [TP] \approx \frac{[T]_{\text{tot}}[P]}{K_D + [P]}$$

其中 $n \approx 1$–$3$ 反映协同性，$K_{\text{sel}}$ 为选择阈值。该模型预测：AIRE 缺陷导致 TRA 表达降低（$\rho \downarrow$），使 $P_{\text{delete}}$ 降低，自身反应性克隆逸出 → 自身免疫。

### 8.3 生发中心亲和力成熟的突变–选择动力学

**生发中心（GC）结构**：生发中心是次级淋巴器官中 B 细胞亲和力成熟的微环境，分为暗区（DZ：增殖与体细胞高频突变 SHM）和明区（LZ：与滤泡树突状细胞 FDC 上的抗原竞争结合及 Tfh 选择）（Victora & Nussenzweig, 2012）。

**体细胞高频突变（SHM）**：活化诱导胞苷脱氨酶（AID）将胞嘧啶（C）脱氨为尿嘧啶（U），在 Ig 可变区引入突变，速率约 $10^{-3}$–$10^{-4}\ \text{/bp/代}$，比自发突变高 $10^6$ 倍（Di Noia & Neuberger, 2007）。

**突变–选择动力学模型**：记 B 细胞克隆 $i$ 的亲和力 $A_i$，克隆大小 $N_i$。每一代经历两步：

1. **突变**：克隆 $i$ 突变为亲和力 $A_j = A_i + \Delta A$（$\Delta A \sim \mathcal{N}(0, \sigma_A^2)$，多数突变中性或有害）
2. **选择**：克隆 $i$ 被保留的概率正比于其与 FDC 抗原结合的亲和力：

$$w_i = \frac{A_i^{h}}{\sum_j A_j^{h}}$$

其中 $h$ 为选择强度（受 Tfh 帮助信号限制）。克隆动力学方程（replicator–mutator 形式）：

$$\frac{dN_i}{dt} = r N_i \left(\frac{A_i^{h}}{\bar{A}^{h}} - 1\right), \quad \bar{A} = \left(\frac{\sum_j A_j^{h} N_j}{\sum_j N_j}\right)^{1/h}$$

其中 $r$ 为细胞周期速率，$\bar{A}$ 为群体平均"选择亲和力"（Oprea & Perelson, 1997；Antia et al., 2018）。

**时间尺度与边界**：理论与实验一致估计，初次免疫后 1–2 周内 GC B 细胞平均 $K_D$ 可下降 $10$–$100$ 倍。但过高亲和力受限于：抗原表位掩盖（epitope masking）、BCR 内化过快导致提呈减少与 Tfh 帮助减弱（免疫–反馈机制）、以及交叉反应自身风险。

**克隆格式塔（clonal gestalt）**：同一 B 细胞克隆在多个 GC 间迁移，使记忆库既广谱又高亲和，构成免疫记忆多样性的来源（Tas et al., 2016）。

### 8.4 细胞因子信号的 JAK–STAT 通路数学建模

**JAK–STAT 通路**：细胞因子受体结合后激活 JAK（Janus 激酶），后者磷酸化受体上的酪氨酸残基，招募 STAT（信号转导与转录激活因子）；STAT 酪氨酸磷酸化、二聚化、入核激活靶基因（O'Shea et al., 2015）。例如 IL-6 → JAK1/JAK3 → STAT3；IFN-γ → JAK1/JAK2 → STAT1。

**简化动力学模型**：设受体 $R$、磷酸化 STAT $S^{*}$、负调控因子 SOCS（细胞因子信号抑制物）。考虑信号、反馈与降解：

$$\frac{dR^{*}}{dt} = k_a C(t) R - k_d R^{*} - k_{\text{SOCS}} S^{*} R^{*}$$

$$\frac{dS^{*}}{dt} = k_s R^{*} - \gamma_s S^{*}$$

$$\frac{d[\text{SOCS}]}{dt} = k_{\text{trans}} S^{*} - \gamma_{\text{SOCS}} [\text{SOCS}]$$

其中 $C(t)$ 为细胞因子浓度。SOCS 通过负反馈抑制信号，使在持续细胞因子刺激下 $S^{*}$ 呈现"瞬时峰—平台衰减"行为，接近完美适应（perfect adaptation）（Yamamoto et al., 2003；Swameye et al., 2008）。

**适应性与浓度阈值**：稳态分析表明，当 $C \to \infty$ 时 $S^{*}_{\text{ss}} \to k_s k_a / (k_d \gamma_s + k_{\text{SOCS}} k_{\text{trans}}/\gamma_{\text{SOCS}})$，存在上限；细胞因此能区分瞬时刺激与持续刺激，避免慢性细胞因子风暴。该模型预测：SOCS1 缺陷小鼠因 IFN 信号无法终止而死于致命炎症（Alexander et al., 1999）。

**剂量–响应与信号整合**：STAT 信号响应遵循 Hill 方程：

$$S^{*}(C) = S_{\max} \cdot \frac{C^{n}}{\text{EC}_{50}^{n} + C^{n}}$$

$n$ 反映受体协同性（IFN 信号 $n \approx 1$；IL-6 异源二聚体 $n \approx 1.5$–$2$）。该定量框架是细胞因子疗法（如低剂量 IL-2 选择性扩张 Treg）设计的理论基础。

## 第九章 免疫学实验技术

### 9.1 流式细胞术与荧光补偿原理

流式细胞术（flow cytometry）通过激光激发荧光染料标记的抗体，实现单细胞水平多参数（表面/胞内分子、信号磷酸化、细胞周期等）定量分析。现代仪器可同时检测 ≥ 20 色（如 Cytek Aurora 全光谱流式），极大拓展了免疫表型分辨率。

**荧光补偿（compensation）原理**：每个荧光染料有特定的激发与发射光谱。例如 FITC 与 PE 同时被 488 nm 激光激发，FITC 的发射光谱尾部会"漏"到 PE 检测通道（spillover）。若不校正，FITC+ 细胞会被误判为 FITC+ PE+。

设单染对照测得 FITC 通道信号 $F_{\text{FITC}}$、PE 通道漏出 $F_{\text{PE}}$，则 spillover 系数：

$$s_{\text{FITC}\to\text{PE}} = \frac{F_{\text{PE}}}{F_{\text{FITC}}}$$

校正矩阵 $S$（$s_{ij}$ 表示染料 $j$ 在通道 $i$ 的漏出比例），实测多色信号向量 $\mathbf{M}$ 与真实信号 $\mathbf{T}$ 的关系：

$$\mathbf{M} = S\,\mathbf{T} \quad \Longrightarrow \quad \mathbf{T} = S^{-1}\mathbf{M}$$

实际计算需用单染对照（或补偿微球）构建 $S$ 矩阵求逆。全光谱流式不依赖补偿矩阵，而用全光谱解混（unmixing）反卷积，更适合高度重叠的染料组合（Roederer, 2002；Futamura & Cao, 2018）。

**应用**：免疫表型（CD3/CD4/CD8；Treg 的 CD4+CD25+FoxP3+）、细胞内信号（pSTAT3）、绝对计数（添加计数微球）。

### 9.2 ELISPOT 检测单细胞因子分泌

酶联免疫斑点法（ELISPOT）是检测单个细胞分泌细胞因子的金标准，灵敏度可达 $1/10^{5}$–$10^{6}$ 细胞，远高于 ELISA 与流式胞内染色（Czerkinsky et al., 1988；Miyahira et al., 1995）。

**原理与流程**：

1. 96 孔 PVDF 膜板预包被抗 IFN-γ（或其他细胞因子）捕获抗体
2. 加入待测细胞（如 PBMC）与抗原刺激，分泌的细胞因子立即被周围抗体捕获 → 形成局部斑点
3. 加入生物素化检测抗体 → 链霉亲和素–HRP → 显色底物（AEC/TMB）→ 每个分泌细胞形成一个斑点
4. 自动斑点计数仪计数 → 单位：spot-forming units (SFU) / $10^{6}$ cells

**定量与局限**：ELISPOT 测得的是"分泌频率"，但不含单细胞分泌量信息。流式微球阵列（CBA/LEGENDplex）与单细胞分泌分析（IsoPlexis）可补充单细胞分泌强度与多因子共分泌谱（Freer et al., 2020）。ELISPOT 是疫苗免疫原性评估、CAR-T 干扰素释放试验与移植免疫监测的标准方法。

### 9.3 TCR 测序与免疫组库多样性分析

**TCR 多样性来源**：人类 TCRβ 库理论多样性约 $10^{15}$，由 V(D)J 重排 + N 核苷酸插入/删除（TdT 介导）产生（Davis & Bjorkman, 1988；Arstila et al., 1999）。实际外周血可测得约 $10^{6}$–$10^{7}$ 克隆型。

**测序方法**：

- **多重 PCR**：针对 V/J 区保守引物扩增 CDR3 区
- **5' RACE**（如 Adaptive Biotechnologies immunoSEQ）：以 TCR 恒定区单一引物 + 模板切换，减少 V 区引物偏倚
- **单细胞 TCR-seq**（10x Genomics V(D)J）：与转录组配对，解析克隆型–表型–功能关联
- **长读长测序**（PacBio/Nanopore）：解析完整 V(D)J 含等位基因

**多样性度量**：

- **Shannon 熵**：$H = -\sum_i p_i \log p_i$，$p_i$ 为克隆 $i$ 频率
- **归一化 Shannon（evenness）**：$E = H / \log N$
- **Simpson 多样性**：$D = 1 - \sum_i p_i^{2}$（克隆型集中度）
- **D50**：覆盖总频谱 50% 所需的克隆数
- **rarefaction**：随采样深度估计克隆数，避免测序深度偏倚

**临床应用**：MRD（微小残留病）监测、TIL 克隆扩张与免疫治疗响应、自身免疫病的寡克隆扩张（如多发性硬化的 MBP 反应性克隆）、感染后免疫记忆演化（Greiff et al., 2015；Emerson et al., 2017）。

### 9.4 CRISPR 筛选在免疫学中的应用

**CRISPR 筛选范式**：将 sgRNA 文库（覆盖全基因或通路）慢病毒转导入 Cas9 表达细胞，通过表型选择 + 测序读出，鉴定关键基因（Shalem et al., 2014；Wang et al., 2014）：

- **loss-of-function（CRISPRko/CRISPRi）**：sgRNA 切割或抑制基因，富集/消减分析
- **gain-of-function（CRISPRa）**：dCas9–VP64/p65–Rta 激活内源基因表达
- **饱和突变扫描**：base/prime editing 扫描关键位点

**免疫学应用实例**：

- **T 细胞耗竭调控**：Peng et al.（2020）全基因组 CRISPR 筛选发现 NR4A、BATF、IRF4 是 T 细胞耗竭主控因子，敲除后 T 细胞抗肿瘤活性显著增强 → 后续 CAR-T 优化的关键靶点
- **CAR-T 增强靶点**：原代 T 细胞筛选鉴定 TGFBR2、CUL5、CBLB 等负调控因子，其敲除可增强持久性（Legut et al., 2022）
- **抗原呈递机制解析**：CRISPR 筛选发现 MHC I 抗原呈递通路新组分（Burr et al., 2017）
- **免疫逃逸**：肿瘤侧 CRISPR 筛选揭示 IFN-γ 通路（JAK1/2、B2M、HLA）失活是免疫检查点抑制剂耐药的核心机制（Pan et al., 2018；Sucker et al., 2017）

**关键技术要点**：原代免疫细胞需优化电转染（RNP 复合物）以避免慢病毒对细胞激活状态的影响；体内筛选需考虑肿瘤微环境的复杂选择压；与 Perturb-seq（CRISPR + 单细胞 RNA-seq）结合可同步读出表型与转录组（Replogle et al., 2022）。

## 第十章 前沿进展

### 10.1 CAR-T 疗法的工程化设计

CAR（嵌合抗原受体）将单链抗体可变区（scFv）与胞内信号域融合，赋予 T 细胞 MHC 非依赖的靶向杀伤能力（Gross et al., 1989；Sadelain et al., 2017）。

**代际演进**：

| 代际 | 共刺激域 | 特点 |
|------|---------|------|
| 1 代 | 无 | 仅 CD3ζ，体内扩增差 |
| 2 代 | CD28 或 4-1BB | 显著增强扩增与持久性 |
| 3 代 | 双共刺激（CD28+4-1BB 或 CD28+OX40） | 进一步增强，但临床获益尚有争议 |
| 4 代（TRUCK） | 共刺激 + 炎症因子释放（如 IL-12） | 改造肿瘤微环境 |

**4-1BB vs CD28 的代谢与持久性差异**：CD28 共刺激的 CAR-T 起效快（偏向效应记忆 $T_{\text{EM}}$），但持久性较短（中位 < 6 月），且细胞因子释放综合征（CRS）发生率高。4-1BB 共刺激促进线粒体生物合成与脂肪酸氧化（FAO），偏向中央记忆 $T_{\text{CM}}$ 表型，持久性可达数年（Kawalekar et al., 2016；van der Windt et al., 2012）。机制上，CD28 结构域激活后 PI3K–AKT 通路迅速上调糖酵解，适合快速杀伤；4-1BB 通过 TRAF/NF-κB 通路增强线粒体适应性，适合长期监视。

**实体瘤 CAR-T 挑战**：

1. **靶点限制**：肿瘤相关抗原（TAA）多在正常组织低表达 → on-target off-tumor 毒性（如 CLDN18.2、HER2）
2. **免疫抑制性微环境（TME）**：TGF-β、腺苷、低氧、抑制性基质
3. **物理屏障**：致密基质、异常血管 → T 细胞归巢与浸润差
4. **异质性**：抗原逃逸导致抗原阴性复发

应对策略包括逻辑门 CAR（AND gate 需双抗原阳性；NOT gate 避开正常组织）、armored CAR（分泌 IL-12/IL-18 改造 TME）、肿瘤局部给药（如腹腔/脑室内）、联合免疫检查点抑制剂（Priceman et al., 2018；Choe et al., 2021）。

**Universal CAR（UCAR）**：为解决自体 CAR-T 制备周期长（2–3 周）、成本高的问题，开发"现货型"异体 CAR-T——通常需敲除 TCR（避免 GVHD）与 HLA I（避免宿主排斥）。CRISPR 多重敲除 TRAC + TRBC + B2M 可显著降低免疫原性（Eyquem et al., 2017；Poirot et al., 2015）。下一代方向是**体内生成 CAR-T**：LNP–mRNA 递送 CAR 基因在体内编辑 T 细胞（Rurik et al., 2022）。

### 10.2 mRNA 疫苗平台

**LNP 递送系统**：mRNA 疫苗使用脂质纳米颗粒（LNP）递送体外转录（IVT）的修饰 mRNA。LNP 通常含 4 组分：

- **可离子化脂质**（如 ALC-0315/SM-102）：内体酸性环境下质子化 → 与内体膜融合 → 释放 mRNA（pH 响应"质子海绵"机制）
- **辅助磷脂**（DSPC）：稳定脂质双层
- **胆固醇**：调节膜流动性
- **PEG-脂质**（ALC-0159）：减少聚集与血清蛋白吸附，延长循环

LNP 通过 apoE 介导被 LDLR 摄取，主要在肌肉注射部位引流淋巴结富集 → 在 APC（尤其是滤泡 DC 与 DC）中表达抗原（Hou et al., 2021；Schoenmaker et al., 2021）。

**佐剂效应与炎症平衡**：mRNA 本身通过 TLR3/7/8、RIG-I、NLRP3 等模式识别受体发挥固有佐剂效应，但同时会引起注射部位炎症、淋巴结肿大及罕见心肌炎（Boraschi et al., 2022）。修饰核苷（如 $\text{m}^{1}\Psi$、$\text{m}^{5}\text{C}$）替换 + 严格的 dsRNA 去除（HPLC 或纤维素纯化）可降低固有免疫激活，提升翻译效率（Karikó et al., 2005；Andries et al., 2015）。新一代 saRNA（自扩增 RNA）与 circRNA（环状 RNA）以更低剂量延长表达，是下一代平台方向（Chen et al., 2022）。

**新冠 mRNA 疫苗效果**：BNT162b2 与 mRNA-1273 在 III 期临床显示 > 94% 症状性 COVID-19 保护效力（Polack et al., 2020；Baden et al., 2021）。中和抗体滴度与 Tfh/生发中心反应强度强相关（Goel et al., 2021）。该平台也为流感、HIV、肿瘤新抗原（如 Moderna mRNA-4157 个体化新抗原疫苗）的快速开发提供了通用框架。

### 10.3 免疫检查点抑制剂的耐药机制

PD-1（程序性死亡受体 1）与 CTLA-4（细胞毒性 T 淋巴细胞相关蛋白 4）是 T 细胞活化的关键负调控共受体。Ipilimumab（抗 CTLA-4，2011）与 nivolumab/pembrolizumab（抗 PD-1，2014）开创了肿瘤免疫治疗新纪元（Topalian et al., 2012；Sharma & Allison, 2015）。然而总体响应率仅 20–40%，耐药机制复杂。

**原发性耐药（肿瘤固有）**：

1. **IFN-γ 通路失活**：JAK1/JAK2 失活突变 → 肿瘤对 IFN-γ 不敏感 → MHC I 表达降低（Zaretsky et al., 2016）
2. **抗原呈递缺陷**：B2M 截断突变 → MHC I 完全缺失（Sucker et al., 2017）
3. **低肿瘤突变负荷（TMB）**：新抗原池小 → T 细胞识别不足
4. **"冷肿瘤"表型**：T 细胞排除（excluded phenotype）由 FAP+ CAF 与 CXCL12 等机制介导

**获得性耐药（治疗压力下演化）**：

1. **抗原逃逸**：靶抗原（如 Melan-A、NY-ESO-1）表达丢失
2. **T 细胞耗竭再编程**：TOX、NR4A、表观遗传锁定（Philip et al., 2017；Kagoya et al., 2020）
3. **替代免疫检查点上调**：TIM-3、LAG-3、TIGIT、VISTA 代偿性升高（Koyama et al., 2016）
4. **肿瘤微环境重塑**：Treg、MDSC、TAM M2 极化增加
5. **表型转换**：上皮–间质转化（EMT）与神经内分泌分化

**联合策略**：双检查点阻断（CTLA-4 + PD-1）增加响应率但毒性增加；免疫 + 靶向（BRAF/MEK 抑制剂联合抗 PD-1）；免疫 + 化疗/放疗（诱导免疫原性细胞死亡 ICD）；双特异性抗体（如 teclistamab BCMA×CD3）。

### 10.4 单细胞多组学在免疫学中的应用

单细胞 RNA 测序（scRNA-seq）与多组学技术彻底改写了免疫学图谱（Papalexi & Satija, 2018；Hao et al., 2021）。

**主要技术**：

- **scRNA-seq**（10x Genomics, Smart-seq3）：转录组分辨细胞亚群
- **单细胞 ATAC-seq**（10x Multiome, SHARE-seq）：染色质开放性 → 调控元件与 TF 活性
- **CITE-seq**（寡核苷酸标签抗体）：同步表面蛋白 + 转录组
- **TCR/BCR + 转录组配对**（10x V(D)J）：克隆型与表型关联
- **空间转录组**（Visium, MERFISH, Stereo-seq）：保留空间信息 → TME 细胞邻域分析
- **Perturb-seq**：CRISPR 扰动 + scRNA-seq → 因果性调控网络（Replogle et al., 2022）

**免疫学贡献**：

1. **免疫细胞图谱**：人类细胞图谱（HCA）、肿瘤单细胞图谱（如 TISCH 数据库）揭示数百种细胞状态
2. **T 细胞耗竭异质性**：鉴定 progenitor exhausted（TCF1+）vs terminally exhausted（TIM-3+ TOX+），前者是免疫治疗响应的关键来源（Sade-Feldman et al., 2018；Miller et al., 2019）
3. **COVID-19 免疫病理**：揭示重症患者 I 型 IFN 缺陷 + 炎症单核细胞扩增 + T 细胞淋巴减少（Mann et al., 2020；Schulte-Schrepping et al., 2020）
4. **疫苗免疫动力学**：追踪淋巴结生发中心反应、Tfh 与记忆 B 细胞发育（Goel et al., 2021）
5. **空间邻域分析**：肿瘤"免疫–基质邻接"预测免疫治疗响应

**分析框架**：Seurat/Scanpy 标准流程——归一化 → PCA → 邻域图 → UMAP/t-SNE → Leiden 聚类 → marker 基因注释 → RNA velocity（scVelo）推断拟时间 → 轨迹推断 → 细胞–细胞通讯（CellChat, NicheNet）。

## 第十一章 批判性讨论

### 11.1 "自我–非我"范式 vs "危险模型"之争

**自我–非我范式（SNS）**：由 Burnet（1959）与 Medawar 提出：免疫系统通过"区分自身与非自身"维持耐受。自身抗原在发育期建立耐受，外来抗原触发应答。该范式主导了 20 世纪下半叶免疫学，是克隆选择学说的基础。

**危险模型（Danger Model）**：Matzinger（1994, 2002）提出：免疫系统并不区分"自我–非我"，而区分"危险"与"安全"。触发免疫应答的不是抗原的"外源性"，而是组织细胞释放的损伤相关分子模式（DAMP，如 HMGB1、ATP、尿酸、HSP）。该模型解释了：为何自身组织损伤（手术、缺血）会触发炎症；为何同种异体移植排斥（即便完全外来的抗原无感染）也涉及"危险信号"；为何肿瘤（"安静"生长）通常不引发强烈免疫应答；为何共生菌（"非我"）能在肠道被容忍。

**整合与张力**：后续发展出"杂合模型"——先天免疫识别 PAMP/DAMP 提供信号 0，适应性免疫提供信号 1/2（Matzinger, 2007；Pradeu & Cooper, 2012）。然而 Matzinger 的核心批判仍值得思考：将"自我"作为免疫学原语在概念上模糊——例如肿瘤是"自我"却被攻击，共生菌是"非我"却被容忍，胎盘（半异体）不被排斥。

**临床启示**：疫苗佐剂的设计（佐剂本质是"DAMP/PAMP 模拟物"，启动信号 0）；自身免疫病（理解危险信号如何驱动自身抗原呈递，如 SLE 的 NET–DNA–抗 DNA 复合物）；肿瘤免疫（"免疫原性细胞死亡" ICD 通过释放 DAMP 增强抗肿瘤应答）。

### 11.2 无菌性炎症与自身免疫的边界

**无菌性炎症（sterile inflammation）**：指无微生物感染参与的炎症反应，由组织损伤、应激、代谢紊乱触发。DAMP 包括：细胞内分子（HMGB1、S100 蛋白、组蛋白、尿酸、ATP）；细胞外基质降解产物（透明质酸片段、biglycan）；核酸（mtDNA 含未甲基化 CpG、DNA–抗体复合物）。DAMP 通过 TLR2/4、NLRP3 炎症小体、RAGE、cGAS–STING 通路激活先天免疫（Chen & Nunez, 2010；Gong et al., 2020）。

**与自身免疫的连续谱**：

- **痛风**：尿酸结晶激活 NLRP3 → IL-1β → 急性关节炎（典型无菌性炎症，可逆）
- **动脉粥样硬化**：oxLDL + DAMP → 慢性血管炎症
- **SLE**：凋亡细胞清除缺陷 → 核酸–抗体复合物持续刺激 pDC → IFN-α 风暴 → 自我增强反馈 → 不可逆自身免疫

**边界的概念问题**：无菌性炎症可视为"急性损伤的生理修复应答"，但当 DAMP 持续暴露（凋亡清除缺陷、慢性组织损伤、代谢失衡）则会打破耐受、激活自身反应性淋巴细胞，演变为自身免疫病（Theofilopoulos et al., 2011）。该连续谱挑战了"健康 vs 疾病"的二分法，提示：早期干预"损伤–炎症"循环可能预防自身免疫；抗炎（如 IL-1β 拮抗 anakinra、IL-6 拮抗 tocilizumab）在多种自身炎症病中有效，但在经典自身免疫病中疗效有限；自身炎症（autoinflammatory，固有免疫驱动）与自身免疫（autoimmune，适应性免疫驱动）的二元分类在临床与机制上常常重叠。

### 11.3 免疫疗法成本与可及性悖论

**成本结构**：CAR-T（axicabtagene ciloleucel、tisagenlecleucel）单疗程 $373,000–$475,000，加住院与并发症管理总成本可达 $1M（Bach et al., 2017；Hanna et al., 2019）；免疫检查点抑制剂年度费用 $100,000–$250,000（美国）；自体 CAR-T 制备周期 2–3 周，对快速进展患者致命；制造复杂、严格冷链、个体化 → 难以规模化。

**可及性鸿沟**：全球 80% 癌症患者在中低收入国家（LMIC），CAR-T 几乎不可及；即便在高收入国家，医疗不平等使少数族裔、农村人口、未保险人群获益有限；异体 UCAR、体内 CAR、自动化封闭系统（如 Miltenyi CliniMACS Prodigy）是降低成本的方向；印度、中国本土化 CAR-T（如 CT103A）尝试以 $30,000–$50,000 价格提供治疗。

**卫生经济学与伦理**：CAR-T 在 B-ALL 儿科中治愈率约 80%，单次治疗长期获益成本–效果优于终身化疗；但肿瘤免疫治疗在末线适应症中位 OS 改善仅数月，成本–效果比（ICER）常超 $150,000/QALY，超过传统支付意愿阈值。"价值导向定价"与"按疗效付费"是新支付模式探索。公平性考量：资源向高成本罕见疗法倾斜 vs 基础疫苗/感染病控制的全球健康优先级。

**反思**：免疫学的基础研究投入（NIH、EU、中国自然科学基金）转化为个体化疗法后，受益者往往是少数能负担的患者。如何使免疫学突破真正普惠，不仅是经济与政策问题，也涉及科研方向（如优先开发低成本、可规模化平台）与全球健康治理。

## 总结

免疫系统是人体最复杂、最精密的防御网络，它持续保护我们免受病原体和肿瘤的侵害。它的核心特征可以概括为：

| 特征 | 说明 |
|------|------|
| **识别自我与非我** | 区分自身组织和外来入侵者 |
| **先天与适应性协同** | 两层防御相互配合 |
| **免疫记忆** | 疫苗接种的基础，使长期保护成为可能 |
| **精准调控** | 避免过度应答（过敏）或应答不足（免疫缺陷） |
| **可塑性** | 免疫系统可根据环境变化调整应答策略 |

> 正如诺贝尔奖得主彼得·梅达沃（Peter Medawar）所说："**免疫系统是我们了解自我的器官，是赋予我们个体身份的关键。**"
