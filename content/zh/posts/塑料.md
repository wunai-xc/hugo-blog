## 引言

塑料（Plastic）是一类以合成树脂（高分子聚合物）为基本成分，并在加工过程中可流动成型的一类材料[reference:0][reference:1]。其主要成分是碳、氢、氧，部分品种还含有氮、氯、硫等元素[reference:2][reference:3]。塑料的出现彻底改变了现代人类的生活方式，从日常包装到航空航天，从电子电器到医疗器械，塑料无处不在。

美国塑料工业协会于1988年制定了塑料分类编码体系，将常见塑料分为七大类[reference:4][reference:5]。随着材料科学的发展，塑料家族已远不止这七种，形成了包括通用塑料、工程塑料、特种工程塑料在内的庞大体系。

本文从化学结构出发，系统梳理各类塑料的化学名称、英文缩写、化学式与结构简式，为材料科学的学习与研究提供参考。

## 第一章 塑料概述

### 1.1 塑料的定义

塑料是一种高分子聚合物，由合成树脂及加工助剂（如增塑剂、稳定剂、色料等）组成[reference:6]。塑料的主要成分是合成树脂，其分子结构为长链状或网状的高分子化合物[reference:7]。

### 1.2 塑料的分类

**按受热特性分类**[reference:8]：
- **热塑性塑料**：受热软化、冷却硬化，可反复加工。如聚乙烯、聚氯乙烯、聚丙烯等[reference:9]。
- **热固性塑料**：受热固化后形成体型网状结构，不能再熔融加工[reference:10]。如酚醛塑料、脲醛塑料等[reference:11]。

**按用途和性能分类**[reference:12][reference:13]：
- **通用塑料**：产量大、用途广、价格便宜。五大通用塑料为聚乙烯（PE）、聚丙烯（PP）、聚氯乙烯（PVC）、聚苯乙烯（PS）及丙烯腈-丁二烯-苯乙烯共聚物（ABS）[reference:14]。
- **工程塑料**：力学性能优良，可替代金属作为结构材料。如聚酰胺（PA）、聚碳酸酯（PC）、聚甲醛（POM）、聚苯醚（PPO）等[reference:15]。
- **特种工程塑料**：耐高温、高性能。如聚砜（PSU）、聚酰亚胺（PI）、聚苯硫醚（PPS）、聚醚醚酮（PEEK）等[reference:16]。

### 1.3 塑料的化学本质

塑料是由小分子单体通过**聚合反应**生成的高分子化合物[reference:17]。其分子结构可用结构简式表示为：`-[单体单元]-n`，其中 n 为聚合度[reference:18]。塑料没有唯一的化学式，而是以重复单元和聚合度共同描述[reference:19]。

## 第二章 通用塑料

### 2.1 聚乙烯（PE）

| 项目 | 内容 |
|------|------|
| **英文名称** | Polyethylene |
| **化学式** | (C₂H₄)ₙ |
| **结构简式** | -[-CH₂-CH₂-]ₙ- |
| **单体** | 乙烯（CH₂=CH₂） |
| **主要特性** | 电绝缘性好、耐化学腐蚀、耐寒、无毒，但耐热性差 |
| **典型用途** | 塑料袋、保鲜膜、容器、管材[reference:20] |

聚乙烯根据密度和支链结构可分为低密度聚乙烯（LDPE）和高密度聚乙烯（HDPE）[reference:21][reference:22]。

### 2.2 聚丙烯（PP）

| 项目 | 内容 |
|------|------|
| **英文名称** | Polypropylene |
| **化学式** | (C₃H₆)ₙ |
| **结构简式** | -[-CH₂-CH(CH₃)-]ₙ- |
| **单体** | 丙烯（CH₂=CH-CH₃） |
| **主要特性** | 机械强度高、电绝缘性好、耐化学腐蚀，熔点在167°C左右[reference:23] |
| **典型用途** | 免洗餐具、容器、汽车零部件[reference:24] |

### 2.3 聚氯乙烯（PVC）

| 项目 | 内容 |
|------|------|
| **英文名称** | Polyvinyl Chloride |
| **化学式** | (C₂H₃Cl)ₙ |
| **结构简式** | -[-CH₂-CHCl-]ₙ- |
| **单体** | 氯乙烯（CH₂=CHCl） |
| **主要特性** | 耐有机溶剂、耐化学腐蚀、耐磨、抗水性好，但热稳定性差[reference:25] |
| **典型用途** | PVC管、电线电缆绝缘层、门窗型材[reference:26] |

PVC是七大塑料中唯一必须使用增塑剂的材料，其状态可从软而弹到硬而脆之间变化[reference:27]。

### 2.4 聚苯乙烯（PS）

| 项目 | 内容 |
|------|------|
| **英文名称** | Polystyrene |
| **化学式** | (C₈H₈)ₙ |
| **结构简式** | -[-CH₂-CH(C₆H₅)-]ₙ- |
| **单体** | 苯乙烯（C₆H₅-CH=CH₂） |
| **主要特性** | 透明、易加工、电绝缘性好 |
| **典型用途** | 发泡胶（保丽龙）、一次性餐具、包装材料[reference:28] |

### 2.5 丙烯腈-丁二烯-苯乙烯共聚物（ABS）

| 项目 | 内容 |
|------|------|
| **英文名称** | Acrylonitrile Butadiene Styrene |
| **化学式** | (C₈H₈·C₄H₆·C₃H₃N)ₓ[reference:29] |
| **结构简式** | 三元共聚物，含苯乙烯、丁二烯、丙烯腈三种单体单元 |
| **单体** | 苯乙烯（C₆H₅-CH=CH₂）、1,3-丁二烯（CH₂=CH-CH=CH₂）、丙烯腈（CH₂=CH-CN）[reference:30] |
| **主要特性** | 强度高、韧性强、易加工成型[reference:31] |
| **典型用途** | 汽车零部件、家电外壳、电子产品[reference:32] |

ABS是丙烯腈（A）、丁二烯（B）、苯乙烯（S）的三元共聚物，三种单体的比例可在一定范围内变化[reference:33]。常见的比例约为A:B:S = 22:17:61[reference:34]。

## 第三章 工程塑料

### 3.1 聚酰胺（PA / 尼龙）

| 项目 | 内容 |
|------|------|
| **英文名称** | Polyamide / Nylon |
| **通式** | -[NH-(CH₂)ₘ-NHCO-(CH₂)ₙ₋₂-CO]- 或 -[NH-(CH₂)ₓ-CO]- |
| **结构特征** | 分子主链含有重复酰胺基团 -[NHCO]-[reference:35] |
| **主要特性** | 结晶性热塑性塑料，力学性能优良，自润滑性好[reference:36] |
| **典型用途** | 齿轮、轴承、纤维、工程结构件 |

**常见品种**：

| 品种 | 结构简式 | 熔点 |
|------|---------|------|
| PA6 | -[-NH-(CH₂)₅-CO-]ₙ-[reference:37] | 220-230°C[reference:38] |
| PA66 | -[-NH-(CH₂)₆-NHCO-(CH₂)₄-CO-]ₙ-[reference:39] | 260-270°C[reference:40] |

### 3.2 聚碳酸酯（PC）

| 项目 | 内容 |
|------|------|
| **英文名称** | Polycarbonate |
| **化学式** | (C₁₆H₁₄O₃)ₙ[reference:41] |
| **结构特征** | 分子主链含有碳酸酯基团（-O-CO-O-）[reference:42] |
| **主要特性** | 高透明性、高冲击强度、耐热性好 |
| **典型用途** | 奶瓶、水壶、眼镜片、电子电器外壳[reference:43] |

### 3.3 聚甲醛（POM）

| 项目 | 内容 |
|------|------|
| **英文名称** | Polyoxymethylene |
| **化学式** | (CH₂O)ₙ[reference:44] |
| **结构简式** | -[-CH₂-O-]ₙ-[reference:45] |
| **主要特性** | 结晶性热塑性塑料，硬度高、耐磨性好，被誉为“超钢”或“赛钢”[reference:46] |
| **典型用途** | 精密齿轮、轴承、机械零部件 |

### 3.4 聚对苯二甲酸乙二醇酯（PET）

| 项目 | 内容 |
|------|------|
| **英文名称** | Polyethylene Terephthalate |
| **化学式** | (C₁₀H₈O₄)ₙ[reference:47][reference:48] |
| **结构简式** | -[-CO-C₆H₄-CO-O-CH₂-CH₂-O-]ₙ-[reference:49] |
| **主要特性** | 透明、强度高、韧性好[reference:50] |
| **典型用途** | 饮料瓶、食用油瓶、聚酯纤维、胶带[reference:51] |

PET是七大塑料分类标志中的1号塑料[reference:52]。

### 3.5 聚对苯二甲酸丁二醇酯（PBT）

| 项目 | 内容 |
|------|------|
| **英文名称** | Polybutylene Terephthalate |
| **结构特征** | 与PET类似，但二醇部分为丁二醇 |
| **主要特性** | 结晶速度快、流动性好、电绝缘性优良 |
| **典型用途** | 电子电器零部件、汽车零部件 |

### 3.6 聚苯醚（PPO / m-PPE）

| 项目 | 内容 |
|------|------|
| **英文名称** | Polyphenylene Oxide / Modified PPE |
| **结构特征** | 主链含苯环和醚键的芳香族聚合物[reference:53] |
| **主要特性** | 耐热性好、尺寸稳定、电绝缘性优良 |
| **典型用途** | 电子电器、汽车仪表盘、水泵壳体 |

## 第四章 特种工程塑料

### 4.1 聚四氟乙烯（PTFE）

| 项目 | 内容 |
|------|------|
| **英文名称** | Polytetrafluoroethylene |
| **化学式** | (C₂F₄)ₙ |
| **结构简式** | -[-CF₂-CF₂-]ₙ-[reference:54] |
| **单体** | 四氟乙烯（CF₂=CF₂） |
| **主要特性** | 耐高温、耐化学腐蚀、摩擦系数极低（不粘性） |
| **典型用途** | 不粘锅涂层、密封件、电线绝缘 |

### 4.2 聚甲基丙烯酸甲酯（PMMA）

| 项目 | 内容 |
|------|------|
| **英文名称** | Polymethyl Methacrylate |
| **化学式** | (C₅O₂H₈)ₙ[reference:55][reference:56] |
| **结构简式** | -[-CH₂-C(CH₃)(COOCH₃)-]ₙ-[reference:57] |
| **单体** | 甲基丙烯酸甲酯（MMA）[reference:58] |
| **主要特性** | 高度透明、易加工，俗称亚克力或有机玻璃[reference:59] |
| **典型用途** | 透明板材、显示器导光板、眼镜片、工艺品 |

### 4.3 聚醚醚酮（PEEK）

| 项目 | 内容 |
|------|------|
| **英文名称** | Polyether Ether Ketone |
| **结构特征** | 主链含醚键和酮键的芳香族聚合物[reference:60] |
| **主要特性** | 耐高温、耐化学腐蚀、机械强度极高 |
| **典型用途** | 航空航天、医疗器械、汽车零部件 |

### 4.4 聚砜（PSU / PES）

| 项目 | 内容 |
|------|------|
| **英文名称** | Polysulfone / Polyethersulfone |
| **结构特征** | 主链含砜基（-SO₂-）的芳香族聚合物[reference:61] |
| **主要特性** | 耐热性好、尺寸稳定、耐水解 |
| **典型用途** | 医疗器械、食品接触材料、电子电器 |

## 第五章 热固性塑料

### 5.1 酚醛塑料（PF）

| 项目 | 内容 |
|------|------|
| **英文名称** | Phenol-Formaldehyde Resin |
| **结构特征** | 苯酚与甲醛缩聚形成的体型网状结构 |
| **主要特性** | 耐热、绝缘、尺寸稳定 |
| **典型用途** | 电器开关、插座、锅柄 |

### 5.2 脲醛塑料（UF）

| 项目 | 内容 |
|------|------|
| **英文名称** | Urea-Formaldehyde Resin |
| **结构特征** | 尿素与甲醛缩聚而成[reference:62] |
| **主要特性** | 无色透明、硬度高、耐热性好 |
| **典型用途** | 电器外壳、纽扣、餐具 |

### 5.3 环氧树脂（EP）

| 项目 | 内容 |
|------|------|
| **英文名称** | Epoxy Resin |
| **结构特征** | 含环氧基团的热固性树脂 |
| **主要特性** | 粘接性强、耐化学腐蚀、电绝缘性好 |
| **典型用途** | 粘合剂、涂料、电子封装材料 |
